# 维度-咒械原

开发分支的腐化女王现使用核心控制的三阶段战斗：每条生命 400、Logos 魔抗 75%，六种女王攻击与两种核心攻击，挣扎时斩断血管；每阶段结束有完整过渡，最终女王与核心共殒，镜头升空并大范围恢复森林。新增猩红枝藤血条。原有四格华服模型、墨绿权杖、首次入场和逐片拆核心净化保留。机制与复现见 [腐化女王核心战](docs/QUEEN_CORE_BATTLE.md)，群系定位和美术见 [腐败精灵森林](docs/BLIGHTED_ELVEN_FOREST.md)。

**Logos: Spellwrought Expanse**，Logos 的独立维度附属 Mod，Mod ID：`logos_dimension`。当前开发版本 **0.11.0**，已公开正式安装包为 **0.10.0**。目标为 Minecraft **26.1.2**、NeoForge **26.1.2.112**、Java **25**，开发版需要 Logos **0.7.0** 或更新版本。

**安装包：[下载 logos_dimension-0.10.0.jar](https://github.com/wushuowei1145/Logos-Spellwrought-Expanse/releases/download/v0.10.0/logos_dimension-0.10.0.jar)** · [正式发布页与校验文件](https://github.com/wushuowei1145/Logos-Spellwrought-Expanse/releases/tag/v0.10.0)。联机时服务端和客户端都需安装同版附属；停服替换旧版后重新启动。Code → Download ZIP 和发布页的 Source code 是源码，需要构建后才能安装。

下载源码时请核对所选分支和 `gradle.properties` 中的 `mod_version`。GitHub 的 **Code → Download ZIP** 导出当前分支，不会自动包含其他分支上已合并的 PR；PR 只有合并到 `main` 后才会进入首页默认下载。源码 ZIP 需要构建，已打包 JAR 的版本以其 `META-INF/neoforge.mods.toml` 为准。

## 龙族少女骑士 拉塞塔

第四位同伴，嘴硬心软的真龙骑士。还没和她立契时，在高山（尖峭山峰、雪坡、裸岩山峰、冰封山峰、云岫峰林，或海拔 120 以上）的露天营火上烤点生的，她每天有三成可能循着香味从天上落下来：喂她最爱吃的（熟牛排、熟猪排、南瓜派、蛋糕）她就单膝立誓、递给你一片烙着你名字的龙鳞；给别的她不吃，一分钟喂不到就赌气飞走。也可以直接用空白的誓约逆鳞（创造模式「远行大陆 · 道具」页，或山地远行小遗迹的宝箱）：右键用它就立契，她从天上落下来；之后右键叫她出来或回鳞里，潜行右键让她留下或跟上；潜行右键她说话、看详细数据。她拿自己的炽焰长剑站前排，按处境换着出四式连招、突刺、旋风斩、红莲劫焰斩、坠星、十文字，挡下近战就弹反、接破军龙牙；开战一声龙吟把 12 格内的敌人引到自己身上，够不着的从左掌心抛龙炎弹。她继承你的生命、攻击、护甲、韧性和保护魔咒，鳞之契越多继承越多（四枚一倍、九枚两倍，之后还涨），护甲和魔咒超出原版上限的部分折成额外减伤。她不会死：撑不住就向你行最后一道骑士礼，化作火星回到鳞里龙眠 5 分钟。你睡觉时她按羁绊在床边守夜、打盹、小憩，信赖以后躺在你身边。你飞起来她就展翅跟在你左后上方，天上和高台上够不着的敌人她飞上去砸一记坠星；你从高处掉下来，她飞过来拉住你的手（信赖以后抱住你）带你慢慢降落，落地至少留半颗心。遇上首领、强敌或被围住时她化回太古巨龙（生命、护甲、韧性翻倍，挨打只受四分之一），挥爪横扫、张口喷一道龙炎，打完变回来；你也可以在对话里让她变，这时收回再叫出来还是巨龙，落地一吼把附近的敌人都引过去。巨龙靠你的魔力维持（每秒 50 起，鳞之契越多越省），魔力不够就变回人形。巨龙形态空手右键骑上去：W 顺着视线飞、空格往上抬、S 刹住，左键挥爪、按住右键喷龙炎，在半空下龙这一摔只受两成。在家闲着时她认下身边的一块钻石块、金块或下界合金块坐上去守着；你举着吃的、营火烧着时她凑过来，对话里能让她用龙息把包袱里的生肉烤熟；你饿了她塞给你吃的；雪地里她裹着翅膀贴着你走；捡到亮晶晶的喊「我的！」；你当着她的面摸别的同伴会吃醋。她守着你睡过一整夜，醒来你有 5 分钟的「绯翼余温」（抗火、不怕冻、近战更强）。巨龙形态从头前右键是撸龙头，她会盘成一圈把你的床圈在怀里。每烙一枚鳞之契解锁一项本事：一印替你挡下身边挨的三成伤害，二印格挡弹反，三印被围时双翼掀开敌人，四印坠星，五印接住坠落的你（歇 5 分钟），六印人形也能喷两秒龙息，七印致命一击后每天一次重新站起来，八印你生命跌破三成时她逆鳞暴怒，九印化身巨龙。管理员可以用 `/alchemy companion lacerta …` 试，见 [拉塞塔](docs/LACERTA_COMPANION.md) 第 17–21 节。

## 双手长剑试玩

新增圣剑「曦誓」与使用原版附魔台粒子符文的「黑钢长剑」，在创造模式「远行大陆 · 武器」页获取。共用拔剑、双手侧持、三段连招、竖剑蓄力、松开举剑下劈与收剑动作，第一人称待机靠右；曦誓不挂剑鞘：拔剑时双臂前伸，光点聚拢成横在掌上的剑，握住转两圈剑花后双手持剑；收剑时把剑插进地面，随后散成光点。本附属的近战武器按准星前方的锥形判定命中（默认 60°，每把武器可在注册时另给），准星正对的目标暴击。暂用钻石剑的基础属性，左键可按住连招，右键保持蓄力；完整获取命令、安装与动作说明见 [双手长剑试玩](docs/LONGSWORDS.md)。

曦誓也可以在远行大陆的山里找到：隐蔽山洞中央的石座里插着它，石座发光、有一道淡淡的斜光照在剑上，插着剑时不可破坏。只有破晓时按住右键才拔得出来，手持曦誓右键空石座可以把剑插回去，见 [石中剑：曦誓之洞](docs/DAWNVOW_STONE.md)。

曦誓的蓄力斩会带出一道贴地剑气。按住右键超过 7 秒进入大型蓄力：站定，四周升起金色光点；12 秒剑身发出长长的金光，15 秒蓄满喷出金色流火，共需 1000 魔力。大型蓄力时周围暗下去、身边亮起来。蓄满后劈下放出 64 格的巨型金色剑气，贴着地面劈开软方块，尽头扎进地面蓄成一团光，一阵几何黑白闪后接金色光柱、镜头一震；之后 60 秒剑身金光不散，攻击更远、每击多 15 点，见 [曦誓的蓄力彩蛋](docs/DAWNVOW_CHARGE.md)。

## 爆裂魔杖

致敬《为美好的世界献上祝福》惠惠的爆裂魔法，在创造模式「远行大陆 · 武器」页获取。主手按住右键吟唱 20 秒、注入 6400 魔力：条带从几十格外汇向杖头的红宝珠，准星所指之处的上空一个接一个出现红色法阵，周围渐渐暗下去。蓄满后松手，火柱从法阵贯穿到目的地，红热、白热、转蓝、十字闪光、黑白闪之后，白热的球体扩成半径 64 格的爆炸，范围内的一切被消灭，留下一直深到基岩的坑（服务端配置可关）。见 [爆裂魔法](docs/EXPLOSION_MAGIC.md)。

## 九尾妖狐 白梅

约三分之一的神狐聚落底下有一处封印之间，拆掉九根封印杭会唤醒附属的第一个 Boss「九尾妖狐 白梅」：杀生石炸开进入过场，她跪坐、起身，手里凝出流火，打出标题后开打。第一阶段人形拿流火拼刀，出招前双眼红光，盾能挡、能弹反，弹反和受伤累积失衡；每掉六分之一血一次投技，被挑飞的人进处决特写。第一条血清空后拍地化成九尾狐，第二阶段冲撞、大跳、尾扫，不能弹反，八分之一血以下尾尖放狐火飞弹。击倒后她化作花瓣，每个参战的人得一把流火。管理员可以用 `/alchemy shiraume awaken|spawn|beast|phase2|reset` 试，详见 [九尾妖狐 白梅](docs/SHIRAUME_BOSS.md)。

狐火是神狐一族的伤害：本质是 Logos 的奥秘伤害，只是伤害类型、颜色和命中特效不同，打中后狐火缠身、怪物可能被惑，神狐和白梅基本不怕。神狐的狐火是幽蓝的，白梅和流火的是淡粉的；神狐的狐火缠绕、流火、白梅的飞弹都是狐火。术式里的 `foxfire` 在编纂台里看不到，只能用 `/alchemy foxfire` 等调试命令拿到，详见 [狐火](docs/FOXFIRE.md)。

龙炎是龙族的火：也是奥秘伤害的子类型，但没有原版火的弱点（不怕火的生物、抗火、火焰保护、护甲都挡不住，水浇不灭），也不吃女巫的魔法减免，Logos 的奥秘抗性照算。打中会烧掉魔力，缠身的火每打一下往上叠、很难灭；龙族只受四分之一。术式里的 `dragonfire` 要学会龙炎之言才写得上，现在只能用 `/alchemy dragonfire` 等调试命令拿到或教会，详见 [龙炎](docs/DRAGONFIRE.md)。

## 原版数据包生成

新增远行大陆群系「太玄灵境」：地面太玄城以约 236 格城墙、四门、坊市与 46 处徽式民居院落形成规模，城心有鼓楼，主街立石牌坊、沿街开水圳，加入代码绘制的花格窗与云纹砖雕；上方七座浮峰以石桥连接宫阙与藏经塔，崖边有老松、竹丛、垂藤和临水庭园。继续使用 Python 局部模块与原版 NBT/jigsaw，没有新增 Java 地形生成器。远行大陆森林群系的树改按原版的 `OCEAN_FLOOR` 高度图落点，并且不在建筑和原版草方块上扎根，自然生成时城里和浮峰上不再长出外来的树。定位指令、模块入口与一条命令完成的测试流程见 [太玄灵境](docs/TAIXUAN.md)。

两个维度都使用原版 `minecraft:noise` 地形、`minecraft:multi_noise` 群系选择、原版树木与植物 Feature、标准 NBT/jigsaw 结构。删除手写 Java 地形、种树与建筑填块生成器。数据随 Mod 内置，正常安装不需要额外下载数据包，存档数据包可以覆盖同名资源。见 [生成数据与迁移](docs/NATIVE_WORLDGEN.md)。

- **咒械原**：每口炼金釜首次进入创建一个 `logos_dimension:<UUID>` 世界，20,000×20,000 格边界，以太为主要环境，硫、汞、盐为大尺度自然群系。
- **远行大陆**：保留 `logos_dimension:cloudsea` ID，33 个地表群系和独立地下群系。湿润气候形成连续密林，林隙与花甸独立成群系；林下有蕨、苔毯、落叶、灌木和季节植物。正常天空、昼夜与天气，四季各 8 个游戏日。
- **无原版矿物**：关闭原版矿脉，移除矿物装饰 Feature，保留原版洞穴、含水层与废弃矿井。炼金硫沉积是本附属自有方块，不引用 26.1 原版硫磺。
- **稀疏中世纪聚落**：使用原版 jigsaw/random_spread，可用 `/locate structure logos_dimension:journey_hamlet` 或 `journey_town` 寻找。新聚落依据 [用户提供的蓝图](references/user_blueprints/README.md) 改造；历史旧模板来源保留在 [第三方说明](third_party/millenaire/SOURCE.md)。

原版生成重设计了布局：不再保证硫→汞→盐的精确同心顺序，也不固定雪山/海岸坐标。中心空岛现为约 **126 格直径、顶面 Y=320** 的原版 NBT 预留平台，原 2,400 格手写岛与玻璃巨构不再生成。岛面不放建筑或植被，拦截自然及刷怪笼生成，宫殿和 Boss 尚未制作。

## 安装与进出

将本附属与 Logos 及其依赖、[星辰花乐团（Starbloom Orchestra）](https://github.com/MagicFoxDemon/StarbloomOrchestra)一起放入 `mods`，本包不内嵌主模组或第三方 JAR。

乐器（钢琴、竖琴、管风琴、弦乐、木管铜管、打击乐、打孔纸带、MIDI、乐团与指挥）从 0.12.0 起拆成独立的模组星辰花乐团，附属依赖它，附属里的精灵、神狐、灵猫可以坐上它的琴凳、站上它的工位演奏。老存档里的乐器读档时自动换成星辰花乐团的，放下的乐器、手里的纸带和指挥棒都在；乐器的客户端设置（MIDI 键盘、音量上限）要在 `starbloom_orchestra-client.toml` 里重新设一次，录音的「音乐厅音源」资源包换成星辰花乐团发布的那个。见 [乐器](docs/INSTRUMENTS.md)。

8 块玻璃围住 `logos:tainted_mana_shard` 合成炼金漩涡，再与原版炼药锅合成炼金釜。**跳入釜内液面**进入独立世界，默认寻找外围以太区安全地面；首次到达在旁边自动生成回程漩涡，右键返回原釜旁，重入复用出口。

已绑定釜的物品名称显示 UUID，悬浮提示和对放置的釜右键显示完整维度名。挖掘、拾取、再放置保留绑定；真正损毁釜或其掉落物才撤离玩家并销毁对应 UUID 世界。见 [炼金釜与回程](docs/CAULDRON_WORLDS.md)。

**取消旧固定 `logos_dimension:crucible` 的注册与入口**，不能再用 `/execute in` 进入空模板。升级存档若仍加载它，启动时撤离玩家、保存并卸载；保留旧目录，避免删除旧建筑。UUID 实例继续使用。

管理员命令：

```text
/alchemy enter
/alchemy return
/alchemy island 0 0
/alchemy region aether|sulfur|mercury|salt
/alchemy phase nigredo|albedo|citrinitas|rubedo
/alchemy boss defeated
/alchemy boss reset
```

`enter` 需要附近有实体炼金釜，不再打开公共模板。`region` 查找原版群系中的安全位置，有限边界和特定种子内可能找不到目标。远行大陆的生存入口是[远行之门](docs/JOURNEY_GATE.md)：主世界自然生成的大号门，给门洞下方的启门石灌满 1000 魔力就会开门；另一侧没有门时当场生成一扇点亮的小号门。管理员也可以先切创造模式，再用：

```text
/execute in logos_dimension:cloudsea run tp @s 0 250 0
```

岛下影雾保留，每个 UUID 世界独立记录 Boss 状态。搜索接口 `LOGOS_DIMENSION_ISLAND_BOSS_HOOK`，当前标签为空。动态玻璃法阵和流体行为沿用上一版。

## 升级和检查

旧区块保留，新区块使用原版生成，边缘可能出现接缝。旧生成器 ID 仅负责存档解码迁移，解码结果直接是原版生成器。推荐新存档或新炼金釜体验完整布局。

20,000 格限制由原版世界边界实现；管理员越界命令仍可能生成边界外区块，不承诺边界外为空。区块按需生成，不预生成整张地图。

```text
./gradlew test runGameTestServer build -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/starbloom_orchestra.jar
./gradlew runClient -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/starbloom_orchestra.jar -PldTest=group:journey -PldTestHeadless -PldTestWindow=1280x720
./gradlew runClient -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/starbloom_orchestra.jar -PldTest=group:cauldron_instances -PldTestHeadless -PldTestWindow=1280x720
```

验证结果见 [VERIFICATION.md](VERIFICATION.md)，生态方向见 [远行大陆](docs/TEMPERATE_JOURNEY.md)。`tools/native_worldgen.py` 输出的 JSON/NBT/PNG 已提交，普通构建不需要运行资源脚本。
