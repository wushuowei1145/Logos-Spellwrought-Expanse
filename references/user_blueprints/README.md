# 用户提供的建筑蓝图

本目录保存 2026-10-19 用户从桌面“小屋”文件夹提供的七份 NBT/Litematic 蓝图的归一化方块几何，用于其明确要求的中世纪村镇改造。`manifest.json` 记录原文件名、SHA-256 和原作者元数据；没有作者字段的文件标记为 Not present，不推定为无作者或公有领域。

`tools/import_user_blueprints.py` 可重新导入原文件。仅提取方块和状态，不导入实体、物品栏、命令或原方块实体数据。Litematic 的反向区域及跨 long 的位打包经过解析，非空气数量与原元数据一致。

`tools/settlements.py` 改造材质、入口和道路接口，使用本附属的石灰岩与灰泥，并移除隐藏控制方块、资源方块和矿石。0.9.2 删除蓝图低处的地表土层、田土和水，保留房屋基础、楼板与高处花槽；室内使用空气清空，外部使用结构空位保护原地形。不导入或追加村民、动物等任何实体。生成物为原版结构模板与 jigsaw 数据，不执行蓝图中的任何指令。这里的来源记录不授予超出原作者许可的权利。
