# 灵猫塔罗牌面绘制规范

二十二张大阿尔卡那都用代码在 112×192 原生网格上重绘。高像素终稿和《要素说明》在仓库外的
`art/mystical_cat_tarot/灵猫大阿尔卡那_终稿与要素说明/`，只用来看构图和核对要素。

**牌面模块不得读取任何图片。不缩图、不量化、不自动描边、不采样参考图的颜色。** 坐标和形状都是读图后手写的。

## 文件

| 文件 | 用途 |
| --- | --- |
| `pixelkit.py` | 画板、色板、蒙版、原版风材质、发光 |
| `figures.py` | 头部精灵、手、猫尾、花、菱扣、四角术式书 |
| `registry.py` | 22 张牌的 ID、牌名 |
| `cards/c<id>.py` | 每张牌一个模块，提供 `draw() -> Card` |
| `render.py` | 画牌、写贴图、出审稿预览、做 lint |
| `ref_grid.py` | 给终稿盖 112×192 坐标网格，读坐标用 |
| `zoom.py` | 放大看成品的局部 |

运行（在仓库根目录）：

```bash
uv run --quiet --with pillow --with numpy python tools/tarot_art/render.py 00_fool
```

```bash
uv run --quiet --with pillow --with numpy python tools/tarot_art/ref_grid.py 00_fool 30 20 70 60
```

`render.py` 把贴图写到 `src/main/resources/assets/logos_dimension/textures/item/tarot/major/`，
预览写到 `art/mystical_cat_tarot/v09_pixel_major/preview/`：`<id>_review.png` 从左到右是 4 倍牌画、
夜间发光模拟、参考图；`<id>_framed.png` 是装进牌框的 3 倍整卡、原尺寸牌画和缩小整卡。

## 风格：像一幅原版画作

牌面放在 Minecraft 里，要像原版画作和方块世界里长出来的东西，同时保留塔罗的构图。

- **地形用方块语言。** 草地用 `turf` + `grass_lip`（草方块的锯齿垂边）+ `soil`；山和崖用 `blocky(mask, 2)` 做阶梯边；
  云是平底矩形堆叠，呼应原版方云，不要画圆润的棉花云。
- **建筑和器物用原版材质。** 石柱、塔、台阶用 `stone_bricks`；木头用 `planks` / `bark`；树冠用 `leaves`；水用 `water`。
- **色调略灰。** 用 `pixelkit` 的色阶，不要自造高饱和颜色。需要新颜色时写在牌面模块顶部，并给足 3–5 档。
- **颗粒只在环境上。** `speckle`、`turf`、`soil` 不上人物和布料；抖动只用于天空渐变和魔光余晖。人物身上全是硬边平涂。
- **大形优先。** 先把轮廓和大色块摆对，再加少量褶子。宁可少一道褶，也不要出现一团读不清的噪点。

## 人物

- 人形灵猫：人类面孔、头发、皮肤、手脚，头顶猫耳，按图保留一或两条尾巴。**不加猫科口鼻、胡须、兽爪、全身毛皮。**
  完整猫形态的灵猫画成真正的猫。
- 头用 `head()`：主角 `size='L'`（整头约 19 宽），同屏多人的配角 `M`，远景小人 `S`。朝向 `front/3q/profile`，`flip` 朝左，`vflip` 倒置。
  长发后片在身体之前用 `hair_paint`、`hair_lock` 自己画，前绺在头之后画。头发颜色用 `HAIR_*` 色阶，眼睛用 `*_IRIS`。
- 手用 `hand()`（open/point/bless/grip/fist/cup/open_s/mitt/dot），不够用就在牌面模块里按同样字符写 ASCII 精灵。**手必须读得出姿势**，
  关键手势（魔术师的上下手、教皇的双指、太阳的张开手掌）值得一格一格摆。
- 身体比例按参考图读坐标，头身比可以比参考图再大一点，脸比身体更值钱。
- 布料用 `shape(mask, ramp, base=…)`：平涂 + 硬边暗带 + 内描边。金边用 `trim`，同一处只走一道，两道并排会变成条纹。
- 小于 5 像素宽的形状不要用 `shape`（描边会把它吃掉），用 `paint` 或 `volume(shadow=1, hi=0)`。

## 光

- 全套光从左上来（`light=(-1,-1)`，和牌框的高光方向一致），除非牌面有明确光源，比如隐士的灯。
- 描边用该材质色阶最暗一档，不用纯黑。纯黑只给瞳孔和 `INK`。

## 发光层

`c.glow(mask, color)`、`c.glow_px`、`c.glow_line`、`c.node`、`c.node_h`、`c.star4` 写进发光层：游戏里这些像素按满亮度显示，夜里也亮。
每张牌选少数几处：

1. Logos 的蓝青节点、连线、晶体（永远发光），颜色用 `TEAL`。
2. 这张牌的魔法焦点（见下表）。

发光像素建议占 2%–8%，lint 上限 12%。大面积发光会让夜里的牌变成一块亮板。发光形状周围可以用 `c.aura` 铺一圈不发光的暗色抖动，读出光的范围。

## 自查

`<id>_review.png` 和 `<id>_framed.png` 都要看。合格的标准：

- 《要素说明》里「不可或缺的要素」「保留重点」逐条能在牌上找到，数量和方向正确（十二星、八辐、一大七小、四个羊角等要数）。
- 原尺寸（`framed` 里那张 1 倍牌画）能一眼读出是哪张牌。
- 没有断开的线、粘成一团的手和脸、被描边吃掉的小形状。放大检查用 `zoom.py`。
- 对称的牌确实对称（`x` 与 `111-x` 成对）。
- lint 显示 OK。

`cards/c00_fool.py` 是全套的基准样板，先看它再动手。
