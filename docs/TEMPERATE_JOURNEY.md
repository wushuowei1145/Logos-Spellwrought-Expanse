# 远行大陆 · 0.2.0

宁静的温带大陆，以低饱和的草绿、石灰岩白、灰岩和红褐屋顶构成长途跋涉的背景。没有巨大法阵、悬浮岩带、魔鲸或魔法环境粒子；原咒械原维度的炼金美术不受这次方向修改影响。

## 地理与生态

使用连续的大陆地形、单纯形噪声、海拔与湿度选群系，替代原来按固定区域切换高度、重复悬空几何的做法。大多数低地是草原和起伏丘陵；湿润地带形成森林，河流沿排水谷地向南部海岸流去。北方山带以 Z≈-6,600 为中心，含裸岩、雪峰、冰川与冰湖；南部海岸约在 Z≈6,800，并随 X 与种子弯曲。气候大陆以约 48,000 格尺度延伸，不是原咒械原的 20,000 格环带。

保留 24 个注册 ID，展示生态分别为：长风草原、山毛榉林、浅海沙洲、北境白桦林、缓流河谷、高地草甸、白崖海岸、裸岩山脊、古河峡谷、橡木林地、静水湖泊、幽深阔叶林、旷野丘陵、北境冷杉林、野花草甸、冰川雪岭、高山河谷、牧草坡地、芦苇湿地、山地松林、南方海湾、银桦疏林、寒带荒原、积雪峰顶。

落叶树为宽冠木块树，白桦使用原版白色原木；松杉为层叠尖冠。八种新植物具有独立模型和 32×32 贴图：林下羽叶蕨、卷叶蕨丛、垂铃花、毛地黄、羽扇豆、原野牧草、河岸芦苇、葡萄藤架。使用薄片与透明像素塑造叶片和花序，植物无实体碰撞，并在失去支撑后清除。基础渲染保持轻量静态模型；风摆效果由支持的光影控制，没有增加逐株渲染器。

## 稀疏文明

每 6,144 格格网只尝试一个聚落，约 46% 的格网继续选址；海中、高山和陡坡拒绝放置。因此实际聚落距离通常大于一个格网，不保证处处都能找到村落。约 16% 的候选类型为城镇，仍需通过地形筛选。位置沿河岸选取，避免凭空在高山或水下生成住宅。

乡村房屋松散，配成熟麦田、葡萄架、修剪成小冠的果园。城镇采用紧凑的多层木骨灰泥住宅、窄街、石墙、方形瞭望塔和护城水沟。五个基础建筑来自 MIT 许可的 Millénaire 诺曼分层投影；已替换材质、修正门窗、移除原 Mod 功能，住宅额外提供 2–4 层变体。完整来源在 [第三方投影说明](../third_party/millenaire/SOURCE.md)。并未导入整座玩家城市。

村民使用原版实体，并在结构装饰阶段少量生成。原野动物复用原版羊与牛；没有新增实体类型。低概率小型倒塌石墙遗迹散落在聚落之外。目前建筑通过生成器放置，不提供独立 `/locate` 聚落类型；后续可继续扩充城市素材。

## 天气、四季与地下

普通昼夜与天气，采用原版太阳、晚霞、星空和薄云。旧的自定义云网格及后台线程没有恢复。光影包可以使用自己的云高、雾色和阴影，画面不保证与普通渲染一致。

每季 192,000 tick（8 个游戏日），一年 32 日。落叶冠与草皮通过随机刻逐步切换四季材质，针叶冠保持常绿。季节温度只在本维度服务端 tick 与客户端画面期间生效，冬季低地能产生原版降雪和结冰；暖季移除本模组草皮上的低地积雪。高山持续寒冷。年份使用本维度时钟，不依赖真实日期；没有模拟全球气候或复杂天气锋面。

地下主体使用原版石头、深板岩、水与深层熔岩，接入原版洞穴和峡谷雕刻器，允许原版废弃矿井。所有群系矿物特征为空，也未启用噪声矿脉；后续特殊矿物留空。取消旧魔气地心和异常洞窟植物。

## 存档与入口

维度 ID 仍是 `logos_dimension:cloudsea`，所有原群系和材料注册 ID 保留，避免旧存档缺注册项。生成器配置增加 `settings: minecraft:overworld`，源码数据包已同步。已有存档若把维度定义复制到了自定义数据包，需要同步该字段。旧区块不会自动重绘，交界处可能不连续，推荐新存档观察完整大陆。

生存入口仍未制作；管理员先切创造，再用：

```text
/execute in logos_dimension:cloudsea run tp @s 300 180 1800
```

北侧雪山与南侧海岸很远，需要长途跋涉或管理员传送。没有覆盖、删除玩家旧区块。
