# 精灵长矛

物品 ID 为 `logos_dimension:elf_spear`。与自然之力同属生命元素武器，使用维护者提供的 `elf_spear.png`，图标原样导入。创造模式在远行大陆标签页获取，或执行：

```text
/give @s logos_dimension:elf_spear
```

首版没有配方或新增掉落来源，不改变精灵 NPC 的现有装备。

## 原版模板与数值

使用原版 `Item.Properties.spear`、`piercing_weapon`、`kinetic_weapon` 和 `attack_range`，物品显示沿用原版长矛的图标/手持模型切换与变换。

| 项目 | 数值 |
| --- | --- |
| 左键戳刺 | 玩家默认基础值合计 4 点，与钻石长矛一致 |
| 左键间隔 | 13 tick（0.65 秒），与木长矛一致；攻击速度属性仍可修改间隔 |
| 右键冲撞 | 完整沿用铁长矛：速度伤害系数 0.95，起手 12 tick（0.6 秒），接触冷却 10 tick |
| 右键速度门槛 | 伤害看相对接近速度 4.6 格/秒；击退看自身前向速度 5.1；击落骑乘者看自身前向速度 11 |
| 右键有效时间 | 起手后 2.5 秒可击落、6.75 秒可击退、11.25 秒可造成伤害 |
| 生存射程 | 标称 2–4.5 格，按原版碰撞箱与 0.125 格命中余量判定；有近身盲区 |
| 耐久、修复、基础附魔性 | 铁长矛标准，耐久 250；进原版长矛和耐久附魔标签 |

原版射线可以穿刺同一直线上的多个实体，方块会阻挡。没有新增投掷、追踪或穿墙命中逻辑。左键伤害、右键速度伤害均正常经过原版防御和附魔结算。

## 萌芽印记与生命易伤

1. 玩家左键实际命中并被目标接受物理伤害后，种下 **6 秒（120 tick）萌芽印记**。重复戳刺刷新期限，不扣魔力，不叠层。
2. 同一玩家用这把长矛右键冲撞，实际命中自己的有效印记目标时，消耗印记和 **5 点魔力**。
3. 保留本次全部原版物理伤害，再独立追加 **6 点 Logos 生命基础伤害**。速度只影响原版物理部分，六点生命追加不随速度再次放大。
4. 生命追加结算后，施加原生 `logos:life_vulnerability`，**I 级，持续 4 秒（80 tick）**。新的易伤不放大刚结束的本次追加；目标原来已有的易伤和生命抗性照常参与。

生命易伤 I 为 +20%，II 为 +50%，遵循 Logos 的属性实现；重复触发刷新，不自动升级，已有更高等级效果沿用原版效果合并规则。使用 Logos 生命伤害与特效入口，不复制注册易伤属性或药水效果。

每个目标只保存最后一名施加者的印记，只允许该施加者触发。印记归属和绝对到期时间随实体保存，卸载/重载不会刷新期限；客户端同步后显示低频小叶片。触发时使用 Logos 的生命伤害特效。

无印记、印记过期、印记属于他人或不足 5 魔力时，右键仅造成正常物理伤害，不消耗残余魔力或有效印记。挥空、出射程、穿墙和伤害被拒绝时不种印、不扣费。穿刺多个有效印记目标时，每个目标独立结算并消耗 5 魔力。

创造模式免魔力。非玩家生物可按原版使用这把长矛造成物理伤害，首版没有为生物新增萌芽法术或独立魔力池。

## Logos 兼容与资源

完整机制要求 Logos 中已注册 `logos:life_vulnerability`，本次对照上游 main `14c3260`（0.6.0）。早期同为 0.6.0 的开发包可能尚无此效果；缺少时保留物理攻击和印记，不扣魔力，并提示更新 Logos。

物品图标原样保存为 32×32；原版长矛的手持贴图射向与图标相反，因此另由代码水平镜像生成手持专用贴图，模型使用原版 `minecraft:item/spear_in_hand`，不用弓的显示变换。萌芽叶片由代码绘制，没有使用图像生成服务，也不生成实际植物方块。

```text
python tools/elf_spear_resources.py --icon /absolute/path/elf_spear.png
./gradlew test runGameTestServer build -PlogosJar=/absolute/path/logos.jar -PdimensionTests=logos_dimension:elf_spear*
./gradlew runClient -PlogosJar=/absolute/path/logos.jar -PldTest=group:elf_spear -PldTestHeadless -PldTestWindow=1280x720
```

实际验证结果见 [VERIFICATION.md](../VERIFICATION.md)。
