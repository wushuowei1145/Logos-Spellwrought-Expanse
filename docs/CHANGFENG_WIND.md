# 长风草原：草带与草浪

长风草原（`logos_dimension:cloudsea_silk_folds`）改为温带内陆的连续平坦草地。旧气候点保留在侵蚀值 0.65 档，新增主体扩展为侵蚀 0.15–1.2 的连续范围并通过密度函数压低起伏，取消随山脊噪声交错轮换的碎条分配；补入温度、湿度、内陆度的连续气候范围，仍用原版多噪声群系生成。寒地高草甸与暖地花甸保留各自分配。

草地表每区块使用原版放置特征尝试 800 次，草类权重合计 84%，其余为少量野花。目标是约 80% 地表覆盖草，允许局部随机变化；并非每个区块强行填满固定数量。土壤、空气和群系过滤保持原样，不使用 Java 地形生成器。已有区块无需重生成即可看到风动；群系分布和覆盖率调整只影响新区块。

风动借鉴 Unreal Engine 的 [SimpleGrassWind / World Position Offset](https://dev.epicgames.com/documentation/unreal-engine/world-position-offset-material-functions-in-unreal-engine)：根尖权重控制顶点位移。本实现将方向、强度和整株根点的空间相位传给自有顶点着色器，叠加约 18 格的长波与细小扰动；根部固定，腰部轻弯，草尖摆幅最大，并略微下压。风力与天气来自已有 `WindField`。没有复制引擎代码或素材。

平原主体另由原版密度函数形成约 Y=74、轻微起伏的开阔地面，气候边缘用样条平滑过渡。地下 Y=48 以下保留原密度与洞穴；群系深度和预估地表高度同步调整，避免把新的地面识别成旧山体的地下。生成脚本为 `tools/changfeng_plains.py`，反复运行不会叠加修改。

## 影响范围

- 只接管远行大陆中长风草皮上生长的原版短草、双层高草、原野牧草与幼年原野牧草。
- 长风草皮上的原版短草与高草换成专用宽叶草簇：三种株型、四向旋转，叶片二至四像素宽、弧形向外伸展，短叶加厚草根、长叶撑起上层，叶脉低对比，留出斜向空隙。模型与贴图由 `tools/changfeng_grass_art.py` 生成；全部贴图为 **16×16**，高草上、下半分别一张，直接按像素绘制。短草四面、双层高草八面，与原版相同；没有新注册一套草方块。
- 其他草保留原模型。统一使用烘焙后的 UV 和颜色，不再叠加一层放大的草来遮挡旧草。双层高草共用根点和弯曲权重，腰部接缝一致。静态与风动使用同一株型，关闭风动也保留新模型；其他地表、物品与破坏粒子不换外观。
- 物品、破坏粒子及其他维度继续用原模型。风动只改变显示，不移动方块、碰撞箱、掉落或服务端生成。
- 保留群系染色、烘焙颜色、实际天空光和方块光、裁切透明与雾。UV0 为原材质，UV2 为真实光照；自有管线的 UV1 存风参数，颜色 alpha 存根尖权重，片元最终 alpha 来自原贴图。
- 近景提交经过 Logos 的 `ShaderPackOverlay.collector`，不清空共享收集器。没有替换原版或 Sodium 的整个地形着色器。

## 开销与开关

每帧仅提交缓存几何，弯曲在 GPU 完成；缓存仍需通过收集器上传顶点，不是 GPU 常驻实例化。每刻最多扫描两个已有的 16³ 区段，另分摊十二个地表探针以发现走近的已加载草地。最大缓存 48 区段，总提交上限 12,000 四边面；预算外保留静态草，不隐藏。不会请求未加载区块。

32–48 格渐渐收回摆幅，超过缓存保留距离恢复静态模型。挖草、放方块和换季会使相应缓存失效；资源重载、切换世界与关闭功能也会清理。静态与动态切换需要一次对应区段重新编译，首次接管时可能短暂看到更新，不代表每帧重建区块。

本机 `config/logos_dimension-client.toml`：

```toml
grassWind = true
grassWindAmount = 1.0
```

关闭 `grassWind` 恢复原静态草；`grassWindAmount = 0` 保持静止，可用于对照。单人开发环境可用 `/logoswind set 1` 固定强风、`/logoswind auto` 恢复。原命令的覆盖值没有专用的联机同步，因此不将它视为联机客户端调试开关。

## 验证方法

```text
./gradlew test build -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/orchestra.jar
./gradlew runClient -PlogosJar=... -PorchestraJar=... -PldTest=group:grass_wind -PldTestHeadless -PldTestWindow=1280x720
```

客户端场景分两种：一块独立测试台用实际原版放置特征种草，统计 32×32 格覆盖率，检查提交预算、挖草同步、关闭与再次开启；另一个场景定位真实噪声生成的长风平原，不放置或整平地表，检查 32 格样地高差及风动缓存，并拍摄实机画面。单元检查根点、双层接缝、零风、负坐标及远坐标相位、远景摆幅渐变。最终实测结果及尚未覆盖的项目记在根目录 `VERIFICATION.md`。
