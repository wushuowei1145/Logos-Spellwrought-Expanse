# 惊鸿与剑阵

维护者于 2026-11-10 提出两步要求：

1. **新武器。** 参考凌霄的模型做一把纹理、样式都不同的剑。之后有武器要同时用五把这样的剑，所以精度可以低一些。
2. **剑阵玩法。** 仙侠剑阵、万剑归宗的感觉：一把剑拿在手上，五把剑扇形展开飘在背后。具体是：
   - 左键是最基本的近战攻击；身后每把剑各有独立的概率升起，从随机方向极快地追加一击，再闪回玩家上方落回原位。
   - 右键参考植物大战僵尸 2，横剑进入格挡；刚进入的 0.3 秒是弹反。弹反成功时，身后随机 2–5 把剑依次扑向被弹开的目标；普通格挡有 50% 的概率飞出一把。
   - 被触发过的剑在一段时间内发光、激活，激活的剑追加 Logos 的物理元素伤害。
   - 按住右键再按左键：手里的剑笔直掷向目标造成基础伤害，再飞回手上。身后激活的剑一起飞出，对目标多段攻击；五把都激活时是最华丽的万剑归宗。这一招之后清除所有激活。
   - 补充：第一人称看不到身后，所以手里的剑要能看出身后激活了几把。

## 1. 剑本身

| 项 | 做法 |
| --- | --- |
| 规格 | 与凌霄相同：原点在剑柄里，主手握点 0.65，剑尖 +Y，刃宽沿 X、剑面法线沿 Z；骨骼与凌霄同名同层级。 |
| 动作 | 共用凌霄的拔剑、四式连招、被弹反、归鞘；格挡、弹剑、掷剑是惊鸿自己的，盖在凌霄的动作上（第 3 节）。 |
| 刀光 | 共用凌霄的设置和剑气样式。剑尖 21.82，与凌霄的 22 只差 0.2。 |
| 精度 | 17 个方块（剑 13、剑鞘 4），凌霄 58 个；骨架贴图 64×64，凌霄 128×128；图标 32 像素。 |
| 样式 | 玄青柳叶剑身，亮银刃口，中间一道青光剑脊；燕翼剑格，嵌青色菱形宝石；深靛缠柄，银色菱形剑首，挂一条朱红剑穗；黑漆剑鞘，带三处青色菱饰。 |
| 数值 | 同凌霄：铁剑伤害 6、耐久 250，攻速 2.4，菱形判定。 |

## 2. 剑阵

### 2.1 身后的五把剑

- **位置：** 五把剑柄沿背后一道半径 0.5 格的圆弧排开（圆心在腰后），剑柄彼此隔开约 0.28 格；剑尖朝外，左右各隔 32° 一把，像孔雀开屏，略向后仰，剑面朝后。各自缓缓上下浮动。第一版剑柄聚在一点，试玩时挤成一团，改成这样。
- **大小：** 第三人称手里那把的 0.85 倍。
- **显示条件：** 只在持剑动作里画。拔剑时展开，收剑时合拢。
- **第一人称：** 自己身后那一扇不画（镜头在剑阵里面）；飞出去的剑照常画。
- **发光：** 激活的剑整把发物理元素的光（亮处近白、外圈钢蓝），全亮，外加一圈柔光。

### 2.2 一次追击

时间轴在 `SwordFlight`，服务端按它结算，客户端按它画：

| 刻 | 发生什么 |
| --- | --- |
| 0–3 | 从剑阵里升起约 1.2 格 |
| 3–5 | 绕到出击点（离目标 3 格，方向随机：方位任意，俯角 10°–55°） |
| 5–6 | 极快地穿过目标：**第 6 刻结算** |
| 6–7 | 冲过头 1.4 格 |
| 8 | 闪回：在那里消失，出现在玩家头顶 |
| 8–13 | 落回剑阵原位，可以再出手 |

多段时（掷剑协同），每多一段多 4 刻：从冲过头的地方绕到新方向的出击点，再穿一次。

飞剑跟着目标当前的位置走。目标没了，就飞到最后看到它的地方。

### 2.3 触发与激活

| 触发 | 飞几把 | 打谁 |
| --- | --- | --- |
| 左键砍中（每一刀的第一个目标） | 每把闲着的剑各掷一次骰子，两成概率；相继出手的错开 2 刻 | 那个目标 |
| 弹剑（格挡开始 0.3 秒内挡下） | 随机 2–5 把，依次错开 2 刻 | 被弹开的攻击方 |
| 普通格挡 | 一半概率一把 | 攻击方 |

- 攻击方离玩家超过 24 格、是自己的宠物或已经死了，都不飞。
- **激活：** 被触发出手的剑激活 15 秒，再被触发就刷新时长。出发时已经激活的剑，那一下另加 Logos 物理伤害（`Effects.followUp`，吃物理元素强度和目标抗性，带 Logos 的物理命中特效）。
- 新亮起一把时有一声清脆的提示音，亮的越多越高。

### 2.4 手里剑身上的刻度

第一人称看不到身后，所以手里那把剑的剑脊从剑根往剑尖分成五段：亮几段，身后就激活了几把。五段全亮时，剑尖那一截也亮起来，并缓缓呼吸，表示可以万剑归宗。第三人称看别人手里的剑也一样。

为了第一人称看得见刻度，格挡时剑面朝着镜头（刃朝前上）；第三人称格挡时剑面朝前。

## 3. 招式

| 招式 | 动作 | 时长 | 转移 |
| --- | --- | --- | --- |
| idle、attack_1–4 | 凌霄的待机与四式连招 | 同凌霄 | 出招中按右键立刻转格挡（同打刀） |
| guard | 横剑：剑横在胸前，剑尖指左，剑面朝前，左手两指搭在剑身中段 | 1.6 秒循环 | 开头 0.3 秒挡下 → parry；左键 → throw；松开右键 → idle |
| parry | 剑尖往左前上方一磕，顿一下落回横剑 | 0.36 秒 | 播完回格挡；左键（缓冲到 0.18 秒）→ throw |
| throw | 剑收到右肩后，一甩掷出（`release` 0.14 秒），右手捏剑指指着目标；剑飞回时张手接住（`catch` 0.62 秒） | 0.9 秒 | 0.7 秒后按右键回格挡 |

- **格挡：** 用原版格挡组件，只把盾的举盾延迟改成 0（同打刀）。减伤、击退、耐久都走原版；弹剑不扣耐久，近战的攻击方进入僵直。
- **掷剑时挡不住：** 掷剑这一招里格挡事件被取消。右键一直按着时原版仍在“使用”，掷剑播完自动回到格挡；不停掉原版的使用，否则客户端会自己预测成仍在使用、不再发右键，回不到格挡。
- **动作编排：** `tools/jinghong_moves.py`，复用凌霄的工具。`release` 到 `catch` 之间骨架里的剑缩成 0，飞出去的剑由客户端在世界里画。
- **新标记：** `release` 和 `catch` 已登记在 COMBAT_SKELETON 第 6 节。

## 4. 掷剑与万剑归宗

**找目标：**

- 先取准星对着的生物，最远 24 格，碰到方块为止；
- 没有就取离视线 6° 以内、看得见的最近的；
- 再没有，剑就笔直飞出去 16 格（或到方块），再回来。没有目标时激活保留。

**掷出去的那把：**

- 3 刻穿过目标，同时结算；
- 在那里掉头，剑尖仍朝外倒着飞回；
- 9.6 刻回到手里，正好是动作的 `catch`。

**有激活的剑（不到五把）：** 激活且在原位的剑在下一刻起依次出手，每把穿过目标两次。

**清除激活：** 有目标时，这一招之后所有剑的激活都清除：

- 协同出手的剑飞完回位时熄灭；
- 正在别处飞的剑回到原位时熄灭。

**万剑归宗（五把都激活且都在原位）：**

| 刻 | 发生什么 |
| --- | --- |
| 0–8 | 五把剑升起，飞到目标头顶 5.5 格处，结成半径 2.2 格的剑环。剑尖朝下缓缓转，环下展开物理法阵。 |
| 8–29 | 36 把虚影剑从目标四周的半球面（半径 7.5 格）依次显现，剑尖对着目标，随即落下贯入。第 12–28 刻每 2 刻结算一下，共 9 下。 |
| 30–33 | 五把剑一齐贯下，第 33 刻结算一记重击，另加 Logos 物理伤害。冲击光环、星芒、雷鸣。 |
| 36 | 闪回 |
| 36–41 | 落回原位，所有激活清除 |

## 5. 伤害（先定的，等试玩再调）

乘数都乘在玩家的攻击伤害属性上，惊鸿是 6：

| 项 | 伤害 |
| --- | --- |
| 一次追击 | 0.5 倍（3）；激活的剑另加物理 2 |
| 掷剑 | 1 倍（6） |
| 协同出手 | 每把两次，每次同追击（3 + 物理 2） |
| 万剑归宗 · 虚影剑 | 每下 0.25 倍（1.5），共 9 下 |
| 万剑归宗 · 五剑贯下 | 2.5 倍（15），另加物理 15 |

**伤害类型：**

- 追击、掷剑和虚影剑用 `logos_dimension:sword_array`：算在玩家头上（击杀、仇恨），不吃受击冷却（多段都能打上），不击退。
- 物理那部分走 Logos：Logos 物理伤害按玩家近战算。

**参考：** 不带物理时，四把协同出手约 6 + 4 × 2 × 3 = 30；万剑归宗约 6 + 13.5 + 15 = 34.5，再加物理 15（乘物理强度）。万剑归宗要五把都在 15 秒内被触发过，最快的办法是弹剑。

## 6. 网络与兼容

**同步：**

- 服务端发 `SwordArrayPayload`：
  - 激活到哪一刻；
  - 哪把剑什么时候出发、打谁、每段的方向；
  - 掷剑；
  - 万剑归宗。
- 伤害、概率和目标都在服务端，客户端只画。
- 开始追踪别的玩家时补发一次激活状态。

**清零与上限：**

- 死亡、换维度、离线时剑阵清零。
- 追击只在 24 格内触发，结算时超过 32 格就不算。

**共用代码只加了两个钩子：**

- `CombatWeapon.Holder.hit`：砍中之后；
- `Holder.blocked`：格挡之后。

弹不开的攻击（`logos_dimension:unparryable`）现在也会经过 `blocked`（按普通格挡算），其余行为不变。

**光影：**

- 剑的网格用实体渲染类型，交给光影处理；
- 发光、拖影、法阵是叠加的自定义几何，走 `ShaderPackOverlay.collector`；
- 手里剑的刻度走 `ShaderPackOverlay.item`。

**测试用接口：**

- `SwordArray.testChance`：把追击和普通格挡的概率定死；
- `activateForTest`：直接设激活。

## 7. 已知限制与未验证

- **追击的轨迹：** 只看目标的中心，不避开方块；剑穿墙飞过去也照样结算。追击是剑阵“法术”性质，暂按穿透处理。
- **身后剑阵的朝向：** 跟原版身体朝向，不跟头。
- **光影下：** 未测。
- **未验证：** 手感、数值、音效都没有试玩过。
