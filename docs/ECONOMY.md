# 异世界货币与外汇

四种货币的原型、现货兑换、万国钱囊，以及钱庄（存款与杠杆交易）。精灵还没定（倾向以物易物），暂不发币。商人 NPC、期货还没做。

代码在 `dev.logos.dimension.economy`，界面在 `client/ExchangeScreen`、`client/WalletScreen`，美术和数据由 `tools/fx_economy_art.py` 生成。

## 货币

余额一律按最小单位记成整数，面额只是换算。所有汇率都报成「一个最小单位值多少铜分」，帝国币是基准，自己恒为 1。开局四种金币大致等值（金冠 ≈ 小判 ≈ 金镑 ≈ 奥里斯 ≈ 一万铜分）。

| 种族 | 面额（小 → 大） | 换算 | 外汇性格 | 日波动 | 单边点差 |
|---|---|---|---|---|---|
| 人类帝国 | 铜分 / 银元 / 金冠 | 1 : 100 : 10,000 | 基准货币，不动 | — | — |
| 神狐 | 文 / 一分银 / 小判 | 1 : 1,000 : 4,000 | 避险：魔潮时上涨 | 2.5% | 0.8% |
| 灵猫 | 便士 / 先令 / 金镑 | 1 : 12 : 240 | 事件驱动：议会、贸易 | 4% | 1% |
| 群狼 | 阿斯 / 塞斯特斯 / 第纳尔 / 奥里斯 | 1 : 4 : 16 : 400 | 和战争绑定，高风险 | 6% | 1.5% |

参数集中在 `Currency` 枚举里。

## 汇率模型（`FxMarket`）

每种可炒货币有一个相对锚定值的对数汇率 x，每 100 刻走一步：

```
x ← x + θ·(f + d − x)·dt + σ·√dt·ε + 事件跳变
显示汇率 = 锚定值 × exp(x + 冲击)
```

- **f** 剧情与探索定下的永久基本面（`milestone`，同一个 key 全服只生效一次）。目前接了一个：第一位玩家走进神狐聚落，狐钱 +3%。
- **d** 事件留下的基本面偏移，约二十天淡去，所以随机事件不会让某种货币一路单边。
- **θ** = 0.15/天，半衰期约 4.6 天。偏离锚定超过 ±60% 时央行干预加速回拉，±100% 封顶。
- **冲击**：按成交了多少枚（以锚定价折算）推动汇率（约 100 金冠：狐 1%、猫 1.7%、狼 2.5%），约 0.75 天散去。按冲击路径的平均价成交（`FxMarket.along`，对路径积分），所以任何一串自己的买卖加起来正好抵消，立刻原路换回只亏点差。冲击不按成交时的价值算：那样大单把价格砸到接近零后，原数买回几乎不推价，空单就能靠自己的冲击凭空赚钱（11-04 修复）。
- **市场深度**：单笔冲击超过约 35%（`FxMarket.MAX_IMPACT` = 0.3，对数）就拒绝，要分批。现货每笔最多约狐 3,000、猫 1,800、狼 1,200 金冠；杠杆单名义金额最多约狐 30,000、猫 18,000、狼 12,000 金冠。累计冲击另有 ±1.5（对数）封顶，兜底防止汇率归零或无穷。
- 交叉汇率由同一组对帝国币的汇率推出，每次兑换收两边点差并向下取整，所以没有三角套利（单元测试覆盖）。

时间用主世界时钟。兑换商 6:00–18:00 开门，按游戏小时记 K 线，保留 240 根（二十个开市日）。夜里汇率照走、事件照常揭晓，早上开盘会跳空。随机数自带状态并存档，读档不会重掷。

## 事件与传闻

每个游戏日开盘有 75% 的概率放出一条传闻，一到两天后的任意时刻揭晓（可能在夜里）。传闻按来源分可信度：

| 来源 | 方向说中 | 根本是假的 |
|---|---|---|
| [告示] | 100% | 0% |
| [可靠] | 85% | 5% |
| [坊间] | 70% | 15% |
| [小道] | 55% | 35% |

| 事件 | 影响 | 计入基本面 |
|---|---|---|
| 帝国增发 / 回收劣币 | 三种货币同涨 / 同跌 5–10% | 80% |
| 魔潮 | 狐 +4–10%，猫 −3–8%，狼 ±6%，之后两天所有货币波动加大 | 20% |
| 灵猫议会 | 猫 ±6–14% | 60% |
| 群狼战事 | 狼 ±10–22%，传闻期间狼币波动加大 | 80% |
| 收成 | 某一种 ±2–5% | 30% |
| 狐火祭（每八天，提前两天官方告示） | 狐 +4–7%，之后回落 | 0% |

揭晓之前，知情资金按**真实结果**把三成变动提前买进价格（狐火祭人人都知道，提前一半）。所以假消息不会带动价格，会看盘的玩家能分辨真假。

### 模拟结果

`FxMarketTest.informedTradersWinAndGamblersLose`：从 100 金冠起步，200 次、每次 30 个游戏日：

| 玩法 | 平均 | 中位 | 最差 | 最好 |
|---|---|---|---|---|
| 每天开盘随手全仓换一种 | −39% | −43% | −67% | +16% |
| 买入不动 | +3% | +3% | −23% | +38% |
| 只信可靠/坊间传闻，押对应货币，揭晓后平仓 | +15% | +15% | −37% | +75% |

调参后重跑这个测试看分布。

## 万国钱囊（`WalletItem`）

- 每种货币一个余额，不限数量；右键打开面板，按一枚或一组（64）取出所选面额。
- 物品栏里把钱币点到钱囊上，或拿着钱囊点钱币，直接存入；面板上可一键存入背包散币；打开「捡钱入囊」后捡到的钱币直接进钱囊。
- 🔒 锁住的货币结账时不会被自动换掉，炒汇玩家用来保护持仓。
- 死亡照常掉落，防火。想保险就放家里的箱子。

## 结账（`Purse.pay`）

给以后的商人用：价格写在商人的货币里。先用钱囊和背包里的这种货币（散币多付找零）；不够时按钱囊的顺序自动换汇：先帝国币，再按折合价值从多到少，跳过锁住的。换汇用和兑换台完全相同的汇率与点差，不额外收便利费。`commit=false` 只预览，不动钱也不动市场。

## 兑换台（`ExchangeCounterBlock`）

右键打开：所选货币的 K 线（红涨绿跌，近五天一小时一根，近二十天四小时一根）、当前报价与一日涨跌、下单（按最大面额输入数量，可点 25%/50%/全部）、最近的告示与传闻。成交要求人在台子八格内、兑换商开门；有钱囊时进出钱囊，没有就收付实体钱币。配方：金粒、书、金粒 / 三块木板 / 木板、空、木板。

## 钱庄（`BankBlock`、`Bank`、`Margin`）

右键钱庄柜台打开，分「账户」「杠杆」「持仓」三页，顶上一行是账户总览：总权益（存款 + 持仓按现价能拿回的 + 挂单冻结）、可用、浮动盈亏、已用保证金、借款。存取、追加保证金、改止损随时可以，开平仓和加仓只在 6:00–18:00；人要在柜台八格内。

### 账户

- 四种货币各一个余额，存在全服存档里，**死亡不掉**。从钱囊和背包散币存入，取出进钱囊（没有钱囊就发钱币）。
- 帝国币可以是负数：保证金不够时差额向钱庄借，眼下只显示负了多少，**没有利息也不催收**。
- 授信额度 100 金冠（`BankAccount.CREDIT_LIMIT`）。必须有上限：输了只是个负数、赢了能取现，等于白送彩票。
- 借款不能变现：欠着钱时，取款后的存款净值不能为负。
- 面板显示授信、已借和含持仓的净值，以及最近的强平、止损、止盈通知。

### 杠杆

拿帝国币作保证金，对狐钱、猫币、狼币**做多**（赌它对帝国币涨）或**做空**（赌它跌）。名义金额 = 保证金 × 倍数，盈亏按名义金额算。

| 规则 | 数值 |
|---|---|
| 玩家可选倍数 | 1–25（`Margin.PLAYER_MAX`） |
| 兼容上限 | 500（`Margin.SUPPORTED_MAX`）：存档、网络、计算都按 500 校验，以后放开不改数据格式 |
| 强平 | 净值跌到保证金的两成（`MAINTENANCE`）。跳空穿仓时超出保证金的亏损记成欠款（帝国币变负），不由钱庄兜底 |
| 点差 | 兑换台的一成：按兑换台的点差，25 倍狼币一开仓就亏掉七成半保证金 |
| 市场冲击 | 按仓位数量（锚定价折算），深度是现货的十倍（`DERIVATIVE_DEPTH`）；单笔超出市场深度拒绝 |
| 隔夜利息 | 每过一夜按名义金额收付两种货币的日利差，另扣 0.02% 融资费 |
| 日利率 | 帝国 0.05%、狐 0.01%、猫 0.08%、狼 0.2%：借帝国币买狼币每夜收利息（套息），做空狼币要付 |
| 止损止盈 | 按中间价触发；必须设在亏损一侧和盈利一侧，否则拒绝 |
| 持仓上限 | 每人 20 笔 |

强平、止损、止盈和利息由服务端随市场每 100 刻结算，**离线也照样发生**。夜里汇率照走，开盘跳空可能直接越过爆仓线，这时保证金亏光，超出的部分记成欠款。穿仓不能由钱庄兜底：否则玩家能用自己一笔仓位的平仓冲击把另一笔推到穿仓，让钱庄替他赔（11-04 修复）。冲击修正前开出的超大仓位在下一次结算时作废并退回保证金。

K 线上画出所选货币各笔持仓的开仓价、爆仓价（紫）、止损（蓝）、止盈（黄）、挂单价（灰），以及正在填写的单子的预计爆仓价；右侧预览名义金额、开仓价、爆仓价、**约可承受的反向波动**和每夜利息，存款不够时提示会借钱。左下是告示与传闻。

### 下单方式与持仓管理

| 操作 | 说明 |
|---|---|
| 市价 / 挂单 | 杠杆页切换。挂单（限价单）随时可下，保证金当场冻结；做多等跌到挂价、做空等涨到挂价，只在开市时按当时市价成交（开盘跳空可能比挂价更好）。跳空后原先的止损止盈若已在错的一侧就不设 |
| 移动止损 | 填离最好价的百分比（最多 50%）。止损跟着有利方向走、只进不退；新设或修改时从现价重新起算 |
| 追加保证金 | 持仓页选中一笔，填金额。爆仓线推远，实际倍数降低；夜里也能补 |
| 加仓 | 同方向按原倍数再买进，按均价合并 |
| 平 1/4、1/2、全平 | 部分平仓按比例分保证金和累计利息 |
| 一键全平 | 平掉所有持仓 |
| 撤单 | 冻结的钱退回钱庄；钱庄、钱囊里都能撤 |

持仓页的每一行写着实际倍数、浮动盈亏、爆仓价和约可承受的反向波动；净值跌破保证金一半时整行标红。

### 预警、提醒与通知

- **爆仓预警**：净值跌到保证金一半时提醒一次，回到七成以上才会再次预警。
- **价格提醒**：在钱囊的行情页设。比现价高就等涨到，低就等跌到；触发一次就删掉，夜里也照常。每人最多 10 个。
- **通知**：强平、止损、止盈、部分平仓、预警、挂单成交、提醒都记成钱庄通知，玩家在线时同时发到聊天栏。离线期间的通知在上线时补发（最多五条，再多给个数）。

### 现货挂单（兑换台）

兑换台也可切成挂单：一边必须是帝国币，用帝国币买等跌到挂价、卖出换帝国币等涨到挂价。钱从钱囊和散币当场冻结，成交所得和撤单退回的钱都存入钱庄（玩家可能不在、钱囊可能放在箱子里）。每人挂单（现货加杠杆）最多 20 张。

## 随身行情

- **钱囊**加了「行情」「持仓」两页：随身看 K 线（画出自己的爆仓线和提醒价）、报价、最新传闻，设价格提醒；看账户总览、持仓盈亏和挂单，可以撤单。开平仓、追加保证金还是要回钱庄。
- **行情条**：在钱囊后两页底部开关，状态记在客户端的 `config/logos_dimension-fx.txt`。开着时屏幕左上角显示三种货币的报价与一日涨跌，有持仓时加上浮动盈亏，最危险那笔跌破保证金一半时闪「接近爆仓」。身上带着钱囊才推送，打开任何界面时不画。

## 调试命令（需要管理员权限）

```
/fx                              当前汇率、开市与否、待揭晓事件数
/fx give <货币> <最小单位数>      发钱
/fx pay <货币> <最小单位数> [confirm]   模拟商人结账，不加 confirm 只预览
/fx event <mint|calamity|council|war|harvest> [小时]   立刻放出一条传闻
/fx shock <fox|cat|wolf> <百分比>   让汇率立刻涨跌（测强平用），之后照常回归
/fx bank                         自己的钱庄余额和各笔持仓净值
/fx reset                        换新种子，汇率回到锚定值
```
