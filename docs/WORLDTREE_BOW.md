# 世界树之弓

物品 ID：`logos_dimension:worldtree_bow`，精灵公主的弓。在创造模式「远行大陆 · 武器」页（和弓之后）获取，或：

```text
/give @s logos_dimension:worldtree_bow
```

本次没有添加配方、掉落表或自然生成奖励。

## 1. 美术交付

仓库外 `新角色完成稿/精灵公主武器/方块版`：`worldtree_bow.bbmodel`、`worldtree_arrow.bbmodel`，以及导出的原版物品模型资源包 `worldtree_cubes_26.1.2.zip`：

- 静止的弓 318 块（主体 48 块加 270 块剔除内侧面的绿色描边），贴图 32×32。
- 三段拉弓模型各 452 块：前 318 块是弯过的弓身、拉开的弦，后 134 块是搭在弦上的世界树之箭。
- 物品模型坐标里弓身竖着（+Y），箭朝 +X，弦在 −X 一侧；交付的展示变换照用。

维护者定：箭不用方块网格（133 块），用原版箭的网格，贴图照世界树之箭的样子重画。所以导入时三段拉弓去掉那支箭，只量出每段的搭箭点和箭头位置。

## 2. 机制

拉弓的姿势、第三人称、生物手里都是原版的弓（`WorldtreeBowItem` 继承 `BowItem`）。

- **锁定框**：按住右键后，视线前方展开一个低透明度的藤蔓框，0.5 秒展开完。框在镜头的切平面上，满时左右各 30°、上下各 18°。屏幕上就是个矩形，与视野大小、第一或第三人称无关。
- **锁定**：框里、48 格以内、看得见的敌人每 0.2 秒锁定一个，最多 16 个。
  - 先锁被锁次数最少的，一样多时锁离框中心最近的。
  - 敌人指怪物，或正盯着这名玩家的生物；不锁玩家、自己的宠物和同队的。
  - 每个扣 5 点魔力，魔力不够就不再锁。
- **锁定的反馈**：
  - 每锁一个响一声代码合成的、很轻的清脆短音，第 n 个用第 n 个音（C4 起按大调往上，第 16 个是 D6）。0.45 秒收尾，文件峰值 -14 dBFS，按 0.5 的音量播（维护者试玩：原来太响）。
  - 被锁定的生物身上一个藤圈标记，锁了几次就绕圈多几片小叶，不写文字。
  - 弓上多一支虚影箭（半透明、自发光），从箭尾往箭头凝聚出来，和流火的凝聚是同一套（`WeaponDissolve`）。
- **实箭**：拉到原版弓拉满的时间（1 秒），背包里有箭、有 10 点魔力时，中间出现一支实箭，同样凝聚出来。之后锁定只用这 10 点以外的魔力。
- **松手**：
  - 朝每个锁定发一支追踪箭（虚影），只打自己的目标，穿过路上的其他东西。
  - 每支的生命伤害按总锁定数算：1 个时 3 点，每多一个加 0.25，16 个时每支 6.75。同一个目标锁了几次就挨几支。
  - 有实箭时再向前射出一支笔直的高速箭（5 格/刻、无重力）：8 点生命伤害，并施加 5 秒生命易伤 I；扣 10 点魔力，用掉背包里的一支箭（创造模式、无限照原版）。
  - 什么都没射出（没锁到、没拉满）时不算一次射击，不扣耐久。
- **左键横着拉弓**（维护者试玩后加）：按住左键，弓横过来拉（三段拉弓模型的展示变换绕箭轴转 90°，第一、第三人称都是）。
  - 蓄力和右键一样快：每 0.2 秒攒一支虚影箭（每支 5 点魔力，最多 16 支），1 秒出实箭。
  - 没有框、不锁定、不响。
  - 松开左键：所有虚影箭在水平方向扇形射出（每档 3°，上下换成左右），实箭在正中；都不追踪，穿过并伤害碰到的每个目标（每个只伤一次）。伤害、易伤、扣费与右键相同。
  - 左键不再攻击、不挖方块。实现：按下左键时客户端发包，服务端开始拉弓；原版“右键没按着就松弓”这时改看左键（`WorldtreeKeybindsMixin`），松开左键走原版的松弓。
- **只有中间那支实箭用箭**：锁定和追踪箭只要魔力，背包里没箭也能拉弓锁定。
- **打断**（切换物品、放下）：清掉锁定，弓上不留虚影。已经扣的锁定魔力不退。
- **箭的寿命**：追踪箭 6 秒、实箭 4 秒后消散。追踪箭不能捡，实箭照原版规则可以捡回。两种箭都带 Logos 的生命拖尾。
- **箭的朝向**：箭身每刻直接朝速度方向（原版每刻只转过去两成）。追踪箭拐弯后立刻把速度发给客户端（`hurtMarked`）；以前没发，客户端一直按离弦时散开的方向画，箭会横着飞（维护者试玩发现）。客户端按箭这一刻实际移动的方向摆箭身（位置减上一刻位置），急转弯时也跟得上。
- **骷髅等生物**：手里就是原版弓，原版 AI、原版箭。

伤害、魔力、框的大小、锁定间隔都是先定的，等试玩再调。

## 3. 实现

| 文件 | 内容 |
|---|---|
| `tools/import_worldtree_bow.py` | 从交付资源包生成静止和三段拉弓模型、物品定义、箭贴图（原版布局，实箭与虚影各一张）、锁定界面贴图（藤蔓框、藤圈） |
| `tools/worldtree_chime.py` | 合成 16 个锁定音：很轻的玻璃叮，基音加几条泛音，高泛音衰减快；3 毫秒升余弦起音，没有噪声和咔嗒 |
| `item/WorldtreeBowItem.java` | 拉弓、锁定、放箭 |
| `worldtree/WorldtreeAim.java` | 锁定框的几何、选目标、伤害公式（服务端判定，客户端按同样的数画框） |
| `worldtree/WorldtreeDraw.java` | 拉弓状态组件：开始的刻、各次锁定（目标与时刻）、实箭出现的刻；只同步不存档 |
| `worldtree/WorldtreeArrow.java` | 箭实体：追踪、生命伤害、易伤 |
| `client/worldtree/WorldtreeArrowsModel.java` | 物品模型 `logos_dimension:worldtree_arrows`：弓上的实箭和虚影箭 |
| `client/worldtree/WorldtreeHud.java` | 藤蔓框与锁定标记 |
| `client/worldtree/WorldtreeArrowRenderer.java` | 飞行的箭（虚影箭半透明自发光） |
| `client/worldtree/SidewaysProperty.java`、`mixin/WorldtreeKeybindsMixin.java` | 横着拉弓：换横过来的拉弓模型；按住左键时不松弓 |

几处做法：

- **同步**：拉弓状态是弓上的物品组件，跟着装备同步。所以别的玩家也看得到弓上的虚影箭，不另发网络包；不存档，读档不会带着上次没放的锁定。
- **弓上的箭**：用原版的 `ModelLayers.ARROW` 网格。按三段拉弓里那支箭量出的搭箭点、箭头放在弓上，横截面收窄到原来的 0.45（原版箭羽是箭长的 5/16，放到这支箭的长度太宽）。虚影箭在弓面上上下交替散开，每档 3°，16 支时到 ±24°；第一人称收一半。
- **第一人称的摆法**：原版拉弓动画是按原版弓贴图的朝向写的。交付的第一人称展示（立着的大弓）套上去，箭会横着指向屏幕右边，静止时弓也离镜头太近（维护者试玩：拿弓的姿势不对）。静止和三段拉弓都改用由原版弓的第一人称展示换算的变换：
  - 箭（模型 +X）对准原版贴图里箭的方向；
  - 弓身（+Y）对准原版的弓梢连线；
  - 握把放在原版握把的位置，大小与原版相同。
  第三人称、物品栏、掉落物仍用交付的展示。
- **锁定标记**：每帧记下镜头的位置、视图旋转与投影，把锁定的生物投到屏幕上。框四角用同一个角转 90° 摆放：界面会剔掉镜像翻过去的面片。
- **扣费检查**：测试里逐刻核对每次锁定的扣费，因为 Logos 回魔快，整段比较会被回复吃掉。

## 4. 测试

```text
./gradlew test -PlogosJar=… -PorchestraJar=…
./gradlew runClient -PlogosJar=… -PorchestraJar=… -PldTest=group:worldtree_bow -PldTestHeadless -PldTestWindow=1280x720
```

单元测试 `WorldtreeBowTest`：锁定框几何与转向、伤害随锁定数增长、扇面不重叠、物品定义与拉弓模型、音效与贴图齐全。

客户端场景 `worldtree_bow`：前方五只僵尸在框里，一只在框外（偏 64°），一头牛在框里。真实按键拉弓，依次检查：

- 只锁框里的敌人，前五次锁的是五只不同的僵尸；
- 拉满出现实箭，每只锁定的都有屏幕标记，锁满 16 个；
- 每次锁定恰好扣 5 点、放箭扣 10 点；
- 追踪箭都打中、框外的和牛没受伤；
- 正中那只挨了实箭、有生命易伤 I，只用掉一支箭；
- 飞行中的虚影箭，画箭用的朝向与实际移动的方向夹角小于 25°（去掉修复时这项会失败）；
- 左键横着拉：没有框、不锁定，攒满 16 支、出实箭；松开后扇形打到多只僵尸，实箭穿透打到正中那只身后的一只。

第一、第三人称都截图。
