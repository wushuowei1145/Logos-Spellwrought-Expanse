# 群誓·狼牙长枪

附属的第一把长枪（物品 `logos_dimension:pack_oath_spear`，战斗武器编号 6）。美术交付在仓库外的 `art/pack_oath_spear/v02`，
动作由 `tools/oath_spear_moves.py` 按编排烘焙，玩家第三、第一人称各一份。动作风格按欧洲（罗马、斯巴达）的枪术：低位双手构、
弓步直刺、过肩反手刺，再加上大开大合的横扫、上挑和转枪。

## 1. 交付检查

- 153 个方块（v01 的 65 个原样保留，新加 88 个），78 个带旋转，角度都是 0 / ±22.5 / ±45，坐标在原版范围内。
- 贴图 32×40，不是正方形，物品模型的 UV 按横纵分别归一化。
- 网格原点在主握点：下段皮握在网格 y ≈ −4，上段皮握在 y ≈ 17.4（銎口下方），枪尾 −16，枪尖 27.4。
  第三人称 1 倍时枪长约 2.7 格。
- 交付的物品模型是网格 × 0.65 再平移到 (8, 8, 8)。魔力缠绕按物品模型表面定位，要求物品模型像素 = 网格 + (8, 1, 8)
  （与长剑、打刀相同），所以 `tools/import_oath_spear.py` 重新生成物品模型，并把各视角的展示变换按同一组几何换算，
  拿在手里、掉在地上、物品栏里的样子与交付一致。
- 没有剑鞘部件；不画背着的枪（拔枪前、收枪后由原版接管，原版不画背上的东西）。

## 2. 招式

| 招式 | 时长 | 说明 |
|---|---|---|
| `draw` | 1.3 秒 | 右手越过右肩抓住背上的枪，举过头顶平转两圈，压下来左手接住，收成待机 |
| `idle` | 2.4 秒循环 | 低位双手构：左肩在前，右手把枪尾收在右胯，枪尖平指前方略向上 |
| `thrust_1` | 0.5 秒 | 弓步直刺：前手不动、枪杆从中滑过；张角 40° |
| `sweep_2` | 0.62 秒 | 拧腰横扫：从右后方一记大弧扫到左边；张角 120°，伤害 0.9 倍 |
| `overhand_3` | 0.66 秒 | 斯巴达式过肩刺：枪提到右肩反手握住，左臂像持盾一样前护，自上而下扎出；张角 40°，伤害 1.15 倍 |
| `launch_4` | 0.86 秒 | 上挑：压低枪尖，自下而上大挑，命中的目标被挑上半空（`effect: launch`）；张角 70°，不击退 |
| `flurry_a/b/c` | 各 1 秒 | 按住右键的连刺，每段 8 刺、落点各不相同（三段用不同的随机种子）；伤害 0.1 倍、张角 30°、不击退、每下按蓄满结算（`effect: flurry`） |
| `slam` | 1.15 秒 | 连刺满三秒后：右手伸向身侧、枪在右侧竖直面里向后转一圈，举过头顶左手接住，双手砸下（`effect: slam`）；伤害 1.6 倍、张角 80° |
| `sheathe` | 1.45 秒 | 左手松开，举过头顶平转一圈，顺势背回身后，右手松开 |

左键连击按长剑的规则缓冲（出招 0.08–0.1 秒后的左键记下，到 `cancel` 接下一段），攻速基准 1.4（物品攻速）。
连击任一下命中之后按住右键，立即转入连刺：挑飞之后马上接连刺，目标还在半空。连刺中途松开右键立即回到待机；
三段连刺播完自动下砸，下砸期间松手也会砸完。还按着右键时，下砸收势后重新开始连刺。

物品：铁级，攻击伤害 7、攻速 1.4，攻击距离比原版多 1 格（`entity_interaction_range` +1）。

## 3. 击飞（`dev.logos.dimension.combat.Airborne`）

- **时长与高度按体型**：体型系数 = (玩家体积 ÷ 目标体积) 的立方根，夹在 0.35–1.5。玩家体型浮空 32 刻（1.6 秒）、升 1.9 格；
  时长 = 32 × 系数（10–48 刻），高度 = 1.9 × √系数（0.9–2.3 格）。铁傀儡约 16 刻，劫掠兽约 14 刻，鸡 48 刻。
- **非玩家在空中什么也做不了**：期间临时打开原版 NoAI（不走 AI、不受重力），由服务端按刻沿“上升 7 刻—悬停”的路线移动
  （`Entity.move`，碰到天花板会停）。结束时恢复原来的 AI 设置，交给原版重力落下；原本就关着 AI 的（训练木桩）放回原高度。
  期间实体带标签 `logos_dimension.airborne`，卸载或崩溃后再加载时按标签恢复 AI。
- **玩家照常行动**：给一个向上的初速度，到顶后临时把重力属性归零悬停，结束时撤掉（临时修饰，不存档）。
  服务端悬空 80 刻会以“非法飞行”踢人，所以玩家的浮空总长不超过 70 刻。
- **不会被挑飞**：`#logos_dimension:airborne_immune`（末影龙、凋灵）、骑乘中或被骑乘的、旁观者和正在飞行的玩家。
- **连刺**：刺中浮空目标伤害翻倍，每下延长 3 刻（剩余不超过 24 刻），并被顶高一点点；一秒八刺时浮空只会越来越长，打完一整套前不会落地。
  浮空目标不受击退。
- **下砸**：把自己挑起、在攻击距离外 2 格以内的浮空目标也算进来（看得见即可，不必在锥形里）。砸中的浮空目标结束浮空、
  直接移回地面，按原版摔落流程（`fallOn` → `causeFallDamage`，摔落伤害类型）结算：摔落距离计入额外的 12 格，
  玩家体型约 11 点。摔落保护附魔、免疫摔落的生物、干草块之类照常生效。枪尖落地处砸出尘土和重锤落地的声音。

## 4. 枪尖残影（客户端）

连刺每刺到头（动作标记 `tip_fx`，与 `contact` 同一时刻），在枪尖放出一枚枪头形状的半透明淡钢蓝光影：箭头对准这一刺的方向，
0.2 秒内继续往前冲出约 1.3 格，边走边拉长、变窄、淡出。贴图 `textures/vfx/spear_tip_ghost.png` 由导入脚本从枪头方块的正面渲染，
枪尖朝贴图右方，尾部（銎口一侧）渐隐。

每个客户端按同步来的招式自己取样，看得到这名玩家的人都看得到，不需要网络包。位置取第三人称骨架算出的枪尖（与玩家渲染层同一串变换）；
本机第一人称时改用第一人称骨架，经镜头换到世界坐标（不计视角摇晃）。代码在 `client/vfx/SpearThrustGhosts.java`。

## 5. 编排与烘焙

`tools/oath_spear_moves.py` 用 `combat_author.py`（打刀那轮做的编排、无腕关节手臂求解与烘焙），为长枪新加了：

- **手沿枪杆滑动**：关键帧的 `rpos` / `lpos` 是手握在杆上的位置（网格单位），骨架的 `grips` 给默认值（长枪右手 −4、左手 8；
  打刀仍是 0.65 / −1.1）。`grip` 关键帧始终是右手的位置，所以改 `rpos` 就是杆从手里滑过。
- **前手不动、杆滑过（`lmode: slide`）**：左手的目标点投到枪杆上，取够得着的那段杆上离目标最近的点（骨架的 `slide` 给可握范围），
  连刺和直刺时前手稳住、枪从中穿出。
- **转枪（`raxial`）**：杆在拳中绕前臂转，方块拳头看不出这个转动，求解只算杆偏离“垂直于前臂”的角度、前臂不自转。
  拔枪、收枪的头顶平转（前臂竖直）和下砸前的侧面风车（前臂向外平伸）都用它。
- **同名标记可以有多个**：连刺一段 8 个 `contact`、8 个 `tip_fx`；同一时刻有几个标记时，导出的 timeline 值写成数组。

预览图和 GIF 在仓库外的 `art/pack_oath_spear/anim_v01`。改编排后重跑：

```bash
uv run --python 3.12 --with numpy --with pillow python tools/oath_spear_moves.py "<Minecraft MOD>/art/pack_oath_spear/anim_v01" --gif
```

打刀的动作重跑后与提交的文件逐字节相同（这轮对 `combat_author.py` 的改动不影响打刀）。
