# 森林精灵（树妖）

附属模组第一个随机外观种族，是 [精灵森林](ELVEN_FOREST.md) 的居民。通用规则见 [NPC 随机外观方案](NPC_APPEARANCE.md) 和 [NPC 人口与繁殖](NPC_POPULATION.md)，本页只写这个种族自己的内容。

本文是规划，**尚未制作**。数字和清单都是第一版，制作时可以调整。

## 1. 定位

- **名称**：种族叫「森林精灵」，和群系名一致。更接近植物的「树妖」风格留给德鲁伊、长者和重要 NPC。
- **三个辨识点**，所有变体都必须有：
  - 精灵耳；
  - 植物风格的服饰；
  - 发色以绿色为主，有不同的绿，长者偏枯黄。
- **和森林协调**：群系家具与照明是浅木色、苔绿色和柔金色，NPC 配色向它靠拢；发光的小果子对应森林里的叶灯和柔金光点。
- **人口**：从巨树核心诞生，不需要两两繁殖（人口文档第 4 节）。新生精灵以幼年出现，使用中性幼年模型。

## 2. 参考图与两档细节

维护者提供的概念参考图（绿色长发、枝冠加发光果、精灵耳、奶油色泡泡袖、叶片连衣裙、树皮腰封、多层叶裙、缠藤短靴）用来定风格。参考图不进仓库，美术按规范自行绘制。

它的细节量远超普通 NPC 预算，所以分两档：

- **重要 NPC 档**：照参考图完整制作，例如世界树的守护者或长老。
- **普通居民档**：保留轮廓和配色，细节画进贴图：
  - 叶裙用 2–3 层带透明叶缘的薄片，锯齿状下摆画在贴图里（渲染器是透明裁切、双面显示）；
  - 藤蔓画在袖子和靴子上，不做成方块；
  - 发光果每人最多 3–5 颗，放进 `ysmGlow` 发光骨骼；
  - **发梢渐变成叶片**：发根深绿，发梢浅黄绿，末端画成叶尖。这是种族标志，用 5 级发色色阶就能做出来。

## 3. 身体

- 约 3.5–4 头身，体型偏纤细；体型只做纤细、标准两种。
- 显示身高约 1.65–1.85 格。
- **精灵耳**：短尖耳、长尖耳两种；耳朵骨骼另加 ±8° 的随机上扬 / 下垂角度。
- **肤色**：象牙白、浅粉、暖桃、浅麦；稀有的淡青色。
- **第一批身体**：成年女性 + 中性幼年。成年男性放到第二批。头部按外观方案第 3.2 节统一，补男性时头部零件不用重做。

## 4. 成年外观段与配色权重

| 发色色阶 | 青年 | 成年 | 长者 |
|---|---|---|---|
| 嫩芽绿（亮黄绿） | 高 | 中 | — |
| 森林绿 | 中 | 高 | 低 |
| 薄荷浅绿 | 中 | 中 | — |
| 松针墨绿（偏蓝） | 低 | 中 | 低 |
| 苔藓暗绿（偏灰） | — | 中 | 中 |
| 枯草黄 | — | 低 | 高 |
| 落叶褐 | — | — | 高 |
| 霜白绿（偏银） | — | — | 中 |
| 秋枫红（稀有，约 3%） | 低 | 低 | 低 |

- **瞳色**：叶绿、青碧、琥珀、浅金；长者可以出现褐色。
- **眼型**：长者多半闭的垂眼，青年多大圆眼。
- 幼年的发色按青年那一列抽。

## 5. 零件库（第一批）

**成年发型（8 套）**：及腰直长发、低双马尾、齐肩短发、高马尾、侧编辫、披肩卷发、盘发（多见于长者）、夹叶的蓬松长发。

**幼年发型（3 套，中性）**：短碎发、齐耳短发、小束发。

**头饰（单独一项）**：枝冠加发光果、花环（花色单独一个色阶通道）、叶片发卡、藤编发带、无。

**五官**：眼型 6 种，眉、嘴各 3 种。

**服装（按职业）**

| 职业 | 款式 |
|---|---|
| 居民、采集者 | 奶油色泡泡袖上衣、叶片短裙、树皮腰封、藤绕短靴（参考图简化版） |
| 守林人 | 带兜帽的叶片短斗篷、束腰短衣、绑腿 |
| 书阁学者 | 长袍加叶片披肩（对应树心藏书区） |
| 德鲁伊 | 长拖尾叶袍、枝杖 |
| 长者 | 枯叶披风加长袍 |
| 幼年 | 中性的叶片短袍 |

职业清单按群系现有设施推测，剧情设定确定后再调整。

**颜色通道**

| 通道 | 选项 |
|---|---|
| 头发、肤色、瞳色 | 见第 3、4 节 |
| 服装主色（叶片） | 春绿、夏绿、深林绿、秋黄（稀有） |
| 服装辅色（布料） | 奶油白、亚麻、浅苔绿 |
| 点缀色 | 树皮褐、浅木色 |
| 发光色 | 柔金（默认，与森林叶灯一致）、月白、萤青 |

发光果可以放进常驻叠加层，做与森林光点同步的 6 秒呼吸明暗。

## 6. 方块预算（普通居民，上限约 300）

| 部分 | 方块数 |
|---|---|
| 身体加耳朵 | 约 60 |
| 一套发型 | 60–90 |
| 一套服装 | 60–90 |
| 头饰加发光果 | 10–30 |

## 7. 制作顺序

1. 共用的成年女性身体加精灵耳，定比例、头部标准和标记色。
2. 原型：直长发、双马尾两套发型，居民服装，三条发色色阶；验证组合、合成、预算。
3. 中性幼年身体和幼年零件，接上树生和成长。
4. 补长者（枯黄发色、半闭垂眼）和守林人。
5. 第二批：成年男性身体及其服装。
6. 按参考图完整制作一个重要 NPC。
