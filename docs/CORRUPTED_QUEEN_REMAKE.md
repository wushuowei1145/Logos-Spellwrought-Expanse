# 腐化女王重做设计

2026-11-16 维护者接手 #271（腐败精灵森林）与 #273（核心战）后的重做方案。森林与世界树生成、女王模型与动画、入场与结局演出继续复用；战斗玩法按本文重新设计。实现完成后，把定下来的部分并入 [BLIGHTED_ELVEN_FOREST.md](BLIGHTED_ELVEN_FOREST.md) 和 [QUEEN_CORE_BATTLE.md](QUEEN_CORE_BATTLE.md)，本文只留设计取舍。

## 1. 基调

- 参照《奥日》《终焉之莉莉》：腐败是看得见的，清理腐败本身就是推进。森林里拆掉的每个核心都会削弱女王；战斗里清掉的每片污秽都会少一份麻烦。
- 和平与希望：女王是被腐败之心控制的受害者，不是恶人。精灵公主是她的旁系亲属（沾亲带故，不是母女），来救她、救森林。不写伤感的母女剧情。
- 一段区域的剧情和 Boss 打完，有一个角色作为同伴加入：白梅之后，这里是精灵公主。

## 2. 已定的规则

### 2.1 改名

| ID | 旧名 | 新名 |
|---|---|---|
| `blight_memory` | 猩红污秽 | 腐败污秽（和原有的腐败污秽同名，只是多记了原材质） |
| `queen_heart` | 女王的腐败核心 | 腐败之心 |

ID 不变，旧存档照常读。

### 2.2 腐败伤害：生命伤害的子类型

照狐火（奥秘的子类型，见 [FOXFIRE.md](FOXFIRE.md)）做：

- 伤害类型复用现有的 `logos_dimension:corruption`（腐败方块的接触伤害已经在用），不另注册。
- 结算同生命：走 Logos 的 `Effects`，生命强化、生命抗性、法术抗性照常算；护甲不减。
- 谁的生命伤害算腐败：施法者或攻击者是腐败一方（女王、腐败之心、腐败衍生物）时，它们打出的生命伤害都是腐败伤害。玩家写不出腐败伤害（生命本来就不能写）。
- **打中腐败衍生物时改为治疗**：同原版瞬间伤害对亡灵，伤害量变成回血量。女王的范围攻击会治疗她自己的衍生物——引开衍生物再躲招是玩法的一部分。腐败方块的接触伤害对衍生物仍然无效，不回血（否则它们站着就能回满）。
- 女王与腐败之心的全部攻击都改用腐败伤害，包括 Logos 载页法术。
- **实现**：和狐火共用同一组 `Effects` 注入点（`FoxfireEffectsMixin` 那几处），把"换伤害来源"抽成通用的子类型表：奥秘→狐火、生命→腐败。不再新开一组 mixin。命中特效同样按子类型换，取代 #273 里包住所有法术的 `QueenSpellRuntimeMixin` 和 `QueenLifeVfxMixin`。

### 2.3 女王的抗性

Logos 的抗性相乘（`(1 − 法术抗性) × (1 − 元素抗性) × (1 + 易伤)`），所以不设总的法术抗性，按元素给：

| 伤害 | 实际承受 | 做法 |
|---|---|---|
| 火（Logos 火、原版火和岩浆） | 50% | 火元素抗性 0.5；原版 `is_fire` 标签的伤害另乘 0.5 |
| 狐火 | 50% | 奥秘元素抗性 0.5 |
| 其他奥秘 | 15% | 奥秘 0.5 之外，不是狐火的奥秘再乘 0.3 |
| 物理（法术）、冰霜、雷电 | 15% | 元素抗性 0.85 |
| 生命 | 130% | 不设抗性，生命易伤 0.3 |
| 虚空 | 100% | Logos 的虚空本来就不吃抗性 |
| 原版魔法（药水等） | 15% | 同女巫，`witch_resistant_to` 乘 0.15 |
| 普通近战与箭 | 100% | 不吃法术抗性，只吃护甲和核心庇护 |

表写进数据文件（`data/logos_dimension/creature_traits/corrupted_queen.json`），按元素、伤害类型、伤害类型标签三种键填，以后别的 Boss 照着填。

### 2.4 核心庇护（像末影龙的水晶）

- 女王周围每有一个还活着的腐败核心（含区域核心），受到的伤害减 3%，最多减 60%。
- 范围：女王水平 64 格内。每秒从 `CorruptionNetworks` 已有的核心表里数一次并缓存，受伤时只读缓存，开销可以忽略。
- 除虚空外的伤害都吃这个减伤。不吃的伤害用标签 `logos_dimension:bypasses_blight_ward` 列出（Logos 虚空、`out_of_world`、`generic_kill`）。
- 被计入的核心朝世界树连一条细血管（客户端画，按核心坐标，不生成实体），玩家在林子里就能顺着找。血条上显示"供养 N"。
- 生成的腐败森林每个区块有一个区域核心，世界树附近 64 格内大约 50 个，封顶 60% 后正好要拆一大半才降下来。

### 2.5 玩家的生命伤害：自然之力

自然之力（`natures_force`，第四阶 10 点生命伤害）目前没有获取途径。这里由精灵公主在世界树门口交给玩家（见第 3 节），配合女王 30% 生命易伤。战后可以再补配方。

## 3. 区域流程

1. **进入腐败森林**：一路有区域核心，拆掉会净化那 16×16 列（已实现）。
2. **世界树门口遇到精灵公主**：
   - 由腐败之心的方块实体在世界树入口的标记点生成，每棵树一位，存 UUID，不重复；有玩家进入范围才出现。门口是去打女王的必经之路，所以一定能遇到。
   - 她站在门口一小片已经净化过的地面上，可以对话（复用同伴的对话菜单）：讲腐败之心、外面的核心在供养女王（报出当前的 N），交出自然之力。
   - 战斗外玩家打不死她；暂时卸载不算她不在了。真的不在了（比如被命令清掉），腐败之心才在门口重新生成一位。
   - 已经收她当同伴的玩家去打另一棵世界树：门口不再生成，由他的同伴公主担任这个角色。
3. **绕路进大厅也跳不过她**：挖墙、末影珍珠进去，女王坐着不起身，要公主到场才开战。
4. **世界树大厅**：女王战（第 5 节）。
5. **结局**：净化镜头 → 变白 → 走出镜头 → 公主对话 → 一起走（第 7 节）。

## 4. 场地

现在树心安全内厅半径 16（直径 32），树干壁厚约 7 格，大厅放不下守护、出怪和躲招。

- **腐化世界树的树干单独加粗**：腐败让树心膨胀，腐化变体的树干半径加 8 格左右，大厅半径扩到 24（直径约 48），高约 36。健康世界树不变。腐化变体本来就由 `tools/blighted_elven_forest.py` 从健康模板转换，加粗只改这个变体的体积再切片。
- **布局**（模板坐标，入口是北侧原有的高拱门 -z；已在第 2 步做完，见 [BLIGHTED_ELVEN_FOREST.md](BLIGHTED_ELVEN_FOREST.md)「树心战场」）：
  - 中央：腐败之心悬在地面上方 7 格，八条主血管接到墙上（按新半径重新算接点）。
  - 入口对面（南，+z 18.5）：树根祭坛，三层收小，顶面高出地面 3 格，底径约 10 格，公主在这里净化。守护有明确的方向：玩家在祭坛和中央之间来回补位。
  - 墙脚三个出怪壁龛（45°、180°、315°，往树壁里挖 6 格，不打通到外面），是衍生物的出口。出口附近的腐败污秽清掉以后，那条隧道出怪变慢。
  - 沿墙一圈环形高台（顶面 y = 10，入口拱门上方断开），血管接头在它上方一人高处，顺着三道树根坡道上去砍。
  - 四条从墙上探进地面的粗树根，加一道西侧贴地拱起的树根，当掩体躲直线攻击。
  - 北侧入口隧道兼作结局时玩家走出去的出口。运行时坐标在 `data/logos_dimension/queen_arena.json`。
- 地板沿用腐败脉光的新纹路。

## 5. 战斗

### 5.1 三个阶段

**阶段一：被操控的女王（单挑）**
- 公主留在门口，不跟进。
- 女王近战加三种 Logos 腐败法术（散射、射线、剑雨），全部是腐败伤害。
- 范围攻击在地上留下腐败污秽，衍生物站在上面会被女王的腐败伤害治疗；玩家边打边清污秽。
- 女王血量打空 → 她跪地挣扎（复用 `queen_resist`），进入阶段二。

**阶段二：守护净化**
- 入场镜头：复用 `CameraShots`，几秒，公主跃上树根祭坛，开始净化。
- 净化光束：公主到腐败之心之间一条持续光束，**直接用 Logos 的生命光束**（`Vfx.beam(..., Element.LIFE, ...)`，每刻重发、稳定 id），以后 Logos 改生命光束的样子，这边自动跟着变。
- 公主的净化进度 0 → 66%，大约 50 秒；进度在她身边画成一个逐渐扩大的净化圈，把地上的腐败污秽推回去。
- 腐败之心从三条隧道放出几波衍生物；衍生物优先打公主。腐败之心自己放环形腐败潮和直线荆棘（复用 #273 的 `core_wave`、`core_thorns`），潮带缺口，要跳过去或找缺口。
- 女王在控制下冲向祭坛打断公主。玩家打她攒硬直，生命伤害算两倍硬直；硬直满了她被压回中央。
- 砍断环形高台上的血管：每断一条，下一波衍生物少一些、来得慢一些。
- **净化窗口**：进度到 33% 和 66% 时，腐败之心被压低、露出约 8 秒。窗口里每次命中按腐败之心最大生命的百分比扣（生命伤害 6%，其他 2%，每次最多扣到本段为止）。心脏生命分三段，每个窗口最多打掉一段。窗口结束没打完这一段：心脏重新抬起，进度退回 15%，再到这个刻度时窗口重开。

**阶段三：女王挣脱**
- 第二个窗口打完，女王挣断控制（复用 `queen_chain_break`），回身用权杖束缚腐败之心（`queen_bind`），不再攻击玩家和公主。
- 腐败之心狂乱：腐败潮加快，污秽从中心漫得更快；公主的进度 66% → 100% 走得更快（约 25 秒）。
- 100% 时最后一个窗口，打掉最后一段 → 女王拥心共殒（复用 `queen_sacrifice` 和现有结局）。

### 5.2 公主

- 战斗里是按剧本行动的友方 NPC，不归哪个玩家所有；打赢后另生成同伴版（同白梅：Boss 本体和同伴是两种实体）。
- 外观先用普通森林精灵（`NpcRenderer` + 森林精灵零件，固定一套外观），实体 ID 单独为 `elf_princess`，以后模型做好直接替换。
- 有自己的血量（约 120）；动作用 `MoveRunner` + 招式文件：引导净化、身边一圈防御脉冲（推开贴身的衍生物，冷却 10 秒）、倒地、起身。
- **倒地**：进度暂停并慢慢回退（每秒 1%）。玩家在她身边按住使用键 3 秒扶起；没人扶，20 秒后她自己起来，进度再扣 25%。不会因为她倒地直接判输。

### 5.3 失败与重置

- 所有玩家战死或离开 40 格超过 30 秒：战斗重置。女王回到坐姿，公主回到门口，净化进度清零，地上战斗中长出的污秽消散。
- 阶段一不存档进度之外的东西；阶段二、三的进度和腐败之心剩余段数存档（同 #273 的做法）。

### 5.4 数值（初值，写进数据文件）

| 项目 | 值 |
|---|---|
| 女王阶段一生命 | 700，护甲 12 |
| 女王普通难度单击 | 近战 14–18，法术 12–16；简单 ×0.75，困难 ×1.25 |
| 腐败之心 | 三段，每段 300；窗口内按百分比扣 |
| 多人 | 生命 ×(1 + 0.5 ×(人数 − 1))，人数按入场时 40 格内的玩家 |
| 核心庇护 | 每核心 3%，最多 60%，64 格 |
| 净化 | 阶段二 0→66% 约 50 秒，阶段三 66→100% 约 25 秒 |
| 公主 | 生命 120，倒地自起 20 秒、扣 25% |

命中形状（扇形半径和角度、根浪速度、直线长宽、环宽）、出招顺序、法术耗魔也进招式文件（`combat/movesets/corrupted_queen.json` 的 Boss 专用字段，照 `ShiraumeMoves.Extra` 的做法），代码里只留形状的种类。

## 6. 视觉

- **VFX**：女王的腐败法术、腐败之心的潮与荆棘、血管断裂、窗口开合，用 Photon 和 `ShaderPackOverlay` 画，贴图按 `logos:` 路径复用。腐败子类型的命中特效按子类型换色（同狐火），不再按施法者上下文包住所有法术。
- **后期**（附属的后期系统，全部按世界坐标取噪声，不贴屏幕纹理）：
  - 把 #273 的 `QueenPurificationScreen` 改成通用的"世界球体着色"通道：一次画多个球，每个球有中心、半径、模式（染腐 / 净化）和噪声边缘。战斗里用它画腐败潮的染色、公主身边的净化圈；结局沿用它的大范围净化。
  - 腐败之心每次搏动，从心脏向外推一道很淡的去饱和波（同一个通道）。
  - 窗口打开：一次黑白闪（`ScreenEffects.flash`，遵守每秒不超过 3 次和"隐藏闪电的闪烁"）+ 电影蒙版。
  - 血管、净化光束的亮部交给 `GlowBloom`。
- 新通道和顺序变化同步到 [CINEMATICS.md](CINEMATICS.md)，改了后期在 [SCREEN_EFFECTS.md](SCREEN_EFFECTS.md) 列的 Sodium、Iris 和两种光影包下各跑一遍。

## 7. 结局

1. **净化镜头**：沿用现有的拥心共殒 → 镜头升空看世界树和周围林地恢复。
2. **画面渐白**：净化镜头最后约 1.5 秒画面逐渐变白（新的"渐变到颜色"效果，加在 `ScreenEffectRenderer` 里，和电影蒙版同一处，慢变不闪）。
3. **走出镜头**（3A 式运镜）：
   - 白屏期间，服务端把玩家放到大厅里靠北的入口一侧、面朝树洞出口（`queen_arena.json` 的 `exit_walk`）；镜头放在玩家前上方，看向出口的光。
   - 画面从白色淡回来。玩家角色从画面外（镜头后方）走进画面，走几步，抬头看外面的光，停下。
   - 镜头平滑回到玩家身上，恢复操作。
   - 实现：给 `CameraShots` 加一个可选的"演员脚本"：镜头停留期间，客户端代为操作本地玩家（向前走 N 刻、转头到某个俯仰角、停），移动仍是玩家自己的正常移动，服务端照常校验。以后别的过场也能用。多人时每人一条错开的路线。
4. **公主在树洞里蹲着观察什么**：腐败之心落下的地方长出一株新芽，她蹲在旁边看（蹲姿用原版潜行姿势，森林精灵模型没有专门动作时退回它）。
5. **对话**：随便聊刚才的战斗（几句可换的台词，按战斗里发生的事挑：她倒地过几次、玩家拆了多少核心、有没有扶她起来）。最后一个选项："要一起走吗？还有很多地方没有净化完……"
   - 选"一起"：她成为同伴，并教会玩家远程净化腐败核心的能力。
   - 选"再想想"：她留在世界树门口，以后找她还能再问。
6. **远程净化**：作为附属的隐藏法术词（同狐火的隐藏词），通过 Logos 的解锁接口在立契时解锁；它的生命效果打中腐败核心时，按拆掉核心处理（网络消散、按记忆还原）。具体写法另行设计。
