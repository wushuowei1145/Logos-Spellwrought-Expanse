# 凌霄仙剑与御剑飞行

维护者于 2026-11-08 指定：伤害按原版铁剑，攻速为铁剑的 1.5 倍，右键御剑，潜行下剑，每秒消耗 10 魔力，攻击使用菱形判定。同日接手后，维护者又要求：

- 重做挥舞动作，参考永劫无间这类动作，做一套符合仙侠宝剑的连招；
- 御剑时剑尖指向前进方向；
- 飞得快一些；
- 持续扣魔力。

本页按接手后的做法写。没有改变 Logos 版本号。

## 1. 交付检查

接手时按 [工作流](COMBAT_WEAPON_WORKFLOW.md) 第 3 节和第 11 节的清单逐项查了一遍。

| 项 | 结论 |
| --- | --- |
| 网格 | 原点在剑柄里，主手握点 0.65，剑尖 +Y，刃宽沿 X、剑面法线沿 Z；58 个方块，剑鞘 16 个单独成 `sheath`。符合。 |
| 物品模型 | 等于网格加 (8, 1, 8)，42 个方块（不含剑鞘）。符合，单元测试照查。 |
| 武器自己的骨骼 | 剑穗左右各三节、两个踏脚挂点、剑镡宝石，都挂在 `Weapon` 下。符合。 |
| 第一人称比例 | **不符合。** 网格多了 `first_person_scale` 0.725，渲染层把它乘进第一人称；但动作按 0.58 烘焙，实际画成 0.42，比烘焙时小。已删掉这个字段和渲染层的改动，第一人称按骨架的 `weapon_scale` 烘焙和渲染，与其他武器一致。 |
| 第一人称取景 | **不符合。** 根骨用了自己的 (13.8, -1.8, 0)、(0, 0, 10)，没有 `reach`，挥到头时剑在画面外。改用打刀、流火的取景：根骨 (15.13, -1.82, 0)、(0, 0, 12)，`reach` (-3, 3, -5)。每一式另写第一人称刀路，挥到头的剑留在画面里，手也够得着。 |
| 动作的制作 | **不符合。** 编排脚本要读仓库外的美术目录（本机没有）。导入脚本还事后改写动作文件，把飞行动作的根骨换成常数，并由代码生成招式文件。已改成：编排脚本直接读仓库里的网格、写仓库里的动作文件；导入脚本只拷网格、贴图和物品模型；招式文件手写维护，由单元测试核对。 |
| 攻速基准 | 招式的 `attack_speed_base` 原为 1.6，按 1.5 倍速播放，时长要除以 1.5 才是游戏里的长度。改成 2.4（本剑攻速），编排的时长就是游戏里的时长。 |
| 被弹反 | 有 `parried`（0.5 秒）和 `parried_npc`（0.8 秒）。符合，重新烘焙。 |
| 世界测试 | 原测试每刻把魔力上限锁成当前余额，用来排除自然回复。现在扣费已经算上回复，改为不锁，直接测面板上实际少了多少。 |

## 2. 获取与操作

`/give @s logos_dimension:lingxiao_sword`，或在“远行大陆”创造物品栏获取。

- **左键：** 清风、拨云、云月、凌霄四式连招，按住左键依次接上，第四式之后回到第一式。
- **右键：** 持剑待机时开始御剑。拔剑、挥剑和收剑途中不能起飞。
- **飞行中移动：**
  - 前后键沿视线飞，左右键水平侧移，跳跃键上升；
  - 抬头或低头配合前进可以升降，松开方向键就悬停。
- **潜行键下剑**，之后照常下落，会有摔落伤害。
- **飞行中不能挥剑。**
- **自动下剑：** 魔力不足、切换或丢弃仙剑、死亡、离线、跨维度时都会下剑，重登后不恢复临时载具。

| 属性 | 数值 |
| --- | --- |
| 基础攻击伤害 | 6，与原版铁剑一致 |
| 攻击速度 | 2.4，是铁剑 1.6 的 1.5 倍 |
| 耐久与工具材质 | 铁剑，250 耐久 |
| 攻击距离 | 玩家的 `entity_interaction_range`，默认 3 格 |
| 飞行耗魔 | 面板每秒实打实少 10（详见第 4 节）；创造模式不耗 |
| 最大移动速度 | 0.7 格/刻，约每秒 14 格（原 0.45，约每秒 9 格）；斜向输入归一化，不额外加速 |

## 3. 招式

### 3.1 路数

剑走轻灵，一式一条线。每式挥到头都定住一下，再接下一式：不定住的话，连起来像在乱挥。

左手不握剑：

- 平时负在身后（负手持剑）；
- 出招时捏剑指前引，或甩到身后头顶亮相。

参考了永劫无间长剑的节奏：

- 快劈起手，反撩接上；
- 第三式有一个看得出“剑在手里转”的大动作；
- 最后一记突刺收尾。

动作和美术都是自己做的，没有用第三方素材。

| 招式 | 动作 | 时长 | 接触 / 取消 |
| --- | --- | --- | --- |
| attack_1 清风 | 剑举到右上方，斜劈到左前下方收住，剑尖指着对手膝前。左手剑指先前引，劈下时甩向左后。 | 0.50 秒 | 0.13 / 0.40 |
| attack_2 拨云 | 剑在左下一沉，反手从左下往右上撩起，斜举过右肩。左手剑指收回胸前。 | 0.52 秒 | 0.12 / 0.40 |
| attack_3 云月 | 剑举到头顶平着绕一圈（云剑），落到肩高从右往左平斩。 | 0.70 秒 | 0.33 / 0.56 |
| attack_4 凌霄 | 收剑到右腰、左手剑指瞄准前方，弓步一记平剑直刺，左手剑指甩到身后头顶，定住亮相。 | 1.00 秒 | 0.20 / 0.70 |

**连段间隔：** 每两下之间隔 0.39 到 0.63 秒，都不短于攻速 2.4 的原版冷却（约 0.42 秒，差一刻以内），伤害不会被冷却吃掉。单元测试 `fourFormsChainWithFullStrengthSpacing` 检查这一点。

**没有手腕时的握法：** 玩家方块手臂没有手腕。每式定住时的剑向都按刀柄偏角挑过（扫描剑向，取方块拳头握得正的方向）。例如清风劈到左前下方就收住，不顺势甩过身体：甩过身体时刀柄偏角在 70° 以上，收住只有 40° 左右。各动作的平均偏角：

| 动作 | 平均偏角 |
| --- | --- |
| 待机 | 14° |
| 云月 | 21° |
| 拨云 | 27° |
| 清风 | 43° |
| 凌霄 | 46° |

凌霄的直刺剑与前臂同向，这是没有手腕时直刺的固有样子。

**剑在手里转：** 云剑和归鞘的剑花用 `raxial`，剑在拳中绕前臂转，方块拳头看不出来。

### 3.2 其他动作

- **出鞘（1.0 秒）：** 左手把剑鞘从左腰横托到腹前，右手越过身前握柄，沿鞘向右一展拔出，剑尖向上划一个立圆收到待机。剑比手臂长，鞘挂在腰侧时右手够不到拔出的位置，所以要横托过来。
- **归鞘（1.8 秒）：** 右侧挽两个剑花，左手横托剑鞘，剑尖找到鞘口向左推回去，鞘送回左腰，双手放下。
- **被弹反：** 剑被磕向右后上方，身子后仰露出破绽。玩家版 0.5 秒，NPC 版 0.8 秒。

**剑穗：** 动作里的剑穗按“视在重力”甩：重力减去剑柄尾的加速度，一节跟一节，越往下越慢，最多离开剑柄延长线 115°。御剑时剑穗由载具渲染层算：朝下垂，飞得越快越往后飘。

**第一人称：** 每一式都另写了刀路（关键帧的 `fp` 字段），挥到头的剑留在画面里，手够得着剑，不脱手。另外：

- 腰的拧转按三分之一；
- 左手放在左下的画面外，后扬的剑指不会从脸前扫过；
- 云剑放到眼前上方转，剑花挽在画面右前方。

## 4. 御剑

### 4.1 剑尖朝向

脚下的剑不再画在骑手的骨架里，由载具 `FlyingSword` 自己画（`FlyingSwordRenderer`）：

- 剑面朝上，网格里两个踏脚挂点的中点落在两脚中间；
- 剑放大 1.8 倍；
- 第一人称低头就能看到脚下的剑。

朝向由服务端决定（`FlightRules`），每刻限速转过去，经原版实体旋转同步插值：

- **水平飞得够快时**（大于最高速度的 15%），偏航顺着飞行方向，每刻最多转 14°。
- **往回退时**（飞行方向与视线夹角超过 100°），剑尖仍朝视线，倒着飞，不在脚下掉头。
- **悬停或只升降时**保持原朝向，视线转开超过 50° 才跟过去，和原版身体跟头转一样。
- **俯仰：** 顺着剑尖方向往上飞时抬剑尖，往下飞时压剑尖，倒着飞时反过来；最多 25°，人还站得住。每刻最多变 5°。

骑手的身体转向剑尖方向，侧飞时侧身，但离视线不超过 75°，头仍看准星。剑的视锥剔除范围按整把剑算，不按载具碰撞体算。

### 4.2 起飞与落地

- **起飞（0.8 秒）：**
  1. 右手把剑竖在面前，左手剑指贴住剑身（御剑诀）；
  2. 一推把剑送出去，剑往前上方飞出、翻平、放大，绕回来落到脚下；
  3. 双手收成御剑站姿：右手剑诀立在胸前，左手负后。
- **交接：** 起飞动作在 `handoff` 标记（0.56 秒）那一刻把剑交给载具。之后骨架里的剑缩成 0，载具开始画；交接前载具不画。剑尖起始朝向取骑手当时的身体朝向，交接时不会转一下。
- **落地（0.6 秒）：** 脚下的剑翻起来飞回右手。

### 4.3 魔力

Logos 的自然回复每刻照常加魔力，默认每秒 6 点。原来只扣 10，面板净减少只有 4 左右。现在每刻扣“0.5 + 这一刻的自然回复”，回复加回来后面板每秒正好少 10。

- **回复的取值：** 通过 `LogosNatureBridge.regenerationPerTick` 读 Logos 的 `SpellModifiers.regenerationPerTick`；旧版 Logos 没有这个入口时按 0 算。
- **余额不足：** 不够一刻的消耗时保留余额、结束飞行，不扣成负数。
- **魔力条：** 拿剑时 Logos 不显示魔力条（它只跟着法杖），御剑时每半秒在动作栏报一次，样式与法杖相同：`☿ ██████░░░░ 120/200  御剑中 · 每秒 -10`。
- **续航：** 默认上限 200 时满魔力能飞 20 秒。

### 4.4 安全

以下行为没有变：

- 服务端决定速度、碰撞和魔力；
- 客户端只发原版输入包；
- 不修改 `mayfly`、`flying` 或重力；
- 碰撞体覆盖骑手头顶；
- 未加载区块和世界边界方向停止推进；
- 临时载具不保存。

## 5. 菱形判定

这是维护者明确要求的单把武器例外，其他武器的锥形判定不变。

- **形状：** 菱形近端在眼睛，远端沿视线到达原版攻击距离；中点最宽，横向半宽为攻击距离的 0.45 倍，两端收窄。另有垂直厚度，用来覆盖生物身体。
- **命中：** 用菱形棱柱和目标碰撞箱的交集判定，只结算真实交集点可见的目标，最多八个。
- **暴击：** 不强制最近目标暴击，沿用原版铁剑的暴击条件。

## 6. 制作

```text
uv run --with numpy --with pillow python tools/lingxiao_moves.py <预览目录> [动作名… | combo] [--gif] [--fp]
uv run python tools/import_lingxiao.py <美术目录>
```

- `lingxiao_moves.py` 调用 `combat_author.py`，分别烘焙第三、第一人称，直接写 `combat/animations/lingxiao_{tp,fp}.animation.json`；同时打印够不着的时段、刀柄偏角和剑尖离地高度。
- 预览放仓库外的 `art/lingxiao/anim_vNN`：
  - 每个动作一张四机位总览图；
  - `--gif` 出慢放 GIF，`combo` 是四式连起来的那一段；
  - `--fp` 按游戏里的第一人称取景做透视预览，看剑在不在画面里。
- 招式文件 `combat/movesets/lingxiao.json` 手写维护；改了动作时长或标记要同步改，`LingxiaoTest` 会抓不一致。

## 7. 检查

**单元测试 `LingxiaoTest`：**

- 菱形端点、中腰、大目标边缘交集、垂直瞄准；
- 带回复时二十刻正好少十点；
- 速度上限；
- 剑尖顺着飞行方向、倒飞不掉头、悬停跟视线；
- 俯仰限幅；
- 两个视角的动作与招式一致，`contact` 和 `cancel` 与招式文件对得上，取消点不早于命中；
- 四式连段间隔不短于冷却；
- 交接后骨架里不画剑、巡航时一直是 0，没有根位移；
- 单块剑尖、物品坐标等于网格平移、没有 `first_person_scale`。

**世界测试 `logos_dimension:lingxiao_*`：**

- 属性；
- 前摇命中；
