# 凌霄仙剑与御剑飞行

维护者于 2026-11-08 指定：伤害按原版铁剑，攻速为铁剑的 1.5 倍，右键御剑，潜行下剑，每秒消耗 10 魔力，攻击使用菱形判定。此次基于 main `2822f04`（#211），包含自然之力反射桥的崩溃修复；没有改变 Logos 版本号。

扣费为每秒 10 点；Logos 自然恢复仍照常生效，所以面板净减少量会小于 10。以当前前置每秒恢复 6 点计算，持续御剑时通常净减少约 4 点。

## 获取与操作

`/give @s logos_dimension:lingxiao_sword`，或在“远行大陆”创造物品栏获取。

- 左键：踏步斜斩、反手上挑、回身横斩；按住可接续三段。
- 右键：持剑待机时开始御剑。拔剑、挥剑和收剑途中不能强行起飞。
- 御剑时移动键沿视线前后移动，左右键水平侧移；抬头或低头配合前进升降，跳跃键上升，松开移动键悬停。默认键位为 WASD、空格。
- 潜行键下剑，默认 Shift。下剑后恢复正常下落。空中御剑不挥舞脚下的剑。
- 魔力不足、切换或丢弃所持仙剑、死亡、离线、跨维度时结束御剑；重登不恢复临时载具。

| 属性 | 数值 |
| --- | --- |
| 基础攻击伤害 | 6，与原版铁剑一致 |
| 攻击速度 | 2.4，是铁剑 1.6 的 1.5 倍 |
| 耐久与工具材质 | 铁剑，250 耐久 |
| 额外伤害倍率 | 无；仍走原版冷却、护甲、附魔、暴击条件 |
| 攻击距离 | 玩家的 `entity_interaction_range`，默认 3 格 |
| 飞行耗魔 | 每刻 0.5，20 刻合计 10，创造模式按项目其他武器惯例免耗魔 |
| 最大移动速度 | 0.45 格/刻，约 9 格/秒；斜向输入归一化，不额外加速 |

## 菱形判定

这是维护者明确要求的单把武器例外。其他武器的锥形判定不变。

菱形近端在眼睛，远端沿视线到达原版攻击距离；中点最宽，两端收窄。横向半宽为攻击距离的 0.45 倍，并给出垂直厚度以覆盖生物身体。准星抬头、低头时形状随视线转动，垂直视线用玩家朝向稳定横轴。

判定用菱形棱柱和目标碰撞箱的交集，不只看目标中心；只结算攻击距离以内、真实交集点可见的目标，最多八个。同载具和自己的驯服动物跳过。凌霄不强制给予最近目标暴击，使用原版铁剑暴击条件。

## 服务端飞行

`FlyingSword` 是只允许绑定玩家使用的临时载具，方向来自原版输入包，服务端决定速度、碰撞和魔力。没有客户端上传坐标的自定义接口，不修改玩家 `mayfly`、`flying` 或重力开关。碰撞体同时覆盖骑手的头顶，不允许借剑穿墙、穿天花板；未加载区块和世界边界方向停止推进。

飞行第一刻就开始付费，避免反复上下剑获得免费的一秒。余额不足 0.5 时保留余额并结束飞行，不扣成负数。实体类型必须允许序列化才能通过原版骑乘检查，但实例的 `save` 和 `shouldBeSaved` 返回 false，不进入区块或玩家根载具保存记录。

原版骑乘负责乘客定位与网络同步，客户端仅把此载具上的玩家从坐姿改成站姿，并沿用现有战斗渲染层绘制脚下的剑。没有替换玩家渲染器，没有强制第三人称，也没有新增 Mixin。

## 模型与动作

剑尖按维护者要求，改为一个斜转 45° 的方块，下半部嵌入延长的剑身，保留总长和剑尖挂点。六个尖端构件减为一个，整剑从 63 减至 58 个构件。美术通过代码绘制。

三连参考史诗战斗单手长剑的发力顺序和节奏，重新编排本剑握点与脚步；没有加入第三方动画资产或运行时依赖。收剑前保留右侧剑花一圈，接稳再对鞘。

美术源放仓库外。`tools/lingxiao_moves.py <美术目录>` 调用现有 `combat_author.py` 分别烘焙 TP/FP；`tools/import_lingxiao.py <美术目录>` 导入网格、贴图、物品模型、动作及招式。导入脚本移除离线舞台演示的升空、前进和侧倾根运动，游戏位移由载具实际完成。第一人称取景基准保留，网格 `first_person_scale` 为 0.725，与美术的 0.58 倍烘焙比例一致；不改其他武器共用骨架。
