# 奥义：同伴终结技、接力连携与玩家的最后一击

每位同伴有一个奥义，玩家也有一个，但玩家的只在全员连携放完以后才放得出来。玩家按 V 令同伴放奥义。在场的同伴在接力窗口里一个接一个都放过，就自动播连携切入（[CHAIN_CUTIN.md](CHAIN_CUTIN.md)），换场以后玩家进入「汇流」，再按一次 V 亲手放出最后一击。

设计来源是维护者的规范《同伴终结技与多人连携玩法机制规范》。这份文档写现在的代码怎么做，以及怎么给一位角色做她的奥义。

**现状（第一阶段，2026-11-28）**：公共入口已经做好：按键、号令轮盘、侧边小队、连携状态机、冷却和耗魔、选目标、接力馈赠的接口、切入和汇流、玩家最后一击的武器大类路由、客户端画面的接入点。四位同伴和玩家都先用**占位的一段**：站定、打一下、冒一团光点。各自的正式奥义（演出、技能效果、馈赠）由每位角色单独的任务做，见第四节。

## 一、玩起来是什么样

### 按键

V 键在按键设置的「同伴」一栏里，可以改。

| 此刻 | 怎么按 | 做什么 |
|---|---|---|
| 常态、接力窗口里 | 短按（松手时触发，按住不到 0.2 秒） | 准星 24 格内对着某位能放的同伴，就令她放；否则按队伍顺序（`Companions.ALL`），令第一位能放、这一轮还没放过的同伴放 |
| 常态、接力窗口里 | 长按（≥ 0.2 秒，客户端配置 `ultimateHold`，0.15–0.6） | 打开号令轮盘：在场的同伴一位一格，鼠标甩到谁、松开 V 就是谁；指针在中间的圈里松手是取消；不暂停世界 |
| 汇流（切入换场后 5 秒） | 一按下就放 | 放玩家自己的最后一击 |

另有「同伴：第一位～第四位的奥义」四个热键，默认不绑，按在场的队伍顺序直接点名（给鼠标侧键用）。

V 在 Logos 里也是化身时的「变回」、附身时的「本能」、骑巨像时的「切换驾驶」。在那几种场合里 V 让给 Logos，平时才是奥义（`UltimateClient.COMMANDING`）。

能放的意思是：在场（召唤在外面、活着、没在撤退、48 格以内，和连携切入点名的口径一样）、冷却好了、这一轮没放过、没在演。

### 画面上的反馈（不写字）

- **侧边小队**（`UltimateHud`）：画面左边一列，每位在场同伴一枚小圆，圆里是她的纹。
  - 好了：外圈亮着她的主色。
  - 冷却中：外圈压暗，盖一块随冷却转走的扇形。
  - 这一轮放过了：外圈暖金、发光；正在演：一圈一圈往外跳。
  - 接力窗口里：没放的那几位外面有一圈暖金的弧，跟着窗口缩短；放过的连一条流动的金线到没放的。
  - 汇流：屏幕底边一条参战同伴主色混成的流光，跟着汇流时间变淡。
- **魔力不够**：不扣冷却、不放。她说一句缺魔的话（`ultimate_no_mana`），她那一格红闪两下，响一声低沉的熄灭音。
- **没人能放**：整列抖一下，响一声闷音。
- **号令轮盘**：能放的外圈亮着主色；放过的暖金加一枚金印；冷却中压暗加扇形。指着的那一格下面写奥义的名字和要花的魔力，魔力不够时是红的。轮盘是玩家自己打开的菜单，所以可以写名字和数字。
- **发动、接力**：同伴说 `ultimate_cast`。出手时如果后面还有人要接，她说 `ultimate_relay`。

## 二、连携

```
IDLE ──在场只有一位──▶ SINGLE ──演完──▶ IDLE
IDLE ──在场两位以上，第一位下令──▶ WINDOW ──窗口里下一位──▶ WINDOW
WINDOW ──超时（最后一次出手后 140 刻、没人在演）──▶ IDLE
WINDOW ──在场的全放过了、都演完了──▶ CUTIN ──第 26 刻──▶ CONVERGED ──按 V 或 100 刻──▶ FINISHER ──演完──▶ IDLE
```

状态机是 `UltimateChain`，纯逻辑，单元测试直接测；服务端的 `Ultimates` 每刻推它。

- **单人**：在场只有一位同伴时放的是单人奥义：不开窗口、不交馈赠、不放切入、没有最后一击。
- **窗口从出手那一刻算**：从这一段的 `impact()` 那一刻起算 140 刻（7 秒），而不是从按键起算，免得前摇和跑位吃掉窗口。有人还在演（还没出手）时窗口不会过。
- **凑齐**：在场的同伴（至少两位）全部在这一轮放过、都演完了，才放连携切入。在场名单每刻重算：有人在冷却，就凑不齐，前面几位照样吃倍率和馈赠，只是不放切入；有人被收回，剩下的放完就算凑齐。
- **汇流**：切入第 26 刻（`ChainTimeline.SWAP` 那一拍，光幕盖满、角色甩出）进汇流。这一刻锁住这一轮最近打的那个主目标（100 刻的强迟缓）。玩家有 100 刻（5 秒）按 V，过了就替他放，攒的连携不会因为犹豫作废。
- **作废**：主人下线、死亡、换世界时，正在演的全部打断，这一轮作废；冷却照旧。

| 数 | 值 | 在哪 |
|---|---|---|
| 接力窗口 | 140 刻（7 秒），从出手起算 | `UltimateChain.WINDOW` |
| 汇流 | 100 刻（5 秒） | `UltimateChain.CONVERGE` |
| 第 1 / 2 / 3 / 4 段的威力 | 1 / 1.25 / 1.55 / 1.9 | `UltimateChain.power` |
| 第 1 / 2 / 3 / 4 段的耗魔 | 基准的 100% / 85% / 70% / 55% | `UltimateChain.manaFactor` |
| 最后一击的威力 | 两位同伴 1 倍，三位 1.6 倍（满格），四位 2 倍；不耗魔 | `UltimateChain.finisherPower` |
| 白梅 | 冷却 35 秒，基准耗魔 260 | `ShiraumeCompanion.ULTIMATE` |
| 精灵公主 | 40 秒，300 | `ElfPrincessCompanion.ULTIMATE` |
| 琥珀 | 35 秒，280 | `KohakuCompanion.ULTIMATE` |
| 拉塞塔 | 40 秒，320 | `LacertaCompanion.ULTIMATE` |

- **冷却**：记在主人身上（附件 `ultimate_cooldowns`，存档、死亡不清），收回再叫不会刷掉。下令那一刻开始算。
- **耗魔**：花的是主人的 Logos 魔力。实际花多少 = 基准 × 第几段的折扣 × 前面交过来的馈赠的折扣。创造模式不花。
- **四位一起**：规范里写到第三段，附属一共四位同伴都能同时在外面，所以第四段和四人满格是补上的值。

## 四、给一位同伴做她的奥义

每位同伴是一个独立的任务，可以几位同时做。每个任务只动她自己的东西，不改公共部分。公共部分缺接口时提出来加，不要在公共代码里写「如果是她就……」。

**动这些（只动这些，几个任务并行时就不会撞）**：

- 她自己的新类（例如 `companion/ShiraumeUltimate.java`，馈赠可以是里面的一个内部类）；
- 她的类里的 `ULTIMATE` 常量；
- `CompanionStyle` 里她那一条的最后一项（`UltimateShow.NONE` 换成她的画面）；
- 她的客户端画面类（例如 `client/companion/ShiraumeUltimateShow.java`）；
- 她的动画、模型、贴图、音效；
- 语言文件里她那几行的值；
- 她的设计文档；
- 她自己的测试。

### 1. 服务端脚本

新写一个 `UltimateScript`，把她类里的常量换成它：

```java
public static final UltimateDef ULTIMATE = new UltimateDef(700, 260, ShiraumeUltimate::new);
```

- **长度**：`length()` 是一共几刻，`impact()` 是第几刻出手（窗口从这一刻算，馈赠也在这一刻交出去）。规范给的世界内演出是 36–44 刻。
- **每刻**：`start` 在第 0 刻之前调一次，`tick(cast, t)` 每刻调，`end(cast, interrupted)` 演完或被打断时调（她倒下、被收回，主人下线、死亡、换世界）。临时属性、临时状态在 `end` 里撤掉。
- **她这几秒归脚本管**：心智停着，不打分、不走、不出别的招。位置、朝向、动作都由脚本摆：
  - 动作走她自己已有的方式（`setMisc`、`setMove`、她的招式文件）；
  - 位移用导航或直接挪，注意别穿墙、别卡进天花板（拉塞塔腾空前要测头顶）。
- **打谁、往哪放**：`cast.target()` 是开演时选好的目标；死了会自动重锁离原来那一点最近的（24 格内），一个都没有时是 null。`cast.aim()` 是目标脚下，没有目标时是准星前方 14 格的地面。没有目标也照样演完。
- **伤害一律走 `cast.hit(target, base)`**：它乘连携倍率和馈赠的威力，让馈赠改伤害、加穿甲，清掉目标的无敌帧（连斩每一下都算）。
  - 默认是她自己的近战伤害。龙炎、奥秘、生命这类走自己的入口：`cast.hit(target, base, (t, amount) -> 你的伤害调用)`。
  - `base` 用她自己的攻击或法强折算（`companion().attack()`、她的法强）。
- **镜头和冲击帧**：只发给 `cast.owner()`。运镜用 `CameraShots.play`，黑白闪用 `ScreenEffects.flash`，遵守 [CINEMATICS.md](CINEMATICS.md) 的规矩（一下冲击只闪一次，全屏明暗交替每秒不超过 3 次，遵从「隐藏闪电的闪烁」）。规范里同伴的奥义都是世界内演出、不切镜头；要切镜头的，单人奥义和连携里都要好看。
- **世界内的特效**（粒子、Logos 的 `Vfx`、溶解）照常从服务端发，附近所有人看得见。

### 2. 接力馈赠

`gift(cast)` 返回一个 `RelayGift`，在出手那一刻交给后面的人（只在连携里交，单人奥义不交）：

| 方法 | 什么时候问 | 规范里的例子 |
|---|---|---|
| `handed(from)` | 交出去的那一刻 | 琥珀「炼金回流」：返还主人这次实际耗魔的 40% |
| `manaFactor(stage)` | 后面某一段下令时 | 精灵公主「森之加护」：下一段耗魔 × 0.75 |
| `power(stage)` | 后面某一段算威力时 | 森之加护：下一段 × 1.3 |
| `hit(cast, hit)` | 后面某一段打中一下时：改 `hit.amount`、`hit.pierce` | 白梅「狐火蚀骨」：打中带印的目标 +25% 并二次引爆；拉塞塔「龙炎碎甲」：`hit.pierce(.4)` 并附一层龙炎 |
| `keep(done)` | 后面某一段演完以后 | 默认只管交出之后的那一段。要管到最后一击（龙炎碎甲、森之加护的全队治愈波）就返回 true |
| `cleared(level)` | 连携结束（放完最后一击、超时、主人下线） | 撤掉目标身上的残樱狐印、碎甲 |

- 判断「是不是紧接着的下一段」：建馈赠时记下 `cast.stage().index()`，问到的段号是它加 1 就是下一段。
- 判断「是不是玩家的最后一击」：看 `stage.finisher()`。

### 3. 客户端画面（需要时）

`CompanionStyle` 里她那一条的最后一项换成 `UltimateShow.Factory`：开演时客户端收到 `Cast`（演的人、目标、第几段、种子、长度、出手的刻），工厂新开一个 `UltimateShow`。

- `tick` 每个客户端刻调，`frame` 每帧调（带帧内插值），`end` 在演完或被打断时调。
- 这里只放客户端才做得了的：后期通道、贴在世界里的特效、跟着镜头走的东西。服务端能定的（动作、伤害、运镜、黑白闪）放服务端脚本。
- 种子和服务端脚本是同一个，两边按它算出来的随机一样。

### 4. 台词和名字

语言文件里已经有她的奥义名（`ultimate.logos_dimension.<id>.name`）和三句台词：发动 `ultimate_cast`、接力 `ultimate_relay`、缺魔 `ultimate_no_mana`，照规范写的，中英文都有。要改只改值，不加别的状态文字。

### 5. 测试

- **单元测试**：放她的纯逻辑：时间表、伤害折算、馈赠的数（同一个种子两端算出一样的结果）。
- **客户端场景**：放她自己的组里，照 `UltimateViews` 搭：`ultimateStage`（生存、魔力上限加满、清冷却）、`spawnFoe`（台子后面一只不动的厚血尸壳）、`press`（按一下 V）、`ultimateTeardown`。至少要有：
  - 她单人放一次，打中靶子；
  - 她在连携里交出馈赠，下一段吃到；
  - 截图看演出。
- **只跑相关的组**：`group:ultimate` 和她自己的组，不跑 `group:logos`。

### 6. 文档

- 她的设计文档里写她的奥义（演出分几拍、伤害、馈赠、台词）；
- 这份文档第二节的表里，她那一行改成她的数。

## 五、玩家的最后一击

- **服务端**：`HeroUltimate.PLAYER`。按主手拿的武器大类（`FinisherTemplate`）一段脚本，必须有空手 `UNARMED`。档案里没写的那一类落到空手，所以加一类只要在档案里加一条，不动连携。
- **客户端**：`HeroCutin.PLAYER.finishers`，同样按武器大类。
- **武器大类**（`FinisherTemplate.of`）：
  - 空手、工具 → `UNARMED`；
  - 铳 → `FIREARM`；
  - 弓、弩 → `BOW`；
  - 三叉戟、长矛 → `POLEARM`；
  - 剑（`#swords`，以及 id 带 sword、blade、katana 的）→ `BLADE`；
  - id 带 staff、wand 的 → `STAFF`。
- **现在**：只有空手一类（规范里的「万象共鸣 · 誓约星穹破」），先是 `StandInFinisher` 占位。
- **基础威力**：`StandInFinisher.base`，`max(近战攻击, 法术强度 × 6)`。再乘最后一击的倍率，吃满全队留下的馈赠（馈赠的 `keep` 要返回 true 才留到最后一击）。
- **打谁**：汇流时锁住的那个主目标；它没了就按常规重选。
- **演出**：最后一击的演出和同伴的一样，写一段 `UltimateScript` 和一个 `UltimateShow`。不同的是演的人是玩家，玩家这时照常能走动，不要锁他的操作。

## 六、包

| 包 | 方向 | 内容 |
|---|---|---|
| `Order` | 客户端 → 服务端 | 下令：指名的同伴 ID；空串时由服务端挑。汇流里收到就放最后一击 |
| `Status` | 服务端 → 主人 | 连携阶段、窗口和汇流还剩几刻、锁住的目标，以及每位在场同伴的冷却、放过没有、在不在演、要花多少魔力、够不够。变了就发，平时每半秒一次（有同伴在场时） |
| `Cast` | 服务端 → 看得见演的人的玩家 | 开演：演的人、画面的键（同伴 ID 或 `hero/<武器大类>`）、目标、往哪放、第几段、是不是最后一击、几位同伴、种子、长度、出手的刻 |
| `End` | 服务端 → 看得见演的人的玩家 | 演完或被打断 |
| `Denied` | 服务端 → 主人 | 没人能放 / 魔力不够（客户端只出画面和声音） |

连携切入只发给发动的玩家（`ChainCutins.play`）。世界里的动作、特效、伤害、治疗对附近所有人可见、生效。

## 七、测试

- **单元测试** `UltimateTest`：
  - 倍率和折扣；
  - 单人不进连携；
  - 两位放完 → 切入 → 汇流 → 超时替玩家放 → 回到常态；
  - 汇流对得上切入的换场；
  - 窗口从出手算、有人在演时不过；
  - 有人在冷却就凑不齐、被收回的不算；
  - 馈赠只交给后面的段、默认只管下一段；
  - 最后一击落到空手；
  - 冷却、包的编解码、每位同伴的奥义名和三句台词中英文都有。
- **客户端场景** `group:ultimate`（`UltimateViews`）：
  - `ultimate_chain`：两位同伴，服务端挑白梅放，扣 260 魔力、冷却 35 秒，打中靶子；短按 V 接精灵公主；凑齐放切入；进汇流、锁住靶子；按 V 放最后一击，打中、回到常态。
  - `ultimate_single`：一位同伴，不开窗口、不放切入。
