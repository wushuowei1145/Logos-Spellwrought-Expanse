# 奥义：同伴终结技、接力连携与玩家的最后一击

每位同伴有一个奥义，玩家也有一个，但玩家的只在全员连携放完以后才放得出来。玩家按 C 令同伴放奥义。在场的同伴在接力窗口里一个接一个都放过，就自动播连携切入（[CHAIN_CUTIN.md](CHAIN_CUTIN.md)），换场以后玩家进入「汇流」，再按一次 C 亲手放出最后一击。

设计来源是维护者的规范《同伴终结技与多人连携玩法机制规范》。这份文档写现在的代码怎么做，以及怎么给一位角色做她的奥义。

**现状（2026-11-28）**：

- **第一阶段，公共入口**（#320）：按键、号令轮盘、侧边小队、连携状态机、冷却和耗魔、选目标、接力馈赠的接口、切入和汇流、玩家最后一击的武器大类路由、客户端画面的接入点。
- **第二阶段，过场套件**（第三节）：
  - 完整版和缩短版；
  - 过场期间按 C 排队；
  - 过场期间主人和同伴不受伤、附近的敌人定住；
  - 分镜运镜 `UltimateFilm`（视角大小、滚转、抖动、定格）和盖在画面上的一层（压暗调色、动态模糊、速度线、擦镜）；
  - 角色自己的全屏后期的接入点；
  - 逐刻截帧的测试工具。
- **占位**：四位同伴和玩家都先用占位的一段：服务端站定、打一下；客户端一段占位过场（`StandInShow`）。
- **各自的正式奥义**（分镜、动作、特效、技能效果、馈赠）由每位角色单独的任务做，见第五、六节。分镜稿在维护者的规范目录里（`<角色>_ult_storyboard.md`）。
- **同伴的过场先关着**（2026-11-29，第三节）：她们照样出手，只是不接管镜头、不盖叠层、不闪冲击帧，也没有过场期间的保护。连携切入和玩家的最后一击照旧有过场。过场的代码都留着，`Ultimates.COMPANION_FILMS` 改成 `true` 就回来。

## 一、玩起来是什么样

### 按键

奥义键默认是 **C**，在按键设置的「同伴」一栏里，可以改。下文的「按 C」都指这个键。

| 此刻 | 怎么按 | 做什么 |
|---|---|---|
| 常态、接力窗口里 | 短按（松手时触发，按住不到 0.2 秒） | 准星 24 格内对着某位能放的同伴，就令她放；否则按队伍顺序（`Companions.ALL`），令第一位能放、这一轮还没放过的同伴放 |
| 常态、接力窗口里 | 长按（≥ 0.2 秒，客户端配置 `ultimateHold`，0.15–0.6） | 打开号令轮盘：在场的同伴一位一格，鼠标甩到谁、松开 C 就是谁；指针在中间的圈里松手是取消；不暂停世界 |
| 汇流（切入换场后 5 秒） | 一按下就放 | 放玩家自己的最后一击 |

另有「同伴：第一位～第四位的奥义」四个热键，默认不绑，按在场的队伍顺序直接点名（给鼠标侧键用）。

奥义键默认是 C（原先是 V，和 Logos 化身时的「变回」、附身时的「本能」、骑巨像时的「切换驾驶」撞键）。改绑到和那几个同一个键时，在那几种场合里让给 Logos，平时才是奥义（`UltimateClient.COMMANDING`）。原版创造模式的「保存快捷栏」也默认是 C，只在和数字键一起按时才起作用。

能放的意思是：在场（召唤在外面、活着、没在撤退、48 格以内，和连携切入点名的口径一样）、冷却好了、这一轮没放过、没在演。

### 画面上的反馈（不写字）

- **侧边小队**（`UltimateHud`）：画面左边一列，每位在场同伴一枚小圆，圆里是她的纹。
  - 好了：外圈亮着她的主色。
  - 冷却中：外圈压暗，盖一块随冷却转走的扇形。
  - 这一轮放过了：外圈暖金、发光；正在演：一圈一圈往外跳。
  - 接力窗口里：没放的那几位外面有一圈暖金的弧，跟着窗口缩短；放过的连一条流动的金线到没放的。
  - 汇流：屏幕底边一条参战同伴主色混成的流光，跟着汇流时间变淡。
- **魔力不够**：不扣冷却、不放。她说一句缺魔的话（`ultimate_no_mana`），她那一格红闪两下，响一声低沉的熄灭音。
- **没人能放**：整列抖一下，响一声闷音。
- **号令轮盘**：能放的外圈亮着主色；放过的暖金加一枚金印；冷却中压暗加扇形。指着的那一格下面写奥义的名字和要花的魔力，魔力不够时是红的。轮盘是玩家自己打开的菜单，所以可以写名字和数字。
- **发动、接力**：同伴说 `ultimate_cast`。出手时如果后面还有人要接，她说 `ultimate_relay`。
- **过场**：放奥义时下令的玩家的镜头被过场接管，几秒后擦镜回到他自己的视角；别的玩家照常看世界里发生的事（第三节）。同伴的过场现在关着，只有连携切入和最后一击接管镜头。

## 二、连携

```
IDLE ──在场只有一位──▶ SINGLE ──演完──▶ IDLE
IDLE ──在场两位以上，第一位下令──▶ WINDOW ──窗口里下一位──▶ WINDOW
WINDOW ──超时（最后一次出手后 140 刻、没人在演）──▶ IDLE
WINDOW ──在场的全放过了、都演完了──▶ CUTIN ──第 26 刻──▶ CONVERGED ──按 C 或 100 刻──▶ FINISHER ──演完──▶ IDLE
```

状态机是 `UltimateChain`，纯逻辑，单元测试直接测；服务端的 `Ultimates` 每刻推它。

- **单人**：在场只有一位同伴时放的是单人奥义：不开窗口、不交馈赠、不放切入、没有最后一击。
- **窗口从出手那一刻算**：从这一段的 `impact()` 那一刻起算 140 刻（7 秒），而不是从按键起算，免得前摇和跑位吃掉窗口。有人还在演（还没出手）时窗口不会过。
- **凑齐**：在场的同伴（至少两位）全部在这一轮放过、都演完了，才放连携切入。在场名单每刻重算：有人在冷却，就凑不齐，前面几位照样吃倍率和馈赠，只是不放切入；有人被收回，剩下的放完就算凑齐。
- **汇流**：切入第 26 刻（`ChainTimeline.SWAP` 那一拍，光幕盖满、角色甩出）进汇流。这一刻锁住这一轮最近打的那个主目标（100 刻的强迟缓）。玩家有 100 刻（5 秒）按 C，过了就替他放，攒的连携不会因为犹豫作废。
- **作废**：主人下线、死亡、换世界时，正在演的全部打断，这一轮作废；冷却照旧。

| 数 | 值 | 在哪 |
|---|---|---|
| 接力窗口 | 140 刻（7 秒），从出手起算 | `UltimateChain.WINDOW` |
| 汇流 | 100 刻（5 秒） | `UltimateChain.CONVERGE` |
| 第 1 / 2 / 3 / 4 段的威力 | 1 / 1.25 / 1.55 / 1.9 | `UltimateChain.power` |
| 第 1 / 2 / 3 / 4 段的耗魔 | 基准的 100% / 85% / 70% / 55% | `UltimateChain.manaFactor` |
| 最后一击的威力 | 两位同伴 1 倍，三位 1.6 倍（满格），四位 2 倍；不耗魔 | `UltimateChain.finisherPower` |
| 精灵公主 | 40 秒，300；完整版 104 刻（第 79 刻出手）、缩短版 44 刻（第 30 刻）；馈赠森之加护（[ELF_PRINCESS_COMPANION.md](ELF_PRINCESS_COMPANION.md) 第 11 节） | `ElfPrincessCompanion.ULTIMATE` |
| 白梅「狐嫁入 · 水镜形代断」 | 冷却 35 秒，基准耗魔 260；完整版 107 刻、第 78 刻出手，缩短版 44 刻、第 24 刻出手（[SHIRAUME_COMPANION.md](SHIRAUME_COMPANION.md) 第 11 节） | `ShiraumeCompanion.ULTIMATE` |
| 琥珀 | 35 秒，280；完整版 106 刻（第 75 刻出手）、缩短版 42 刻（第 26 刻），馈赠「炼金回流」 | `KohakuCompanion.ULTIMATE`（`KohakuUltimate`，见 [KOHAKU_COMPANION.md](KOHAKU_COMPANION.md) 第 20 节） |
| 拉塞塔 | 40 秒，320 | `LacertaCompanion.ULTIMATE` |

- **冷却**：记在主人身上（附件 `ultimate_cooldowns`，存档、死亡不清），收回再叫不会刷掉。下令那一刻开始算。
- **耗魔**：花的是主人的 Logos 魔力。实际花多少 = 基准 × 第几段的折扣 × 前面交过来的馈赠的折扣。创造模式不花。
- **四位一起**：规范里写到第三段，附属一共四位同伴都能同时在外面，所以第四段和四人满格是补上的值。

## 三、过场

每一段奥义（同伴的、玩家的最后一击）都是一段日漫式的过场：先定好分镜和节奏，再做一整段运镜和动画。

### 同伴的过场先关着

`Ultimates.COMPANION_FILMS` 现在是 `false`：同伴的过场这一版先不放，代码都留着，改成 `true` 就回来。

- **谁定**：每一段开演时服务端定下这一段有没有过场（`UltimateCast#filmed`，随 `Cast` 包发给客户端）。玩家的最后一击总是有；同伴的看这个开关。
- **她照样演**：动作、世界里的特效、伤害、馈赠、接力窗口都不变。排队也照旧：前一段还在演时下令，放完接上。
- **下令的玩家只看世界里的那一半**，和别的玩家一样：
  - `UltimateFilm#play` 不接管镜头、不盖叠层；
  - 她的 `UltimateShow#screen` 不画（`UltimateFilm.playing()` 不是她的）；
  - 脚本不闪冲击帧（`if (cast.filmed()) ScreenEffects.flash(...)`）。
- **保护只在有过场时算**（下面「过场期间的保护」）：她演的时候主人和同伴照常受伤、敌人不定住、别的同伴照常打，只有她自己的心智停着。连携切入那 1.65 秒和最后一击照旧受保护。
- **测试**：
  - `ultimate_queue` 测关着的样子；
  - `ultimate_film` 和各位角色的过场场景用 `UltimateViews.filmStage` 临时打开；
  - 每个场景开头和收尾都放回默认。

### 规矩

- **时长**：
  - 同伴的**完整版**不超过 110 刻（5.5 秒，`UltimateDef.MAX_FULL`），单人奥义和连携里的第一位演它；
  - 连携里**第二位起**演**缩短版**，不超过 44 刻（约 2 秒，`UltimateDef.MAX_CONDENSED`），免得四人满连携看三十秒过场；两版的伤害和馈赠一样；
  - 玩家的最后一击作为主角压轴，**不受这个限制**（分镜稿是 156 刻），总是完整的。
- **谁看得到**：只有下令的那个玩家的镜头被接管、看得到盖在画面上的东西；别的玩家看的是世界里的那一半（动作、粒子、Logos 的特效），所以世界里的动作本身也要好看。
- **过场期间的保护**（`Ultimates.cinematic`）：
  - 主人和他的同伴不受伤（虚空、`/kill` 照样）；
  - 主人身边、各段目标身边 24 格内的敌人定住：不走、不追、不打，被奥义打飞照样会飞（只用临时的属性修饰，存档时不会留下来）；Boss 不定，反正打不到人；
  - 整个小队的心智都停下来（不只是演的那一位）；
  - 连携切入那 1.65 秒也算；汇流时玩家能动了，保护和定住都放开，只剩锁定主目标的强迟缓。
- **排队**：过场放着的时候下令（奥义键、轮盘、热键），够魔力就排上（侧边小队里那一格的外圈一闪一闪地等），这一段放完立刻接上她的；扣魔、冷却到真正开演时才算。
- **不写字**：拟声字也不画。打击感靠速度线、冲击帧、抖动、顿帧。
- **冲击帧**：每段过场最多一次 `ScreenEffects.flash`（出手那一拍）；满规格的四拍黑白闪留给玩家的最后一击。全屏明暗交替每秒不超过 3 次，遵从「隐藏闪电的闪烁」（[CINEMATICS.md](CINEMATICS.md)）。
- **对齐**：分镜稿里结算伤害的那一拍就是脚本的 `impact()`，接力窗口从这一刻算。
- **声音**：先用原版和附属已有的声音拼，不新做音频。
- **不碰方块**：碎岩、裂地、火柱都是特效，不破坏、不点燃任何方块。

### 套件

**服务端**：

- 脚本照常写 `UltimateScript`（第五节第 1 条）；完整版和缩短版是两个类，或者一个类带一个开关；
- 档案里写 `new UltimateDef(冷却, 耗魔, Full::new, Condensed::new)`；
- `cast.condensed()` 告诉脚本这一段演哪一版。

**客户端**：画面写在她的 `UltimateShow` 里。开演时用 `UltimateFilm` 搭一段过场、`play()` 出来；不是本机玩家下的令时 `play()` 什么都不做，只放世界里的东西。

```java
UltimateFilm.of(cast)
        .darken(0, 13, 4, 2, .85f)                                   // 压黑起手：淡入 4 刻、淡出 2 刻
        .cut(0, 13, s -> s.look(s.around(s.feet(), 20, 1.4f, .2f), s.chest()))
        .cut(13, 28, s -> s.look(s.around(s.target(), s.lerp(-60, 30), 6, 2), s.targetChest(), s.lerp(0, 180), 50))
        .freeze(37, 41)                                              // 滞空定格：镜头停在第 37 刻那一帧
        .lines(41, 50, 2, UltimateFilm.Lines.CONVERGE, .8f, 0, 0xFFFFFF)
        .blur(51, 63, 2, UltimateFilm.Blur.DIRECTIONAL, 1, 90, .5f, .5f)
        .shake(63, 70, 2, .3f)
        .wipe(91, 107, UltimateFilm.Wipe.PETAL, 0xFFC2E0, 0xF7B6D6)  // 最后一镜：擦镜回到玩家视角
        .play();
```

- **一镜**（`cut`）：每帧按这一镜的进度给机位（`Shot`）：
  - **进度**：`t()`、`ease()`、`easeIn()`、`easeOut()`、`lerp(...)`；
  - **锚点**：演的人 `feet()`、`eyes()`、`chest()`、`forward()`、`right()`；目标 `target()`、`targetChest()`、`toward()`；`aim()`；`owner()`；
  - **环绕**：`around(中心, 方位, 距离, 高度)`，方位 0 是她正前方、90 是她右手边；
  - **出机位**：`look(从哪, 看哪[, 歪几度, 视角])`，滚转 180 是上下颠倒，视角是度数（`NaN` 照玩家的）。
  - 镜与镜之间是硬切。
- **定格、抖动**：`freeze` 让镜头停在某一帧（卡肉顿帧、滞空），世界照常走；`shake` 让镜头抖。
- **盖在画面上的一层**（`UltimateFilmRenderer`，排在所有后期之后、连携切入之前）：
  - `grade`：压暗、去饱和、染色、暗角；`darken` 是只压暗的简写；
  - `blur`：方向或径向的动态模糊；
  - `lines`：漫画速度线，平行、往外喷、往里吸，中间留一块不盖住主体；
  - `wipe`：擦镜，花瓣、叶子、纸片、碎晶、烟、火星、星芒从左往右扫过，正中盖满的那几刻镜头回到玩家视角（`returning` 改回来用几刻，默认 6）。
  - 同一种层同一刻只有一层起作用（后加的）。
- **她自己的全屏后期**：浮世绘、画面凝进琥珀、碎镜这类，写在她的 `UltimateShow#screen` 里（每帧在过场叠层之前调），自己注册管线、画全屏三角形，照 `UltimateFilmRenderer` 的写法，不用改 `ScreenEffectMixin`。只在 `film.mine()` 时画。
- **世界里的特效**：粒子、Logos 的 `Vfx`、`PostVfx`、`GlowBloom` 照常用，从服务端发的所有人都看得见。有奥义的画面在放时 `PostVfx` 自动收几何（`UltimateClient.postVfx`），交上去的发光特效（穿雾、在后期调暗之后仍亮）不会被丢掉。
- **最小的用法**：`StandInShow`（占位过场）。

### 截帧看动态

- **截帧**：场景里用 `UltimateViews.film(s, 名字, 帧数, 每秒几刻)`，把游戏放慢（`/tick rate`）、从下令起每刻截一张。
- **拼动图**：`uv run --with pillow python tools/frames_to_gif.py <截图目录> <输出目录>` 拼成真实速度和慢放的两张动图。
- 看节奏、运镜、擦镜都靠它；`ultimate_film` 是例子。

## 四、代码在哪

| 文件 | 做什么 |
|---|---|
| `ultimate/Ultimates.java` | 服务端入口：下令（`order`）、扣魔、冷却、每刻推进各段、超时、切入、汇流、最后一击、主人下线时作废、发状态 |
| `ultimate/UltimateChain.java` | 连携状态机（纯逻辑）：阶段、放过的名单、窗口、倍率和折扣、馈赠交给谁 |
| `ultimate/UltimateDef.java` | 一位同伴的奥义：冷却、基准耗魔、脚本工厂。放在她的档案 `CompanionDef#ultimate` |
| `ultimate/UltimateScript.java` | 一段奥义在服务端怎么演（同伴的和玩家的最后一击都是它） |
| `ultimate/UltimateCast.java` | 正在演的那一段：谁演、为谁、第几段、打谁、往哪放、`hit` 算伤害 |
| `ultimate/RelayGift.java`、`UltimateHit.java` | 接力馈赠的接口；打中的一下（伤害、穿甲） |
| `ultimate/UltimateTargets.java` | 打谁：准星指着的 → 主人刚打过的 → 她正在对付的 → 离主人最近的敌对生物；准星对着哪位同伴 |

| `ultimate/StandInUltimate.java`、`StandInFinisher.java` | 占位的那一段（专属演出做好以前用） |
| `ultimate/UltimatePayloads.java` | 包（第六节） |
| `client/ultimate/UltimateClient.java` | 按键（短按、长按、汇流、直接热键）、收状态、按演的人找画面并推着走 |

## 五、给一位同伴做她的奥义

每位同伴是一个独立的任务，可以几位同时做。每个任务只动她自己的东西，不改公共部分。公共部分缺接口时提出来加，不要在公共代码里写「如果是她就……」。

先读她的分镜稿（维护者规范目录里的 `<角色>_ult_storyboard.md`），定好每一镜的刻数，再动手。

- **完整版**：照分镜稿做，不超过 110 刻。
- **缩短版**：约 2 秒，挑分镜里最有辨识度的一两镜加出手那一拍、再擦镜。
- **对齐**：分镜稿写的「结算伤害、接力窗口起算」那一拍就是 `impact()`。

**动这些（只动这些，几个任务并行时就不会撞）**：

- 她自己的新类（例如 `companion/ShiraumeUltimate.java`，馈赠可以是里面的一个内部类）；
- 她的类里的 `ULTIMATE` 常量；
- `CompanionStyle` 里她那一条的最后一项（`StandInShow` 换成她的画面）；
- 她的客户端画面类（例如 `client/companion/ShiraumeUltimateShow.java`）；
- 她的动画、模型、贴图、音效；
- 语言文件里她那几行的值；
- 她的设计文档；
- 她自己的测试。

### 1. 服务端脚本

新写一个 `UltimateScript`，把她类里的常量换成它：

```java
public static final UltimateDef ULTIMATE = new UltimateDef(700, 260, ShiraumeUltimate::full, ShiraumeUltimate::condensed);
```

- **长度**：`length()` 是一共几刻（完整版 ≤ 110，缩短版 ≤ 44），`impact()` 是第几刻出手（窗口从这一刻算，馈赠也在这一刻交出去）。
- **每刻**：`start` 在第 0 刻之前调一次，`tick(cast, t)` 每刻调，`end(cast, interrupted)` 演完或被打断时调（她倒下、被收回，主人下线、死亡、换世界）。临时属性、临时状态在 `end` 里撤掉。
- **她这几秒归脚本管**：心智停着，不打分、不走、不出别的招。位置、朝向、动作都由脚本摆：
  - 动作走她自己已有的方式（`setMisc`、`setMove`、她的招式文件）；
  - 位移用导航或直接挪，注意别穿墙、别卡进天花板（拉塞塔腾空前要测头顶）。
- **打谁、往哪放**：`cast.target()` 是开演时选好的目标；死了会自动重锁离原来那一点最近的（24 格内），一个都没有时是 null。`cast.aim()` 是目标脚下，没有目标时是准星前方 14 格的地面。没有目标也照样演完。
- **伤害一律走 `cast.hit(target, base)`**：它乘连携倍率和馈赠的威力，让馈赠改伤害、加穿甲，清掉目标的无敌帧（连斩每一下都算）。
  - 默认是她自己的近战伤害。龙炎、奥秘、生命这类走自己的入口：`cast.hit(target, base, (t, amount) -> 你的伤害调用)`。
  - `base` 用她自己的攻击或法强折算（`companion().attack()`、她的法强）。
- **镜头**：分镜运镜写在客户端的 `UltimateFilm`（第三节），不用服务端的 `CameraShots`。
- **冲击帧**：服务端在出手那一拍调一次 `ScreenEffects.flash(cast.owner(), …)`（第三节的规矩）。
- **世界内的特效**（粒子、Logos 的 `Vfx`、溶解）照常从服务端发，附近所有人看得见。

### 2. 接力馈赠

`gift(cast)` 返回一个 `RelayGift`，在出手那一刻交给后面的人（只在连携里交，单人奥义不交）：

| 方法 | 什么时候问 | 规范里的例子 |
|---|---|---|
| `handed(from)` | 交出去的那一刻 | 琥珀「炼金回流」：返还主人这次实际耗魔的 40% |
| `manaFactor(stage)` | 后面某一段下令时 | 精灵公主「森之加护」：下一段耗魔 × 0.75 |
| `power(stage)` | 后面某一段算威力时 | 森之加护：下一段 × 1.3 |
| `hit(cast, hit)` | 后面某一段打中一下时：改 `hit.amount`、`hit.pierce` | 白梅「狐火蚀骨」：打中带印的目标 +25% 并二次引爆；拉塞塔「龙炎碎甲」：`hit.pierce(.4)` 并附一层龙炎 |
| `keep(done)` | 后面某一段演完以后 | 默认只管交出之后的那一段。要管到最后一击（龙炎碎甲、森之加护的全队治愈波）就返回 true |
| `cleared(level)` | 连携结束（放完最后一击、超时、主人下线） | 撤掉目标身上的残樱狐印、碎甲 |

- 判断「是不是紧接着的下一段」：建馈赠时记下 `cast.stage().index()`，问到的段号是它加 1 就是下一段。
- 判断「是不是玩家的最后一击」：看 `stage.finisher()`。

### 3. 客户端画面：过场

`CompanionStyle` 里她那一条的最后一项换成她的 `UltimateShow.Factory`。开演时客户端收到 `Cast`，工厂新开一个 `UltimateShow`。`Cast` 里有：

- 演的人、下令的玩家、目标；
- 第几段、是不是缩短版；
- 种子、长度、出手的刻。

- **过场**：在工厂里用 `UltimateFilm` 搭她的过场并 `play()`（第三节），完整版和缩短版看 `cast.condensed()`。
- **每刻和每帧**：`tick` 每个客户端刻调，`frame` 每帧调（带帧内插值），`screen` 画她自己的全屏后期，`end` 在演完或被打断时调（被打断时 `film.stop()`）。
- **只放客户端才做得了的**：运镜、后期、贴在世界里的特效、跟着镜头走的东西。服务端能定的（动作、位移、伤害、黑白闪）放服务端脚本。
- **种子**：和服务端脚本是同一个，两边按它算出来的随机一样。

### 4. 台词和名字

语言文件里已经有她的奥义名（`ultimate.logos_dimension.<id>.name`）和三句台词：发动 `ultimate_cast`、接力 `ultimate_relay`、缺魔 `ultimate_no_mana`，照规范写的，中英文都有。要改只改值，不加别的状态文字。

### 5. 测试

- **单元测试**：放她的纯逻辑：时间表、伤害折算、馈赠的数（同一个种子两端算出一样的结果）。
- **客户端场景**：放她自己的组里，照 `UltimateViews` 搭：`ultimateStage`（生存、魔力上限加满、清冷却）、`spawnFoe`（台子后面一只不动的厚血尸壳）、`press`（按一下 V）、`film`（放慢逐刻截帧）、`ultimateTeardown`。至少要有：
  - 她单人放一次完整版，打中靶子，逐刻截帧拼成动图看节奏；
  - 连携里第二位演她的缩短版；
  - 她在连携里交出馈赠，下一段吃到。
- **只跑相关的组**：`group:ultimate` 和她自己的组，不跑 `group:logos`。

### 6. 文档

- 她的设计文档里写她的奥义（演出分几拍、伤害、馈赠、台词）；
- 这份文档第二节的表里，她那一行改成她的数。

  - 火苗钉在掌心投到画面上的那一点，跟着它走。
- **光敏**：整段全屏明暗只有一次缓慢的压黑再抬起（单元测试数过）。黑白闪只有第 99 刻那一次，本身遵从「隐藏闪电的闪烁」和两次之间 0.7 秒的间隔。

  - 渲染状态上带一份 `HeroCutin.Pose`，由 `ChainCutinModelMixin` 套上（和连携切入里的玩家同一份）；身子转向要砸的那一点。
  - 顺序：伸臂托火 → 左臂张开压住 → 双臂高举 → 抡过头顶 → 砸出去 → 右臂留在身前 → 慢慢垂下，交还原版。
  - 只改渲染状态，实体本身不动。
- **誓约锁定**（`VowLockMarker`）：
  - 汇流时锁住的主目标头顶一枚暖金色星芒，脚下一圈细金环；汇流最后 1.5 秒一闪一闪地催。
  - 放最后一击以后跟到砸下那一刻淡掉。
  - 只画在主人自己的画面上（状态包 `Status.lock()` 只发给他）。不写字。
- **名字**：`ultimate.logos_dimension.hero.unarmed.name`。
- **测试**：单元测试 `HeroFinisherTimelineTest`；客户端场景 `group:hero_finisher`（`HeroFinisherViews`）：
  - `hero_finisher_film`：两位同伴放完连携进汇流，靶子头顶有星芒；按 C 放最后一击打中锁住的靶子；每秒 2 刻逐刻截帧（`hero_finisher_frame_NNN`，截一张图要一百多毫秒，每秒 5 刻时会隔一刻才截一张），镜头一直没塞进方块，极远镜退到几十格外，放完回到玩家视角；
  - `hero_finisher_no_target`：没有靶子，朝准星前方的地面放完整段，回到常态；
  - `hero_finisher_cave`：台子罩在矮石屋里，极远镜改洞内退距，镜头不穿进墙和屋顶。

## 七、包

| 包 | 方向 | 内容 |
|---|---|---|
| `Order` | 客户端 → 服务端 | 下令：指名的同伴 ID；空串时由服务端挑。汇流里收到就放最后一击 |
| `Status` | 服务端 → 主人 | 连携阶段、窗口和汇流还剩几刻、锁住的目标，以及每位在场同伴的冷却、放过没有、在不在演、排没排着、要花多少魔力、够不够。变了就发，平时每半秒一次（有同伴在场时） |
| `Cast` | 服务端 → 看得见演的人的玩家 | 开演：演的人、下令的玩家（只有他的镜头被接管）、画面的键（同伴 ID 或 `hero/<武器大类>`）、目标、往哪放、第几段、是不是最后一击、是不是缩短版、几位同伴、种子、长度、出手的刻 |
| `End` | 服务端 → 看得见演的人的玩家 | 演完或被打断 |
| `Denied` | 服务端 → 主人 | 没人能放 / 魔力不够（客户端只出画面和声音） |

连携切入只发给发动的玩家（`ChainCutins.play`）。世界里的动作、特效、伤害、治疗对附近所有人可见、生效。

## 八、测试

- **单元测试** `UltimateTest`：
  - 倍率和折扣；
  - 单人不进连携；
  - 两位放完 → 切入 → 汇流 → 超时替玩家放 → 回到常态；
  - 汇流对得上切入的换场；
  - 窗口从出手算、有人在演时不过；
  - 有人在冷却就凑不齐、被收回的不算；
  - 馈赠只交给后面的段、默认只管下一段；
  - 最后一击落到空手；
  - 第二位起演缩短版、最后一击总是完整的；
  - 冷却、包的编解码、每位同伴的奥义名和三句台词中英文都有。
- **客户端场景** `group:ultimate`（`UltimateViews`）：
  - `ultimate_chain`：两位同伴，服务端挑白梅放，扣 260 魔力、冷却 35 秒，打中靶子；短按 C 接精灵公主；凑齐放切入；进汇流、锁住靶子；按 C 放最后一击，打中、回到常态。
  - `ultimate_single`：一位同伴，不开窗口、不放切入。
  - `ultimate_denied`：魔力不够时她说缺魔那一句、那一格闪红、不扣冷却；都在冷却时整列抖一下。
  - `ultimate_wheel`：三位同伴，按住 C 打开号令轮盘，甩到第二格松手就是精灵公主。
  - `ultimate_queue`：过场放着时再下令就排上，放完接上（演缩短版）；过场期间主人不受伤、靶子被定住；汇流时都放开。
  - `ultimate_film`：放一段占位过场，放慢逐刻截帧，叠层画了、放完镜头回来。
