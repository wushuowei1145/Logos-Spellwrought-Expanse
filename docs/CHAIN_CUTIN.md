# 连携切入（Chain Cut-in）

> 几个系统怎么选、共同的规范（通道顺序、深度、兼容、光敏、测试）见总览 [CINEMATICS.md](CINEMATICS.md)。

日系 RPG 里小队合力一击时的切入演出：画面被几道斜着的光线切开，玩家和在场的同伴一个接一个冲进各自的斜格里，落位时中间炸开一团白光。每一格都是一个小镜头，不是一张图：镜头跟着她冲进来、冲过头一点再回来，停留时还在推、扫、歪着；她身后是她自己颜色的能量和速度线，身前飘着她的光屑。最后光幕盖上来，角色顺着进来的方向甩出去，光幕很快退开，回到 3D 画面。玩家永远在正中间那一格，同伴按当时召唤在外面的人数自动排开。

现在只有画面：放完什么都不做，不打伤害、不挪人，没有标题字和台词。怎么触发、打多少、白光底下要不要合围，以后再定。

## 怎么用

```java
// 服务端：点名在玩家身边的同伴，给这个玩家放一次（没有同伴在场时返回 false，不放）
ChainCutins.play(player);
```

试效果：召唤一到四位同伴，输入 `/alchemy chain`。

- 在场的同伴：召唤在外面、活着、同一个世界、48 格以内，按同伴表的顺序（白梅、精灵公主、琥珀、拉塞塔）。
- 只发给发动的玩家，附近其他人看不到。没装附属的客户端收不到，服务端照常走。
- 时刻都在 `ChainTimeline` 里（单位：刻），以后接伤害、合围时按它的 `SWAP`（光幕盖满、分格卸掉）、`END` 对齐。

## 分格

| 人数 | 分格 |
|---|---|
| 玩家 + 1 位 | 两个大斜格；同伴在左，玩家在正中，右边露出压暗的战场 |
| 玩家 + 2 位 | 三格几乎占满，两边只剩很窄的暗边 |
| 玩家 + 3 位 | 按五格的格距铺满；左边两位，右边一位的格子一直延到屏幕边上 |
| 玩家 + 4 位 | 五格铺满全屏 |

- 同伴从中间往两边排：第一位在玩家左边，第二位在右边，第三位最左，第四位最右。人数是偶数时左边多一格。
- 分割线都带倾角，越靠外越斜（中间约 5°，最外约 12°），左边往左上倒、右边往右上倒，形成向上张开的扇形。
- 分割线的外焰取两边离中间远的那一格的颜色：同伴用她界面的主色（`CompanionStyle.accent`），玩家那一格是暖金。
- 布局是 `ChainLayout.of(同伴数)` 里的一张表，改格子的位置、宽度、倾角只改这里。

## 时间轴

按游戏刻计时，暂停时停，约 1.65 秒：

| 段 | 刻 | 画面 |
|---|---|---|
| 先手刺穿 | 0–2 | 战场去色压暗；光线从屏幕底下错落地刺上来（中间最高），界面还在 |
| 黑底接管 | 2–4.5 | 黑底一下子盖住战场，界面藏起来，速度线已经在走。玩家先冲进来，同伴从中间一左一右往外，一个接一个（每隔 1.1 刻）；按格子一上一下（第 1、3、5 格从上往下，第 2、4 格从下往上）。镜头跟着从远处冲过来 |
| 落位爆闪 | 4.5–9 | 玩家到位那一下中间横着炸开一团白光，能量底显出来，画面轻震；每个人落位时镜头冲过头一点再回来，歪的角度摆正；最后一位在 8.9 刻到 |
| 停留 | 9–21 | 镜头照各自的档案继续推、扫、升降（越来越慢，但不停）；角色极慢地漂；速度线、能量雾、光屑一直在走 |
| 过曝预升 | 21–23 | 整体变亮，光线变粗，光幕泛起一点 |
| 峰值 | 23–25.5 | 光幕在一刻半里盖上来；角色顺着进来的方向甩出屏幕（1.8 刻，越甩越快，拖影），镜头往前冲；她们大半出了格子以后，黑底在光幕底下化开 |
| 幕布 | 25.5–26 | 分格卸掉、界面回来，只留光线的残影 |
| 退潮 | 26–33 | 光幕前两刻退掉大半，后面拖个尾巴；压暗的战场慢慢回到原来的颜色，残影淡掉 |

## 怎么做到的

两步，都在世界画完之后、界面之前（`ScreenEffectMixin`，排在所有全屏通道最后，因为它是盖在整个画面上的 2D 层）：

1. **角色**：每一格的角色单独画进自己的一张贴图。做法和原版物品栏里的小人（`GuiEntityRenderer`）一样：把输出临时改到这张贴图（`RenderSystem.outputColorTextureOverride`），换一个投影，照常 `EntityRenderDispatcher.submit` 再 `renderAllFeatures`。只是换成透视的仰拍镜头（仰 5°），眼睛落在画面上方三成左右；镜头每帧都在动（下一节「每个人的镜头和光屑」）。
   - 同伴画的是她在切入里的样子（`CompanionStyle.Cutin`，见下一节）：一个不放进世界的展示模型，摆着她自己的切入姿势和表情，穿着她现在那一套（`CompanionEntity.outfitId`）。画面装她身上 1.15 格（大头的二头身，头约 0.4 格），是头到腰，竖在身侧、高过头顶的武器也在画面里。
   - 玩家画他本人：皮肤、手里的东西，摆出他档案（`HeroCutin.PLAYER`）里的架势，身子侧 18°。画面装 1.6 格，不是一张大脸占满一格。
   - 身子朝中间侧一点（再加上档案里的 `turn`），头回过来看着镜头。都按满亮画，不受所在位置的明暗影响；蹲着、游泳、滑翔时也站直了拍。
   - 展示模型不在世界里，不会自己长大：GeckoLib 的动画按它的 `tickCount` 走，不推就停在过渡的起点，几层表情全露出来（角色面板、友人帐也是每刻推一下）。所以刺穿那一拍就开始画（不显示），刚造出来的每帧快进两刻、到 8 刻为止，之后每个客户端刻推一下；冲进来时表情、姿势已经到位。
   - 贴图往画面下面多画 0.45 个画面高（`EXTEND`）：冲进来、甩出去时格子里露出的是身子，而不是贴图的下边；贴图的上下边再淡掉一点。逆光描边只描角色的轮廓，不描贴图的边。
   - 贴图宽半个画面，高按画面那一段最多 1440 像素算（4K 下按比例缩），播完就释放。五张贴图在 1080p 下约 60 MB 显存，只在这一秒多里占着。每一格用自己的投影矩阵缓冲，一帧里不在同一个缓冲上来回改写。
2. **合成**：一个全屏通道把主画面复制一份当底，压暗战场，再按分割线算出每个像素在哪一格：格里是她自己颜色的能量底、角色和逆光描边（冲进冲出时拖影）、飘在她前面的光屑；分割线是白芯加主题色外焰；最后是白光云、过曝和光幕。格子是直接算的，不用模板缓冲。

## 角色的姿势

切入里每个人都摆一个合人设的架势，不是站着。同伴的写在她的档案里：`CompanionStyle` 的 `cutin`（`Cutin(make, turn, shot, motes)`），和角色面板的 `showcase` 并排；玩家的是 `HeroCutin.PLAYER`。

| 谁 | 姿势 | 表情 | 从哪来 |
|---|---|---|---|
| 白梅 | 流火竖在右肩外（八相），刀尖过头，左手叉腰；握刀的手在胸口高度、肩膀外侧，不挡脸 | `face_kitsune`（狐狸似的眯眼笑） | 刀的编排（握点、刀向、刃向、左手）解出来的 |
| 精灵公主 | 世界树之弓拉满，朝前瞄，身子再侧 28° | `face_determined` | `use_mainhand:bow` 0.5 秒 |
| 琥珀 | 右手拄着长杖，左手抬到下巴前竖起一指（想到解法的那一下） | `face_focus`（竖瞳） | `act_formula` 0.7 秒的右手镜像到左手，再往里收 |
| 拉塞塔 | 炽焰长剑剑尖朝下拄在身前、手按剑柄（骑士拄剑），双翼全展 | `face_battle` | `crimson_sheathe` 0.8 秒 + `act_wingspan` 1.8 秒的翅膀 |
| 玩家 | 主手抬到胸前，手里的东西竖在脸旁；副手往前下方一展；两脚一前一后 | 皮肤本身 | `HeroCutin.PLAYER.pose()`（原版人形模型的骨骼角度，左手惯用时镜像） |

- 同伴的姿势是她动画文件里的 `cutin`，由 `tools/chain_cutin_poses.py` 生成：从她已有的出招、施法、小动作里取某一刻（都是照她的人设做的），几段叠起来，必要时左右镜像（把右手的手势搬到左手）、再微调几根骨骼。拿刀的姿势在已有动作里找不到合适的一刻时，写刀的编排（握点、刀向、刃向、另一只手、脚），由战斗动作的解算器（`tools/combat_author.py`）在她自己的骨架上解出手臂和刀，手一定握在刀柄上。表情、眼睛、嘴不写进去，交给 `face_*`。改姿势就改这个脚本再跑一遍，别的动作一个字节不变。
- **格子很窄**：五人时一格只有约 0.35 格宽，大约是肩宽。往两边伸的手臂、横着的刀剑会被斜边切掉，所以姿势都是竖着的：武器竖在身侧、高过头顶，或剑尖朝下拄在身前；手收在身前、脸旁。
- **刀要衬在暗底上**：流火是半透明的晶刃，横在白衣服前面几乎看不出来，只剩握刀的手停在小腹前（像把手伸进了衣服里）。刀身要伸到身体轮廓外面（也别躲在垂到肩前的头发后面）；握刀的手别停在身前正中、腰以下。五人时格子比她的头发还窄，竖在肩外的刀会被斜边切掉，只露出刀柄和一点狐火，两到四人时才看得全。
- 挑姿势先离线预览：`tools/geo_pose_preview.py` 把模型按某一刻摆出来平涂画成图（不进游戏，一次能看几十个候选，刀剑画成一条线），挑好了再进游戏截图确认。
- 加新同伴：在她的 `CompanionStyle` 里给一个 `Cutin`（造展示模型、`stage(表情, "cutin")`、要拿武器的照她的展示方法打开，再给镜头和光屑），在脚本里加她的取样，跑一遍。

**界面**：黑底盖着的那一段（黑底接管到幕布）在 `RenderGuiEvent.Pre` 以 `LOWEST` 取消；按 F1 隐藏界面时照样画，因为它不在界面层里。

## 每个人的镜头和光屑

每一格都是一个小镜头。镜头、光屑、格子的颜色都写在那个人自己的档案里：同伴在 `CompanionStyle.Cutin` 的 `shot`（`CutinShot`）和 `motes`（`CutinMotes`），格子的底色和光用她界面的 `night0`、`accent`；玩家在 `HeroCutin.PLAYER`。渲染器只读档案，不写死谁是什么样。

| 谁 | 视角 | 推 | 扫 | 歪 | 升降 | 光屑 | 意思 |
|---|---|---|---|---|---|---|---|
| 白梅 | 46° | 14% | 14° | 9° | 往下沉 | 狐火（淡粉） | 横扫、歪得最多：骄傲的九尾 |
| 精灵公主 | 38° | 20% | 4° | 5° | 不动 | 光叶（薄荷绿） | 几乎不扫，一直往脸上推：拉满弓时的专注 |
| 琥珀 | 42° | 10% | -10° | 7° | 往上升 | 黄符纸（正中一道朱砂） | 从左往右扫、慢慢升起来：想到解法的那一下 |
| 拉塞塔 | 50° | 8% | 8° | 4° | 往下沉 | 火星（橙金） | 最广、最稳，越来越仰拍：寸步不退的前排 |
| 玩家 | 42° | 14% | -10° | 4° | 往上升 | 星芒（暖金） | 正中那一格，暖金的底 |

- **镜头**（`CutinShot`）：
  - 视角：画面装的那一段高度不变（同伴 1.15 格、玩家 1.6 格），视角越广镜头贴得越近，伸向镜头的手和武器越大。第一版是 2.4 格外的长焦（不到 30°），透视很平。
  - 推、扫、升降：从她落位走到峰值，越走越慢，但到峰值还有三成速度，不会停住。扫的角度落位时在一半。
  - 歪：她的头往格子外侧倒，和斜分割线同向（正中那一格往右）；冲进来时多歪七成，落位后一两刻里摆正。
  - 大家一样的部分在 `ChainTimeline`：冲进来时镜头远六成、跟着冲过来（`approach`），落位时冲过头 6% 再用 3 刻回来，甩出时往前冲 35%；停留走到哪是 `progress`，歪的回正是 `settle`。
  - 格子窄，所以张力靠「往镜头方向」而不是往两边伸：广角加推镜，离镜头近的手和武器变大，不会被斜边切掉。
- **背景**（着色器里的 `energy`）：她自己的夜色当底；身后一团她主色的光，往外放射光束；大团的能量雾慢慢流；远处闪着小光点；速度线和两边的分割线一样斜，冲进来时又多又亮，停留时少一点、一直在走。都顺着她冲进来的方向走，比她慢（远）。
- **光屑**（`CutinMotes`，着色器里的 `motes`）：两层，中景是清楚的形状，近景是虚掉的大光斑，都比她冲得快（近）。冲得快时不画（一帧跳一大截只会一闪一闪），脸前面淡一点。五种形状：狐火、光叶、符纸、火星、星芒；加新的在 `CutinMotes.Kind` 和着色器的 `moteShape`、`moteDrift` 里各加一个，顺序要对上。
- **拖影**：冲进来、甩出去时，角色沿着来路拖出残影（从她半刻以前的位置拖到现在，取 8 次）。
- 加新同伴时给她挑一个合人设的镜头和光屑，写进她的 `Cutin`。

## 和 Sodium、光影的关系

- 不再渲染一遍世界，也不碰 Iris、Sodium 的类。光影包只管世界渲染，角色贴图是在世界画完以后画的，和角色面板、物品栏小人走同一条路，所以角色在各种环境下画出来一样。
- 合成只读主画面最终的颜色，和别的全屏通道一样。

| 环境 | 结果 |
|---|---|
| 不装 Sodium 和 Iris | 通过 |
| 只装 Sodium 0.9.2 | 通过 |
| Sodium + Iris 1.11.4，光影关闭 | 通过 |
| Sodium + Iris + photon v1.3b | 通过；刺穿那一拍的战场是光影包画的，格子里的角色和原版一样 |
| Sodium + Iris + Complementary Reimagined r5.9.3 | 通过；格子里的角色和原版一样 |

这些都是无窗口客户端的结果，其他光影包没有测过。GPU 耗时没有量。

## 光敏

- 平常：黑底接管（变暗）、落位爆闪（变亮）、峰值的光幕（变亮）三次明暗变化，落位和光幕隔 0.9 秒以上，任何一秒里不超过 3 次。后面几位落位时不再爆闪，只有镜头冲一下。
- 收尾不是全白。第一版是全屏纯白，盖满 4 刻，晃眼；现在：
  - 光幕用屏幕混合，从中间往外衰减得快（中间最亮约 0.55、四周约 0.12），像一团光从正中炸开；四周带一点小队的主色，底下的画面还看得见；
  - 底下的画面是过曝：亮处先烧白、饱和度掉，暗处还是暗的，像镜头被强光冲了一下，而不是盖了一张白卡。曝光只推高一成半，分割线只变粗一半，不把整片衣服烧成白的；
  - 盖满只有一刻半，退的时候前两刻就退掉大半；黑底、战场压暗、白光云都是慢慢化开的，没有硬切；
  - 正中横着一道虚的光条，光幕最亮时最亮；
  - 量过（白瓷测试台，世界本身平均亮度约 0.76）：整屏平均亮度停留时约 0.57，峰值约 0.77，接近纯白的像素最多两成、约一刻；第一版是 1.0，整屏纯白 4 刻。调亮度用 `chain_cutin_frames` 的截图量。
- 原版选项「隐藏闪电的闪烁」打开时：不爆闪，黑底用 2 刻慢慢盖上，光幕提前从预升前开始慢慢盖，退潮也更慢，曝光推得少一半。光幕盖满的时刻不变，以后接的时序不受影响。

## 能量底、光屑是画在屏幕上的

CINEMATICS.md 第三节不许后期里有固定在画面上的纹理。能量底（速度线、能量雾、光点）、光屑、焰柱是例外：它们只出现在黑底盖住世界的那一段，这时看不到世界在动，不会晕；而且它们自己一直在动。分割线本来就是画面上的图形。压暗战场那一段只做去色、调暗和暗角，没有纹理。


## 限制

- 只有画面，没有伤害、合围、标题字、台词和声音。
- 姿势是从已有动作里取的一刻，停留时身子不动（动的是镜头、背景和光屑），表情是已有的那几种，没有专门的喊话张嘴；要更夸张，就给某位单独做一段 `cutin` 动作，替换脚本的输出。玩家的皮肤做不出张嘴，原版手臂也弯不了手腕，只能靠这几个角度。
- 角色还是按满亮的平光画的，没有按她的主色打侧逆光。
- 演出期间不锁操作，转视角、走动照常，回来时可能已经看着别处。
- 播的时候世界照常在走，怪物照样会打你。

## 测试

```text
./gradlew test --tests dev.logos.dimension.ChainCutinTest -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/starbloom_orchestra.jar
./gradlew runClient -PldTest=group:chain_cutin -PldTestHeadless -PldTestWindow=1280x720 -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/starbloom_orchestra.jar
```

- `chain_cutin_full`：四位同伴都在，用 `ChainCutinRenderer.hold` 停在每一段上截图。
- `chain_cutin_frames`：四位同伴都在，每半刻截一张（66 张），拼成动图就是 40 帧每秒的真实速度。镜头、速度线、光屑、光幕这些动起来才看得出的，看这个。
