# NPC 模型制作指南：怎样做得好看

[NPC 模型美术规范](NPC_MODELS.md) 规定的是「能用」：骨骼命名、格式、尺寸、渲染方式、交付与验证。本指南讲「好看」：在保持可爱、保留角色特征的同时，融入 Minecraft 的整体美术风格。

内容来自艾洛蒂模型的多轮制作与验收，以及对几个优秀 YSM 角色模型（如目白麦昆、伊蕾娜）的测量。文中的数字以艾洛蒂为例，换角色时按比例调整，思路不变。

## 1. 先定显示高度，再按 2 倍制作

1. 先决定角色在游戏里多高。艾洛蒂发顶约 1.7 格，猫耳尖约 1.9 格。
2. 再按 2 倍制作，渲染器固定缩放 0.5。艾洛蒂发顶 55 单位，耳尖 60 单位。

不要反过来，拿一个已有的原尺寸模型直接放大 2 倍。YSM / TLM 的原尺寸模型（头 7×7×7）本身约 42–47 单位高，按 1 倍画已经接近 3 格。再放大 2 倍并缩放 0.5，游戏里会有 2.7 格以上。

放大已有版本还会把旧版本的问题一起放大，比例和形状都会变怪。要改尺寸，就按新尺寸重新搭。

艾洛蒂的参考数字（2 倍制作单位）：

| 部位 | 高度 |
|---|---|
| 脚底 / 膝 / 髋 | 0 / 13.5 / 25 |
| 肩 / 下巴 | 38 / 39 |
| 头部方块 | 11×11×11（艾洛蒂后来手改为宽 9、深 10.5） |
| 发顶 / 耳尖 | 约 55 / 约 60 |

- 约 3.5–4 头身，按「下巴到发顶」算一头。
- 腿约占全身的 45%。可爱来自大头和大眼，不靠短腿。
- 头发轮廓宽约为头宽的 2 倍，发量撑出可爱的轮廓。

## 2. 总体风格：粗贴图、细几何

- **贴图密度**：每单位 1 纹素（显示时每单位 2 纹素），接近原版玩家皮肤的颗粒感。「像 Minecraft」的根本原因就是这一点；贴图画得太细，看起来像高清图片贴在方块上。眼睛是唯一的例外，见第 3 节。
- **细节用几何**：高光、睫毛、嘴、扣子、发结、鞋扣，用 0.2–0.5 单位的小方块或薄片表现，填纯色，不靠提高贴图分辨率。
- **上色**：大色块加 2–4 级明暗，再加少量像素杂色。杂色要克制：每个纹素一个单位大，杂色多了像迷彩；1 像素交替的条纹像格子或砖墙。
- **颜色要更亮**：原版实体光照下，正面只有贴图亮度的约 74%，侧面约 50%。粉彩色要画得比参考图更亮、更饱和，否则游戏里发灰、发脏。
- **不画方向光**：明暗只画结构（发缕深浅、发梢、关节、褶子），不要把某一侧的光照画死，游戏会再按朝向着色。
- **旋转角度随意**：这是 Bedrock / GeckoLib 几何，支持任意角度，没有 Java 方块模型 22.5° 一档的限制。发条、褶片常用 1–20° 的小角度，翘起处用 30–60°。

## 3. 头和脸

### 头

- 头保持方形体积，正面是平的，不做鼻子，不做下巴形状。
- 侧面完全被头发盖住，从正侧面看不到脸。

### 眼睛（最重要）

- **位置与大小**：眼睛要低、要大。眼睛下缘离下巴约 1–1.5 单位，上方的额头被刘海盖住。眼宽约为脸宽的 30%，两眼间距约 1.5–2 个眼宽。
- **眼白**：至少露 1 纹素；可以按角色放在内侧，也可以放在外侧。
- **上睫毛**：做成凸出脸面的深色方块（约眼宽 +0.5、高 0.9、厚 0.8），外眼角另加一小块斜向下的眼尾。这条粗黑的立体横条是这种风格最醒目的特征，远看也能读出「大眼」。
- **眉毛**：细，每侧两段折出眉弓，颜色比头发略深的浅紫灰。大多藏在刘海后面，但必须在脸面之前，不能被推进脸里。
- **贴图精度**：每只眼一块平面，单独分配贴图（艾洛蒂为 **25×30** 像素），用来画描边、虹膜渐变、瞳孔和高光。这是全身唯一不遵守 1 纹素/单位的地方。
- **分层**：眼白、瞳、高光分开画成几层平面时，**瞳不能突出脸面**。

**凹眼结构（推荐）。** 很多二次元三维角色的眼睛凹在头里，瞳孔面放在里面，看起来像在看镜头。这里用同样的思路：

- 脸面上眼睛位置的纹素改为透明。
- 在脸面的**同一平面**放一块「眼睑」皮肤片，与眼睛同像素密度，颜色取自脸部贴图（含腮红），中间挖出圆角的眼眶。它正好补在挖空处，不和脸面重叠，所以不会闪烁。
- 眼睛各层从前到后放在头内：高光约 0.10，瞳约 0.24，眼白约 0.38，最深处约 0.50 放一块四周大出 0.6 的白色底片，斜着看也看不到头内部。

瞳比眼眶边缘深，转头时位移比眼眶小，相对眼眶会偏向镜头一侧。原版实体光照只按面的朝向着色，没有投影和环境光遮蔽，凹进去的朝前平面与脸面一样亮，眼白不会被压暗。第三方光影包可能有阴影，需要单独看。

### 嘴、腮红

- **嘴**：猫猫嘴（ω）由四段 0.2 左右粗的细线拼成，颜色浅（浅粉褐），不要用太粗的方块或太深的颜色。
- **腮红**：画在脸部贴图上，在眼睛下方外侧，左右对称。

## 4. 头发

头发决定一半的观感，也是最容易做丑的部分。

### 基本构造

- **每缕发一根骨骼**，由 3–5 段方块首尾相接，逐段累积旋转，做出弯曲。直直的一根很难看。
- 后一段比前一段略窄、略薄，转折处互相重叠（约 15%），不留缝也不闪烁。
- 发条厚约 1 单位，宽 1.5–4 单位，越到发梢越窄。
- 每缕一根骨骼，以后可以逐缕做摆动或物理效果。

### 各部分

**头顶**
- 头保持方顶，用十字形的发壳切掉四角。
- 边缘一圈发条：根在顶面靠边处，先平铺，再逐段折下，盖住发壳侧面。每缕的长度、折角、宽度都要不同；内圈再铺几缕短发打散。
- 避免三种失败形状：
  - 从发旋放射的直条，会变成**锥形尖顶**；
  - 先水平伸出再折下，会悬空成**灯罩**；
  - 每缕都一样，会排成**整齐的一圈**，像鼓边。

**刘海**
- 较宽、互相交叠的一层，先略鼓出再收回内卷，末端停在睫毛上沿，露出眼睛。
- 另加一两缕细发：一缕斜越过一只眼的上方，一缕落在两眼之间。
- 不要让刘海一根根分开像挂着的棍子，也不要把中间几缕垂到嘴边。

**脸前的发丝**
- 两侧各一缕细发，从太阳穴沿脸外缘下垂，到眼睛以下向内越过脸颊。参考日系插画中常见的处理。
- 位置要避开眼睛，不要盖住眼睛外侧。

**脸侧**
- 主鬓发绕过脸侧收向下巴，末端外翘，同时盖住侧脸。

**后脑与侧后方**
- 轮廓要**外凸**：先向后鼓出（约 20°），再逐段收回，发梢收向后颈。
- 不要让发条先竖直下垂、到发梢越翻越外，那样后脑是凹的。

**发梢外翻**
- 累计不超过约 40°。翻得太多会像翅膀一样向两侧张开。

### 其他注意

- **底层**：头发下面要有贴头的底层（发壳、两侧、后脑），颜色用偏深的浅紫，防止从发条缝隙看到头皮或头内部。
- **高光位置**：高光（天使环）不要每缕都画在同一行，会连成一条「发箍」；放在头顶发条的折弯处，并错开。
- **发饰**：蝴蝶结等发饰、绑起的小束，要做得够大，能一眼认出。

## 5. 兽耳

- **耳框**：不要用一层层收窄的方块拼，那样又薄又像台阶。用两条斜置的长方体搭三角形耳框，要有厚度（2 倍制作下约 1.8–3.5），耳尖补一小块。
- **耳廓与绒毛**：耳背填满；粉色耳廓比耳框前缘后退约 0.25，要露得出来，退太多会被耳框挡住。耳内下部放几簇斜向上的白色绒毛，比耳廓靠前。
- **耳根**：抬到头发表面之上。被头发埋住的话，耳廓和绒毛都看不见。
- **朝向**：耳框可以绕 Y 轴转一点，让耳朵像向前张开的杯形。转完要检查耳廓和绒毛是否还在耳框里、看得见。

## 6. 身体

- **脖子**：宽约胸宽的 3/5，太细像竹签。
- **肩**：用斜置的肩部方块从脖子过渡到上臂，收窄肩宽，体型不会显得魁梧；手臂贴近身体、略向外张。
- **腰**：在毛衣下摆与腿之间加几块腰部方块，让身体到腿的过渡自然，裙下仰视也不会断开。
- **手臂**：不要太粗。袖子按「上袖 → 渐宽的下袖 → 罗纹袖口」分段，手不做手指，前臂方块直接当手。
- **服装分层**：外衣和里面的衬衫是两层，有前后关系，不要画在同一个面上。比如毛衣前片用透明的 V 领开口，露出后面单独一层的衬衫和扣子，V 领边用斜置的细条；尖领压在外衣领口外。
- **领口、袖口、袜口**：这类细节做成套在肢体外的一圈方块，或画在贴图上的两三道条纹，不用画出每一针。

### 体态细节：轮廓、结构线、省略

参考图（尤其是按「Minecraft 和 TLM 风格」生成的图）常带有胸部曲线、锁骨这类细节。不用全做成平板身材，也不追求真实曲线，按三档取舍：

| 档 | 用什么表现 | 内容 |
|---|---|---|
| 轮廓 | 几何，每处 1–3 个方块 | 胸部、收腰、肩宽、臀胯，主要看侧面剪影 |
| 结构线 | 贴图，每处 1 纹素的深浅 | 锁骨、胸下阴影、腰线、膝盖 |
| 省略 | 不做 | 肚脐、肌肉、真实的胸部曲面 |

- **轮廓用台阶，不用曲面**：胸部在躯干正面加 1–2 级小台阶，每级突出 1–1.5 单位（2 倍制作），上面那级比下面小，只占 2–4 个方块。原版实体光照会让台阶上表面亮、下表面暗，体积感自然出来，不用另画阴影。不要用旋转方块或一堆小方块拼圆弧，会破坏像素颗粒感，显得廉价。
- **曲线主要靠服装表现**：腰封收腰、泡泡袖撑开肩线、裙子外散。衣服盖在身体外面，所以胸部台阶实际做在服装的方块上，下面被盖住的身体面隐藏，不额外占方块。因此服装零件要按身体分开做。
- **结构线只画贴图**：露肩款的锁骨，用肩颈交界处 1 纹素略深的肤色加 1 纹素高光就够。被衣服盖住的地方不画。
- **按身体区分**：
  - 成年女性：胸部小台阶，腰线收窄；
  - 成年男性：肩更宽，胸背平直，腰线不收；
  - 幼年：全平的中性身体，不做台阶。
- **按角色设定**：娇小、偏少女的角色（如艾洛蒂）可以全平，体态差别本身也是设定的一部分。
- **保持克制**：普通居民数量多、到处可见，体态细节宜少，符合 Minecraft 全年龄的整体气质。重要 NPC 可以多一级细节，但仍然只用台阶加贴图线。胸部台阶的大小不做成随机参数，体型参数只控制胖瘦和身高。

## 7. 裙子、尾巴

### 百褶裙

- 每片褶一块薄板、一根骨骼，方便以后做物理效果。
- **褶的正确角度直接做在模型的静止姿势里**，不要指望用叠加动画去「摆正」。动画和物理只在静止姿势上叠加小幅变化。
- 整齐的百褶要按「褶峰—褶谷」交替的折线摆：
  1. 裙摆一圈取 2N 个点，外（峰）、内（谷）交替；
  2. 每片褶连接相邻的峰与谷，顶端都在腰围上，藏在上衣下摆里；
  3. 相邻两片在裙摆处共用一条边。
- 角度、半径随意交替的褶片会显得很乱。
- 里面加一层颜色深一级的衬裙，挡住褶片之间的缝。

### 尾巴

- 骨骼链（`Tail → Tail2 → …`），越往后越细，末节可稍大做出蓬松感。
- **根部放在上衣下摆与裙腰之间**，在下摆里藏一点。第一节向后倾约 40°，越过裙子外侧，再接近竖直下垂，末端勾起。
- 不要让尾巴从裙子里面穿出来。

## 8. UV：尽量用满

| 做法 | 说明 |
|---|---|
| **单色面共用 1 个纹素** | UV 取纹素中心、尺寸为 0（例如 `[12.5, 40.5, 12.5, 40.5]`），不会采样到旁边的颜色。 |
| **相同的面共用一块** | 像素完全相同的面共用同一块区域，例如左右对称的部件、重复的褶片、同尺寸的发条。 |
| **看不见的面不分配 UV** | 面的 texture 设为空，例如被下一段盖住的发条上表面、被头发盖住的头部侧面和后面。这类面也不会渲染。 |
| **紧密排布** | 其余区域按高度从大到小排，不留间隔。 |
| **尺寸不必是 2 的幂** | Java 版实体贴图不要求，例如 64×80、96×80。以后加表情时再扩大。 |

艾洛蒂的贴图利用率约 81–92%。

在 Blockbench 里手改时：

- **自动 UV 会撞上已占用的纹素**：新加的方块可能被放到别的部件正在用的纹素上，给新方块上色时，会把别的部件也染了色。艾洛蒂 v9 的腰部方块就把眼白染成了浅蓝。加完方块要检查它的 UV 有没有落在已用区域。
- **拆分或缩放后 UV 会变形**：方块拆分、缩放后，UV 可能出现小数或尺寸不符，贴图被拉伸。要按实际尺寸重新取 UV。
- **故意共用纹素要能说清**：有意让两个面共用纹素是可以的，但要确认重叠的像素只出现在看不到的地方，或者颜色相同。

## 9. 在 Blockbench 里手改后的检查

手改完、交付或打包前，逐项看一遍：

1. **方块都在骨骼里**：放在大纲根层的方块，Bedrock 导出时会落进单独的静态骨骼，不跟随身体动作。
2. **名称唯一**：复制出的方块、骨骼沿用了原名，要改成唯一名称。
3. **脸部部件在脸面之前**：移动过脸面后，眉毛、嘴、睫毛这类部件要检查有没有被推到脸面之后（看不见）。
4. **缩放后贴图没被拉伸**：缩放过的部件（比如改了脸宽），贴图要按新尺寸重画或重取，保留原来的颜色和位置。
5. **内部部件还在原位**：转动或加厚外框（耳框、外衣）后，里面的部件（耳廓、绒毛、衬衫）要还在里面、看得见。
6. **以最新手改为准**：之后的修改都以最新手改保存的 `.bbmodel` 为准，在它的副本上做局部修改，不要重跑旧的生成脚本覆盖。

## 10. 动画与物理

- 静止姿势必须本身就好看、正确。
- 动画与物理只做叠加：头发、裙褶、尾巴各自是独立骨骼，物理效果在渲染器代码里按 NPC 的移动和转身计算摆动，叠加在静止姿势和动画之上。
- 发光部件用 `ysmGlow` 前缀骨骼，见规范第 5 节。

## 11. 验收前自查清单

- [ ] 游戏内显示高度符合设定（2 倍制作，缩放 0.5）；
- [ ] 正、侧、背、3/4 都看过；侧面看不到脸，后脑是外凸的；
- [ ] 头发每缕都弯曲，没有直条、锥顶、灯罩、整齐一圈、像翅膀的发梢，高光没有连成发箍；
- [ ] 眼睛够大、够低，眼白至少 1 纹素，瞳不突出脸面，睫毛条和眼尾清楚；
- [ ] 兽耳有厚度，耳廓与绒毛看得见，耳根在头发之上；
- [ ] 脖子不细，肩不宽，手臂不粗，腰与腿过渡自然；
- [ ] 体态只用台阶和贴图线表现，没有旋转方块拼的曲面；
- [ ] 外衣与内衣分层；百褶裙是整齐的峰谷折线，尾巴从衣裙之间伸出，不穿过裙子；
- [ ] 颜色在原版光照下不发灰；
- [ ] UV：单色共用纹素、无意外重叠、看不见的面没有 UV、利用率尽量高；
- [ ] 第 9 节的手改检查都通过，再走规范第 8 节的交付与验证。
