# 远行大陆草皮重做 · 0.5.1

覆盖全部 32 种草皮与四季，替换原先平均分布的细碎短线。采用成簇的草叶明暗、柔和斑块和不规则草根边缘，大面积铺设时保持安静、自然的地表。此处的类别只是材质方向，不新增或改动群系。

| 地表方向 | 对应环境与细节 |
| --- | --- |
| 草原 | 长风草原、旷野丘陵、野花草甸、牧草坡地、曦光林隙、星铃花甸；清新绿草与小簇草叶 |
| 落叶林地 | 山毛榉林、橡木林地、幽深阔叶林、古冠山毛榉林、铜叶林丘；暗绿、腐殖土与少量落叶，秋季增加褐金叶 |
| 湿苔 | 翳蕨密林、雾苔溪林、静水湖泊；偏冷的厚苔和连片明暗 |
| 松针 | 北境冷杉林、山地松林、杉影深林；橄榄绿苔草与细褐针叶 |
| 高山 | 高地草甸、裸岩山脊、古河峡谷、高山河谷；较短的灰绿草与少量石粒 |
| 寒地 | 北境白桦林、银桦疏林、寒带荒原、月露白桦林；淡绿草、枯叶与细石 |
| 海岸 | 浅海沙洲、白崖海岸、南方海湾；浅沙砾底、稀疏草芽 |
| 积雪 | 冰川雪岭、积雪峰顶；冷白积雪和低对比冰霜纹理 |
| 湿地 | 缓流河谷、芦苇湿地；深绿草与湿润泥炭斑块 |

每种草皮每季三套贴图，配合 0/90/180/270 度原版模型变体，减少相同图案排列；不增加单块的几何面数。全部为 32×32 不透明像素贴图，每个模型仍是带六面剔除的完整立方体。侧面包含草层阴影、起伏草根和成簇泥土纹理；底面沿用对应土层材质。冬季使用柔和霜色混合，寒冷环境覆霜更重，海岸不统一涂成白色。

不改碰撞、随机换季、植被密度、原版世界生成、葡萄或叶块资源。已有区块换用新模型与材质；保留所有注册 ID。没有新渲染器、持续扫描或地表方块实体；没有硬件 FPS 对照。

资源入口仍是 `tools/native_worldgen.py`。`tools/journey_art.py` 最后调用独立的 `tools/journey_turf.py`，生成 384 个六面草皮模型与各季状态。基础模型和贴图路径保留，额外两套使用 `_v1`、`_v2` 后缀，模型选择完全使用原版加权变体。

`group:journey_turf` 中四个场景为专门摆放的草原、林地地表、四季、32 种草皮对照，最后一个为真实自然生成森林。画廊临时关闭随机刻以避免四季对照在拍摄中换色，结束时恢复原值。截图位于 `screenshots/journey-turf/`，本轮验证范围见 [VERIFICATION.md](../VERIFICATION.md)。
