# 麦田平原与队徽怪圈

远行大陆新增 `logos_dimension:wheat_plains`，是一种极少出现的**大陆平原**，不是岛屿。只从现有长风平原的温带、少雨、内陆平坦气候中选址，使用一张低频原版噪声抽出连片稀有区域。该噪声只写入群系采样标记，不修改山体密度或海岸线；原版密度函数保持平原的缓坡高程。只影响新生成区块。

自然地表采用原版草方块和泥土，在裸露可耕土壤上逐列放置原版耕地和成熟小麦。4096 次原版候选/区块使可耕地面的期望覆盖率超过 99.999%；露天洞口、水面、裸岩和其他结构保留。小麦可以正常收割、重新播种，耕地遵循原版踩踏和干湿规则。没有矿物、动物或村民生成。

怪圈是 128×128 格的原版 NBT/jigsaw。团队提供的队徽在 `art/wheat_plains/team_logo.png`，由代码去除与边界连通的灰底，再将明暗转换为深色泥巴、土径和干草块，外围补双环。麦穗形成浅金背景，泥巴明确勾勒人物、护目镜、扳手与双环，土径填中间调，干草块表现倒伏麦秆。人物外缘加一格深色轮廓，避免三种黄色混在一起。没有注册新方块、物品或自定义渲染器；图案不会随作物成长消失，玩家仍然可以破坏它。

怪圈候选网格间隔 12 区块、分离 10 区块，只允许在麦田平原起始；一片较大的麦田可能有数个怪圈。原版重力处理器按每列地表落地，不削平、不复制土台。水面、岩石、其他群系的草皮受到保护，群系边缘不足以容纳整个图案时允许自然截断，不跨进水体或相邻地表。原版结构开关关闭时，麦田仍生成，怪圈不生成。

首次进入麦田平原会由原版位置条件授予紫色挑战级成就 **麦田怪圈**，播放原版挑战提示与音效。发现进度按玩家保存，重复进入不再授予；不需要额外奖励或聊天命令。

> 风吹过麦穗，未解之事也有了形状。

定位指令（在远行大陆内执行）：

```mcfunction
/locate biome logos_dimension:wheat_plains
/locate structure logos_dimension:wheat_crop_circle
```

这是蘑菇岛级别的稀有群系；原版 `/locate biome` 的有限搜索半径内可能没有，离开当前区域后再定位。旧存档已经探索过的区块不回填。

生成资源与俯视图：`python tools/wheat_plains.py`。模板审计：`python tools/audit_wheat_plains.py`。完整原版生成管线最后也调用此脚本。世界测试选择 `logos_dimension:wheat_*`；实际客户端场景选择 `group:wheat_plains`，该场景只寻找自然结构，不铺设测试麦田。
