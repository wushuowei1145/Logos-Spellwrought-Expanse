# 神狐和弓

神狐聚落的和弓，四套配色：素竹·米白握（`fox_yumi_bamboo`）、墨漆·朱红握（`vermilion`）、素竹·靛青握（`indigo`）、栗漆·褐革握（`chestnut`）。玩家按弓道的射法拉弓；骷髅等生物拿着它时就是一把原版弓。

## 1. 美术交付

仓库外 `art/fox_yumi/v01`：四套配色共用几何与 UV（86 个方块，贴图 24×72），GeckoLib 解析通过。弓已经分好节：`Weapon` 下 `BowGrip`，上弓身 `BowUpper1`–`10`、下弓身 `BowLower1`–`7`（上长下短，握把在下三分之一），两段弦 `BowStringUpper` / `BowStringLower` 与搭箭点 `BowNock` 都挂在搭箭点（弓网格 (0, 0.85, 3.09)）。弓身在 YZ 面里，+Y 上弭，+Z 弦侧，射向 -Z，握点在原点；弓高 32 单位。交付没有动作，也没有箭。

尺寸：combat 网格的 `scale` 是 1.625，第三人称弓高 41.6 像素，约玩家身高的 1.3 倍（真实的和弓约 2.2 米）。立体物品模型没有放大，骷髅等生物手里的尺寸不变。

导入时另加：

- `BowArrow`：放箭的骨骼，挂在 `Weapon` 下、枢轴在搭箭点。
- 箭（矢）：`combat/weapons/yumi_arrow.json` 与 `textures/entity/projectiles/yumi_arrow.png`（16×16），竹杆、筈、三片鹰羽、缠线与箭头，长 21 单位，原点在筈、箭头朝 -Z。搭在弓上和飞行中的箭用同一份网格。
- 物品图标（32×32）由各配色的贴图取色生成；手持、掉落用的立体物品模型是静止（不拉弦）的弓。

## 2. 机制

- 按住右键：搭箭、侧身对靶、双手把弓举过头顶（打起し，0.45 秒），再引分け（0.6 秒）拉到会，之后一直持满。
- 松开右键放箭。力度只从引分け开始算，按原版弓的曲线在 0.6 秒里拉满；举弓时松手不放箭，弓倒放回执弓（招式 `lower`）。
- 拉满时箭速 4.5（原版弓 3.0）、基础伤害 2.4（原版箭 2.0），满弓一箭约 11 点（原版约 6），散布减半。会暴击、吃附魔与药水箭，弹药与无限都走原版流程。
- 放箭后是离れ、返弦与残心（1.4 秒）；残心 0.75 秒后可以接着拉下一箭。
- 拉弓时视野像原版弓一样拉近。
- 玩家射出的箭标记为和弓的箭（`NatureAttachments.YUMI_ARROW`，同步并存档），客户端画成和弓的矢；生物射的箭保持原版。

## 3. 射法（招式 `combat/movesets/yumi.json`）

| 招式 | 时长 | 内容 |
|---|---|---|
| `ready` | 0.5 | 取弓，提到执弓的位置 |
| `idle` | 2.4 循环 | 执弓：左手握弓垂在左腰，上弭略向前，右手放在右腰 |
| `uchiokoshi` | 0.45 | 转身侧对靶、两脚分开（足踏み），弓提到身前取箭搭弦（弓構え），再双手举过头顶 |
| `lower` | 倒放 | 举弓中松手，倒放 `uchiokoshi` 回到执弓 |
| `hikiwake` | 0.6 | 左手推向靶的斜上方、右手拉到额前（大三），落到会 |
| `kai` | 1.6 循环 | 持满：左臂完全伸直推弓，略高于肩，箭在口高，右手在右颊后，右肘高抬在后；极轻的伸合（只有右手再拉一点） |
| `hanare` | 1.4 | 离れ：弦回弹、弓身颤动，右手向后一字甩开，弓在左掌中翻转约 200°（返弦）；残心时左臂保持伸直，再倒弓、转回正面 |

没有收弓动作：换物品立刻交回原版。

## 4. 弓的骨骼怎么动

弓的骨骼不在编排里直接写，由 `tools/yumi_moves.py` 的 `YumiBaker` 在烘焙每一帧时算出：

- **搭箭点**：编排的 `string` 为 1 时跟着右手拳心，为 0 时回到弦的静止位置。第三人称只跟拳心前后拉开，上下、左右只跟一小部分，箭始终近乎垂直于弓；第一人称完全跟着右手，箭从右颊下方斜着射向弓。
- **弓身**：按搭箭点拉开的距离占满弓的比例逐节弯曲，中段弯得多、靠握把与两弭的地方硬。满弓时的总弯角按“两段弦保持原长”标定（弦不伸缩）：玩家上段 23°、下段 67°。神狐手臂短，满弓只拉开弓长的五分之一，纯按弦长算弓几乎不弯，所以取玩家弯角的六成作下限。第一人称按镜头取景，拉开的距离比下段弦还长，弯角与第三人称相同，下段弦允许伸长（多半在画面外）。
- **弦**：两段弦从搭箭点指向弯过之后的两弭，沿长度方向伸缩。
- **箭**：箭筈在搭箭点，箭杆搭在握把右侧、左拳上方的箭台；箭长按满弓时箭头露出弓外 3.2 单位定。`arrow` 为 0 时缩成 0（还没取箭或已射出）。
- **返弦后的颤动**：`shiver` 叠在弯曲比例上。

左臂伸直用编排的 `straight`（`reach_out`）：给出握点的高度和前后，朝靶的一侧按该骨架的臂长伸到头，玩家、第一人称、神狐的肘部都不弯。握点比肩靠前，箭才能从脸前过，所以左臂朝内收约 19°。

整个人的转身用编排的 `turn`（Root 的 Y 旋转，第三人称见 [COMBAT_SKELETON.md](COMBAT_SKELETON.md) 第 2 节）。双脚的足踏み写在 `rfoot` / `lfoot`，玩家只取张开的角度。右肘高抬时把 `rlift`（抬肘扣分倍数）设为 0。

## 5. 第一人称

玩家第一人称骨架为刀剑取景，肩比眼睛只低 2 像素、靠前 3.5 像素，转身后左肩会挡在镜头正前方。和弓把整个身体压低 4 像素、左移 3.5 像素，手的目标按镜头坐标写（`fpv`）：

- 执弓：弓竖在画面左侧。
- 打起し：弓举到左上方、手臂伸远，不把弓举过头顶，准星一带保持看得见。
- 会：弓竖在准星左侧，左拳在下，左臂伸直（握点深度按臂长算出），箭从右下方斜着指向握把。
- 拉弦的右前臂贴着镜头时整段缩成 0（`rhide`），只看得到弓、左手和箭。

## 6. 生物

`YumiItem` 继承原版 `BowItem`，并加进 `skeleton_usable_bows`、`skeleton_preferred_weapons`、`enchantable/bow`、`enchantable/durability` 四个标签：骷髅拿着它用原版远程 AI 与原版射箭，射出的是原版箭。持物用立体物品模型，手臂平举时弓竖直、比原版弓大。

## 7. 制作

```bash
uv run --with numpy --with pillow python tools/import_yumi.py "<Minecraft MOD 目录>/art/fox_yumi/v01"
uv run --with numpy --with pillow python tools/yumi_moves.py "<Minecraft MOD 目录>" "<输出目录>" [动作名…] [--gif]
```

`yumi_moves.py` 把玩家第三、第一人称的动作写进 `combat/animations/yumi_{tp,fp}.animation.json`，在输出目录画每段动作的总览（玩家、神狐各两个角度，另有第一人称透视预览）与 GIF，并把神狐的动作写成 `yumi_fox.animation.json` 留档。预览在仓库外 `art/fox_yumi/anim_v02`。

`combat_author.py` 为和弓加了几项通用功能：`turn`（整个人转身，脚步跟着转）、`rlift` / `llift`、手的 `weapon` 模式（按武器网格坐标摆，`rweapon` / `lweapon`），以及骨骼缩放（导出 Bedrock 的 `scale` 轨道）。打刀重新烘焙与提交的动作文件逐字节相同。
