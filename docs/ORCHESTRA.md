# 乐团：指挥台、指挥棒与统一演奏

状态：第一版已实现（本文由设计稿改成实现说明，维护者 2026-11-11 的决定见第 13 节）。建立在魔女之森乐器
（[HEXENWALD_INSTRUMENTS.md](HEXENWALD_INSTRUMENTS.md)）之上，用到 #244 的两层音源、坐着拉的琴、纸带按声部移调和真实时间的播放时钟。
第一版没做的写在第 11 节。

## 1. 目标

- 一个玩家站上指挥台、拿着指挥棒，就能让一整个乐团按同一份总谱、同一个拍子一起演奏。
- 指挥的动作跟着音乐：按拍号画出正确的手势，拍点落在拍子上，强弱、声部进入、预备拍、收束都看得出来。
- 选中某个声部时，那个声部的乐器在画面里被这个声部的颜色描边。
- 合奏稳：所有乐器共用一个时钟，服务端卡顿时也不散、不哑（#243 的教训）。

不在这一轮：玩家亲手接管某个声部（第 10 节「B 方案」）、用指挥棒的动作控制速度、NPC 乐手。

## 2. 玩起来是什么样

1. 摆好乐器（方块乐器、放了手持乐器的乐谱架都算），在乐团前面放一座**指挥台**（朝向是放置时玩家面对的方向，也就是指挥面朝乐团）。
2. 拿着纸带右键指挥台，把**总谱**放上斜谱架（谱架上摊开一本谱子）；手打的多声部纸带、导入的 MIDI 都行，最多 16 个声部。
3. 拿**指挥棒**右键指挥台绑定它，再右键乐器一件件加进乐团（再点一次退出）；或者在指挥台界面按「召集附近」。
4. 打开指挥台界面（空手右键指挥台）：左边是声部（颜色、谁在演奏），右边是成员。自动分好的声部可以改。
5. 站上指挥台、拿着指挥棒右键指挥台（或给指挥台红石信号）：指挥先抬手预备一拍，乐团起奏。
6. 演奏中：界面里点声部、或拿着指挥棒右键空中选中一个声部，那个声部的乐器亮起描边；可以静音、独奏、调响度、调速度。
7. 最后一个音之后，指挥画一个收束的小圆弧，放下手；再过一会儿指挥台自己停下。

坐在大提琴、低音提琴后面的玩家（**A 方案**）：琴照常按总谱演奏，玩家的弓跟着拉——坐着时的动画看的是这件琴有没有在响，
乐团里的音也算，所以不用另做。

## 3. 指挥台与指挥棒

| 名字 | 种类 | 作用 | 合成 |
|---|---|---|---|
| 指挥台 `hexen_podium` | 方块，两格宽一格深：主块和指挥右手边的侧块，拆任一块整座拆掉，只掉一座和谱架上的总谱 | 存总谱、成员、声部分派、速度、响度；站上去指挥 | 讲台在上、金锭居中、深色橡木板 ×5 |
| 指挥棒 `hexen_baton` | 物品，不叠放 | 右键指挥台：绑定 / 开始 / 停止；右键乐器：加入 / 退出；右键空中：换选中的声部 | 木棍 + 金粒（无序） |

- 样子（`tools/instrument_art.py` 的 `podium_elements`）：两格宽的深胡桃木台身、台面下一道金线、台面略探出；台前（朝乐团）
  一级踏步，立面一排六朵星辰花镶嵌；台后两角各一根矮栏柱，金箍、金球，柱间一道低扶栏和两根细栏杆；台面前沿正中一座斜谱架，
  谱板向乐团倾 32°，托条朝着指挥，谱板上沿在指挥胸下（挥到拍点的手臂从上面过，垂着的手碰不到）。放了总谱时（方块状态 `score=true`）摊开一本谱子：红封面露一圈边，两页白纸各两行五线谱。
  贴图全部按路径复用（深色橡木板、金块、星辰花镶嵌、白 / 红 / 黑混凝土），没有新贴图。
- 指挥棒的物品图是代码画的 16×16：金色尾球、软木色握柄、白色细杆。
- 指挥站在台面中央（两格交界处），按「谁站在上面」找指挥：站在台面上、主手拿着指挥棒的玩家。不骑实体，可以自由转身。
- 指挥状态（站在台上、主手拿着指挥棒）下左键什么都不做：不挥手、不攻击生物、不挖方块，免得误伤乐手、拆掉乐器。
  客户端不发左键，服务端也拦一道（`AttackEntityEvent`、`LeftClickBlock`）。

## 4. 谁加入乐团

- **指挥棒点选**：指挥棒第一次右键指挥台时绑定（物品组件 `baton_podium` 记着维度和位置，提示里写着坐标）；
  拿它右键乐器加入这座指挥台的乐团，再右键一次退出。演奏中不能增减。
- **召集附近**：界面按钮，把台前方 16 格内、左右各 80° 扇形里的乐器一次加进来；已经属于别的乐团的不抢。
- **不自动加入**：放下乐器不会被谁收编。
- 限制：距离指挥位置 32 格以内，最多 32 件；一件乐器只属于一个乐团，加入别的乐团时从原来的退出。
- 自动退出：乐器被拆（方块实体移除时通知指挥台）；乐谱架上的乐器被拿走（架子换了方块状态之后通知，指挥台去掉演奏不了的成员）；
  乐谱架换了一件乐器则按新乐器重新分声部。拆掉指挥台时成员都放开。
- 成员、分派、锁定、速度、响度、静音、独奏存在指挥台里；乐器记着自己的乐团（`orchestra`）。正在演奏的状态不存：重进存档后是停着的。

## 5. 声部分派（`OrchestraArranger`，纯逻辑）

对每个「声部 × 乐器」打分：

- 能弹到的比例 × 40；整体移八度后（`MusicRoll.octaveShifts`）能弹到的音少于 60% 的配对不考虑。
- 音色号对上乐器种类 +100；弦乐合奏一类音色（44、45、48–51）配提琴家族 +60。对照：0–5 钢琴、6–7 大键琴、8/10 钢片琴、
  9/11–13 钟琴、14 管钟、16–20 管风琴、24/25/46 竖琴、40 小提琴、41 中提琴、42 大提琴、43 低音提琴、47 定音鼓、56 小号、
  68–69 双簧管、70 巴松管、72–75 长笛。
- 声部的中位音高（移八度后）离乐器音域中心每差 12 个半音 −10。

三轮配对，分数从高到低，同分时声部在前的、座次靠左（指挥的左手边）的先配：

1. 每个声部配一件（所以两把小提琴分到第一、第二小提琴，左边那把拉第一）。
2. 多出来的乐器去齐奏它最合适的声部。
3. 还没人演奏的声部叠给已经有声部、能弹多声部的乐器（钢琴、竖琴、管风琴、大键琴、钢片琴）。

换了总谱、成员变化时自动分一次。界面里手动改的锁定，之后自动分派不动它；解锁后重新分。

## 6. 统一演奏

### 6.1 一个时钟

- 指挥台持有播放状态：哪卷总谱、起点（真实时间 `System.nanoTime`，同 #243 修过的乐器时钟）、速度倍率。起奏时从
  「起奏小节的时刻 − 一个指挥拍」开始，所以先有一拍预备（位置为负）。
- 一个乐团状态包 `ensemble_state` 发给指挥台 96 格内的玩家：总谱、位置、时长、速度、每件成员演奏的声部、各声部响度、静音、独奏。
  开始、停止、任何改动时发，演奏中每 100 刻再发一次心跳。成员多也只发这一个包。
- 客户端（`Conducting`）每个乐团一个共用时钟（`MusicClient.Clock`：锚点 + 倍率，位置可以为负），每件成员一路
  `MusicClient.Track` 跟着它，只放分给它的声部，乘声部响度、去掉静音（有独奏时只留独奏）。松键按纸带上的毫秒记，
  对时、改速度都不用重排。心跳差 150 毫秒以上才挪时钟，只挪时钟、不止音；差 3 秒以上才重新定位。
- 演奏期间成员乐器自己的纸带、红石不起作用（`conductedBy`）；停了恢复。最后一个音之后 3 秒指挥台自己停下（尾音、收束做完）。

### 6.2 速度、响度、静音

- **速度** 50%–150%，演奏中改从下一小节起生效：在那条小节线上把时钟的起点换掉，位置不跳。音高不变。
- **声部响度** −12 dB 到 +6 dB，乘在力度对应的音量上（管风琴乘在混音的响度上）；**静音**、**独奏**每个声部一个开关。
- **从第几小节开始**：界面上选，起奏前照样有预备拍。

## 7. 指挥的动作

### 7.1 拍子从哪来：纸带的速度与拍号表

- 纸带末尾加一段可选的「速度与拍号表」（标记字节 `'T'`，每项 { 时刻、每分钟拍数 ×100、每小节几拍、拍单位 }），只在中途有变化时写；
  没有变化的纸带与旧格式逐字节相同，旧纸带照读。MIDI 导入把中途的 tempo（0x51）和拍号（0x58）都写进去；编辑器、导入界面保留它。
- `BeatMap`：按开头的速度、拍号和表里的变化分段。只改速度时小节、拍接着数；改拍号时从那里起是新的一小节（差一点点的当成小节线）。
  任何时刻 → 第几小节、第几拍、拍内相位；起奏前是第 −1 小节。

### 7.2 手势图形（`ConductorPattern`，纯逻辑）

棒尖在身前一个竖直平面上画标准的指挥图形，每一拍的拍点（棒尖最低、最快的一瞬）正好落在拍子上：

| 拍子 | 图形 |
|---|---|
| 一拍 | 下 → 上（快的三拍、二拍、3/8 一小节打一下） |
| 二拍 | 下 → 上 |
| 三拍 | 下 → 右 → 上 |
| 四拍 | 下 → 左 → 右 → 上 |
| 六拍 | 下、左、左、右、右、上（慢的 6/8） |
| 其他 | 第一拍下，中间几拍从左往右排开，最后一拍上挑 |

- 快的复拍子合拍：每分钟八分音符超过约 110 个时 6/8 打二拍、9/8 打三拍、12/8 打四拍。
- 拍内：0–0.4 弹起到这一拍的高点（先快后慢），0.4–1 落向下一拍的拍点（先慢后快，中间略往外鼓，走成弧线）。
  第一拍是整小节最低点；最后一拍弹得最高，为下一小节的下拍蓄势。
- 收束：最后一个音之后 1.2 秒画一个小圆弧，停在胸前，再用 1.5 秒放下。

### 7.3 跟着音乐变化（`Conducting.poseOf`）

- **强弱**：纸带到了之后算一条每 100 毫秒的响度包络（在响的音的力度之和，起音那一格加重，按 95% 分位归一），
  手势幅度 = 0.55 + 0.7 × 稍前一点（150 毫秒后）的响度。
- **提示**：某个声部休息了两小节以上（含从头休息到这里）、一拍之内要进来时，左手提前指向演奏它的乐器的中心；同时有几个时指最早的。
- **左手平时**：响的段落（幅度超过 1.05）跟着右手做镜像，否则自然放下。
- **预备拍**：起奏前那一拍的前 40% 从站姿抬起，然后照图形落到第一拍。
- 别人看到的和自己看到的按同一个时钟算。第一人称：拿棒的手跟着棒尖在拍子平面上的位置挪动、俯仰（`applyForgeHandTransform`），
  起点和原版拿东西的位置一样，不跳。
- 实现：`ConductingPoses` 加一个两手的手臂姿势 `CONDUCT`（NeoForge 的枚举扩展），指挥棒在被指挥时返回它；右臂指向棒尖在身前的位置
  （拍点时手臂在水平下约 28°，普通的拍弹到约 11°，每小节最后一拍弹到水平上约 20°；第二拍往身前收、第三拍往外），
  左臂指向提示的方向（世界方向按身体朝向换到模型里）或做镜像，平时垂在身侧略往后（不碰谱架）。左撇子整幅镜像。
- 指挥棒的物品模型改了拿法：原版拿剑的转法会让棒子垂直于手臂（手臂平举时棒子朝天），这里转到顺着前臂往前、略往上翘，
  握柄仍在拳里；第一人称缩小到 0.45。

## 8. 选中声部的描边（`PartOutline`）

- 只在选中声部时描；只有选中的人看得到（选中是各自客户端的事），并且要拿着绑在这座指挥台上的指挥棒，或开着它的界面；
  按 F1 隐藏界面时不画。没选中时一个通道都不跑。
- 演奏这个声部的每件乐器外面一圈这个声部颜色的线（16 种颜色，界面色块同色），720p 时 2 像素、1080p 约 2.7 像素，按屏幕高度缩放，
  最多 5 像素；线外再一道 1 像素的暗边，铜色的定音鼓配浅红的线也分得清。看得见的轮廓不透明度 0.95，被挡住的 0.36。
  这个声部有音进来时线变亮一下（160 毫秒衰减），静音时不亮。线是纯色，没有贴在屏幕上的纹理。
- 做法：世界画完之后，把选中乐器各格的方块模型（真实的几何，图集里透明的像素不算）按世界的投影画到一张和屏幕一样大的图上：
  g 是剪影，r 是没被挡住的部分（和半透明之前留下的深度比，玻璃、水挡不住，留 0.12 格余量）。再一个全屏通道在剪影外面一圈找最近的剪影：
  附近有看得见的就是实线，只有被挡住的就是淡线；手挡在前面的地方不画。时机在泛光之后、画风和黑白闪之前（`ScreenEffectMixin`），
  所以有没有 Sodium、用什么光影包都是同一条路，后面的全屏效果照样作用在它上面。
- 指挥台界面不模糊背景（只稍微压暗），选声部时看得见画面里的描边。

## 9. 界面（`PodiumScreen`）

- 顶上：总谱名、拍号与速度、演奏中的小节号。左边声部：色块、名字（纸带里的，没写时「声部 n」）、几件乐器 / 无人演奏 / 静音 / 独奏。
  右边成员（可滚动）：乐器、演奏的声部（叠了几个都列出来）、锁。
- 点声部选中它；选中后左键点成员让它改演奏这个声部（锁定）、右键成员解锁、潜行左键成员让它退出。
- 底下：召集附近、重新分派、速度 −/+（每次 5%）、从第几小节 ◀▶、开始 / 停止、取出总谱；选中声部的响度 −/+（每次 3 dB）、静音、独奏。

## 10. 以后

- **B 方案：玩家接管声部**：坐在琴后的玩家选「我来拉」，这件乐器的声部从总谱里静音、玩家实时演奏，演奏条上跟着指挥的拍子指示。
- 指挥棒真正「指挥」：鼠标划动的速度控制乐团速度。
- NPC 乐手；小军鼓、大鼓、镲、三角铁，之后单簧管、圆号、长号、大号。

## 11. 第一版没做的（设计稿里有）

- 加入时的小光点、拿着指挥棒时成员上方的声部色标（4.3）。
- 界面里拖动改派、点成员时在画面里闪一下它（第 9 节）；现在是点选。选中声部后用指挥棒右键乐器改派也没做（指挥棒右键乐器是加入 / 退出）。
- 乐团的复音预算（每件保底几个音、按密度分，6.3）：现在仍是全局 96 个音、公平让出。
- 编辑器里加速度、拍号标记（7.1）：编辑器只保留导入时带来的表。
- 收束时左手收拳、指挥的头看向选中的声部（7.3、7.4）。
- 响度、静音的改动是马上生效，不等下一小节；只有速度等下一小节。
- 两个客户端（指挥和听众）对拍点的多人验证。

## 13. 已定（维护者 2026-11-11）

1. 指挥台两格宽、更有气势。
2. 描边每个声部一种颜色，互不相同。
3. 只在选中声部时描边；选中时被挡住的乐器也描（淡的），平时不描。
4. 乐团上限 32 件。
5. 这一轮指挥动作只跟着 MIDI / 纸带的节奏走，不反过来影响速度；用指挥棒的动作控制速度留到以后。
