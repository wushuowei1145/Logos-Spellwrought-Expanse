# 腐败（Corruption）

腐败污秽是世界观里类似反派的存在：像幽匿一样不断扩散，吞噬碰到它的活物。代码在 `dev.logos.dimension.corruption`。

## 方块

| 方块 | ID | 说明 |
| --- | --- | --- |
| 腐败核心 | `corruption_core` | 一个腐败网络的中心。空手右键看网络大小和正在蔓延的电荷。拆掉不掉落 |
| 腐败污秽 | `corruption` | 被脉络转化的方块 |
| 腐败脉络 | `corruption_vein` | 贴在方块表面、能爬上墙和天花板，和原版幽匿脉络一样 |

污秽和脉络用锄挖得快，核心用镐。三者都不掉落（创造模式物品栏里有）。贴图由 `tools/CorruptionAssets.java` 画出（`java tools/CorruptionAssets.java src/main/resources`），核心的顶面和侧面带心跳一样的脉动动画。

## 玩法

- **蔓延**照搬原版幽匿催发体（`SculkSpreader`、`SculkVeinBlock`、`SculkBlock`）：电荷以光标的形式沿着腐败方块游走，停在脉络上时把脉络贴着的方块换成腐败污秽（每换一块用掉 1 点电荷），再从新的污秽往外铺脉络。原版代码把幽匿方块写死了，所以 `CorruptionSpreader`、`CorruptionBehaviour`、`CorruptionVeinBlock` 是各自的照抄。和原版不同的地方：
  - 污秽上不长幽匿感测体、尖啸体之类的东西，电荷在污秽上只衰减。
  - 能被换掉的方块是标签 `logos_dimension:corruption_replaceable`，默认就是原版的 `#minecraft:sculk_replaceable`。
  - 配置 `convertBlocks` 关掉后，脉络照样在表面蔓延，但不再换掉任何方块。
- **电荷从哪来**：
  - 放下核心时往四周撒一点（`seedCharge`）。
  - 核心每隔 `idleSeconds` 秒自己添一点（`idleCharge`），从网络里随便一格出发，所以网络没杀到东西也会慢慢长。设 0 关掉。
  - **腐败杀死玩家或生物时**，在它死的地方给杀它的那个网络加电荷，多少 = 最大生命值 × `chargePerMaxHealth`（默认 1：猪 10，玩家和僵尸 20，铁傀儡 100）。
  - 离核心越远电荷掉得越快，超过 `growthRadius` 格（默认 24，和催发体一样）基本长不动。
- **接触伤害**：玩家和非亡灵生物碰到污秽或脉络（站在上面、贴着侧面、走在脉络里都算），每半秒受 `contactDamage` 点魔法伤害（默认 4，无视盔甲、不击退），同时流失 `manaDrain` 点魔力（默认 8）。玩家掉的是 Logos 的魔力；Logos 的魔力生命体、森林精灵、神狐也会掉各自的魔力。亡灵（`#minecraft:undead`）、旁观者、创造模式不受影响。伤害类型 `logos_dimension:corruption`，死亡信息是“被腐败吞噬了”。

## 网络

- 一个核心是一个网络。它的光标放下的脉络和污秽都记在它名下，**网络大小**就是名下的方块数（不算核心）。玩家或命令放下的腐败方块，挨着哪个网络的方块或核心就归哪个网络，都不挨就不属于任何网络（照样伤人，但杀了东西不会蔓延）。
- 网络存在各维度自己的存档数据里（`SavedData`，ID `logos_dimension:corruption`），光标也在这里，所以核心只是一个记号，没有方块实体。
- **合并**：两个网络的方块（或核心）挨上时，小的整个并进大的（一样大时老的留下）：方块、正在蔓延的光标都归大的，小网络的核心消散。
- 方块进出网络靠方块自己的放置、移除回调。只设置不通知邻居的改动（比如 `/setblock ... strict`）收不到移除回调，所以每个网络每 5 秒查一遍名下已加载的方块，把不是腐败的除名。

## 拆掉核心

1. 拆核心的玩家看到和运镜测试方块一样的镜头：升到玩家头顶 10 格（被方块挡住就矮一些），看着核心原来的位置，升 24 刻、停 60 刻、回 24 刻（`CameraShots.play`，见 [CAMERA_SHOTS.md](CAMERA_SHOTS.md)）。只有拆的人镜头会动。
2. 核心不掉落，网络解散。
3. 名下的脉络和污秽**从核心开始一圈圈往外消散**：拆后 12 刻（镜头升到一半）开始，消散波每刻往外推 0.25 格（24 格的网络约 5 秒散完），每块消散 1.2 秒，颜色是发紫的病红。同一刻扫到的方块按区块分组，每组单独发给看得到那个区块的玩家。没加载的方块先留着，区块加载后再消散。消散中的网络也存在存档里，关服后接着散。
   - **污秽变回原来的方块**：蔓延把方块换成污秽时，网络记下了原来是什么。消散波扫到时原方块立刻放回去，污秽的样子罩在它外面一点点剥落（`Dissolving.replace`，见 [DISSOLVE.md](DISSOLVE.md)），像一层皮脱掉、露出底下的泥土和石头。
   - **脉络直接消散**（`Dissolving.blocks`），泡在水里的脉络留下水。
   - 玩家或命令直接放的污秽没有原方块，也直接消散成空气。

### 记原方块的开销

- 内存：每个由蔓延变来的污秽一条“位置 → 原方块状态”。方块状态是游戏里共用的同一个对象，一条只多一个位置和一个引用，约 20 字节；一万块约 200 KB。
- 存档：存成一张调色板（泥土、石头、草方块……通常只有几种）加每个位置的序号。
- 还原：消散波本来就是每块调一次 `setBlock`（以前是放空气），现在是放回原方块，次数一样，照样按圈分摊到每一刻。世界测试 `corruption_large_network_restores` 量过：3721 块的网络（另有一半铺着脉络），消散最慢的一刻，还原原方块 2.2–2.9 毫秒，同样的网络只放空气 2.1–2.7 毫秒（各 5 次，一刻的预算是 50 毫秒；还原的那组里有一次是 10 毫秒，像是刚开服 JIT 还没热）。客户端每块画的影子和以前一样多。

被合并掉的小网络的核心也是消散掉的，但没有镜头，也不会让小网络的方块消散（它们已经归大网络了）。

## 配置

`serverconfig/logos_dimension-server.toml` 的 `[corruption]` 一节，每个存档一份：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `convertBlocks` | `true` | 脉络是否把方块换成腐败污秽 |
| `contactDamage` | `4.0` | 每半秒的魔法伤害 |
| `manaDrain` | `8.0` | 每半秒流失的魔力 |
| `chargePerMaxHealth` | `1.0` | 杀死一个生物，每点最大生命值换多少电荷 |
| `seedCharge` | `24` | 新核心放下时撒的电荷 |
| `idleCharge` / `idleSeconds` | `4` / `60` | 核心自己添电荷；`idleCharge` 为 0 时关掉 |
| `growthRadius` | `24` | 离核心多远之后电荷很快散掉 |

## 没有做的

- 腐败感染生物（变成腐败生物）、腐败生物、净化手段、自然生成核心。
- 光标经过时的粒子：原版幽匿的电荷粒子是幽匿的蓝绿色，没借用。
- 消散的火星和柔光贴图仍是火的（消散本身的限制，见 [DISSOLVE.md](DISSOLVE.md)），只是染成了腐败的颜色。
- 超出视距的部分照样消散，但镜头只能看到区块已经发给玩家的范围（运镜的已知限制）。

## 测试

```text
./gradlew runGameTestServer -PdimensionTests="logos_dimension:corruption_*" -PlogosJar=/absolute/path/logos.jar
./gradlew runClient -PldTest=group:corruption -PldTestHeadless -PldTestWindow=1280x720 -PlogosJar=/absolute/path/logos.jar
```

世界测试：核心在泥土地上长出脉络和污秽并记在名下、记着原来是泥土，拆核心后变回泥土、脉络消失；猪受伤、戴头盔的僵尸不受伤；生存模式玩家站在脉络上掉魔力和血；被腐败杀死的猪给网络加电荷；两个网络挨上时小的连核心并掉；拆核心不掉落、近的先散远的后散、直接放的污秽散成空气；生存玩家拿镐拆得掉核心；大网络还原的耗时和存档读写。

实际客户端场景 `corruption_core_break`：草地上一片以核心为中心的污秽（记着原来是草方块）和外圈脉络，玩家拿铁镐真的挖掉核心，截图看镜头升起、污秽剥落露出草地并往外推、镜头回来，最后检查污秽全部变回草方块、脉络全没了。
