# 区域画风（World Styles）

一块区域的世界是另一种画风，比如黑白或童话风。站在门外，透过门能看到里面的画风，和外面格格不入；走进去，球形波从脚下铺开，整个世界变成完全体；回头看门外，那边才是原来的样子。

## 怎么用

在服务端登记一块区域，随存档保存，自动同步给这个世界里的玩家：

```java
StyleRealms.add(level, StyleRealm.of(
        new BlockPos(-14, 101, 10), new BlockPos(14, 160, 36),      // 区域范围，墙算在里面
        WorldStyle.FAIRY_TALE,
        StyleDoor.opening(new BlockPos(-1, 101, 10), new BlockPos(1, 104, 10), Direction.NORTH)));  // 门洞，朝外的方向
```

- 一个区域可以有多扇门，窗户也算门。
- `StyleRealms.clear(level)` 清空这个世界的区域，`StyleRealms.in(level)` 查询。
- 新画风：在 `WorldStyle` 加一项，再在 `post/world_style.fsh` 的 `applyStyle` 里加算法。

试效果：

```text
/alchemy realm demo fairy_tale
/alchemy realm demo monochrome
/alchemy realm clear
```

`demo` 在玩家面前搭一座带门的小院子并登记成区域，朝着门走进去就行。`clear` 只清登记，不拆院子。

## 看到的效果

| 位置 | 画面 |
|---|---|
| 门外，直接看 | 原画 |
| 门外，透过门看 | 区域画风的**预览档** |
| 走门进去 | 球形波从脚下铺开，扫过的地方升到**完全体**，波前有一圈光 |
| 门里，直接看 | 完全体 |
| 门里，透过门看 | 原画 |
| 走门出来 | 只有一圈光，门外本来就是原画 |
| 传送进出 | 球形波替换整个世界，波外保持原来的样子 |

为什么分两档：人穿过门的瞬间，门的视野已经盖满前方，按几何算波没有东西可换。分成两档后波才看得见：

| 画风 | 预览档 | 完全体 |
|---|---|---|
| 黑白 | 去色 | 再拉高对比、加暗角 |
| 童话 | 提饱和、暗部偏紫、描墨线 | 再涂抹成色块、亮部泛光、加暗角 |

## 怎么做到的

门和球都不往世界里画几何，只用两样东西：半透明之前的深度和最终画面的颜色。

- **门**：用深度还原每个像素的位置，看视线碰到物体之前有没有穿过门框所在的矩形。比门近的东西穿不过去，自然不会被染色，所以不需要模板缓冲。
- **球**：像素到球心的距离。超过 96 格的都算一样远，波走到那里就把天空也换掉了。
- **半透明之前的深度**：在 `RenderLevelStageEvent.AfterOpaqueFeatures` 留一份，原版高画质透明也是在这一步复制深度。这样玻璃和水挡在门前也不会打断门的判定。
- **进出判定**：镜头在区域范围内就算进入，不给玩家存状态，所以传送、死亡、重新登录都不会错。范围会自动扩到包住所有的门，保证穿门的那一刻正好算进入。
- **投影矩阵**：还原位置要用世界渲染真正用的那个，含视角晃动和受伤倾斜，否则走路时遮罩会和门框错开。
- **没有开销的情况**：附近 128 格内没有门、也不在区域里时，通道完全不跑。

## 和 Sodium、光影的关系

| 环境 | 结果 |
|---|---|
| 不装 Sodium 和 Iris | 通过，含原版高画质透明 |
| 只装 Sodium 0.9.2 | 通过，含原版高画质透明 |
| Sodium + Iris 1.11.4，光影关闭 | 通过 |
| Sodium + Iris + photon v1.4（延迟光照） | 通过 |
| Sodium + Iris + Complementary Reimagined r5.9.3 | 通过 |

这些都是无窗口客户端的结果，其他光影包没有测过。

GPU 耗时（RTX 5080，1080p，满屏童话风完全体，只算这个通道）：原版约 0.27 毫秒，photon 约 0.68 毫秒，Complementary 约 0.35 毫秒。中低端显卡没有测过。

## 限制

- **只能换画风，不能换地方**：门后就是这个世界门后真实的场景。想要门后是完全不同的地方，就把那个场景实际建在门后。透过门显示别处要再渲染一遍世界，那才是会和 Sodium、Iris 冲突的部分，不要走这条路。
- **区域要有墙**：从外面只有透过门才看得到里面的画风，没有门的方向看就是普通的地形。翻墙看进去、从高处俯视都是原画。
- **开光影时手盖在门洞上会被染色**：光影包把手合成进了画面，手又不在半透明之前的深度里，只能按手背后的东西判断。不开光影时没有这个问题。走进去之后手都会变，两边一致。
- **同屏最多 4 扇门**：取最近的 4 扇，再多的不生效。
- **滤镜叠在光影的结果之上**：只改最终画面，不改光照，同一个画风在不同光影包下观感不一样。
- **半透明和粒子按背后的东西判断**：门前的粒子如果背后是门里，会一起被染色。

## 测试

```text
./gradlew test --tests dev.logos.dimension.StyleRealmTest -PlogosJar=/absolute/path/logos.jar
./gradlew runClient -PldTest=group:world_style -PldTestHeadless -PldTestWindow=1280x720 -PlogosJar=/absolute/path/logos.jar
```

测兼容时加 `-PldTestSeedDir=/absolute/path/seed`。跑完先确认日志里有 `Using shaderpack`，再看截图里光影是否真的生效：光影包缺失时 Iris 会静默退回原版画面，场景照样通过。`world_style_fabulous` 只在没有开光影的环境下跑。
