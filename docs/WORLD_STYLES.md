# 区域画风（World Styles）

一块区域的世界是另一种画风，比如黑白或童话风。站在门外，透过门能看到里面的画风，和外面格格不入；走进去，球形波从脚下铺开，整个世界变成完全体；回头看门外，那边才是原来的样子。

## 怎么用

在服务端登记一块区域，随存档保存，自动同步给这个世界里的玩家：

```java
StyleRealms.add(level, StyleRealm.of(
        new BlockPos(-14, 101, 10), new BlockPos(14, 160, 36),      // 区域范围，墙算在里面
        WorldStyle.FAIRY_TALE,
        StyleDoor.opening(new BlockPos(-1, 101, 10), new BlockPos(1, 104, 10), Direction.NORTH)));  // 门洞，朝外的方向
```

- 一个区域可以有多扇门，窗户也算门。
- `StyleRealms.clear(level)` 清空这个世界的区域，`StyleRealms.in(level)` 查询。
- 新画风：在 `WorldStyle` 加一项，再在 `post/world_style.fsh` 的 `applyStyle` 和 `original` 里加算法。

试效果：

```text
/alchemy realm demo fairy_tale
/alchemy realm demo monochrome
/alchemy realm demo ink_wash
/alchemy realm clear
```

`demo` 在玩家面前搭一座带门的小院子并登记成区域，朝着门走进去就行。`clear` 只清登记，不拆院子。

## 群系画风

整片群系也可以是一种画风：把群系放进标签 `#logos_dimension:world_style/<画风>`，镜头在这个群系里时画面就是这个画风的完全体。现在只有云岫峰林在 `world_style/ink_wash` 里。

- 进出群系时 2.5 秒淡入淡出，不放波；换到另一种群系画风时先淡出旧的再淡入新的。
- 球形遮罩：离镜头 64 格以内是原画，64–128 格渐变，128 格以外（含天空）才是完整的画风。脚下和身边的东西看得清，远景才像画。遮罩以内整段算法都跳过，不花时间。区域和门的画风不带遮罩。
- 群系画风替代的是「原画」：在这种群系里，门外、透过自己的门看出去、波外，凡是原画的地方都是群系画风；区域自己的画风照样盖在上面。
- 镜头在水里、岩浆里时不算，淡回原画。
- 客户端设置 `biomeStyle`（`config/logos_dimension-client.toml`，0 到 1，默认 1）调强弱，0 关掉。

### 国画

云岫峰林的画风。底子是宣纸，墨只落在该落的地方：

| 部分 | 做法 |
|---|---|
| 淡墨 | 一个面先抹成一片（只在同一个平面上取平均，方块纹理没了，面与面的明暗还在），再按明暗定墨的浓淡：受光的顶面留白，向光的侧面一层淡墨，背光的侧面落重墨。原版白天地面亮度的中位数约 0.3、最暗一成约 0.18，曲线按这个定 |
| 边缘浓、中间淡 | 轮廓里侧 6–12 像素一圈墨更重，往面里淡下去 |
| 勾 | 两道外轮廓：细的湿笔断续、粗细随笔势变，粗的干笔更碎（飞白）。只勾前后差得多的地方（大于 1.5 格或距离的 6%），一两格的台阶不勾。远处的线淡 |
| 树叶 | 不勾线，整团落浓墨（墨团）；叶缝里漏出的纸和天也补上墨。苔藓石头上的绿也按这个算，成了一个个墨点 |
| 皴、点苔 | 崖壁中间调上竖着的长笔触；峰顶朝上的面上零星墨点 |
| 侧对镜头的面 | 落墨 |
| 淡彩 | 留六成原来的颜色（原版颜色本来就淡），绿往石绿、花青偏；墨越浓、离得越远颜色越少 |
| 远山 | 越远墨越淡，视距边上化进纸里，看不见区块的断口 |
| 天空 | 纸色，往天顶带一点花青的淡染 |
| 云带 | 峰腰 104–152 的云海和谷底 50–80 的薄雾，见下 |

- **没有贴在屏幕上的纹理**：笔触、墨色不匀、飞白、点苔这些噪声全部用从深度还原出来的世界坐标取，转视角时贴着山走。没有纸纹、暗角，也没有逐像素的抖动。天空的淡染跟着视线方向，和天一起转。
- 纸和墨的明暗跟着这一帧最终的雾色走（`ViewportEvent.ComputeFogColor`，排在最后），夜里纸也是暗的，下雨也跟着灰。
- 云带沿视线只在云带所在的高度里积分，十步；水平方向用世界坐标上的噪声剪成一团一团，随风慢慢飘（风另外传，笔触不跟着飘）。镜头周围 6–40 格内渐起，屋里、脚边不起雾。世界坐标每 4096 格重复，先取模再传进着色器，远离原点也不抖。
- 群系自己的原版雾推远到 64–420 格，国画的远山和云带负责氛围，能见度不再被原版雾压低。
- 高度是按云岫峰林的地形定的（台地约 88–92，柱顶 160–220）。别的群系想用国画，云带高度要跟着改。
- 参考：思路和几个参数（侧面落墨的范围 0.1、阈值 0.5、噪声 0.5，三个平面坐标相加贴噪声，两道勾线一道更碎）来自 [sacshadow/3D_ChineseInkPaintingStyleShader](https://github.com/sacshadow/3D_ChineseInkPaintingStyleShader)（MIT）。那边是逐物体的着色器，这里按后期重写，没有照搬代码。只让暗处洇开、噪声贴在世界坐标上的想法来自 [Heortappel-hub/Personal_Project_InkNPR](https://github.com/Heortappel-hub/Personal_Project_InkNPR)，那个仓库没有许可证，只参考了思路。

GPU 耗时（RTX 5080，只算这个通道，镜头在云带里、满屏都是地形）：不带遮罩的最费情况 3440×1369 约 1.1 毫秒、1920×1080 约 0.5 毫秒，同样条件下童话风约 0.3 毫秒，其中云带约占三分之一。作为群系画风带遮罩时，64 格以内不算，同一个画面（约一半在 64 格外）约 0.6 毫秒。中低端显卡没有测过，嫌重可以把 `biomeStyle` 调成 0。

## 看到的效果

| 位置 | 画面 |
|---|---|
| 门外，直接看 | 原画 |
| 门外，透过门看 | 区域画风的**预览档** |
| 走门进去 | 球形波从脚下铺开，扫过的地方升到**完全体**，波前有一圈光 |
| 门里，直接看 | 完全体 |
| 门里，透过门看 | 原画 |
| 走门出来 | 只有一圈光，门外本来就是原画 |
| 传送进出 | 球形波替换整个世界，波外保持原来的样子 |

为什么分两档：人穿过门的瞬间，门的视野已经盖满前方，按几何算波没有东西可换。分成两档后波才看得见：

| 画风 | 预览档 | 完全体 |
|---|---|---|
| 黑白 | 去色 | 再拉高对比、加暗角 |
| 童话 | 提饱和、暗部偏紫、描墨线 | 再涂抹成色块、亮部泛光、加暗角 |
| 国画 | 纸上落墨、勾线、树叶成墨团 | 再加远山淡墨、天空留白、峰腰云带 |

## 怎么做到的

门和球都不往世界里画几何，只用两样东西：半透明之前的深度和最终画面的颜色。

- **门**：用深度还原每个像素的位置，看视线碰到物体之前有没有穿过门框所在的矩形。比门近的东西穿不过去，自然不会被染色，所以不需要模板缓冲。
- **球**：像素到球心的距离。超过 96 格的都算一样远，波走到那里就把天空也换掉了。
- **半透明之前的深度**：在 `RenderLevelStageEvent.AfterOpaqueFeatures` 留一份，原版高画质透明也是在这一步复制深度。这样玻璃和水挡在门前也不会打断门的判定。
- **进出判定**：镜头在区域范围内就算进入，不给玩家存状态，所以传送、死亡、重新登录都不会错。范围会自动扩到包住所有的门，保证穿门的那一刻正好算进入。
- **投影矩阵**：还原位置要用世界渲染真正用的那个，含视角晃动和受伤倾斜，否则走路时遮罩会和门框错开。
- **没有开销的情况**：附近 128 格内没有门、不在区域里、也不在带画风的群系里时，通道完全不跑。

## 和 Sodium、光影的关系

| 环境 | 结果 |
|---|---|
| 不装 Sodium 和 Iris | 通过，含原版高画质透明 |
| 只装 Sodium 0.9.2 | 通过，含原版高画质透明 |
| Sodium + Iris 1.11.4，光影关闭 | 通过 |
| Sodium + Iris + photon v1.4（延迟光照） | 通过 |
| Sodium + Iris + Complementary Reimagined r5.9.3 | 通过 |

这些都是无窗口客户端的结果，其他光影包没有测过。

国画另测了一遍（`cloud_peaks_pine`，白天、夜里各一张）：只装 Sodium 0.9.2、Sodium + Iris 1.11.4 关光影、Iris + photon v1.3b、Iris + Complementary r5.9.3 都通过，两个光影包的日志里都有 `Using shaderpack`。开光影时国画画在光影包的结果之上，光影包的光照会影响墨的浓淡。

GPU 耗时（RTX 5080，1080p，满屏童话风完全体，只算这个通道）：原版约 0.27 毫秒，photon 约 0.68 毫秒，Complementary 约 0.35 毫秒。中低端显卡没有测过。

## 限制

- **只能换画风，不能换地方**：门后就是这个世界门后真实的场景。想要门后是完全不同的地方，就把那个场景实际建在门后。透过门显示别处要再渲染一遍世界，那才是会和 Sodium、Iris 冲突的部分，不要走这条路。
- **区域要有墙**：从外面只有透过门才看得到里面的画风，没有门的方向看就是普通的地形。翻墙看进去、从高处俯视都是原画。
- **开光影时手盖在门洞上会被染色**：光影包把手合成进了画面，手又不在半透明之前的深度里，只能按手背后的东西判断。不开光影时没有这个问题。走进去之后手都会变，两边一致。
- **同屏最多 4 扇门**：取最近的 4 扇，再多的不生效。
- **滤镜叠在光影的结果之上**：只改最终画面，不改光照，同一个画风在不同光影包下观感不一样。
- **半透明和粒子按背后的东西判断**：门前的粒子如果背后是门里，会一起被染色。国画的云带同理：水面、玻璃、粒子按背后的东西算远近。
- **国画的云带是画上去的**：不挡视线、不遮实体判定，从云里飞出来时只是滤镜变淡；它和原版云、光影包的体积云各算各的。

## 测试

```text
./gradlew test --tests dev.logos.dimension.StyleRealmTest -PlogosJar=/absolute/path/logos.jar
./gradlew runClient -PldTest=group:world_style -PldTestHeadless -PldTestWindow=1280x720 -PlogosJar=/absolute/path/logos.jar
./gradlew runClient -PldTest=group:cloud_peaks -PldTestHeadless -PldTestWindow=1600x900 -PlogosJar=/absolute/path/logos.jar
```

`group:cloud_peaks` 在每个机位先拍一张关掉群系画风的原画（`_plain`），再拍国画；柱顶黄山松机位多一张夜景（`_night`）。镜头在群系外的机位（群系边缘回望）两张一样，这是对的。

测兼容时加 `-PldTestSeedDir=/absolute/path/seed`。跑完先确认日志里有 `Using shaderpack`，再看截图里光影是否真的生效：光影包缺失时 Iris 会静默退回原版画面，场景照样通过。`world_style_fabulous` 只在没有开光影的环境下跑。
