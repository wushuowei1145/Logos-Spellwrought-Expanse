# 精灵公主 · 同伴

第二位同伴。公共的系统（召唤收回、契、数值成长和继承、心智、表情、台词、对话、面板）见 [同伴](COMPANIONS.md)；
这一份只写她自己的。代码在 `dev.logos.dimension.companion`：`ElfPrincessCompanion`、`PrincessBow`、`PrincessMagic`、
`PrincessMind`、`PrincessMood`、`PrincessTalk`、`BaggedWorldTreeItem`；客户端的渲染在 `CompanionClient.PrincessRenderer`，
面板样式在 `CompanionStyle.PRINCESS`；客户端场景在 `client/PrincessViews`（组 `elf_princess_companion`）。

## 1. 她是谁

魔能之森的精灵公主，腐化女王的旁系亲属（她叫女王「姑姑」）。性格（维护者定的）：

- **近乎笨拙的温柔与使命感**：森林在哭泣，所以哪怕只有万分之一的机会，她也想试试看。
- **天然呆**：缺一点危机感。
- **温柔的任性**：净化腐化之心根本不是她的职责，但她觉得身为公主就该这么做。

这些落在游戏里：

| 性格 | 怎么表现 |
|---|---|
| 天然呆、缺危机感 | 敌人冒出来那一下她还在发呆，过一拍才「哇！」地吓一跳（`act_late_startle`），吓完才出手（主人血少时顾不上发呆）。新地方先愣住（`face_daze`） |
| 使命感 | 每天早上为森林祈愿（`act_pray`）；在林子里偶尔停下来听森林（`act_listen`）；主人打倒强敌时握拳给自己打气（`act_resolve`）；第四印「万分之一」 |
| 笨拙的温柔 | 治疗、护盾都照顾到你的宠物、使魔、别的同伴、森林精灵；你受伤、摔一跤，她是担心（`face_worried`），不笑话你 |
| 温柔的任性 | 对话「为什么要去净化腐化之心？」；不参与攻击时照样治疗 |

## 2. 加入方式和信物：袋装世界树

布袋子里装着一捧土，土上长着一株迷你世界树（图标是代码画的 16×16，`tools/bagged_world_tree_icon.py`）。她撤退时就是回到这棵小树里休养。

- **写着名字的**：召唤道具。右键叫她出来或收回；潜行右键让她留在原地或跟上。
- **空白的**：已经立契的人拿着它右键她，盖一枚**叶之契**（小树多长一片叶子）。
- 丢了：拿一株树苗（任意树苗）去找她，或者在对话里说「我弄丢了袋装世界树」，她用一捧土再做一个。
- **加入方式还没定**（原计划是腐化女王之战以后她成为同伴，见 docs/CORRUPTED_QUEEN_REMAKE.md 第 5 阶段）。在那之前：还没和她立契的人
  右键一袋空白的袋装世界树，这一袋就成了他的，她第一次从里面出来。空白的袋子放在创造模式「工具」标签页里；命令 `/alchemy companion princess summon` 也会立契并给一袋。

叫不出来（还在树里歇着）时不显示文字：袋子上的物品冷却转着，就是还要歇多久（上线时补上）；用它只会沙沙响一下、落几片小叶子。

## 3. 世界树之弓

就是玩家用的那把（docs/WORLDTREE_BOW.md），同一种箭；拉弓状态也挂在她手里那把弓的组件上，所以弓上一样凝出虚影箭、拉满出现实箭，
锁定一个响一声叮（她手里更轻）。弓平时不拿在手里，打起来才拿出来（一小阵叶子），打完六秒收起来。

| | 玩家 | 她 |
|---|---|---|
| 拉满（实箭出现） | 20 刻 | **12 刻**（在她手里蓄力更快） |
| 锁定间隔 | 4 刻 | **2 刻** |
| 魔力、箭 | 每锁 5 魔力，实箭 10 魔力加一支箭 | 不花 |
| 锁谁 | 框里的敌人，不锁玩家 | 框里的敌人；不锁主人、主人的宠物（含车万女仆这类有主人的生物）和使魔、别的同伴；「攻击玩家」开着时也锁和主人起冲突的玩家（打主人的、主人在打的、打她的） |

- **锁定模式**（敌人远）：每 2 刻锁一个，同一个目标一轮最多 2 次；拉满（12 刻）以后框里的都锁过了就放：每个锁定一支追踪箭，
  中间一支实箭（同玩家的伤害：追踪箭一个锁定 3 点、每多一个 +0.25；实箭 8 点并附生命易伤 I），两轮之间隔 18 刻。
- **散射模式**（敌人贴到 3.5 格内，是脱身用的）：横着拉弓（`bow_fan`），12 刻后 6 支箭水平扇形射出、穿透，再加一支穿透的实箭，**紧接着往后一跳**
  （`backstep`，往主人那边偏一点，落点不是悬崖、岩浆），隔 40 刻才能再散射。
- 箭都是生命伤害，按她的法术强度乘（箭的主人是她，Logos 按她身上的 `logos:spell_power` 算）。
- 她射的箭不伤主人、主人的宠物和使魔、别的同伴（`WorldtreeArrow.canHitEntity` 问她的 `canHarm`；穿透的扇形箭会扫过一路上的东西）。
- 渲染：原版的拉弓姿势（`use_mainhand:bow`，两臂平举），渲染器按她的视线把两臂连着弓抬到目标的高度（`npcAiming`）。

## 4. 生命涌动

她是辅助（维护者定的，2026-11-18）：本事花在照顾同伴上，打起来站在主人身后、离敌人远远的（第 5 节）。都按她的法术强度乘（第 9 节）。
施法有动作（走 combat 控制器），到出手的那一刻才生效；常青之息不用动作。

| 能力 | 契印 | 做什么 | 数 |
|---|---|---|---|
| 生命涌动·愈 | 本来就会 | 身边 14 格内血最少（低于八成半）的那一位回一口血：主人、主人的宠物和使魔、别的同伴（比如一起出来的白梅）、森林精灵（没在和主人、她打的）、她自己（排在最后）；它身边 4 格内别的受伤同伴也回一半 | 5 × 法强，每 4 秒一次（`cast_heal`）。走到 12 格内、看得见才放 |
| 常青之息 | 本来就会 | 她身边 8 格内受伤的同伴都回一点血；不用停下来、不打断别的事，脚边冒两点绿光 | 0.5 × 法强，每 2 秒 |
| 生命涌动·缠 | 第一枚 | 主人一打起来，就把生命之力缠到主人手上（Logos 魔力缠绕，生命元素）：主人每一下附带生命伤害 | 2.5 × 法强，30 秒，冷却 45 秒（`cast_bless`）。主人手上已经缠着东西（她的、白梅的狐火、Logos 的）时不缠 |
| 叶之护 | 第二枚 | 快撑不住（低于六成）、又被盯上的那一位，先给一层护盾（Logos 法术护盾，`Effects.shield`） | 8 × 法强，冷却 12 秒（`cast_heal`） |
| 荆棘缠绕 | 第三枚 | 对着强敌跪下按地，用游脉在它脚边绕一圈荆棘，留在地上 10 秒；碰到的受生命伤害，被往圈中间拉 | 载页 `data/logos_dimension/companion/spells/thorn_snare.logos`（维护者给的那一页，见下），每下 5 × 法强，冷却 20 秒（`cast_thorns`） |
| 万分之一 | 第四枚 | 主人血掉到两成半以下、在她 16 格内时，她一下子把生命之力全送过去 | 回主人生命上限的一半（乘法强，不超过上限），再给 5 秒生命恢复 II；每个游戏日一次。来不及做动作，直接放 |

强敌（荆棘缠绕只对它们用）：生命上限 ≥ 40，或者一下子围上来三个以上。

**荆棘缠绕的载页**：底稿是维护者给的那一页，改了三处——
1. 启式是 `cast` 时最外层没有 `target`，`foe` 对使魔来说是主人点名的目标；所以圈心用施放时交给她的那一点 `here`（代码传她在对付的那个强敌的脚下）；
2. 先把圈心记下来（`$c`），往记下的圈心拉（`on-hit` 里的 `here` 是碰到的地方）；
3. `:spread 360`，绕满一圈。

「攻击玩家」开着时代码在 `:trigger cast` 后面加 `:players true`，荆棘也缠和主人起冲突的玩家。载页可以直接改，改完重新加载数据包就用新的。

## 5. 心智和行动策略

通用的行为在 `CompanionMind`，她加了三个：`MEND`（治疗、护盾）、`BLESS`（缠上生命之力）、`ENSNARE`（荆棘缠绕）。打分：

| 行为 | 分 |
|---|---|
| 有人快撑不住又被盯上（给护盾） | 0.97 |
| 受伤的同伴（治疗） | 打着的时候 0.96，没敌人时 0.5 |
| 掩护主人（通用：主人四成血以下、敌人在旁边） | 0.95 |
| 荆棘缠绕 | 0.91 |
| 生命缠绕 | 0.9 |
| 迎战（通用） | 0.7–0.8 |

照顾同伴排在射箭前面：有人受伤时她先去治，治完再接着射。

**站位**：打起来时她先站好位置再射——从敌人看过去在主人身后 3 格；主人离敌人太近时再往后，让她离敌人不近于「隔开」的距离；
离那个位置超过 3 格才走过去，走位时不射。敌人近过「隔开」就往外退（退向主人那边）。

行动策略在她身上的意思：

| 策略 | 隔开 | 散射 | 她怎么打 |
|---|---|---|---|
| 随机应变 | 7 格 | 3.5 格内 | 站到主人身后锁定射；被贴到跟前才散射、往后跳 |
| 优先远程 | 11 格 | 3 格内 | 隔得更远 |
| 优先近战 | 5 格 | 4.5 格内 | 她没有近身武器，「近战」是站得近一点、早一点散射；不会冲上去 |
| 不参与攻击 | | | 不射箭，躲到主人背后（被贴脸就往后跳）；治疗、护盾照常（那不是攻击） |

后撤（血少）：退到主人身后，被追到跟前就散射一下往后跳，站定了照常锁定射。

## 6. 撤退：她为什么不会死

维护者的问题：同伴倒下以后回到玩家那里休息，之后还能再叫，要有合理的解释（有的角色是重伤后紧急撤退，白梅本来就是式神、留下形代替死）。
精灵公主这样表现：

> 她累到撑不住的时候，世界树会像荷花合拢那样把她包起来。所以她不会倒下，只是回去睡一觉。（往事第五段）

致命的一下打到她身上时不死（取消死亡事件，同不死图腾那一步之后），播 `withdraw`（3.6 秒）：

1. 中招一缩，膝盖一软跪下，合手按着胸针、闭眼低头（和白梅一样，倒下时不说话）；
2. 一朵张开的荷花从她脚下长出来（就是入场那朵花苞，倒着放）；
3. 花瓣合拢把她包住；
4. 整个花苞沉进地里，她回到袋装世界树里歇 5 分钟（袋子上的冷却转起来）。

撤退的这几秒打不到她、她也不动。和白梅一样不会自动叫回，要歇完再用袋子叫。

## 8. 对话和面板

- 话题：我弄丢了袋装世界树、你喜欢吃什么、森林在哭泣、为什么要去净化腐化之心、讲讲你以前的事、袋子里的小树、你觉得我怎么样、回去歇一会吧。
- 她一直用「你」，说话软，常常说着说着跑题，说到森林就认真起来。
- 往事十段（第 0 段本来就记得，之后每枚叶之契多讲一段），**草稿**，等维护者改：世界树下、姑姑、第一张弓、不会说谎的森林、走丢的那一天、
  荷花池、叶子发黑的那年、净化、万分之一、和你。
- 口味：最喜欢蜂蜜瓶、发光浆果、苹果（`elf_princess_favorite_food`）；不吃腐肉、毒马铃薯、蜘蛛眼、河豚、谜之炖菜（`elf_princess_refused_food`）。
- 面板：名字「精灵公主」、读法 Elfenprinzessin、称号「林间的净化者」，契印叫叶之契；数值页把攻击换成**法术强度**；纹是世界树的叶。

|---|---|---|---|---|

## 10. 模型和动画

模型和工具在 `MinecraftLogosMod/forest-elf-model/elf_princess_companion`（README 有每一版改了什么）；导出的三个文件原样拷进
`assets/logos_dimension/geckolib/…/elf_princess_companion.*` 和 `textures/entity/elf_princess_companion.png`。为进游戏加的动画（第 4 版，`tools/clips.py` 的 `GAME`）：

| 动画 | 控制器 | 内容 |
|---|---|---|
| `hold_mainhand:bow` | hold | 拿着弓，右手垂在身侧 |
| `use_mainhand:bow` | use | 原版的拉弓姿势（视线的俯仰、偏航由渲染器叠到 Arm 上） |
| `bow_fan` | combat | 横着拉弓，身子侧一点 |
| `backstep` | combat | 蹲、腾空收小腿、落地（位移由游戏给速度） |
| `cast_heal` / `cast_bless` / `cast_thorns` | combat | 治疗、缠绕、荆棘（直身跪下按地）；`heal` / `bless` / `root` 标记是出手的那一刻 |
| `eat` / `refuse` | misc | 吃东西（同白梅的 2.4 秒、三口、1.75 秒咽下）、不吃 |
| `withdraw` | misc | 撤退：跪下 → 荷花张开着长出来 → 合拢 → 沉进地里 |

入场的荷花苞是模型里的骨骼 `SummonBud`（平时缩到 0，渲染器只在 `summon`、`withdraw` 时画它）。

眼睛（模型第 5 版，从维护者手改的第 4 版来）：两眼之间的白线由维护者挪 `eyelid_left` / `eyelid_right` 修好；高光不画在瞳孔上，
画在独立的高光面 `LeftEyeShine` / `RightEyeShine` 上（同白梅），以后能单独动。
