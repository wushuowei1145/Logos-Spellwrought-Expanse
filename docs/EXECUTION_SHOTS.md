# 处决特写（Execution Shot）

投技、处决的特写镜头。约两秒：

1. 目标被抛到半空，画面突然变成黑白：背景白、身体黑（或反过来）。
2. 刀光从四面八方一道道穿过身体，越砍越快。每刀在身上炸开一朵火花，留下一道刀痕，刀痕一侧的身体被斩得错开一点；身体往刀走的方向一下子歪过去，四肢往反方向甩。镜头一刀比一刀推得近，集中线越来越密。只有三个节拍上（第一刀和两次切机位）黑白对调一拍再换回来。
3. 最后一刀划完，静下来一会儿。
4. 重击：背景变红，之前所有的刀痕同时爆开成白线，画面定格。
5. 目标被拍到地上：落地那一拍全白，然后恢复颜色，尘土炸开，镜头回到玩家。

## 怎么用

在服务端调：

```java
// Boss 抓住玩家：玩家自己看特写
ExecutionShots.play(player, player, ExecutionShot.of(random.nextInt()));

// 玩家处决一只怪：玩家看特写，怪被定住
int ticks = ExecutionShots.play(player, mob, ExecutionShot.of(random.nextInt()).slashes(8));
```

`viewer` 看特写（镜头和画面），附近其他玩家只看到目标被抛起、挨打、拍下。返回整段的刻数。

| 写法 | 作用 |
|---|---|
| `ExecutionShot.of(seed)` | 默认：12 刀，白底黑身，只在节拍上对调，带遮幅。同一个种子每次、每个客户端都一样 |
| `slashes(n)` | 重击之前有几刀，1 到 24 |
| `onBlack()` | 黑底白身 |
| `swaps(Swaps.BEATS)` | 默认。只在节拍上对调，每秒不超过三次；每刀有火花、斩开错位，镜头越推越近 |
| `swaps(Swaps.EVERY)` | 第一版：每刀都对调，没有火花、错位和推镜。每秒约 9 次全屏黑白交替，见下面「光敏」 |
| `swaps(Swaps.NONE)` / `noSwaps()` | 一次都不对调，其余和默认一样 |
| `noLetterbox()` | 不加遮幅 |

伤害、击退这些不在这里做，由调用方在合适的时候自己做。时刻都可以从 `new ExecutionTimeline(shot)` 取：重击是 `finalHit()`，落地是 `impact()`，单位是刻。

试效果用命令（只是画面，不扣血）：

```text
/alchemy execution                               处决自己，12 刀
/alchemy execution <目标> [刀数]                  处决一个生物
/alchemy execution <目标> <刀数> beats|every|steady   换对调的方式（默认 beats）
/alchemy execution <目标> <刀数> [样式] black      黑底白身
```

比较三种：`/alchemy execution @s 12 beats`、`/alchemy execution @s 12 every`、`/alchemy execution @s 12 steady`。

例如 `/alchemy execution @e[type=zombie,limit=1,sort=nearest] 10`。

## 可交互的处决

刀不是种子定好的，由处决的人点左键一刀刀砍出来（流火的处决就是这种，见 [流火](RYUKA.md) 3.4 节）。别的武器要用，在服务端调：

```java
ExecutionShot shot = ExecutionShot.of(seed).live(40, 0xF7B6D6);   // 留 40 刻（2 秒）点击；旁人看到的刀光颜色
InteractiveExecutions.start(player, target, shot, 1, handler);     // 两刀最短隔 1 刻
```

`handler`（`InteractiveExecutions.Handler`）在每一刀（`slash`）、重击（`finish`）、落地（`impact`）、结束（`end`，中途断了时 `completed` 为假）时被调，伤害、招式都由它自己做。

| 谁 | 看到什么 |
|---|---|
| 处决的人 | 特写。镜头锁着，左键（按它绑定的那个键）变成出刀：这边先画一刀，再告诉服务端 |
| 被处决的玩家 | 特写，刀由服务端一刀刀发过来 |
| 旁人（128 格内） | 目标在半空一刀刀被打歪，身上闪过刀光（`ExecutionSlashes`，`tint` 色） |

- **时间**：第一刀的时刻（0.3 秒）起开窗，开 `window` 刻；关窗后静 0.2 秒是重击，之后同普通的特写。重击、落地、整段时长只看窗口长短，和砍了几刀无关，所以两端仍然各算一遍。
- **节奏**：点击先排队，服务端每 `minGap` 刻结算一刀；关窗后 2 刻内到的还算（网络把相邻两刻的点击挤到同一刻送到时）。处决的人那边按同样的间隔先画，所以两边刀数对得上。
- **机位和节拍**：机位在窗口的三分之一、三分之二处切；黑白对调只在第一刀和每次切机位后的第一刀，任何一秒不超过三次。镜头一刀刀推近，16 刀推到最近。刀痕最多留最近的 24 道。
- **中途结束**：目标死了、处决的人死了、下线、换了世界或离目标超过 24 格。被定住的目标死了不再定住，照常倒下。
- **击退**：被处决的目标这段时间不吃击退（不然被定住的生物攒着速度，放开时一下子飞走）。
- **受击冷却**：被定住的生物不走刻，冷却不会自己退，`Handler` 每刀之前要自己清（流火的就是这样）。

## 节奏

默认 12 刀时的时间表：

| 时刻 | 发生什么 |
|---|---|
| 0 | 抛起。镜头 0.2 秒切出去，原画上压白色集中线 |
| 0.17 秒 | 快到最高点，画面突然变黑白 |
| 0.3 秒起 | 一刀刀划过。间隔从 0.12 秒缩到 0.085 秒，音调越来越高。第一刀对调 |
| 第 4、8 刀 | 机位硬切：侧面低角度 → 另一侧近一点、画面歪着 → 正面仰拍。切镜的同时对调 |
| 约 1.5 秒 | 最后一刀划完，切到远一点的机位。速度线停住，什么都不响 |
| 约 1.7 秒 | 重击：变红，刀痕爆开，视角猛地推近，镜头大抖，定格 0.25 秒 |
| 约 1.95 秒 | 往下拍，背景里竖着的速度线 |
| 约 2.1 秒 | 落地：白一拍，然后恢复颜色，尘土和烟往四周炸开，视角往外一弹 |
| 约 2.2 秒 | 镜头用 0.55 秒回到玩家，身体同时站起来 |

刀和刀最短也隔两拍多：对调的一拍和下一刀对调的一拍之间总有一拍换回来，再快也看得出是一刀一刀的。

刀数少时整段相应变短。刀少于 4 时不切机位。

## 为了张力和速度加的东西

- **一拍一张**：画面、刀光和身体的动作都按 24 帧一拍地跳，像动画；镜头的移动和抖动按帧连续地走。
- **顿帧**：刀划过身体的那一拍身体不动，下一拍才被打歪；重击后整个定格 0.25 秒。
- **蓄势**：最后一刀和重击之间留 0.2 秒什么都没有，速度线停住，声音全停。
- **长焦和推镜**：特写时视角收到 55 度；每刀猛地推近一点，重击推近并定住，落地时往外弹。
- **镜头抖动和画面倾斜**：每刀抖一下、歪一点，重击和落地抖得最厉害。
- **刀痕**：每刀划过后留一道细线，重击时所有刀痕同时爆开。
- **色差**：重击和落地的那一拍红蓝稍微分开。
- **声音**：原版的横扫、暴击、重锤落地、爆炸声，按刀的时刻逐帧放。

下面几样是为了不靠满屏闪烁也有节奏，只在默认（`BEATS`）和 `NONE` 里有，第一版（`EVERY`）保持原样：

- **受击火花**：刀划过身体的那一拍，在刀和身体相交的地方炸开一圈长短不一的尖刺（反色），下一拍缩小。只占身体附近一小块，不是全屏。
- **斩开错位**：每道刀痕把它一侧的身体沿刀的方向错开一点，刀越多身体越像被一块块斩开；重击时错得更开，拍下去时合回去。
- **越来越紧**：镜头随着刀数一点点推近（最多 7%），集中线从疏到密，拍下去时松开。
- **对调落在节拍上**：只在第一刀和两次切机位的那两刀对调，切镜加对调是一个重音。

## 光敏

常见的光敏安全线是任何一秒里全屏明暗交替不超过 3 次。

| 样式 | 对调 | 每秒最多 |
|---|---|---|
| `BEATS`（默认） | 第一刀、两次切机位，两次之间至少隔 0.35 秒 | 3 次 |
| `EVERY`（第一版） | 每刀 | 约 9 次，超出安全线 |
| `NONE` | 不对调 | 0 次 |

另外：

- 原版选项「隐藏闪电的闪烁」打开时，三种都不对调，落地也不白那一拍；黑白和红色照常。
- 重击变红只是一次变化，落地白一拍是一次闪；和节拍上的对调合起来，任何一秒里仍不超过三次。
- `EVERY` 只适合不怕闪的场合；要正式用它，建议在开头加光敏警告。

## 限制

- **只是画面**：身体被抛起、拍下都是画出来的，实体的位置和判定没动。旁人看到的身体在半空，碰撞箱还在地上。
- **定住**：不是玩家的目标这段时间整个跳过刻（不走 AI、不受重力、不着火结算）。玩家目标靠锁按键站住，别的东西照样能打到它。
- **剪影的范围**：剪影是「深度还原的位置落在身体的盒子里」，盒子比判定箱宽 0.6 格、高 0.35 格，跟着身体转。离目标很近的别的东西会一起变黑；手里特别长的武器会被切掉一截。
- **只有人形的模型甩四肢**：玩家、僵尸、骷髅这类用人形模型的会张开、甩动四肢；其余生物只是整个身体被打歪。
- **镜头路线**：机位被方块挡住时会缩到方块前面，但切镜和抖动都不做碰撞，贴墙时可能看到墙里。

## 实现

- `ExecutionTimeline`：时间表和每刀的方向、位置、力度，全由种子算出。服务端和每个客户端各算一遍，只发一次包。
- `ExecutionShots`（服务端）：发包；不是玩家的目标记下到哪一刻为止，`EntityTickEvent.Pre` 里整个跳过。
- `ExecutionClient`（客户端）：
  - 每个被处决的实体一段，按时间表算身体的姿态：整体绕身体中心的旋转和位移，人形模型的四肢。
  - 看特写的那一段还是 `CameraDirector` 的机位提供者（`CameraDirector.Rig`）：进出的过渡和遮幅照旧，停留期间硬切、抖动、倾斜。
  - 视角在 `ViewportEvent.ComputeFov` 里改，声音和尘土按帧放。
- `ExecutionEntityMixin`：取实体渲染状态时带上姿态，提交时在外面套一层旋转和位移，并去掉影子。`ExecutionModelMixin` 摆人形模型的四肢。
- `ExecutionRenderer` + `execution.fsh`：
  - 和黑白闪同一种全屏通道，排在区域画风之后、黑白闪之前。
  - 玩家的模型是半透明的，所以深度在半透明的实体画完之后（`AfterTranslucentFeatures`）留一份，水和玻璃不在里面。
  - 剪影：用深度还原每个像素的位置，换到身体自己的坐标里，落在盒子里就是身体。身体内部深度突变的地方画细白线，看得出手臂压在身前。
  - 刀光：画面上以目标为中心的一笔，刀头那端最粗、刀尾拖长，弯一点；压在什么颜色上就是它的反色。
  - 斩开错位：取剪影时，在每道刀痕正的一侧把取样位置沿刀的方向挪一点，那一侧的身体就错开了。
  - 火花：刀线上离身体中心最近的那一点，一圈 11 根长短不一的尖刺。

```text
./gradlew test --tests dev.logos.dimension.ExecutionTimelineTest -PlogosJar=/absolute/path/logos.jar
./gradlew runClient -PldTest=group:execution_shot -PldTestHeadless -PldTestWindow=1280x720 -PlogosJar=/absolute/path/logos.jar
```

客户端场景：

- `execution_shot_stills`：默认样式处决自己，每个阶段停一拍截图；检查不在节拍上的刀不对调、节拍上的刀对调、下一拍换回来、变红、落地全白，结束后镜头、身体、操作都还回来。
- `execution_shot_every`：用命令选第一版，检查每刀都对调。
- `execution_shot_mob`：用命令处决一只走动的僵尸，检查它被定住、身体按特写摆、结束后恢复。
- `execution_shot_timing`：真放三次，按帧记录。默认样式：阶段顺序、3 次对调、任何一秒不超过 3 次、约两秒落地、按住前进也不动；第一版：12 次对调；打开「隐藏闪电的闪烁」后不对调。
