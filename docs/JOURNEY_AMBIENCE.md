# 远行大陆环境微光 · 0.6.0

温带旅途大陆保留自然的天空和地表，在近处植被、水边和林间加入细微魔力活动。

| 环境 | 表现 |
| --- | --- |
| 温暖季节的黄昏、夜晚 | 暖金萤火虫成小群低飞，双帧翅膀、各自闪烁、缓慢盘旋 |
| 白天 | 春季淡金花粉、夏季薄荷浮光、秋季暖色微尘，在草叶和树荫间缓慢升起 |
| 冬季 | 冷蓝霜光，保留植物微光，停止萤火虫 |
| 花草和蕨类附近 | 偶尔出现小型四角星芒，轻转并上浮消散 |
| 水面和深处岩洞 | 已加载的水边有浮光；Y<55 的无天光原版基岩地表可有稀疏浮光 |

萤火虫属于环境粒子，没有可捕捉或掉落的生物实体。雨天停止出现；黄昏与黎明连续淡入淡出。三类粒子都使用原版粒子引擎，发光贴图在黑暗中可见，不投射动态光照，也不改变整片地形的亮度。已有露灯菌等植物的方块光保持原规则。

## 数量与生命周期

- 原版“全部粒子”设置：总计上限 80，萤火虫最多 40、浮光 32、星芒 8。
- “减少粒子”：总计上限 28，降低发射频率；“最少粒子”：清理并关闭本附属环境粒子。
- 只在远行大陆运行。切换维度、断开世界、离开玩家 24 格，或进入实体方块/流体时清理。
- 每 3 个客户端刻采样，减少设置每 8 刻；最多四个已加载近邻列、每列最多 12 个候选高度，不扫描整张地图，不请求未加载区块。
- 原版粒子池清空时会回收不再参与更新的本地记录，避免长期占满名额。暂停游戏不继续发射。

不新增实体、世界生成、方块实体、动态光源或线程。上述上限是代码与实际客户端检查覆盖的数量约束，不是测得的 FPS 提升比例。

粒子定义为 `journey_firefly`、`journey_mana_mote`、`journey_plant_glimmer`，美术为四张 16×16 RGBA 贴图。资源入口 `tools/ambient_particles.py`，由完整资源生成脚本调用；普通构建直接使用已提交文件。

实机场景为专门摆放的树林池塘，效果来自正式环境发射器。验证范围见 [VERIFICATION.md](../VERIFICATION.md)，截图在 `screenshots/journey-ambience/`。
