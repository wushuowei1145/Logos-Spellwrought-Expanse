# 声望

玩家在各个势力眼里是什么样的人：NPC 敌不敌对、肯不肯交易、愿意拿出什么、给不给授信。交易、职业、种族特产、稀缺物资都会把声望当作门槛来读，所以先做声望。

本文是设计方案，**尚未实现**。世界观以维护者的设定为准；mod 只发生在「彼方的世界」。

## 1. 原则

- **声望挂在势力上，不挂在种族上。** 种族不等于国家：荻原只有约三成居民是神狐，也有人类和少量灵猫（例如猫屋敷）；魔女之森由人类领导，内阁里常有灵猫。每个 NPC 记三项：种族（外观、语言、第一印象）、势力、派系。
- **冲突来自战与和，不来自种族。** 各族之间有芥蒂，但大多数人向往和平，也把玩家看作希望。所以各势力的初始态度最多是「冷淡」，不会一见面就敌对；只有玩家自己做了坏事才会掉到敌对。
- **不做零和的阵营战。** 在野外杀一个帝国士兵，不会让群狼或荻原给你加分，玩家不是哪一方的雇佣兵。加分看的是**保护**：击退正在威胁某个聚落的敌人（袭击队，第 5 节），那个聚落和它的势力会感谢你，不管来犯的是谁。会在多个势力之间连带的，只有「站在战争一边还是和平一边」（第 2.2 节）和名声（第 2.5 节）。
- **每个玩家各算各的。** 一个玩家做的事只影响他自己的声望（第 7 节）。
- **声望是门槛，不只是折扣。** 高声望换来的东西按各族设定区分（第 4 节），不只是同一份价目表打几折。

## 2. 结构

### 2.1 势力

| id | 势力 | 主要居民 | 货币 | 初始态度 |
|---|---|---|---|---|
| `sieglinde` | 齐格林德帝国 | 人类 | 铜分 / 银元 / 金冠 | 中立 |
| `hexenwald` | 魔女之森 | 人类、灵猫 | 便士 / 先令 / 金镑 | 友善 |
| `ogiwara` | 荻原 | 神狐，也有人类和少量灵猫 | 文 / 一分银 / 小判 | 冷淡 |
| `fenrir` | 群狼之国 | 群狼 | 阿斯 / 塞斯特斯 / 第纳尔 / 奥里斯 | 冷淡 |
| `elves` | 魔能之森的精灵 | 森林精灵 | 无 | 迷途者（见 4.5） |

- 魔女之森的金镑在魔法生物之间也流通，因为这个国家在它们眼里名声还不错。[ECONOMY.md](ECONOMY.md) 里写成「灵猫」的那套货币就是魔女之森的货币，以后改名时一起改。
- 精灵住在魔女之森境内，但不受国会管辖，是单独的势力；魔女之森的声望不会带到精灵那里。
- 灵猫和群狼的 NPC 还没做，可以先注册势力，NPC 做好后再接上。

### 2.2 派系（国家内部的主战与主和）

帝国不是从上到下都无可救药，荻原也不是人人都支持奉公权现。有派系之分的国家，在国家声望之外再给每个派系记一个偏移值：

| 势力 | 主战一侧 | 主和一侧 |
|---|---|---|
| 齐格林德帝国 | 军部：天空塔、腐败武器化项目 | 民间、前线军官和士兵 |
| 荻原 | 奉公权现 | 皇室旧部，海见这样的地方 |
| 魔女之森、群狼、精灵 | 第一版不分派系 | |

- NPC 看到的值 = 国家值 + 这个 NPC 所属派系的偏移。偏移限制在 ±500。
- 平常的事只动国家值。只有「站队」的事才动派系，而且会连带：例如替帝国军部回收腐败样本，军部偏移上升，帝国民间和荻原主和派的偏移下降，名声下降。
- 主和派之间互相认可：阻止一次屠杀、救下敌国的伤员这类事情，各国主和派的偏移都会上升一点。
- **玩家可以投靠主战派**：完成主战派的委托（第 9 节）就会提高主战派的偏移，同时降低本国主和派和各国主和派的偏移，恶名上升。主战派的委托报酬更高，路也更窄。
- 袭击队多半是主战派派出来的：击退它们只降低主战派的偏移，不影响那个国家的民间。

### 2.3 群狼的家族（第二版）

群狼的小队就是一个家族，佩戴同一个家徽。群狼的声望按家族记，国家值由各家族汇总：

- **共感**：帮了一个家族，这个家族的所有成员立刻都知道。其他家族要靠传闻，过一两天才知道，而且只按一定比例计入。
- 声望最高时，你会被家族接纳，得到家徽。
- 家族在生成群狼聚落或小队时随机产生，记家徽和名字。

### 2.4 聚落（第二版）

某个聚落对你可以比整个势力更熟或更冷，例如你救过的那个村子。不同聚落的风气也不同：现在的神狐聚落就像海见，知道开战了，但总觉得战争很远。这里的居民都是主和一侧，帝国军部那边的事情传到这里会被淡化。

将来如果战火真的烧到某个聚落，那是世界状态的变化，不在本文范围里。

### 2.5 名声（全局）

名声记的是「你有多出名」，不是「谁喜欢你」，分成**声名**和**恶名**两个独立的值：

- 腐败是所有人的共同敌人。帝国从文献里找到了它，从魔女之森招募炼金术师试图把它武器化，实验失败后失去控制。所以净化腐败会提高声名，所有国家的主和一侧也各加一点；魔女之森最在意这件事。
- 屠杀平民、帮腐败扩散会提高恶名。
- 你没打过交道的势力或聚落，按名声决定第一印象。

## 3. 数值与档位

- 国家值是 −1000 到 +1000 的整数，切成七档。**所有势力的档位范围和效果完全一样**，只是显示的名字按各自的文化来取（狼像家族里的称呼，荻原像神社和武家的用语……），写在语言文件里，代码只认下表的档位：

| 档 | 范围 | 默认行为 |
|---|---|---|
| 仇视 | ≤ −600 | 主动攻击，喊同伴；不交易 |
| 敌对 | −600 ~ −300 | 主动攻击；不交易 |
| 冷淡 | −300 ~ −50 | 不主动攻击；只卖基础货品，价格差 |
| 中立 | −50 ~ 50 | 正常交易 |
| 友善 | 50 ~ 300 | 更多货品，点差变小 |
| 尊敬 | 300 ~ 600 | 稀缺货品、授信、特殊委托 |
| 崇敬 | ≥ 600 | 势力专属奖励（第 4 节） |

- **初始值**：友善 = 100，中立 = 0，冷淡 = −100。
- **衰减**：每个游戏日朝初始值回落一点，速度按势力配置。精灵几乎不衰减，群狼的荣誉衰减慢、背叛的记仇更慢。
- **每日上限**：交易、小帮忙这类可以重复刷的来源，每天每个势力有加分上限。
- 名声的两个值都是 0 到 1000，不衰减。

## 4. 各势力的性格

底层数值一样，涨跌规则和奖励按设定区分。

### 4.1 齐格林德帝国

- 法治国家：在帝国境内犯罪会被**通缉**，通缉和声望分开记，可以交罚金撤销。
- 帝国币是基准货币，帝国城市是经济中心。
- 奖励：魔导装备、炼金材料，还有空间锚点这类军用装置。

### 4.2 魔女之森

- 多族共存、讲规矩，对玩家的初始态度最好。
- 奖励：星辰花之都和古辉老街的商店、秘径之门（可以接远行之门的样式）、学院藏书。灵猫在设定里能提升魔法师的魔力亲和，高声望可以和 Logos 的施法、编纂联动。

### 4.3 荻原

- 重礼节。神狐的力量依赖人类的信仰：在 hokora 供奉、写绘马，都会提高声望。
- [运势](LUCK.md) 里的「待人运」（`LuckKind.MEETING`）可以接成中立神狐的第一印象偏移。
- 奖励：神狐的祝福（作物、天气），狐钱的授信额度。

### 4.4 群狼之国

- 看重战功和荣誉，按家族记（2.3）。守诺、并肩作战会加分；背叛的惩罚极重，而且整个家族立刻都知道。
- 奖励：家徽；被接纳之后，同行的群狼会和你配合作战。

### 4.5 精灵

精灵与世无争：部落社会，没有经济的概念，也没有货币，族内接近共产。认定你是客人之后，几乎什么都愿意分享。所以精灵的声望不是价目表，而是**身份**：

| 身份 | 对应档位 | 表现 |
|---|---|---|
| 迷途者 | 中立及以下 | 森林会让你迷路，再莫名其妙地回到出口（第二版） |
| 客人 | 友善、尊敬 | 慷慨地分享食物、材料、住处，不收钱也不讲价 |
| 族友 | 崇敬 | 族内待遇，能参与部落的事务 |

- **第一次成为客人**：帮精灵清除一个腐败核心。在这之前，再怎么交易和帮小忙，最多停在迷途者；清除之后直接升到客人的起点。
- 之后的加分：种树、继续净化腐败、帮精灵打退敌人。
- 扣分：砍巨木、让腐败扩散，以及**贪心**。客人适度取用不扣分，但囤积精灵送的东西、拿去转卖会扣分。
- 精灵不接经济系统的点差和授信。

## 5. 加减分来源（第一版）

| 事件 | 变化 | 说明 |
|---|---|---|
| 攻击该势力的 NPC | 国家值 −，按伤害算 | 创造模式不算 |
| 杀死该势力的 NPC | 国家值大幅 −，恶名 + | 平民比士兵扣得更多 |
| 帮该势力的 NPC 打退敌人 | 国家值 + | 僵尸、灾厄村民、腐败生物；有每日上限 |
| 击退威胁聚落的袭击队 | 聚落和国家值 + | 见下文；来犯者的主战派偏移 − |
| 完成委托 | 发布者的国家值或派系偏移 + | 见第 9 节 |
| 和该势力的 NPC 交易 | 国家值小幅 + | 有每日上限；精灵没有这一项 |
| 在荻原的 hokora 供奉 | 荻原 + | 有每日上限 |
| 净化腐败核心 | 声名 +，各国主和一侧 + | 精灵附近的第一个核心让你成为客人 |
| 在野外杀死敌国士兵 | 不加分 | 见第 1 节 |

**袭击队**照原版灾厄巡逻队和袭击的思路：

- 威胁会主动找上聚落：腐败生物的潮涌、帝国的巡逻队、灾厄村民，按聚落所在的地方和世界的局势决定来的是谁。
- 只有袭击队打的是聚落、而你在聚落范围内击杀它们时才计分。按击杀数加分，守住整场袭击另有一笔奖励；有每日上限。
- 守住之后可以给一个类似「村庄英雄」的短时效果，比如这个聚落的交易更优惠。
- 袭击队里最先做腐败潮涌，因为它不牵涉任何势力；帝国巡逻队等派系内容定了再做。

第二版加「目击」：没有该势力的 NPC 看到，就不计。数据里先给每个事件留好「发生位置」和「目击者」字段。

## 6. 和现有代码怎么接

- **敌对判断**：`ForestElf` 和 `DivineFox` 现在只主动攻击 `isFoe` 里的目标（亡灵、灾厄村民、腐败生物），被打了才用 `HurtByTargetGoal` 反击。接入后加一个目标：玩家的档位在「敌对」以下时主动攻击。反击照旧，但反击会触发扣分。
- **腐败**：被腐败的玩家仍按 `CorruptionMobs.isCorrupted` 强制敌对，不看声望。
- **`ElfFactions`** 管的是原版怪物和精灵、神狐之间的关系，和玩家声望无关，保持不动。
- **经济**：[ECONOMY.md](ECONOMY.md) 后续计划里的「点差随声望变化」「按声望提高授信额度」直接读这里的档位。

## 7. 数据与代码

- 包：`dev.logos.dimension.faction`。
- **势力定义走数据**：`data/logos_dimension/faction/<id>.json`，写初始值、衰减速度、派系列表、档位名的语言键。改设定不用动代码。
- **存储**：每个玩家一份，存在玩家附件里（照 `Omikuji` 的写法，死亡后保留），只在服务端修改；只把玩家自己的值同步给他的客户端，供界面显示。
- **和原版的区别**：原版村民的「闲话」（gossip）其实也是按玩家记的。多人一起涨价，通常是另外两个机制造成的：一是**需求**，某样货任何人买多了，所有人的价格一起涨；二是旧版本治愈僵尸村民的折扣会被所有玩家共享（后来修掉了）。这里分得更清楚：
  - **声望**只属于玩家自己，别人的作为不会算到你头上；
  - **供需**是整个聚落共享的。谁把货买空了，所有人都会遇到缺货和涨价。这一点留给稀缺物资系统去做。
- **借鉴原版闲话**：聚落层（2.4）和第二版的目击判定，可以照闲话的方式做。每个 NPC 记着它对哪个玩家听说了什么，NPC 碰面时互相传话，时间久了慢慢淡忘。
- **API**：
  ```java
  int value = Reputation.get(player, Factions.OGIWARA);              // 国家值 + 派系偏移
  Standing tier = Reputation.tier(player, Factions.OGIWARA, faction); // 档位
  Reputation.add(player, Factions.OGIWARA, 20, Cause.OFFERING);       // 按 Cause 记每日上限
  ```
- NPC 实现 `FactionMember`，提供 `faction()` 和 `subfaction()`。
- 调试命令：`/rep get|set|add <玩家> <势力> [值]`，权限和 `/fx` 一样。
- 界面：一页声望列表，显示每个打过交道的势力、档位和档位名；没打过交道的势力显示「未知」。

2. 玩家声望存储、档位、衰减、每日上限、API、调试命令
3. 精灵、神狐接入：敌对判断，以及第 5 节里已经能触发的事件

**第二版**：群狼家族与共感、聚落层、名声、目击判定、精灵的迷途森林、帝国通缉、袭击队（帝国巡逻队等）、委托、经济点差和授信接入。

## 9. 叙事与委托

叙事走类魂的路子：没有指明的主线，也没有任务日志指路，只有各个聚落发布的委托、NPC 的只言片语和散落的物件。但无论玩家怎么走，最后都会走到主线上。声望就是这套叙事的骨架：

- **委托由聚落发布，按档位解锁。** 同一个聚落，冷淡时只给跑腿的活，尊敬以后才会托付真正的事。主战派和主和派各发各的委托。
- **殊途同归。** 每个势力的委托链各讲一段，但都指向同一批真相，比如腐败是怎么失控的、天空塔要去哪里。帮精灵、帮神狐、帮帝国平民，甚至替帝国军部做事，最后都会走到同一个地方，只是看到的角度不同，到那里时谁站在你身边也不同。
- **不锁死路线。** 不因为声望太低就永远关上某条主线；最多是换一条更难走的路过去。例如某个势力敌视你，你还可以从它的主和派或者别的势力那里拿到同一段真相。
- **信息不写明。** 委托说明只写 NPC 会说的话，不写「前往某坐标」；声望界面也只显示档位名，不显示具体数值。

委托系统另写一份文档。这里只约定：委托完成时调用 `Reputation.add`，原因记为 `Cause.COMMISSION`；委托的解锁条件读档位。

## 10. 已定

- 声望每个玩家一份，不共享（第 7 节）。
- 档位的范围和效果全势力统一，只有显示的名字按文化区分（第 3 节）。
- 精灵：帮它们清除腐败核心，才第一次成为客人（4.5）。
- 玩家可以通过主战派的委托投靠主战派（2.2）。
- 击退威胁聚落的袭击队会加声望（第 5 节）。
