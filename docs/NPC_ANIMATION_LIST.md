# NPC 动画清单

整理时间：2026-10-27。动画名、控制器和匹配规则见 [NPC 动画制作规范](NPC_ANIMATIONS.md)，本文只列「要做哪些」和「现在有哪些」。借用 TLM 动画时在 [CREDITS.md](../CREDITS.md) 登记。

## 0. 结论：能不能直接用现成的

| 来源 | 能不能直接用 | 说明 |
|---|---|---|
| **Minecraft 原版** | 不能当动画文件用 | 原版人形（玩家、僵尸、村民）的动作是 Java 代码里的公式（`HumanoidModel.setupAnim`），不是动画文件。GeckoLib 模型不会自动套用。原版的关键帧动画（监守者、骆驼、嗅探兽等）也写在代码里，而且是四足或怪物骨架，不适合人形。可以照这些公式，在渲染器里用代码补一套「兜底」动作，见第 3 节。 |
| **车万女仆（TLM）默认动画** | 能，署名借用 | TLM 1.21 分支的 `animation/maid.animation.json` 有 100 个动画，覆盖了第 1 节几乎全部通用动作，骨骼名也和我们的模型一致（只缺 `LongHair`）。美术授权为 CC BY-NC-SA 4.0：按 [CREDITS.md](../CREDITS.md) 署名、登记，含借用动画的文件以同一协议发布，模组不能商用（[NPC_MODELS.md](NPC_MODELS.md) 第 7 节）。`walk`、`idle`、`jump`、`attacked`、`ladder_*` 可以直接用；`run`、拉弓、眨眼用到 `ysm.head_pitch` 等 TLM 专用 Molang 变量，要驱动先支持（第 3 节）。 |
| **TLM 模型包里** | 能 | 把精灵模型做成 TLM 模型包时，TLM 会自动补上它的默认动画，只补模型自己没有的名字。只在 TLM 里生效，本模组里的精灵用不上。 |
| **TLM 作参考** | 能 | 只看节奏和姿势、自己从头做的动画不算借用，不用登记。 |

**为什么现在看起来没有动画**：精灵的动画文件里只有一个 `idle`（4 秒，上身、头、手臂、耳朵 1–2° 的呼吸）。走路、拉弓、受伤、爬绳都没有对应动画，GeckoLib 也不会退回原版的摆腿摆臂，所以精灵是平移着走的，弓垂在手里。

## 1. 通用动作（所有人形种族共用）

做一次，以后所有种族都能用：同一套骨骼名，动画文件可以复制给新种族，再按体型微调。

「精灵用到」：✅ 现在的行为里会出现；▫ 暂时不会出现，以后的种族或功能用。「现状」：有 / 缺。

### 1.1 主状态

| 动画名 | 用途 | 精灵用到 | 现状 | 建议 |
|---|---|---|---|---|
| `idle` | 站立待机 | ✅ | 有（幅度很小） | 可以加大一点，或加眨眼（见 1.4） |
| `walk` | 行走 | ✅ | 有（借用 TLM） | |
| `run` | 冲刺 | ▫ | 缺 | 精灵后撤时是快走，不是冲刺；没有时自动用 `walk` |
| `jump` | 空中 / 跳跃 | ✅ | 有（借用 TLM） | |
| `attacked` | 受伤后仰 | ✅ | 有（借用 TLM） | |
| `death` | 倒下 | ✅ | 有（维护者制作） | 跪下再向前倒地，1.55 秒，接在最后一击的 `attacked` 之后；有死亡动画的 NPC 不再变红、不向侧面倒下。没有死亡动画的 NPC 仍按原版侧倒 |
| `ladder_up` / `ladder_stillness` / `ladder_down` | 爬梯子、绳梯 | ✅ | 有（借用 TLM） | 精灵向上约 4 格/秒，向下约 3 格/秒 |
| `swim_stand` | 站在水里 | ✅ | 有（借用 TLM） | |
| `swim` | 游泳姿势 | ▫ | 缺 | |
| `sit` | 坐下 | ▫ | 缺 | 要先有「坐下」行为（树屋的叶座） |
| `sleep` | 睡觉 | ▫ | 缺 | 要先有作息 |
| `boat` / `chair` | 坐船 / 骑乘 | ▫ | 缺 | |

### 1.2 手部

| 动画名 | 用途 | 精灵用到 | 现状 | 建议 |
|---|---|---|---|---|
| `hold_mainhand:bow` | 平时持弓 | ✅ | 有（自绘） | 所有拿弓的 NPC 共用 |
| `use_mainhand:bow` | 拉弓瞄准 | ✅ | 有（自绘） | 1.2 秒拉满后停住；俯仰与偏航由渲染器叠加到 `Arm`，弓指向目标 |
| `swing_hand` | 默认挥手 / 近战 / 交互 | ✅ | 有（借用 TLM） | |
| `hold_mainhand:empty` | 空手 | ▫ | 缺 | 空手时放松的手型 |
| `hold_mainhand:sword` + `swing:sword` | 持剑、挥剑 | ▫ | 缺 | 以后的近战种族 |
| `hold_offhand:shield` + `use_offhand:shield` | 举盾 | ▫ | 缺 | |
| `use_mainhand:eat` / `use_mainhand:drink` | 吃、喝 | ▫ | 缺 | |
| `hold_mainhand:crossbow` / `use_mainhand:crossbow` / `hold_mainhand:charged_crossbow` | 弩 | ▫ | 缺 | |

### 1.3 剧情动作（`misc` 控制器）

驱动已经支持，名字自己定。精灵用同步字段给出当前动作，播完自动清掉（`ForestElf.playAction`）。

| 建议动画名 | 用途 | 对应的现有行为 |
|---|---|---|
| `greet` | 打招呼 | 玩家右键精灵，配「搭话」语音；精灵用第 2 节的林间礼 |
| `refuse` | 摇头 / 摆手 | 战斗中被右键，配「不满」语音；有（自绘） |
| `nod` | 点头 | 配「肯定」语音（以后交易用） |
| `cast` | 通用单手施法 | 所有会 Logos 法术的 NPC 共用；精灵可以用第 2 节的专属版代替 |
| `look_around` | 东张西望 | 闲时随机播放 |

### 1.4 常驻叠加层

| 动画名 | 用途 | 现状 |
|---|---|---|
| `pre_parallel0` | 眨眼（`Eyelid` 显示 / 隐藏，几秒一次） | 缺 |
| `pre_parallel1` | 呼吸（`UpBody` 微小起伏） | 缺（目前写在 `idle` 里，走路时就没了） |
| `parallel*` | 发梢、披风等小幅摆动 | 缺，按需要做 |

## 2. 森林精灵专属

只做体现种族特色的一小部分，其余都用通用动作。

| 动画名 | 内容 | 放在哪 | 优先级 |
|---|---|---|---|
| `use_mainhand$logos_dimension:natures_force` | 自然之力专用拉弓：搭箭时箭尖凝出叶光，拉满后稳稳停住、耳朵后贴。精确物品名优先于通用的 `use_mainhand:bow`，拿普通弓时仍用通用版 | 手部 | 高 |
| `heal_touch` | 抚生之触：左手（右手拿弓）前伸、掌心朝向目标，双臂随视线指向目标。**有（自绘）** | `misc` | 高 |
| `heal_ring` | 生息之环：双手由胸前向两侧展开、画一个圈。**有（自绘）** | `misc` | 高 |
| `parallel0`（耳朵） | 长耳偶尔抖一下，几秒一次 | 叠加层 | 中 |
| `greet`（精灵版） | 右手抚胸、微微欠身的林间礼，代替通用挥手。**有（自绘）** | `misc` | 中 |
| `alert` | 发现敌人：耳朵竖起、身体前倾，配「警觉」语音 | `misc` | 低 |
| `death`（精灵版） | 跪下再向前倒地，死亡动画开始时换上茫然挂泪的表情（`expression_dazed_tears`）。**有** | 主状态 | 高 |
| 化作落叶 | 倒地后消散成落叶与绿色光点，代替原版青烟（粒子由我做） | 粒子 | 低 |
| `ladder_*`（绳梯版） | 双手交替拉绳、脚踩绳结，比通用爬梯更轻盈 | 主状态 | 低（通用版先用着） |

## 3. 需要代码配合的部分（我来做）

- **剧情动作**：已接上（治疗、行礼、拒绝）；警觉还没做。
- **TLM 专用 Molang**：`ysm.head_pitch`、`ysm.head_yaw`、`ysm.is_close_eyes` 等变量我们的驱动还没有。要借用 TLM 的 `run`、拉弓、眨眼，我先补上这几个变量；自己做的动画也可以用。
- **可选：原版式兜底**：动画文件缺 `walk`、拉弓等动作时，渲染器按原版人形的公式摆腿、摆臂、举弓，至少不再平移滑行。做好对应动画后自动让位。要不要加，你来定。

## 4. 建议的制作顺序

1. `walk`、`hold_mainhand:bow`、`use_mainhand:bow`：精灵每时每刻都在用；
2. `attacked`、`ladder_up` / `ladder_stillness` / `ladder_down`；
3. `heal_touch`、`heal_ring`（同时我接上 `misc`）；
4. `jump`、`swing_hand`、眨眼和耳朵叠加层；
5. 其余通用动作，等对应行为出现时再做。
