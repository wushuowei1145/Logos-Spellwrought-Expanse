# 远行之门

主世界和远行大陆（`logos_dimension:cloudsea`）之间的传送门，是远行大陆的生存入口。

## 玩家怎么用

1. 在主世界找到一扇自然生成的大号门（森林、针叶林、平原、草甸、樱花林、热带草原），`/locate structure logos_dimension:journey_gate` 也能找。门洞是空的，地面中心那块是**启门石**。
2. 给启门石灌满 **1000 点魔力**，门洞从下往上填满传送面。
3. 走进门，站两秒（创造模式立刻）到另一侧。另一侧相同坐标 128 格内有门就落在那扇门里，没有就当场生成一扇点亮的**小号门**。从那边走回来也一样。

## 启门石

| 方式 | 说明 |
|---|---|
| 手持魔力物品右键 | Logos `mana_fuel` 数据表里不带 `unstable` 的都能放，每次吃一个，算表里的魔力值：紫水晶碎片 25、青金石 50、回响碎片 400、魔力碎片 500、魔力结晶 1000、魔力晶石 5000。放满时多出来的不存 |
| 术式 `infuse-block` | 只灌缺的部分，可以分多次，灌满共耗 1100 魔力（Logos 的 1.1 倍损耗） |
| 魔力存储罐、魔力收集器 | 启门石实现 Logos 的 `ManaVessel`，朝它输出就行 |

- 被污染的魔力碎片这类不稳定魔力不收，也不会被吃掉。
- 灌满自动开门。空手右键查看魔力；魔力已满且门没开时重新开门。
- 外观分五档，灌得越满符纹越亮。
- 用镐子能挖走，带回家自己搭门。**挖走后魔力清零**，掉落的是普通的启门石。没有合成配方，只能从自然生成的门上拿。

## 门框判定（`GateShape`）

从启门石正上方开始，在竖直面内泛洪，碰到方块就停。两个朝向各试一次，合拢的那个就是门面。

- 不要求矩形，也不限材质，大号门的八边形和玩家自己搭的门框是同一套规则，结构怎么旋转都不用记录朝向。
- 能被传送面占据的：空气、草和单层雪这类可替换方块、自然长进门洞的树叶（玩家放的树叶算门框）。其他方块都算门框。
- 门洞至少两格高，最多 128 格。超过就是没有合拢。
- 门只在主世界和远行大陆能开。

门框有方块被打掉（包括地面和启门石），传送面和下界传送门一样连锁消失，启门石里的魔力还在。修好后空手右键重开。

## 两种门

| | 大号门 `gate/journey_gate` | 小号门 `gate/small_gate` |
|---|---|---|
| 来源 | 维护者的投影蓝图 `logos维度传送门.litematic` | 代码生成，沿用大号门的语言 |
| 尺寸 | 19×15×7，开口 57 格 | 9×9×5，开口 21 格 |
| 出现方式 | 只在主世界自然生成，`random_spread` 间距 48 区块 | 另一侧有实体过来时当场生成，两边都用它 |
| 状态 | 没点亮，要灌魔力 | 点亮，启门石是满的 |

模板由 `tools/GateAssets.java` 生成（单文件 Java，不依赖项目）：

```text
java tools/GateAssets.java <logos维度传送门.litematic> src/main/resources
```

大号门转换时，蓝色羊毛（占位）存成空气，地面中心那块泥土换成启门石，其余空气不存，门框周围的地形和植被不会被挖掉。5 块藏在树冠里的石头是洞穴藤蔓的挂点，要保留。

小号门的位置：由近到远（24 格内）找一块不在水上、四角高差不超过一格的地面；实在没有（比如大海中央）就放在目标点的水面上。底下悬空的地方用泥土垫实，最多垫 8 格。

## 过门和加载（`GateTravel`）

- 走的是原版 `Portal` 接口，任何实体都能过，冷却、乘客这些都和下界传送门相同。
- 传送面的每一格是兴趣点（`logos_dimension:gate_portal`），另一侧靠它找门，半径 128。主世界和远行大陆 1:1 对应。
- 到达时放一张传送票（`TicketType.PORTAL`，300 刻），到达的区块保持加载一段时间。

## 外观

- **传送面**：淡蓝色流光，用随机噪声生成，纹路没有固定的间距和方向。贴图 128×128 横跨 8×8 格，方块状态的 `col`、`row` 记录这格显示哪一块，整片门面的纹路连续，大号门上也基本看不出循环。方块状态和 320 个模型由 `tools/GateAssets.java` 生成，不要手改。
- **楼梯、台阶、活板门的缝**：`edge_*` 为真时模型多画一格盖住相邻半格，被挡住的部分藏在实心部分后面。一个半格可能挨着两三格传送面，都画的话半透明会叠两层，所以只归一格管（`GateShape.withEdges`）。
- **点亮特效**（`client/vfx/GateIgnition`）：贴图全用 Logos 现成的（`force/ring`、`fire_beam/spiky_ring`、`heal/swirl`、`heal/glow`、`fire_beam/flare`、`fire_beam/glow`、`force/dot`、`force/streak`），颜色由顶点给成蓝青色。服务端发 `GateIgnitionPayload`，96 格内的玩家能看到。

| 时间（刻） | 内容 |
|---|---|
| 0–24 | 门洞正在填。光点从四周螺旋汇向门面，门洞内两圈反向旋转的光环和中心的旋涡越来越亮，脚下一圈尖刺光环转起来 |
| 24 | 填满。星芒和闪光，光柱从门里冲上天，贴地荡开两圈冲击环，光痕向上飞散 |
| 24–84 | 光柱收细，光点从门面慢慢飘起，全部淡去 |

## 没有做的

- 站在门里等传送时的屏幕效果：原版只有下界传送门那套紫色的，这里没有用（`Portal.Transition.NONE`）。
- 自然生成时，树可能在结构之后长进门洞。树叶开门时会被替换，树干会算成门框的一部分，门洞就小了一块。挖掉重新点亮即可。
