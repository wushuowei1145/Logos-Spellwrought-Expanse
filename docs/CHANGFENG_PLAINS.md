# 长风草原：连片平原与宽叶草簇

长风草原（`logos_dimension:cloudsea_silk_folds`）改为温带内陆的连续平坦草地。旧气候点保留在侵蚀值 0.65 档，新增主体扩展为侵蚀 0.15–1.2 的连续范围并通过密度函数压低起伏，取消随山脊噪声交错轮换的碎条分配；补入温度、湿度、内陆度的连续气候范围，仍用原版多噪声群系生成。寒地高草甸与暖地花甸保留各自分配。

草地表每区块使用原版放置特征尝试 800 次，草类权重合计 84%，其余为少量野花。目标是约 80% 地表覆盖草，允许局部随机变化；并非每个区块强行填满固定数量。土壤、空气和群系过滤保持原样，不使用 Java 地形生成器。群系分布和覆盖率调整只影响新区块。

平原主体另由原版密度函数形成约 Y=74、轻微起伏的开阔地面，气候边缘用样条平滑过渡。地下 Y=48 以下保留原密度与洞穴；群系深度和预估地表高度同步调整，避免把新的地面识别成旧山体的地下。生成脚本为 `tools/changfeng_plains.py`，反复运行不会叠加修改。

## 宽叶草簇

- 长风草皮上的原版短草与高草换成专用宽叶草簇（`client/ChangfengGrassModel`）：三种株型、四向旋转，叶片二至四像素宽、弧形向外伸展。模型与贴图由 `tools/changfeng_grass_art.py` 生成，全部贴图为 **16×16**，高草上、下半分别一张。短草四面、双层高草八面，与原版相同；没有新注册一套草方块。
- 双层高草从共同根点检查草皮、选株型，上下两半对得上。
- 草簇和原版草一样画进区块网格，所以光影包的阴影、光照和它们自带的草摆动都照常生效。物品、破坏粒子、其他地表和其他维度的草保留原模型。

## 为什么不做风动

#288 曾用自有顶点着色器让近处的草随风弯曲（类似 Unreal 的 World Position Offset）。为此要把近处的草从区块网格里拿掉、每帧另外提交，结果：

- 区段里任何方块变化（幼草生长、草皮按季节换色）都会让那一段风动草撤掉再重建，中间要等区块重编译，草按区块频繁闪烁；
- 开光影时这批草只能叠画在光影包合成好的画面上，不投阴影、不吃光影包的光照，和远处的静态草按区段分出明暗。

主流光影包本来就会让草摆动，所以去掉了风动，只保留草簇外观。不要再在原版渲染路径上另做草的顶点风动。

## 验证方法

```text
./gradlew test build -PlogosJar=/absolute/path/logos.jar -PorchestraJar=/absolute/path/orchestra.jar
./gradlew runClient -PlogosJar=... -PorchestraJar=... -PldTest=group:changfeng -PldTestHeadless -PldTestWindow=1280x720
```

客户端场景分两种：`changfeng_grass` 在一块独立测试台上用实际原版放置特征种草，统计 32×32 格覆盖率，检查草都换成了宽叶草簇；`changfeng_natural` 定位真实噪声生成的长风平原，不放置或整平地表，检查 32 格样地高差和草簇，并拍摄实机画面。实测结果记在根目录 `VERIFICATION.md`。
