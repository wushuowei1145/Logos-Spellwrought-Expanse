# 神狐薙刀

附属的薙刀（物品 `logos_dimension:fox_naginata_<刃型>_<刀装>`，三种刃型 × 四套刀装共 12 把，战斗武器编号 12–23，数值相同）。美术交付在仓库外的 `art/fox_naginata/v01`，动作由 `tools/naginata_moves.py` 按编排烘焙。这一轮玩家可用；神狐的动作只烘焙到模型目录，还没有接进 NPC。

## 风格

维护者的要求：参考只狼破戒僧的大开大合，同时要优雅；薙刀在江户时代成为武家女子的武艺，和现在的神狐都是女性相合。

第一版（试玩包 `builds/fox-naginata-2026-11-05`）有风车、全身旋舞、频繁换手。维护者看过后认为太花哨，转圈也不好看。第二版按维护者给的传统薙刀术照片重做：

- **平时单手立持**：右手在胸前握杆，杆竖在身体右侧，石突近膝、刃高出头顶。
- **出招才双手**：左手搭上来，挥完放开，回到单手立持。
- **只用一种握法**：左手在前靠刃，右手在后靠石突，两手拉开约一臂。
- **杠杆挥法**：刃靠杠杆走大弧，后手往回拉、前手往前压。袈裟斩完右手收到耳边、刃在左前下方；面劈完右手在脸侧、刃指前下。这两个收势就是照片上的姿势。
- **不转圈、不换手**，每一刀都是一条从举起到落下的大弧。

## 1. 交付检查

- 每把 85 块武器 + 45 块刃套，共用 4 张 56×72 图集（不是正方形，UV 按横纵分别归一化）。
- 网格原点在主握点。`+Y` 刃尖、`+X` 刃口，刀背向 `-X` 弯。石突 −10.4，前握 5.5，杆顶 16，刃尖 23.6–25.2（随刃型）。
- 三种刃型的杆身、握点、装具逐块相同，所以共用一套动作；单元测试检查。
- 第三人称 1 倍时全长约 2.2 格，约为玩家身高的 1.1 倍。杆身很细（0.58 像素宽），远看是一条线。
- 刃套的网格原点也在握点，离刃套本身约 20 单位，所以手握刃套的位置要另给（`saya_grip`），刃套转动也绕它自己的中心算（`NaginataBaker.sheath`）。
- 交付的 `exports/*.mesh.json` 已经带 `scale: 1.25`，物品模型由 `tools/import_naginata.py` 按“网格 + (8, 1, 8)”生成，魔力缠绕和杆身对齐。图标由配色生成，属于占位。

## 2. 招式

物品：铁级，攻击伤害 7，攻速 1.3，攻击距离比原版多 0.5 格。格挡用原版格挡组件，举盾延迟 0，减伤、击退、耐久走原版。

| 招式 | 时长 | 接触 | 张角 | 说明 |
|---|---|---|---|---|
| `draw` | 1.2 秒 | | | 立持（套着刃套）→ 单手把杆横到胸前，左手握住刃套 → 右手往右抽，刃套退下来 → 左手把刃套插到左腰，杆立回去 |
| `idle` | 2.4 秒循环 | | | 单手立持，刃口朝前，左手自然垂下。第一人称是杆竖在画面右侧、刃面朝镜头 |
| `kesa_1` 袈裟斬り | 0.82 秒 | 0.35 | 110° | 左手搭上来，刃举到右肩后，一压从右上斩到左前下方 |
| `kaeshi_2` 逆袈裟 | 0.74 秒 | 0.20 | 110° | 刃在左下翻过来，后手下压、前手上挑，从左下撩到右上 |
| `sune_3` 脛払い | 0.84 秒 | 0.39 | 140° | 刃从右上举过头顶送到左后方，压低贴地从左扫到右；伤害 0.9 倍 |
| `men_4` 面 | 1.1 秒 | 0.48 | 60° | 刃举过头顶，在脑后停一拍，双手劈到正前方，停住（残心）；伤害 1.3 倍 |
| `guard` | 1.6 秒循环 | | | 中段受け：双手把杆斜架在身前，石突在右下、刃在左上。任何时候按右键立即切过来 |
| `guard_hit` | 0.34 秒 | | | 挡下一击时杆被压回身前再撑开。照常消耗耐久，这不是弹刀 |
| `parried` / `parried_npc` | 0.5 / 0.8 秒 | | | 被弹反的僵直（#195 的保留招式）：刃被磕向右后上方，左手脱开，身子后仰，顶住一下再收回单手立持；不接受任何输入 |
| `sheathe` | 1.3 秒 | | | 拔刀倒过来：杆横到胸前，左手从左腰取回刃套从刃尖套回去，杆立回身体右侧 |

每一刀收招时左手放开，回到单手立持；按住左键时在 `cancel` 接下一刀，两手一直在杆上。

状态图：

```text
draw → idle ─左键→ kesa_1 → kaeshi_2 → sune_3 → men_4 ┐
        ↑  ↑                                         │（左键循环，1.6 秒内接着上一刀）
        │  └─────────────────────────────────────────┘
        └─松开─ guard ⇄ guard_hit（block）     任何一刀 ─右键→ guard（立即）
换物品 → sheathe → 交回原版
```

连招按长剑的规则缓冲：出招 0.08 秒后的左键记下，到 `cancel` 接下一刀，可以按住。

## 3. 编排工具

- `combat_author.py` 新增两个骨架字段，默认都关闭，打刀的烘焙逐字节不变：
  - `saya_grip`：手握鞘的高度，默认 3.1。
  - `two_slides`：双手握时够不着就沿杆往主手滑，手不离杆。
- `naginata_moves.py`：
  - `swing()` 按“刃依次指向哪些方向、右手依次经过哪些点、躯干依次怎么拧”生成一段挥动。刃口自动朝运动方向（砍下去）或背向运动方向（举起来），所以举刀和砍下去时刃口朝向一致。
  - `contact_time()` 取刃最接近正前方的时刻作为接触。
  - `NaginataBaker`：刃套跟编排走（`cover_w` 为 0 时套在刃上，`cover` 是沿刃退出的距离，1 时挂在腰上，中间由左手带过去）；右手握点够不着时沿“肩—握点”连线收回来。
  - 第一人称：没写自己的位置时，右手按 `fp_hand` 整体往前、往下收，举到脸边的手不贴镜头。

## 5. 现状与后续

已经可以试玩。下面这些没有做：

- **神狐接入。** 动作已烘焙到 `fox_model/divine_fox/Animation/naginata`（1.7 倍，和玩家的身长比例相近；美术静态持握是 2 倍）。NPC 的骨骼、动画合并、AI 还没接。
- **弹刀。** 用户只要求格挡，所以没有打刀那样的弹刀和反击。需要时给 `guard` 加一条 `window` 限定的 `block` 转移即可。
- **图标**是配色生成的占位。
- **挥动音效**沿用原版横扫声，没有听感验证。
- 手感、连招节奏、动作好不好看要等维护者试玩反馈；伤害和时长都是先定的值。
