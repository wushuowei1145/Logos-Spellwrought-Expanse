# 流火：魔力凝成的打刀

整理时间：2026-11-08。美术是 `art/liuhuo/v04_uv128`（128×128 贴图版）。这把刀完全由魔力凝成，没有重量：挥得极快、手感轻，但每一刀挥到终点都要停一下，保持节奏。动作按 [战斗骨架与兼容性规范](COMBAT_SKELETON.md) 制作，流程照 [三维动作武器工作流](COMBAT_WEAPON_WORKFLOW.md)。

英文名 **Ryūka**（流火的日文音读 りゅうか），物品 id、文件名、类名都用 `ryuka`；只有美术交付（仓库外 `art/liuhuo`）里的文件名还是最初的拼音。

2026-11-08 维护者已定：奥秘元素；右键与神狐打刀一致，但弹刀窗口放宽到格挡开始的 0.5 秒；第 3.1 节四项附加设定全部要；白樱换色按预览做。

### 1.1 精简（2026-11-08 试玩后）

维护者试玩：一拿出来就严重掉帧。原因不只是块数：刀柄、刀镡的小方块每个面都贴了一整块材质区域（28×32 格），而 Logos 的物品表面火焰（狐火）按物品模型的贴图格子**每格画一片**，附属的凝聚、消散也按贴图格子切片。496 块加起来每帧约 **114 万片**（神狐打刀约 1400 片）。

按维护者的要求精简到和神狐打刀相当（打刀 98 块，最多精细三成），由 `tools/import_ryuka.py` 生成：

| 部分 | 原来 | 现在 | 做法 |
|---|---|---|---|
| 刀身 | 96 行 × 3 层 = 288 块 | 20 段 × 3 层 = 60 块 | 每段顺着弧线转一个角度（只绕 Z 轴），刀背和刃不起台阶；刀身一段约 1.2–1.4 长，最后 5 行一行一段，刀尖还是尖的 |
| 刀柄 | 71 块 | 7 块 | 麦穗纹和光点（64 块）按原来的位置和颜色画进柄正反面的贴图 |
| 刀镡 | 137 块 | 57 块 | 八朵花各留花心和五片花瓣，花瓣尖和花粉点去掉；框、金边、六片叶、刀镡下的金环不变 |
| 合计 | 496 块 | **124 块** | |

贴图格子也按方块实际大小取：刀柄、刀镡每个面取所属材质区域里按大小算的一小块（每单位约 6 格）；刀身贴图横向本来每单位 20 格、竖向 7 格，横向减半。物品模型（只在地上缩到 0.42 出现，以及表面火焰贴着的表面）再粗一半。结果：表面火焰约 **1800 片**，凝聚、消散约 9400 片（只在拔刀、收刀那不到一秒里画）。手上看到的刀是战斗网格，贴图不受物品模型变粗的影响。

## 2. 外观

- **贴图**：按材质区域把原图的明暗映射到白樱色阶。取色参考附属的白樱叶（`cloudsea_white_cherry_leaf_*`）和原版樱花叶。按明暗排名取色，区域里最多的亮度落在色阶中段（淡粉），最暗的魔力纹和最亮的高光落在两端，所以纹理保留。柄卷从酒红改成灰粉，金件改成浅香槟色。由 `tools/import_ryuka.py` 生成，不手改。
- **晶莹感**：刀身另画一层自发光（发光遮罩换色后的 `ryuka_glow.png`，加法叠加），刀身略透明。透明度在游戏里调。
- **命中**：Logos 每次元素伤害都放一团奥秘冲击特效，流火出刀快，第一人称会被白光盖住（维护者看过截图后要求去掉）。`RyukaBurstMixin` 只在结算流火这一下时跳过 Logos 的命中特效（`Vfx.burst` 的 `DAMAGE`），换成一小簇樱花瓣和几点淡粉的光；Logos 别的伤害不受影响。注入写了 `require = 0`，Logos 改了这个方法就注入不上、退回原样，不会崩。
- **狐火**：拿在手上时刀身一直燃着淡粉的狐火（`SurfaceAura` FIRE 样式，客户端直接加在刀上，不占玩家的魔力缠绕）。玩家另外施加的魔力缠绕照常显示。
  2026-11-10 维护者嫌粉得太浓：Logos 的表面火焰只收一个色相，橙红的底色转过去饱和度不变；这里在色相上加个记号（`client/longsword/PaleFire`），`mixin/PaleFireMixin` 在 `VfxParts.hue` 里认出记号后把饱和度乘 0.55，刀身上的火、飘出去的火星一起变淡。只改流火自己的这层火，狐火缠绕（`FoxfireClient.fire`）的淡粉没动。Logos 改了这个方法时注入不上，退回原来的浓粉。
- **刀光**（[刀光](WEAPON_TRAILS.md)）：自己的样式 `combat/trail_styles/ryuka.json`，樱粉晶刃的身子、速度线、狐火火舌、刀尖一侧的碎晶反光和一道白热刃线，甩出樱花瓣。狐火是刀自带的，缠上别的元素也不换（`fixed`）。五段连斩、弹刀、突刺按挥刀的那一段出光（`combat/trails/ryuka.json` 的 `windows`，取自 `tools/ryuka_moves.py` 每一刀的 `arc`），蓄势不出；凝聚、散去、只剩刀柄时刀身不完整，不出。刀身量从樱花刀镡之上（y 1.6）到刀尖（y 18）。白梅手里的流火读同一份设置，见 [白梅](SHIRAUME_BOSS.md) 11.1。
- **预览**：`art/liuhuo/anim_v01/retexture_v01.png`（四视角，暗处与亮处），`retexture_hilt_v01.png`（柄部近景）。

### 3.1 附加设定（四项都做）

1. **花散**：用这把刀斩杀的生物不留尸体，整只化作樱花瓣消散（附属的生物消散，粉色边缘、花瓣粒子）。
2. **只剩刀柄**：魔力耗尽时刀身散去、只剩刀柄（上面已写进“魔力不够”）；不想要就改成直接收刀。
3. **落樱终式**：连招最后一刀把魔力放出去，刀光化成一道向前飞的樱花刀气，额外消耗 30 点魔力，打中路径上的所有目标。
4. **无形之刃**：魔力刃穿过盾牌，不能被原版盾挡下。只对这把刀的伤害生效，不改 Logos 奥秘伤害本身。

### 3.2 狐火印（2026-11-10 维护者加的）

| 项 | 数值 | 说明 |
|---|---|---|
| 留印 | 每砍中一次一枚 | 连招、突刺、上挑、樱花刀气都算；爆开、缠身每秒烧的、处决的刀不算。印跟着目标走，谁的流火打的都算。 |
| 爆开 | 攒满 5 枚 | 一下 **30** 点淡粉狐火（流火一刀 9），印清零，随后狐火缠身 **8 秒**（平时的缠身 3 秒），每秒 1 点。最后一枚是谁打的就记在谁名下。 |
| 能处决 | 爆开后 **8 秒**内 | 这段时间里上挑砍中它就处决（3.4 节）；处决一开始就用掉这次爆开，要再处决得再攒满一次。窗口里再砍照样攒新的印。 |
| 散掉 | 隔 6 秒没再添印 | 从头攒。 |
| 同族 | — | 神狐照样留印、爆开、能被处决，只是狐火伤害照规矩只剩四分之一（摔落那 25 照算），也不会缠身。白梅挑不飞，处决不了。 |

- 头顶绕着几点淡粉的狐火，一枚印一点，越接近攒满转得越快、越亮；爆开时一圈往外散，同时放一团大的淡粉狐火。
- 能处决的那 8 秒：身体中部绕着一圈五点更大、更亮、一闪一闪的狐火，和平时的狐火缠身分得开；处决开始或到点就没了。
- 2026-11-10 第一版让平时的刀不缠身、只用缠身当处决条件；维护者改成平时照常缠身，处决条件换成「爆开后的一段时间内」。
- 实现：`ryuka/FoxMarks`（服务端、同步包），`client/longsword/FoxMarksClient`（样子）。爆开那一下用 `Foxfire.Context` 的 `burn` 关掉平时的 3 秒缠身，再单独点 8 秒的。
- 顺带修了一处：Logos 的 `Effects.damage` 只在目标被打死时返回真，原来流火只在斩杀时才放命中的樱花和声音，现在按血量有没有掉来判断打没打进去。

### 3.3 平一文字の構え与突进上挑（2026-11-10 维护者加的）

- **进架势**：按住右键格挡时按住左键，转成平一文字の構え（维护者给的参考图：双手握在右肩前、颈的高度，刀身横平地横在身前，刀尖指向左边，刃朝前）。仍是格挡：照样是魔力护盾，挨打时做架势里的格挡动作（刀被压得往脸前一缩），之后留在架势里。弹刀只在普通格挡的开头 0.5 秒里有，架势里没有。
- **蓄力**：在架势里按住左键不到 0.3 秒就松开，回到普通格挡；超过 0.3 秒（或者架势里挨过一下）松开就**闪身突进**。松开右键退出架势回到待机。
- **突进**：另付 **20** 点魔力（不够就不突进，回到待机），放下格挡，沿视线的水平方向冲出去，每刻 1.6 格，最多 5 刻（8 格）。前面撞上一个生物就停在它面前，走满或撞墙也停；两种都接**上挑**。
- **上挑**：从右后下方一刀撩到左上，照常付一刀的 10 点魔力，伤害 1.5 倍（13.5），命中身前 120 度，不击退；砍中的生物被**挑飞**（同群誓·狼牙长枪的上挑，`combat/Airborne`，Boss 等挑不飞的照常挨刀）。目标的**狐火印爆开后 8 秒内**改成**处决**（3.4 节），一次上挑只处决一个（准星对着的优先），其余照常挑飞。上挑本身也留一枚印：目标身上已经有四枚时，上挑这一刀补满、爆开，紧接着就处决。
- 实现：招式文件新增输入 `attack_release`（松开左键，客户端 `LongswordPayload.AttackRelease`）；`ryuka/RyukaDash`（突进）、`RyukaExecution.rise`（上挑之后）。

### 3.4 处决（2026-11-10 维护者加的）

条件：狐火印爆开后 8 秒内被上挑砍中（3.2 节）。

- 目标被抛到半空，画面变黑白（[处决特写](EXECUTION_SHOTS.md)的可交互版）。从第 0.3 秒起 **2 秒**里，处决的人每点一下左键砍一刀，**11** 点淡粉狐火；两刀最短隔 **0.05 秒**（1 刻），点得再快也按这个节奏结算。
- 2 秒到了静 0.2 秒，追加一刀重击（11 点），再把它拍到地上，另算 **25** 点摔落伤害（摔落保护照常算；铁傀儡这类原版不受摔落伤害的不掉这 25）。
- 特写（镜头、黑白、刀光、震动）只有处决的人和被处决的玩家看得到；旁人只看到目标在半空一刀刀被打歪，身上闪过淡粉的刀光。
- 处决的人这段时间镜头锁着、人不动，左键只用来出刀。目标中途死了、处决的人死了、离开或走出 24 格，处决提前结束，镜头回来。
- 一刻一下点满 2 秒是 40 刀，440 点；加上重击和摔落，一共最多约 476 点（神狐的狐火只吃四分之一）。
- 实现：`execution/InteractiveExecutions`（通用：给 `Handler`，其他武器也能用）、`ryuka/RyukaExecution`（流火的伤害和招式）。

## 4. 招式与状态机

挥刀极快：刀从起点到终点只用 2–3 刻（0.10–0.15 秒），然后在终点定住约 0.15 秒（`ease='hold'`），再进入下一刀或收回。轻刀所以**单手持握**，左手空出来（拔刀时抹过刀身、出招时做平衡）。

```
切到这把刀 ──► 凝聚 manifest ──► 待机 idle ──左键──► 一 ─► 二 ─► 三 ─► 四 ─► 五 ─► 回到一
                                   │  ▲            │ 任何时刻右键（不排队，立即）
                                   │  └──松开右键──┤
                                   └──右键────────► 格挡 guard ─(0.5 秒内被击中)─► 弹刀 parry ─左键─► 突刺 riposte
                                                       │
                                                       └─按住左键─► 平一文字 stance ─(0.3 秒后松开左键)─► 突进 dash ─► 上挑 rise ─► 待机
                                                                     │  ▲ 挨打                                               │
                                                                     └► stance_block ─► stance_hold ─松开左键─► 突进          └─(目标狐火缠身)─► 处决 execution ─► 重击 execution_end
切走 ──► 散去 dissipate ──► 恢复原版
```

## 5. 凝聚与消散

附属现有的消散（[DISSOLVE.md](DISSOLVE.md)）只会“消失”，并且只处理原版物品渲染；动作武器是战斗骨架按自定义几何画的。所以要给消散加三样通用能力，以后别的武器、技能也能用：

1. **反向（凝聚）**：阈值从高往低走，格子从无到有。
2. **动作武器**：骨架画刀时按同一套格子切分，形状用 `tip` / `hilt`（沿刀身）。
3. **颜色与粒子**：边缘颜色可传（这里用原版樱花树的粉，约 `#f7b9dc`），粒子可换成原版樱花瓣 `cherry_leaves`。

凝聚、消散只在客户端画，由同步的招式（`manifest` / `dissipate`）驱动，不另发网络包。
