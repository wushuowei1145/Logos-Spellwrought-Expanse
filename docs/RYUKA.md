# 流火：魔力凝成的打刀

整理时间：2026-11-08。美术是 `art/liuhuo/v04_uv128`（128×128 贴图版）。这把刀完全由魔力凝成，没有重量：挥得极快、手感轻，但每一刀挥到终点都要停一下，保持节奏。动作按 [战斗骨架与兼容性规范](COMBAT_SKELETON.md) 制作，流程照 [三维动作武器工作流](COMBAT_WEAPON_WORKFLOW.md)。

英文名 **Ryūka**（流火的日文音读 りゅうか），物品 id、文件名、类名都用 `ryuka`；只有美术交付（仓库外 `art/liuhuo`）里的文件名还是最初的拼音。

2026-11-08 维护者已定：奥秘元素；右键与神狐打刀一致，但弹刀窗口放宽到格挡开始的 0.5 秒；第 3.1 节四项附加设定全部要；白樱换色按预览做。

### 1.1 精简（2026-11-08 试玩后）

维护者试玩：一拿出来就严重掉帧。原因不只是块数：刀柄、刀镡的小方块每个面都贴了一整块材质区域（28×32 格），而 Logos 的物品表面火焰（狐火）按物品模型的贴图格子**每格画一片**，附属的凝聚、消散也按贴图格子切片。496 块加起来每帧约 **114 万片**（神狐打刀约 1400 片）。

按维护者的要求精简到和神狐打刀相当（打刀 98 块，最多精细三成），由 `tools/import_ryuka.py` 生成：

| 部分 | 原来 | 现在 | 做法 |
|---|---|---|---|
| 刀身 | 96 行 × 3 层 = 288 块 | 20 段 × 3 层 = 60 块 | 每段顺着弧线转一个角度（只绕 Z 轴），刀背和刃不起台阶；刀身一段约 1.2–1.4 长，最后 5 行一行一段，刀尖还是尖的 |
| 刀柄 | 71 块 | 7 块 | 麦穗纹和光点（64 块）按原来的位置和颜色画进柄正反面的贴图 |
| 刀镡 | 137 块 | 57 块 | 八朵花各留花心和五片花瓣，花瓣尖和花粉点去掉；框、金边、六片叶、刀镡下的金环不变 |
| 合计 | 496 块 | **124 块** | |

贴图格子也按方块实际大小取：刀柄、刀镡每个面取所属材质区域里按大小算的一小块（每单位约 6 格）；刀身贴图横向本来每单位 20 格、竖向 7 格，横向减半。物品模型（只在地上缩到 0.42 出现，以及表面火焰贴着的表面）再粗一半。结果：表面火焰约 **1800 片**，凝聚、消散约 9400 片（只在拔刀、收刀那不到一秒里画）。手上看到的刀是战斗网格，贴图不受物品模型变粗的影响。

## 2. 外观

- **贴图**：按材质区域把原图的明暗映射到白樱色阶。取色参考附属的白樱叶（`cloudsea_white_cherry_leaf_*`）和原版樱花叶。按明暗排名取色，区域里最多的亮度落在色阶中段（淡粉），最暗的魔力纹和最亮的高光落在两端，所以纹理保留。柄卷从酒红改成灰粉，金件改成浅香槟色。由 `tools/import_ryuka.py` 生成，不手改。
- **晶莹感**：刀身另画一层自发光（发光遮罩换色后的 `ryuka_glow.png`，加法叠加），刀身略透明。透明度在游戏里调。
- **命中**：Logos 每次元素伤害都放一团奥秘冲击特效，流火出刀快，第一人称会被白光盖住（维护者看过截图后要求去掉）。`RyukaBurstMixin` 只在结算流火这一下时跳过 Logos 的命中特效（`Vfx.burst` 的 `DAMAGE`），换成一小簇樱花瓣和几点淡粉的光；Logos 别的伤害不受影响。注入写了 `require = 0`，Logos 改了这个方法就注入不上、退回原样，不会崩。
- **狐火**：拿在手上时刀身一直燃着淡粉的狐火（`SurfaceAura` FIRE 样式，客户端直接加在刀上，不占玩家的魔力缠绕）。玩家另外施加的魔力缠绕照常显示。
- **预览**：`art/liuhuo/anim_v01/retexture_v01.png`（四视角，暗处与亮处），`retexture_hilt_v01.png`（柄部近景）。

## 3. 机制

| 机制 | 数值 | 说明 |
|---|---|---|
| 维持 | 每秒 1 点魔力 | 只在主手拿着时扣。 |
| 出刀 | 每刀 10 点魔力 | 每挥一刀扣一次，没砍中也扣（我定的，可改成只在命中时扣）。 |
| 伤害 | 不造成近战伤害，全部换成魔法伤害，暂定每刀 9 | 原版近战伤害为 0（攻击力属性 −1），接触时改由 Logos 的 `Effects.damage` 打出**奥秘**伤害（纯魔力）。 |
| 魔力不够 | — | 不够 10 点时挥刀，刀身闪一下、没有伤害，不扣魔力。维持费付不起时刀身消散，只剩刀柄；魔力回到 20 点后刀身重新凝聚。 |
| 耐久 | 无 | 魔力凝成，不会坏。 |
| 右键 | — | 与神狐打刀一致：按住立刻格挡，开头 **0.5 秒**内被击中弹刀（打刀是 0.3 秒），弹刀后左键极快突刺，攻击方被弹反。 |
| 魔力护盾 | 挡下一击扣原版盾牌该掉的耐久那么多魔力（伤害不到 3 不扣，否则 1 + 伤害取整）；弹刀不扣 | 2026-11-08 维护者加的：和黑钢长剑一样（共用 `ManaGuard`），正面的魔法伤害（原版 magic / indirect_magic，Logos 除物理、火以外的元素）与敌方法术体也挡，虚空一律穿透。魔力付不起这一下就挡不住。 |
| 破盾 | 普通格挡另付 4 × 破盾秒数（斧头、监守者 5 秒 → 20 点）；弹刀不另付 | 斧头、监守者这类会让盾牌破防的近战（弹射物不算）。魔力够就照常挡住、不破防；只有不够时才破防，按原版秒数不能格挡。破防的这一击仍然挡下。实现：格挡组件的破盾倍率设成 0，由 `Ryuka.guarded` 接手。创造模式不扣也不破。 |

### 3.1 附加设定（四项都做）

1. **花散**：用这把刀斩杀的生物不留尸体，整只化作樱花瓣消散（附属的生物消散，粉色边缘、花瓣粒子）。
2. **只剩刀柄**：魔力耗尽时刀身散去、只剩刀柄（上面已写进“魔力不够”）；不想要就改成直接收刀。
3. **落樱终式**：连招最后一刀把魔力放出去，刀光化成一道向前飞的樱花刀气，额外消耗 30 点魔力，打中路径上的所有目标。
4. **无形之刃**：魔力刃穿过盾牌，不能被原版盾挡下。只对这把刀的伤害生效，不改 Logos 奥秘伤害本身。

## 4. 招式与状态机

挥刀极快：刀从起点到终点只用 2–3 刻（0.10–0.15 秒），然后在终点定住约 0.15 秒（`ease='hold'`），再进入下一刀或收回。轻刀所以**单手持握**，左手空出来（拔刀时抹过刀身、出招时做平衡）。

```
切到这把刀 ──► 凝聚 manifest ──► 待机 idle ──左键──► 一 ─► 二 ─► 三 ─► 四 ─► 五 ─► 回到一
                                   │  ▲            │ 任何时刻右键（不排队，立即）
                                   │  └──松开右键──┤
                                   └──右键────────► 格挡 guard ─(0.5 秒内被击中)─► 弹刀 parry ─左键─► 突刺 riposte
切走 ──► 散去 dissipate ──► 恢复原版
```

| 动作 | 时长（秒） | 标记 | 内容 |
|---|---|---|---|
| `manifest` | 0.9 | cancel 0.7 | 右手虚握在身前，刀从柄向尖凝聚；左手两指沿刀背抹过，最后一抖进待机 |
| `idle` | 2.4 循环 | — | 右手单手，刀尖斜指身后下方（脇构），左手垂在身侧，带呼吸；刀身狐火 |
| `slash_1` | 0.34 | contact 0.10 / cancel 0.22 | 右向左横一闪，终点刀在左肩外定住 |
| `slash_2` | 0.34 | 0.10 / 0.22 | 反手逆袈裟，左下向右上撩起，终点刀举过右肩 |
| `slash_3` | 0.38 | 0.12 / 0.26 | 右上向左下袈裟斩，身体压低，终点刀尖贴地前 |
| `slash_4` | 0.50 | 0.16 / 0.36 | 逆胴：借三的势把刀收到左后方，腰往右拧，刀从左到右平扫过身前（与一相反），定在右侧；命中身前半圈。原本是原地转一圈的回旋斩，2026-11-08 维护者试玩后要求换掉 |
| `slash_5` | 0.62 | 0.20 / 0.44 | 落樱终式：后撤蓄一拍，向前一挥放出樱花刀气（魔力够 30 时），终点定住半拍；接回一 |
| `guard` | 1.6 循环 | 弹刀窗口 0–0.5 | 刀竖在身前，左手掌心抵住刀背 |
| `parry` | 0.36 | — | 刀身一抖把攻击弹开 |
| `riposte` | 0.30 | contact 0.06 | 极快的单手突刺 |
| `parried` / `parried_npc` | 0.5 / 0.8 | — | 被弹反的僵直（规范第 5 节，所有近战武器都要有） |
| `dissipate` | 0.6 | — | 手腕一转把刀甩到身侧，刀从尖向柄散成花瓣 |

所有时长、伤害先按上表做，试玩后再调。

## 5. 凝聚与消散

附属现有的消散（[DISSOLVE.md](DISSOLVE.md)）只会“消失”，并且只处理原版物品渲染；动作武器是战斗骨架按自定义几何画的。所以要给消散加三样通用能力，以后别的武器、技能也能用：

1. **反向（凝聚）**：阈值从高往低走，格子从无到有。
2. **动作武器**：骨架画刀时按同一套格子切分，形状用 `tip` / `hilt`（沿刀身）。
3. **颜色与粒子**：边缘颜色可传（这里用原版樱花树的粉，约 `#f7b9dc`），粒子可换成原版樱花瓣 `cherry_leaves`。

凝聚、消散只在客户端画，由同步的招式（`manifest` / `dissipate`）驱动，不另发网络包。
