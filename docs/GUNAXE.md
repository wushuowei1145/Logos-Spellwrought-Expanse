# 铳斧

附属的第一把铳（物品 `logos_dimension:gunaxe`，战斗武器编号 50）。

它是转轮步枪，枪管下装一条长刃，近战当长柄斧用，可以穿插中距离射击。弹药与换弹的通用规则见 [FIREARMS.md](FIREARMS.md)。

## 1. 模型

- **来源**：维护者手改过的 Blockbench 工程是唯一来源，在仓库外的 `art/gunaxe/blockbench/gunaxe.bbmodel`（Bedrock 格式，注意事项见同目录 `说明.md`）。
  - `tools/import_gunaxe.py` 由它生成网格、贴图、物品模型、图标。
  - 初稿由 `tools/gunaxe.py` 程序化生成（TaCZ 风格：比例修长、小部件做出几何、贴图平整），手改之后不再运行它。
- **坐标**：原点在右手握点（枪托握颈），枪口 +Y，刃朝 +X（枪的下方），网格 `scale` 1.25，第三人称约 2 格长。
- **转轮**：六棱转轮，前后端板带倒角，六面开窗，看得见里面的六发（`Round0`–`Round5`，`Round0` 在最上、对着枪膛）。
- **备用转轮**：换弹用的 `SpareCylinder` 与 `SpareRound*` 由导入脚本从转轮复制，不进 Blockbench 工程、不进物品模型，动作里平时缩成 0。
- **其他骨骼**：`Crane`（留作转轮摆出，目前没用）、`Hammer`、`Trigger`、`MuzzleLocator`（铳口）、`ForeGripLocator`（左手）。
- **照门与准星**：照门（`rear_sight_n`、`rear_sight_s` 两耳加 `rear_sight_base`，两耳之间是缺口）在枪管上、转轮前方，准星（`front_sight`）在枪口。
  - 瞄准线从照门两耳的顶连到准星顶，`gunaxe_moves.py` 直接从模型里取，手改后自动跟上。
  - 照门要高过它后面的机匣后沿（`frame_round`）和顶梁（`top_strap`），不然第一人称瞄准时缺口被挡住。2026-11-26 为此把照门整体抬高了 0.27。
  - `gunaxe_moves.py` 运行时会打印照门、准星在屏幕上的位置和缺口被挡住几个像素，挡住一半以上会警告。
- **贴图朝向**：原版物品模型的每个面 U 方向和动作网格相反，导入脚本和物品模型生成时都对调了一次（其他武器直接抄 bbmodel 的 UV，物品模型和手持相互镜像，只是贴图大多对称看不出来）。

## 2. 招式

近战全是单手大开大合，像单手抡一柄长柄斧，左手空着配重。只有举枪瞄准时左手才握护木前端，换弹时左手取放转轮。

| 招式 | 时长 | 说明 |
|---|---|---|
| `idle` | 2.4 秒循环 | 单手提着，枪口斜指前下方 |
| `attack_1` | 0.72 秒 | 过头斜劈：枪抡到脑后，从右上劈到左下；张角 100° |
| `attack_2` | 0.7 秒 | 反手上撩：从左下抡到右上；张角 110° |
| `attack_3` | 0.78 秒 | 抡圆横扫：齐胸从右扫到左，胳膊伸直；张角 150°，伤害 1.1 倍 |
| `attack_4` | 0.62 秒 | 单手弓步突刺；张角 40°，伤害 1.3 倍 |
| `shot_5` | 0.95 秒 | 刺到底扣扳机（0.06 秒）。单手扛不住后坐，整条胳膊连枪被掀到头顶，人后仰滑退半步 |
| `dry_5` | 0.55 秒 | 空膛的第五下：只咔哒一声，枪口一沉 |
| `aim` | 2.0 秒循环 | 按住右键举枪：枪托抵肩、贴腮；第一人称准星落在照门缺口正中、和两耳平齐，都在屏幕中心的十字上 |
| `aim_shot` | 0.6 秒 | 瞄准开枪（0.03 秒）：枪口顶起二十多度、上身后仰，0.5 秒内压回 |
| `aim_dry` | 0.35 秒 | 瞄准空响 |
| `reload` | 2.4 秒 | 换弹（下文） |
| `parried`、`parried_npc` | 0.5、0.8 秒 | 被弹反 |

换弹（节奏参考 TaCZ 步枪的战术换弹 2.3–2.7 秒、装到位约 1.5 秒）：

1. 0–0.24 秒：枪横到胸前偏左，转轮窗口翻过来朝着眼睛。
2. 左手到左后腰取出新转轮，对准后一把压进机匣。
3. 旧转轮（备用转轮）被从另一侧顶出去，在世界里自由落体、翻滚着掉落。
4. 1.3 秒新转轮到位（`feed`）。
5. 左掌一抹，新转轮飞转一圈，击锤扳下，2.4 秒回到单手待机。

第一人称是按镜头一帧一帧单独写的（`gunaxe_moves.py` 的 `fpc`），不是第三人称的副本：

- 待机：枪从画面右下斜进来；
- 劈砍：从画面中间扫过；
- 突刺、开枪：对着准星；
- 换弹：枪横在画面中下方，左手从枪口一侧捏住新转轮，转轮窗口一直看得见。

托底板离眼睛至少 5 个单位，单手握在长枪末端时枪托不糊脸。

第一人称瞄准（`ads`）：

- 枪按瞄准线摆，照门在眼前 10.2 个单位。
- 击锤比瞄准线高，只在第一人称瞄准时往前扳倒（`AIM_HAMMER`），第三人称照常。
- `LongswordClient.hand` 给第一人称骨架整体多抬了 2°（`Axis.XP`）。瞄准时反着转回来（`FP_TILT`），预览也按游戏里的样子加上这 2°，不然游戏里枪会比预览高十几个像素。

**数值**（试玩后再调）：

- 近战伤害 9（铁斧），攻速 1.0，攻击距离多 1 格，耐久 750。
- 开一枪耗 1 点耐久；子弹的伤害由弹药决定。

## 3. 刀光

`combat/trails/gunaxe.json`：刃从 10.6 到 21.2（刀尖上挑，`tip_x` -0.84），物理元素样式，四段连击各出光。开枪、换弹不出光。

## 4. 验证

- **单元**：`GunaxeTest`。
  - 两个视角的动作与招式文件一致：时长，接触、开火、装弹、取消点。
  - 第五下有弹开枪、空膛空响；瞄准开枪。
  - 换弹在 1.3 秒装到位；没东西可装不换弹；打空后的换弹缓冲到取消点。
  - 招式校验；物品模型与网格对齐，不含备用转轮。
  - 霰弹衰减。
- **客户端场景** `group:gunaxe`（`GunaxeView`）：
  1. 短按 R 换弹：装满六发，背包扣六发。
  2. 举枪瞄准开枪：瞄准时不画原版准星，木桩掉血、少一发，放下枪后准星回来。
  3. 四连击接第五下开枪（侧面机位）。
  4. 背包没弹药时打空只空响、不换弹；捡到弹药后空响自动换弹。
  5. 长按 R 打开弹药轮盘。
  
  换弹、瞄准、开枪各截图。
- **离线预览**：`art/gunaxe/anim_v06`（动作，含第一人称瞄准大图）与 `model_v06`（模型）。

## 5. 已知限制

- 骨骼动作不带物品模型：魔力缠绕按物品模型表面画，转轮摆动、换弹时会有点错位（同和弓）。
- 第一人称单手挥砍时仍有几帧看得到一大截枪托（握在长枪末端的代价）。
- 声音、火光暂用原版。
