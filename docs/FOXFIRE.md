# 狐火

神狐一族的伤害。本质就是 Logos 的奥秘伤害，只是伤害类型、颜色、命中特效和打中后的效果不同。整套都在附属里，Logos 本体不用改。

## 1. 要点

- **结算同奥秘**：照样走 Logos 的 `Effects`，奥秘强化、奥秘抗性、法术抗性都照常算；同原版魔法一样，护甲不减。
- **伤害类型 `logos_dimension:foxfire`**：
  - 原版标签和间接魔法一样：`bypasses_armor`、`bypasses_wolf_armor`、`panic_causes`、`witch_resistant_to`，另加 `c:is_magic`。
  - 所以神狐、女巫对魔法的四成减免照样算，流火等刀的魔力护体也挡得住它。
  - 死亡消息是「X 被 Y 的狐火吞没了」。
- **两种颜色，一种伤害**：神狐一族的狐火是幽蓝的；白梅的是独一份的淡粉，她的刀流火燃的也是这种。
  - 两种只有颜色不同，所以不拆成两种伤害类型。拆开的话，每条规则、每个标签、每处判断都要写两遍，死亡消息里本来就带着放火的人。
  - 颜色跟着放火的人走：白梅的两种形态（以后的少女形态也是）实现 `FoxfireBearer`，其余都是幽蓝。
  - 以后真要给白梅的狐火加独有的规则，也挂在颜色上，不另开伤害类型。
- **命中**：不放 Logos 的奥秘命中特效，换成对应颜色的一团狐火。两处例外：
  - 流火的命中仍是它自己的一小簇樱花。它出刀太快，一团火会盖住第一人称画面。
  - 白梅的刀和牙照旧是奥秘伤害，也照旧不放命中特效。

## 2. 谁放狐火

| 来源 | 颜色 | 说明 |
|---|---|---|
| 神狐「狐火缠绕」 | 幽蓝 | 命中附带 3 点，挥刀放出的横扫游脉扫到的 5 点。原来的点燃 1 秒换成狐火缠身。 |
| 流火（玩家手里） | 淡粉 | 每一刀都是（照常缠身 3 秒）；攒满五枚狐火印爆开时打一下 30 点并缠身 8 秒，之后 8 秒内可以处决，见 [流火](RYUKA.md) 3.2 节。 |
| 白梅的狐火飞弹 | 淡粉 | 盾挡得住。打中时炸开一团淡粉的火，之后狐火缠身。 |
| 白梅烧掉玩家放的方块 | 淡粉 | 方块消散的颜色。 |
| 白梅的刀和牙 | — | 仍是奥秘，没有改。 |
| 调试术式 | 幽蓝 | `/alchemy foxfire page`、`/logos cast`，见第 4、6 节。 |
| 以后少女白梅给玩家的缠绕 | 淡粉 | `FoxfireWraps.wrap(玩家, SHIRAUME, 每下附带, 秒)`，已经能用。 |

## 3. 打中之后

数值都在 `FoxfireRules` 里。

- **狐火缠身**：
  - 目标身上燃 3 秒狐火，每秒烧 1 点狐火伤害，记在点火的人名下。
  - 再被打中只续上时间，不叠层。
  - 它不是原版的火：水浇不灭，抗火挡不住，也不点燃方块。
  - 缠身每秒烧的那一下不再附带缠身、惑，也不放命中特效。
- **同族**：实体标签 `logos_dimension:foxfire_kin`，现在是神狐和白梅的两种形态。
  - 受到的狐火只剩四分之一，再叠神狐对魔法的四成减免。
  - 不会缠身，也不会被惑。
  - 被腐化的同族反而更怕：受到的多一半，缠身也烧 6 秒，狐火能净化它们。但现在还没有被腐化的狐狸。腐化狐狸做出来以后，同时放进 `foxfire_kin` 和腐化的标签就生效。
- **惑**：
  - 怪物被打中时有四分之一的机会丢掉目标，原地打转 1.5 秒，头上绕着几点狐火。
  - 同一只隔 6 秒才会再被惑；Boss 不会被惑。
  - 玩家被打中时，画面四边泛起一圈狐火色，一秒内退掉，只是看着。

## 4. 术式里的 `foxfire`

- **怎么写**：在写 `arcane` 的地方写 `foxfire`，例如 `(damage target 3 foxfire)`。编译器把它当奥秘读，类型、耗魔、外观推断都同奥秘，并记下这是一条狐火术式。
- **整条术式都算狐火**：
  - 它的奥秘伤害都是狐火；
  - 施放时脚下那一圈、符文自己放的那一团（例如缠上手时）、魔力缠绕在手里东西上的样子、游脉，都换成狐火。
- **颜色**：施法者是白梅时淡粉，其余幽蓝。
- **编纂台里完全看不到**：
  - 元素列表、补全、拼写提示里都没有它。
  - 玩家在编纂台（画图、誊写）、书与笔、术式发射器、书灵里写它，都和写错一个词一样报错。
  - Logos 按源码缓存编译结果；缓存里有调试时编过的同一条狐火术式也不行。
- **在编纂台里打开一张狐火术式页**：显示成奥秘，存回去就是普通的奥秘术式。
- **用得了的地方**：调试（`/logos cast`、`/alchemy foxfire page`），以及附属自己的生物（神狐的狐火缠绕）。

## 5. 样子

| 地方 | 样子 |
|---|---|
| 命中 | 一闪，几缕火舌往上窜，交给泛光（泛光压得很轻，免得把第一人称整个画面染色） |
| 施放 | 脚下亮起一圈，五缕火从圈上飘起 |
| 符文自己放的一团 | 例如魔力缠绕缠上手时那一下：换成狐火颜色的一团，没有奥秘的紫色火星 |
| 魔力缠绕 | 手里的东西燃着对应颜色的表面火焰（同神狐刀上的幽蓝、流火刀上的淡粉） |
| 游脉 | 和 Logos 各元素共用的游脉一样沿地面一路冒火、带起碎屑，冒的是狐火：幽蓝是原版的灵魂火焰，淡粉是淡粉的尘和樱花瓣 |
| 缠身 | 身上一圈火舌往上窜，带着同样的火星；烧着的是自己时，第一人称画面底边泛起狐火色 |
| 惑 | 玩家画面四边泛起狐火色；怪物头上绕着三点狐火 |

- **第一人称**：打在自己身上的那一团、自己身上的缠身火星都不画，否则会贴在镜头上；自己挨打、烧着由画面边缘和底边表示。
- **贴图**：都用 Logos 现成的特效贴图和原版粒子，没有新加。

**还没换颜色**：调试用的狐火术式如果用到下面这些形体，仍是奥秘的样子：

- 魔弹、光柱、射线、领域、炼成体；
- 玩家的蓄力；
- 空手（拳头）上的缠绕。

现在游戏里真正放狐火的只有缠绕、游脉、命中和白梅的飞弹，这几样都换好了。剩下的要等一轮狐火形体特效。

## 6. 调试命令

管理员命令：

```
/alchemy foxfire page <wrap|sweep>             一张狐火术式页：狐火缠绕，或单独一道狐火横扫游脉
/alchemy foxfire hit <目标> [点数] [shiraume]   以自己的名义放一下狐火
/alchemy foxfire wrap <目标> [秒] [shiraume]    给目标的手缠上狐火，每下附带 3 点
/alchemy foxfire burn <目标> [shiraume]         让目标狐火缠身
```

不带 `shiraume` 是幽蓝，带了是白梅的淡粉。

## 7. 实现

| 部分 | 文件 |
|---|---|
| 伤害、颜色、藏着的词 | `foxfire/Foxfire.java`、`FoxfireFlame.java`、`FoxfireBearer.java` |
| 缠身、同族、惑 | `foxfire/FoxfireRules.java` |
| 狐火缠绕 | `foxfire/FoxfireWraps.java`、`FoxfireAttachments.java` |
| 给客户端的提示 | `foxfire/FoxfireCue.java` |
| 客户端 | `client/foxfire/FoxfireClient.java` |
| 命令 | `foxfire/FoxfireCommands.java` |
| 注入 Logos | `mixin/Foxfire*Mixin.java`、`SpellObjectAccess`。命中特效在 `RyukaBurstMixin` 里换。 |
| 数据 | `damage_type/foxfire.json`；原版和 `c` 的伤害标签；`tags/entity_type/foxfire_kin.json`；死亡消息 |

注入 Logos 的地方：

- **编译**：把 `foxfire` 读成奥秘，并记下狐火术式。
- **玩家写术式的五处**：编纂台誊写、术式图、书与笔、术式发射器、书灵。
- **结算的三个入口**：术式伤害、生物伤害、普通缠绕的附带伤害。在里面换伤害来源，打进去后附带效果。
- **形体**：施法圈、游脉、术式缠绕。
- **客户端**：手里东西的缠绕外观，游脉的颜色。

注入都是 `require = 0`。Logos 改了被注入的方法时注入不上，狐火退回普通的奥秘伤害，不会崩。

## 8. 测试

- **GameTest**：`-PdimensionTests=logos_dimension:foxfire_*`，10 个，每个单独一批（狐火横扫扫得到隔壁测试的生物）。
  - 狐火和奥秘掉血一样，只是伤害类型不同；
  - 同族只受四分之一；
  - 缠身烧 3 点后熄灭；
  - 藏着的词：调试能用，玩家写不了，编译缓存也绕不过；
  - 书与笔、书灵真的拒绝它；
  - 狐火术式打出的是狐火，横扫游脉被认出来、扫到的是狐火；
  - 普通缠绕附带的是淡粉狐火；
  - 惑。
- **实机场景** `foxfire_views`：
  - 神狐施法圈、刀身的火、砍中、缠身，朝空地的一道横扫游脉；
  - 玩家手上的淡粉缠绕与附带的一下；
  - 玩家被打中时的画面边缘与底边；
  - 怪物被惑。
- **白梅战** `shiraume_duel`：狐火飞弹改成狐火以后照样跑通。
