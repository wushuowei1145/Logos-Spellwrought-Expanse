# 武器的 AI 用法（诸武精通）

同伴怎么用本附属的战斗武器，包括每把武器的特殊攻击。起因是拉塞塔的「诸武精通」（[拉塞塔](LACERTA_COMPANION.md) 第 5.3 节）：你交到她手上的武器她都会用。别的同伴、以后的车万女仆走同一套。

## 1. 维护者定的（2026-11-28）

- 用法写在招式文件里：每一招加一个 `ai` 块，说这一招是干什么用的（第 3 节）。
- AI 和玩家跑同一份招式文件，像玩家一样「按键」：左键、右键按下 / 松开、松开左键、换弹，加上潜行、疾跑、跳这些身法。特殊攻击玩家怎么打出来，AI 就怎么打出来：蓄力要蓄够，子弹要有，魔力要够，时间窗、前提（`require`）对两边一样。
- 只对玩家有意义的机制不给 AI：凌霄的御剑飞行、流火的处决、超电磁炮、爆裂魔杖的 20 秒蓄力。这些招在招式文件里标 `"ai": false`，或者干脆不写 `ai` 块。
- 车万女仆先不做：附属还没开 TLM 联动。
- 同一把武器，某个角色要用通用以外的用法，就在这个角色自己那边覆盖，自己维护（第 4 节）。武器的招式文件只写通用用法。

## 2. 三层

| 层 | 谁写 | 写什么 |
|---|---|---|
| 一 · 持握者 | 公共代码 | 谁拿着武器（`combat/Wielder`）：玩家、同伴各一个实现。武器的钩子（`CombatWeapon.Holder`）都对持握者写，不再只认 `ServerPlayer` |
| 二 · 用法 | 每把武器的招式文件 | 每一招的 `ai` 块：用途、距离、条件、软冷却、分数（第 3 节）。大多数武器只需要这一层 |
| 三 · 钩子 | 少数武器的 Java | 机制不在招式文件里的（世界树之弓的锁定、惊鸿掷剑的瞄准、精灵长矛的印记）：钩子里按持握者做 AI 那一份 |

### 2.1 持握者（`combat/Wielder`）

武器的钩子只问持握者，不问是不是玩家：

| 问什么 | 玩家 | 同伴 |
|---|---|---|
| `entity()` / `player()` | 自己 / 自己 | 自己 / null |
| `aim()` 朝哪打 | 视线 | 看着要打的那个（没有就朝前） |
| `aimed()` 对着谁 | null（准星射线自己找） | 驾驶员挑的目标 |
| `reach()` 够多远 | 原版攻击距离（`entity_interaction_range`） | 角色自己的（身高、握剑的长度） |
| `attackDamage()` 一下多少 | 原版攻击力 × 攻击蓄力 | 她的攻击 +（1 + 武器的攻击力修饰），和空手的玩家拿这把武器一样多 |
| `attackSpeed()` | 原版攻速 | 角色自己的 |
| `intends("sneak" / "sprint")` 身法 | 按着潜行、在疾跑 | 驾驶员这一下想走的那一支 |
| `mayHit(e)` 打不打得 | 不打自己、同乘的、自己的宠物 | 只打她当作敌人的 |
| `ignites()` 每一下都带火 | 否 | 角色的状态（拉塞塔逆鳞时是） |

以后要用到再加：魔力从哪扣、子弹和箭从哪拿（玩家背包、同伴包袱）。

`CombatWeapon.Holder` 里换成持握者的钩子：`allowsAttack`、`combatTick`、`swing`、`strike`、`hit`、`blocked`、`fire`、`feed`、`allows`。只对玩家有意义的写法是钩子开头 `if (w.player() == null) return 默认值;`。`manaGuard`、`manaGuarded` 跟着原版盾牌格挡走，还是只认玩家。

### 2.2 同伴手里的武器（`combat/NpcWeapon`）

同伴跑武器招式的那一份，对应玩家的 `LongswordCombat`：

- 按键：`attack`、`attackRelease`、`reload`、`hold(true / false)`（按住 / 松开右键：按住时每刻补一次 `use_press`，松开时每刻补一次 `use_release`，同玩家）、身法开关（潜行、疾跑），要「空中」时先跳。
- 接触：命中判定和玩家共用（`combat/CombatHits`：眼睛为顶点、朝 `aim()` 的锥形，张角是招式的 `cone` 或武器的；对着的那个排第一，最多八个）。伤害先问武器的 `strike`，武器不管就 `hurtServer`（生物近战伤害，`attackDamage()`）。招式的 `damage` 倍数、不击退、浮空不击退、连刺打浮空翻倍和玩家走同一个受伤事件。挑飞、连刺、下砸（`effect`）照玩家的规矩（`combat/CombatEffects`、`combat/Airborne`）。受击冷却也照玩家：只放过这套招上一下自己留下的。
- 格挡：在接受 `block` 的招式里（横防）被正面近战打中，挡下、交给招式文件的 `block`。转进带 `effect: parry` 的招式就弹开，对方僵直（`combat/Parry`）。
- 被弹反：切到招式文件的 `parried_npc`，同伴实现 `Parry.Reactive` 接上。弹反只认亲手的近战（`Parry.melee`）：武器自己结算成法术伤害的（炽焰长剑的龙炎、流火的魔法伤害）弹不开，玩家拿着也一样。
- 招式里的跟进：起手到最后一下接触之间身子追着目标转；武器自己不推她（`combatTick` 返回假）时，起手到第一下接触之间往目标带一步。
- 动画：同步「前缀 + 动作名」给客户端，前缀是招式文件顶层 `ai.clips` 加下划线（炽焰长剑 `crimson_`）。动作要烘焙到这个同伴的骨架上（第 6 节）。

### 2.3 驾驶员（`combat/WeaponPilot`）

挑招、按键。同伴的心智决定打不打、站哪里、打谁；打哪一招、怎么按交给驾驶员。

挑招：这一刻能走到的每一招（第 3 节的条件都满足、没在软冷却里）打分，取最高的，低于 0.2 就不打（同伴的心智让她走过去）：

```
分数 = weight + 喜好（likes）+ 角色和策略的偏好（prefer）+ 顺手（接在上一招后面：上一招有缓冲的左键转移到它 +0.5，另加 after）
       − 刚放过的（最近一招 0.45，往前每一招减半，记四招）+ 一点抖动（±0.05）
```

怎么按：从当前这一招沿转移图找过去（最多三步）。每一步是一次按键（带前提的就先打开那个身法开关、要空中就先跳），或者等这一招播完走 `next`。按早了没关系：缓冲的转移会等到取消点再切。代码里硬切、转移图里找不到的招在 `ai` 块里写 `via`（第 3 节）。

策略（`CompanionTactic`）的偏好是公共的：优先近战 `gap_close` +0.15，优先远程 `ranged` +0.2。

## 3. 招式文件里的 `ai`

### 3.1 每一招

```json
"crimson_thrust": {
  "length": 0.72, "contact": 0.2, "...": "...",
  "ai": {"role": "gap_close", "range": [3.2, 6], "weight": 0.8, "likes": {"fleeing": 0.2}, "cooldown": 2.5}
}
```

一招有几种用法时写成数组，取分数最高的那一种：

```json
"flame_sweep": {
  "...": "...",
  "ai": [
    {"role": "aoe", "range": [0, 11], "crowd": {"count": 2, "radius": 11, "arc": 72}, "weight": 0.85, "cooldown": 3.5},
    {"role": "ranged", "range": [5, 11], "target": "grounded", "weight": 0.7, "likes": {"fleeing": 0.1}, "cooldown": 3.5}
  ]
}
```

| 字段 | 意思 | 默认 |
|---|---|---|
| `role` | 用途，一个或几个：`opener` 起手、`combo` 连段、`finisher` 收尾、`gap_close` 突进、`aoe` 群攻、`launcher` 挑空、`juggle` 追打浮空、`ranged` 远程、`guard` 横防、`counter` 反击、`reload` 换弹、`buff` 增益 | 必填 |
| `range` | 到目标的距离（她脚下到目标脚下），格 | `[0, 够得着]`（她的 `reach()` 加目标半宽） |
| `crowd` | 至少几个敌人：`{"count", "radius", "arc"}`，`radius` 默认 `range` 的上限，`arc` 默认 360° | 不看 |
| `target` | 目标得是：`airborne` 浮空、`grounded` 在地上、`strong` 强敌（最大生命 ≥ 40）、`fleeing` 在跑开、`above` 比她高 2–5 格、`staggered` 被她弹开正僵直 | 不看 |
| `likes` | 符合时加分：`target` 那几种，另有 `crowd`（身边 3.5 格三个以上） | 无 |
| `weight` | 底分 | 0.5 |
| `after` | 上一招是谁时另加分：`{"招式名": 分}` | 无 |
| `cooldown` | 软冷却（秒） | 0 |
| `via` | 代码里硬切的招怎么按，例：`["use_press", {"hold": 7}, "use_release"]` | 从转移图找 |

`"ai": false`：AI 不用这一招（玩家专用）。没写 `ai` 的招 AI 也不会主动挑，但走转移图时可以路过（例如经过横防去红莲横扫）。

### 3.2 顶层

```json
"ai": {"family": "longsword", "clips": "crimson"}
```

| 字段 | 意思 |
|---|---|
| `family` | 哪一族：`longsword`、`katana`、`polearm`、`bow`、`gun`、`staff`。认不出的武器按物品标签归到通用的一族（第 5 节） |
| `clips` | NPC 骨架上这一族动作的前缀（`crimson` → `crimson_cleave_1`） |
| `keep` | 惯用距离 `[近, 远]`，同伴站位用 |
| `prefer` | 偏好：`{"用途": 加分}`。武器文件一般不写，角色文件写 |

## 4. 角色自己的用法

角色文件放在 `combat/movesets/<角色>/<武器>.json`，`extends` 武器的文件。驾驶员先找角色文件，没有就用武器的。

- 只改用法：这一招只写 `ai`，招式本身照武器的（这是 `extends` 唯一不整招替换的情况）。`ai` 里没写的字段也照武器的，只写 `"ai": false` 就是这个角色不用这一招。
- 改招本身：整招写出来（原来的 `extends` 规矩）。
- 顶层 `ai` 也是只改写到的字段，`prefer` 写在这里。

```json
{
  "extends": "logos_dimension:crimson_flame_longsword",
  "ai": {"prefer": {"finisher": 0.1}},
  "moves": {
    "skyfall_judgement": {"ai": {"weight": 0.9}}
  }
}
```

角色自己的条件不写在文件里，留在角色的心智：例如拉塞塔的坠星要第四印、横防和弹反要第二印，是她的心智挑招时滤掉的。

## 5. 没声明的武器（以后）

- 原版和别的模组的武器按物品标签归一族，走通用招式套：剑、斧、三叉戟、重锤、弓、弩。归类可以复用奥义收尾的 `FinisherTemplate`。通用套的动作要新做。
- 认不出来的，她不用，吐槽一句，接着用自己的武器（拉塞塔照第 5.3 节）。

## 6. 动作

每一族的动作要烘焙到每个同伴的骨架上（`tools/*_moves.py`，同神狐的打刀）。同伴能用一把武器 = 招式文件有 `ai` 块 + 她的动画文件里有 `clips` 这一族的全部动作。车万女仆以后另议：玩家的武器动作是按 TLM 骨骼名做的，可以注册进 TLM 的动画控制器（`AnimationManager.register`），骨骼名对不上的模型退回原版挥手；还要 Logos 本体开口子让附属给女仆加用武器的行为。

## 7. 每把武器归哪一层（估计）

| 武器 | 特殊攻击 | 层 |
|---|---|---|
| 打刀、薙刀 | 格挡、弹反、反击 | 二（神狐已经在用打刀） |
| 炽焰长剑 | 空中坠星、疾跑旋风、潜行突刺、弹反接破军龙牙、横防里横扫 | 二（第一步做的） |
| 曦誓 | 蓄力剑气、7 秒大蓄力 | 二，大蓄力写 `via` |
| 群誓·狼牙 | 挑空接连刺（打浮空翻倍） | 二 |
| 铳斧 | 第五下开火、扇射、瞄准、换弹 | 二；子弹从包袱拿，没敌人时补弹 |
| 流火 | 每刀耗魔、架势冲刺、升龙 | 二；处决不给 AI |

## 8. 顺序

1. **持握者、同伴手里的武器、驾驶员；拉塞塔和炽焰长剑先迁过去。** 她跑玩家那份 `crimson_flame_longsword.json`，删掉抄来的 `lacerta_companion.json` 和 `LacertaBlade` 里重写的冲刺；挑招从 `LacertaMind` 写死的打分换成招式文件里的 `ai` 块。她接上了 `Parry.Reactive`（原来没接，别人弹开她时她没反应）；不过炽焰长剑的每一剑是龙炎，本来就弹不开，换上普通武器以后才用得上。
2. 拉塞塔用包袱里的武器：打刀、长枪、铳斧，每一族烘焙一套动作；包袱里挑武器照拉塞塔第 5.2 节。
3. 原版武器的通用套。
4. 车万女仆（附属开 TLM 联动以后）。
