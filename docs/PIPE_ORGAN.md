# 教堂管风琴

> 状态：维护者 2026-11-11 确认方向（音栓预设 + 自由开关、限制放宽；音管自由搭建；混响看环境，另有手动开关；音色在客户端合成），第一版已实现，第 8 节是实现说明。其他乐器见 [HEXENWALD_INSTRUMENTS.md](HEXENWALD_INSTRUMENTS.md)，纸带、红石、多人同步、编辑器、MIDI 导入都与之共用。

## 1. 外观与方块

魔女之森教堂里的管风琴：胡桃木琴台、淡金收边、象牙色音栓拉钮，背后是一整面银色锡管和深色木管，正面可以横伸几支金色号角管。

| ID | 名字 | 说明 |
|---|---|---|
| `hexen_organ_console` | 管风琴演奏台 | 2 宽 × 2 高（主块在左下），两层手键盘、两侧音栓拉钮、谱架、地上一排脚键盘；纸带槽、红石、界面与钢琴相同 |
| `organ_wind_chest` | 风箱 | 胡桃木底座，正面星辰花镶嵌；挨着演奏台、彼此相连 |
| `organ_tin_pipe` | 锡音管 | 立在风箱上，往上叠自动接成一根长管（最下一格有管口，最上一格收口）；解锁锡管音栓 |
| `organ_wood_pipe` | 木音管 | 方形深色木管，同样可叠；解锁木管音栓 |
| `organ_trumpet_pipe` | 号角管 | 立在风箱上、向前横伸的金色喇叭；解锁号角管音栓 |

**结构识别**：从演奏台的四格出发，沿相连的风箱找过去（最远 24 格），再数每个风箱正上方叠着的音管，总共最多 256 格。服务端和客户端各自识别，结果缓存 2 秒。

- 声音从所有音管的中心发出；没有音管时从演奏台发出。
- 可闻距离 = 16 + 每根音管 1 格，最多 64 格；实时演奏转发给附近玩家的半径同此。
- 只要有一根某种材质的音管，这一类音栓就能用；没有音管时只有长笛 8′ 能用（很轻）。

## 2. 音栓

| 音栓 | 材质 | 音色 |
|---|---|---|
| 长笛 8′ | 木 | 闭管：几乎只有奇次泛音，柔和 |
| 长笛 4′ | 木 | 开管、高八度 |
| 低音 16′ | 木 | 低八度的闭管，给全奏打底 |
| 主音栓 8′ | 锡 | 管风琴的「本音」：泛音丰富、逐渐减弱 |
| 八度 4′ | 锡 | 主音栓高八度 |
| 十五度 2′ | 锡 | 主音栓高两个八度 |
| 混合音栓 | 锡 | 2′、1⅓′、1′、⅔′ 四排叠在一起，高音区按八度折回 |
| 天籁 8′ | 锡 | 细弦音的一对管，一支略高，拍出缓慢的颤动 |
| 号角 8′ | 号角 | 明亮的铜管音 |
| 双簧管 8′ | 号角 | 带鼻音的簧管音 |

**预设**（一键切换，切完可以继续单独开关）：柔和（长笛 8′）、晨祷（主音栓 8′ + 长笛 4′）、合唱（主音栓 8′ + 八度 4′ + 十五度 2′）、全奏（低音 16′ + 主音栓 8′ + 八度 4′ + 十五度 2′ + 混合 + 号角 8′）、号角独奏（号角 8′ + 长笛 8′）、天籁（天籁 8′ + 长笛 8′）。

**限制放宽的做法**：客户端按当前开着的音栓，把各音栓在后台合成并混成一套循环采样（全奏约 0.3 秒），之后一个音只占一路声音，所以十个音栓全开也可以。按住音时改音栓，已经按住的音在约 0.1 秒内交叉淡入新组合。当前音栓存在演奏台上、同步给所有人。

## 3. 声音

- **在客户端合成，不放 ogg**：每隔 3 个半音一个采样（C1–C7，25 个），32 kHz 单声道。管风琴是稳定的长音，每个采样只做约 1 秒、首尾正好接上的循环段：所有分音都取成循环段里整数个周期（天籁那一支多 1–2 个周期，于是拍频也正好接上）；因此采样的实际音高有一点偏差，记进校正表，播放时补回去。
- **播放**：游戏本身就能无缝循环静态声音。客户端合成的数据经一个 mixin 交给声音缓存（`SoundBufferLibrary.getCompleteBuffer` 遇到 `logos_dimension:sounds/organ_runtime/…` 时返回内存里的数据）。起音用 2–3 tick 把音量推上来，松键 2–3 tick 淡出。管风琴不分力度，也没有延音踏板。
- 内存：一套组合约 1.6 MB，最多留 4 套；正在发声的组合不会被清掉。

## 4. 混响

默认「自动」：以音管中心为起点，向四面八方均匀射出 42 条射线，每条最远 48 格。

- **封闭程度**：碰到方块的射线不到六成就当作露天，没有混响；树叶只算半个。
- **房间大小与材质**：平均距离越远、墙越硬（石头、玻璃、金属），混响越长；羊毛、地毯、木头吸音，混响越短。约 0.3–4 秒。
- 只在客户端算，乐器发声时每 5 秒重算一次。

手动档位：自动 / 关 / 小厅（1.2 秒）/ 教堂（3.5 秒），在音栓页切换，存在演奏台上。装了 Sound Physics Remastered（它给所有声音加混响）时，「自动」视为「关」，免得两层混响叠在一起；手动档位照常生效。

**效果**：松键时播一段按当前组合和房间生成的尾音（同一个音色在混响时间里衰减，高频先暗），同一个音再弹时替换它之前的尾音，尾音总数有上限。

## 5. 界面

管风琴的界面有三页：演奏（键盘同钢琴，音域 C1–C7）、音栓（十个开关、六个预设、混响档位、音管数量与识别到的混响）、纸带（同钢琴）。

## 6. 第一版范围与以后

第一版：上面全部。以后：上下两层手键盘与脚键盘分开的键位、纸带记录换音栓、起音的气流声（chiff）、震音器（tremulant）、自定义预设、在星辰花之都的教堂里摆放。

## 7. 测试

- 单元：每个采样的循环段首尾连续、校正后音高误差小于 0.1 音分；混响时间随房间大小与材质的变化；音栓与预设。
- 世界：演奏台四格整体拆除；音管叠起来的形状；结构识别（风箱链、音管计数、上限）；没有音管时服务端只接受长笛 8′。
- 客户端：外观截图（演奏台、风箱、管墙、号角管），音栓页，合成出一套组合并能发声。

## 8. 第一版实现说明

### 8.1 怎么玩

- 合成：演奏台 = 石英块 ×3 + 金锭 ×2 + 音符盒 + 深色橡木板 ×3（`QQQ / GNG / PPP`）；风箱 ×2 = 深色橡木板 ×6 + 皮革 ×2 + 金粒（`PPP / LGL / PPP`）；锡音管 ×3 = 铁锭 ×2 + 金粒（竖排）；木音管 ×3 = 深色橡木板 ×2 + 金粒（竖排）；号角管 ×2 = 金锭 ×4（斜排）。都在功能方块页。
- 搭法：演奏台背后（或旁边）摆一排风箱，风箱上立音管，往上叠就是长管；号角管也立在风箱上，喇叭朝放置时你面对的方向。风箱可以拐弯、分叉，只要彼此相连并挨着演奏台。
- 空手右键演奏台：演奏页弹（键位同钢琴），音栓页开关音栓、按预设、切混响档位（页面上写着识别到的音管数、可闻距离和这里是否算室内），纸带页同钢琴。

### 8.2 代码

| 位置 | 内容 |
|---|---|
| `music/organ/OrganStop` | 十个音栓、材质、预设、组合的响度 |
| `music/organ/OrganSynth` | 无缝循环段的合成、音高校正、混响尾音（纯 Java） |
| `music/organ/RoomAcoustics` | 由射线统计估计混响、档位（纯 Java） |
| `music/organ/OrganStructure` | 风箱与音管的识别 |
| `music/organ/OrganConsoleBlock`、`OrganPipeBlock`、`OrganTrumpetBlock` | 方块；风箱是普通方块 `organ_wind_chest` |
| `music/InstrumentBlockEntity` | 新增音栓、混响档位、音管结构缓存、可闻距离 |
| `mixin/OrganBufferMixin` | 声音引擎取 `organ_runtime/…` 时交给内存里的数据 |
| `client/music/OrganMixer` | 后台合成组合、交给声音引擎的缓冲、尾音、缓存 4 套 |
| `client/music/OrganRoom` | 42 条射线量房间（管风琴自己的方块不算墙、要有顶才算室内） |
| `client/music/VoiceBank` | 管风琴的循环声、起音、尾音、换音栓时的交叉淡入 |
| `tools/instrument_art.py` 的 `organ()` | 模型、方块状态、掉落、配方（只用原版贴图和已有的琴键、星辰花镶嵌） |

### 8.3 维护

```text

./gradlew test --tests "dev.logos.dimension.music.organ.*" -PlogosJar=...
./gradlew runGameTestServer -PlogosJar=... "-PdimensionTests=logos_dimension:organ_*"
./gradlew runClient -PlogosJar=... "-PldTest=organ_views,organ_play_ui" -PldTestHeadless -PldTestWindow=1280x720
```

### 8.4 还没验证的

- 音色与混响只能人工试听。
- 多人同步只在单人存档里跑过；专用服务器、光影包没测；没有装 Sound Physics Remastered 试过「自动」是否真的让开。
- 很大的管墙（接近 256 格上限）在低端机器上的开销没量过；合成一套全奏约 0.1 秒，在后台线程。
