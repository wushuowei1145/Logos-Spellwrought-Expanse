# 教堂管风琴

> 状态：维护者 2026-11-11 确认方向（音栓预设 + 自由开关、限制放宽；音管自由搭建；混响看环境，另有手动开关；音色在客户端合成），第一版已实现，第 8 节是实现说明。2026-11-14 声音重做（每个泛音各自起音、管列微失谐与慢起伏、真正的房间混响），维护者听过新旧对比后定稿，第 9 节是说明和参考。其他乐器见 [HEXENWALD_INSTRUMENTS.md](HEXENWALD_INSTRUMENTS.md)，纸带、红石、多人同步、编辑器、MIDI 导入都与之共用。

## 1. 外观与方块

魔女之森教堂里的管风琴：胡桃木琴台、淡金收边、象牙色音栓拉钮，背后是一整面银色锡管和深色木管，正面可以横伸几支金色号角管。

| ID | 名字 | 说明 |
|---|---|---|
| `hexen_organ_console` | 管风琴演奏台 | 3 宽 × 2 高（主块在下排正中），两层手键盘和脚键盘居中、左右两块音栓侧板，整台左右对称，琴凳放在正中那格前面；纸带槽、红石、界面与钢琴相同。旧存档里 2 宽的演奏台（`wide=false`）照旧能用，拆掉再放就是 3 宽 |
| `organ_wind_chest` | 风箱 | 胡桃木底座，正面星辰花镶嵌；挨着演奏台、彼此相连 |
| `organ_tin_pipe` | 锡音管 | 立在风箱上，往上叠自动接成一根长管（最下一格有管口，最上一格收口）；解锁锡管音栓 |
| `organ_wood_pipe` | 木音管 | 方形深色木管，同样可叠；解锁木管音栓 |
| `organ_trumpet_pipe` | 号角管 | 立在风箱上、向前横伸的金色喇叭；解锁号角管音栓 |

**结构识别**：从演奏台的每一格出发，沿相连的风箱找过去（上下也算相连，风箱可以一级级往上接到高处的管墙；最远 24 格），再数每个风箱正上方叠着的音管，总共最多 256 格。服务端和客户端各自识别，结果缓存 2 秒。

- 声音从所有音管的中心发出；没有音管时从演奏台发出。
- 可闻距离 = 16 + 每根音管 1 格，最多 64 格；实时演奏转发给附近玩家的半径同此。
- 只要有一根某种材质的音管，这一类音栓就能用；没有音管时只有长笛 8′ 能用（很轻）。

## 2. 音栓

| 音栓 | 材质 | 音色 |
|---|---|---|
| 长笛 8′ | 木 | 闭管：几乎只有奇次泛音，柔和 |
| 长笛 4′ | 木 | 开管、高八度 |
| 低音 16′ | 木 | 低八度的闭管，给全奏打底 |
| 主音栓 8′ | 锡 | 管风琴的「本音」：泛音丰富、逐渐减弱 |
| 八度 4′ | 锡 | 主音栓高八度 |
| 十五度 2′ | 锡 | 主音栓高两个八度 |
| 混合音栓 | 锡 | 2′、1⅓′、1′、⅔′ 四排叠在一起，高音区按八度折回 |
| 天籁 8′ | 锡 | 细弦音的一对管，一支略高，拍出缓慢的颤动 |
| 号角 8′ | 号角 | 明亮的铜管音 |
| 双簧管 8′ | 号角 | 带鼻音的簧管音 |

**预设**（一键切换，切完可以继续单独开关）：柔和（长笛 8′）、晨祷（主音栓 8′ + 长笛 4′）、合唱（主音栓 8′ + 八度 4′ + 十五度 2′）、全奏（低音 16′ + 主音栓 8′ + 八度 4′ + 十五度 2′ + 混合 + 号角 8′）、号角独奏（号角 8′ + 长笛 8′）、天籁（天籁 8′ + 长笛 8′）。

**限制放宽的做法**：客户端按当前开着的音栓（和所在的房间），把各音栓在后台合成并混成一套采样，之后一个音只占一路声音，所以十个音栓全开也可以。按住音时改音栓，已经按住的音在约 0.1 秒内交叉淡入新组合。当前音栓存在演奏台上、同步给所有人。

## 3. 声音

- **在客户端合成，不放 ogg**：每隔 3 个半音一个采样（C1–C7，25 个），32 kHz 单声道。每个采样 = 0.75 秒起音段 + 2.05 秒（2¹⁶ 点）循环段；声音引擎先放一遍起音，之后在循环段里一直响（OpenAL 的循环点）。25 个音在后台线程并行合成。
- **每个音栓是几排管，每排管是一串泛音**（加法合成，最多 96 个泛音，最后三分之一渐弱）：闭管长笛只有奇次泛音、越往高越纯；主音栓泛音逐渐减弱、低音区再收一点；弦音高泛音衰减慢；号角、双簧管有固定的共振峰（号角约 1.5、3.2 kHz，双簧管约 1.35、2.9 kHz）；混合音栓四排超过约 4.8 kHz 按八度折回。
- **起音**：每个泛音各自从静音以 S 形长出来（长笛、主音栓约 30 ms 到一半响度，簧管快一些、音高从低约 20 音分处滑上来）。同一个键上所有管子按琴键的音高一起开始，越高的分音来得越晚一点、长得越慢一点，起音先暗后亮；**不叠任何噪声冲击，也不冲高**——起音比稳定的音亮或响，听起来就是「啪」「嗒」一下（第 9 节）。
- **持续音**：各排管彼此差一两音分（在高音区才拍得出来，同真管风琴一样）；每排管带很慢的音高（0.35–0.8 音分）和响度（1.5–3%）起伏；沿各排管前四个泛音有一层轻气声（长笛约 −35 dB、主音栓约 −38 dB）。这些起伏和气声都是循环段里整数个周期的，所以首尾无缝。天籁是一对弦音管，拍频从低音约每秒 0.9 次到高音约 4 次。
- **相位**：所有分音在循环起点对齐（主音栓的波形近似锯齿、闭管近似方波、簧管近似脉冲）。几排管落在同一频率上时在每个琴键上都同样叠加（#243）；也不能把相位打散——低音区一个周期长达 30–60 ms，打散的相位会变成一层「沙沙」的电子味。
- **音高**：16′ 基音在循环段里取整数个周期，采样的实际音高因此有一点偏差，记进校正表，播放时补回去（误差 < 0.1 音分）。
- **响度**：每个采样各自缩放到满幅附近，相邻采样相差不超过 1 dB（低音波形尖、峰值高，整套共用一个倍数的话高音会被压轻几 dB）；不同组合之间的响度差由音栓的响度表给。和第一版的响度相差约 ±1.5 dB。
- **播放**：起音已经在采样里，按键时直接全音量放；松键后约 0.2 秒淡出（真管子停得快），房间有混响时接上这一套的尾音。管风琴不分力度，也没有延音踏板。
- **合成时间与内存**：全开 + 教堂档一套约 2 秒 CPU，分到多核约 0.2–0.4 秒（第一版约 0.1 秒）。换了音栓或房间时新组合在后台合成，好之前先用上一套发声，好了交叉淡入；只有进存档后第一次弹、什么都还没合成时才当场等它。一套组合约 4.5 MB，教堂档另有约 7 MB 尾音（第一版 1.6 MB）；最多留 4 套，正在发声的组合不会被清掉。

## 4. 混响

默认「自动」：以音管中心为起点，向四面八方均匀射出 42 条射线，每条最远 48 格。

- **封闭程度**：碰到方块的射线不到六成就当作露天，没有混响；树叶只算半个。
- **房间大小与材质**：平均距离越远、墙越硬（石头、玻璃、金属），混响越长；羊毛、地毯、木头吸音，混响越短。约 0.3–4 秒。
- 只在客户端算，乐器发声时每 5 秒重算一次。

手动档位：自动 / 关 / 小厅（1.2 秒）/ 教堂（3.5 秒），在音栓页切换，存在演奏台上。装了 Sound Physics Remastered（它给所有声音加混响）时，「自动」视为「关」，免得两层混响叠在一起；手动档位照常生效。

**效果**（2026-11-14 起）：房间是组合的一部分。干声在合成时走过一个 8 路反馈延迟网络（`OrganReverb`）：起音段里混响渐渐长起来，循环段里是混响已经稳定的声音，所以按住时音就在房间里，和弦会慢慢「开花」。之后输入静音得到的就是这个音松键后房间本身的衰减（高频先消失、低频稍长），松键时播出来；按得越短、混响长得越少，尾音也越轻。同一个音再弹时替换它之前的尾音，尾音总数有上限。房间按混响时间 0.25 秒一档、亮暗两档分，档变了就合成一套新的。

| 混响参数（由混响时间 RT 与明亮程度 b 换算） | 值 |
|---|---|
| 中频混响时间 | RT |
| 220 Hz 以下 | RT ×（1.12 + 0.18 ×（1 − b）） |
| 高频阻尼（混响时间减半处） | 1800 + 4200 × b Hz |
| 预延迟 | 4 + 5 × RT ms（最多 30 ms） |
| 房间大小（延迟线长度倍数） | 0.55 + 0.19 × RT（0.6–1.3） |
| 湿声 / 干声 | 0.28 + 0.1 × RT（最多 0.7；教堂档约 −4 dB） |

## 5. 界面

管风琴的界面有三页：演奏（键盘同钢琴，音域 C1–C7）、音栓（十个开关、六个预设、混响档位、音管数量与识别到的混响）、纸带（同钢琴）。

## 7. 测试

- 单元：每个采样的循环段首尾连续、同样的输入两次合成逐点相同、校正后音高误差小于 0.1 音分；起音头 80 ms 每个频段不比稳定时响 2.5 dB 以上、频谱重心不比稳定时亮 1.35 倍以上（不「啪」）；低音 C1 一个周期里只有一个陡边（不「沙沙」）；八度分音的平衡在相邻采样间不跳（#243）；尾音开头淡入、约 3 秒衰减 45 dB、高频先消失、按得短尾音轻；相邻采样的缩放倍数差 < 1 dB；混响的中频混响时间合乎设定、高频短、低频不短、能量归一、阻尼滤波器的增益；混响时间随房间大小与材质的变化；音栓与预设。
- 世界：演奏台六格整体拆除、旧的 2 宽演奏台照旧；音管叠起来的形状；结构识别（风箱链、风箱往上接、音管计数、上限）；没有音管时服务端只接受长笛 8′。
- 客户端：外观截图（演奏台、风箱、管墙、号角管），音栓页，合成出一套组合并能发声，按住的和弦在循环，松键后大厅里有尾音；重启声音引擎后同一个键仍在响。
- 试听：`OrganDemoTest`（`-PorganDemo=<目录>`）照游戏里的放法把同一段谱子用第一版（测试里原样留着的 `LegacyOrganSynth`）和现在的合成各渲染一遍，写成 wav。

## 8. 第一版实现说明

### 8.1 怎么玩

- 合成：演奏台 = 石英块 ×3 + 金锭 ×2 + 音符盒 + 深色橡木板 ×3（`QQQ / GNG / PPP`）；风箱 ×2 = 深色橡木板 ×6 + 皮革 ×2 + 金粒（`PPP / LGL / PPP`）；锡音管 ×3 = 铁锭 ×2 + 金粒（竖排）；木音管 ×3 = 深色橡木板 ×2 + 金粒（竖排）；号角管 ×2 = 金锭 ×4（斜排）。都在功能方块页。
- 搭法：演奏台背后（或旁边）摆一排风箱，风箱上立音管，往上叠就是长管；号角管也立在风箱上，喇叭朝放置时你面对的方向。风箱可以拐弯、分叉，也可以叠高一级级往上接（例如从演奏台升到高处的管墙），只要彼此相连并挨着演奏台。
- 空手右键演奏台：演奏页弹（键位同钢琴），音栓页开关音栓、按预设、切混响档位（页面上写着识别到的音管数、可闻距离和这里是否算室内），纸带页同钢琴。

### 8.4 还没验证的

- 音色与混响只能人工试听。
- 多人同步只在单人存档里跑过；专用服务器、光影包没测；没有装 Sound Physics Remastered 试过「自动」是否真的让开。
- 很大的管墙（接近 256 格上限）在低端机器上的开销没量过；合成一套全开 + 教堂档约 2 秒 CPU（25 个音并行），核少的机器换音栓后新组合要多等一会儿（这期间先用上一套发声）。
- 没有 `AL_SOFT_loop_points` 的 OpenAL（原版带的 OpenAL Soft 都有）上，按住的音会从头连起音一起循环。

### 9.2 三稿里踩过的坑

- **第一稿起音「啪」一下（柔和最明显）**：起音叠了一阵 1.5 ms 就冲满的气流噪声，长笛的二、三次泛音冲高到稳定时的 7 倍、比基音早到。实测按键后 2 ms 内 3–8 kHz 比稳定时高 11–14 dB。手持乐器第一版的「鼓声」是同一个原因。
- **第一稿低音踏板有科幻感**：为了压低号角的峰值把分音相位打散（随倍数平方变），C1 一个周期里盖满一层毛刺。改回对齐的相位，号角峰值高就靠逐个采样缩放解决。
- **第二稿仍有一下「嗒」**：没有噪声了，但长笛 20 ms 就几乎全响；而且每排管的快慢按它自己的音高算，4′、2′、混合音栓这些小管子先到，合唱、天籁起音头 20–30 ms 比稳定时亮 1.5–2.4 倍。改成同一个键上的管子按琴键音高一起起音、高的分音晚一点，起音先暗后亮。
- 这三条都写进了单元测试（第 7 节）。以后改音色，渲染试听后先量：每个频段的起音包络（不超过稳定时约 2 dB）、起音的频谱重心（不超过稳定时约 1.3 倍）、低音一个周期的波形（干净）。

### 9.3 合成管线

```
每排管：泛音表 × 起音包络 × 慢起伏（音高、响度）──┐
气声：白噪声 → 各排管前四个泛音处的共振（循环段里首尾相接）──┼→ 干声（起音段 + 循环段）
                                                    │
干声 → 8 路 FDN：起音段（混响在长）→ 第二遍循环段（混响已稳定）→ 输入静音（尾音）
       └→ 采样 = 干声 + 湿声；尾音单独一段；按刻记混响长到几成（bloom）
25 个音并行 → 每个采样缩放到满幅附近、相邻差 ≤ 1 dB → 16 位
```
