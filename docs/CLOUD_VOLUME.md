# 天门云域云层已移除

按用户确认，删除的是天空云海效果，保留天门云域维度及其地形、群系、地下与聚落。原有存档和注册 ID 不变。

删除了云密度场、等值面网格生成、后台工作线程、81 格缓存、49 格逐帧提交、云内雾和云纹理。没有以另一套云网格替换。旧云层高度现在是开放天空，玩家自由飞行。魔鲸仍是偶尔出现的轻量天空景象。

旧截图 `screenshots/refinement/cloud-*.png` 记录 0.1.2 历史版本，不能代表当前画面。开发场景改为 `group:open_sky`，检查原云层空域、维度保留以及没有云网格工作线程。光影包可自行画自己的天空和远云，本附属不控制光影包自己的云开关。
