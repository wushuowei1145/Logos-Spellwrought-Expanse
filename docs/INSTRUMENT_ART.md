# 乐器美术重做：方向与规范

2026-11-14 起，魔女之森全部乐器的模型与贴图按这份规范重做。生成脚本在 `tools/instrument_models/`（按组分文件），
共用工具在 `tools/instrument_kit.py`，离线预览 `tools/model_preview.py`，游戏内验收场景 `instrument_gallery_ui`。

## 1. 方向（维护者 2026-11-14 定）

- **配色不变，做工升级**：沿用 2026-11-10 定下的白色大理石纹漆、深色胡桃木、淡金收边、星辰花与灵猫母题
  （见 [HEXENWALD_INSTRUMENTS.md](HEXENWALD_INSTRUMENTS.md) 第 1 节）。要「精致、华贵」，但仍是学院和教堂里的古典乐器，不堆金、不浮夸。
- **原版密度**：1 个模型单位 = 1 像素（16 像素 / 格），和原版方块、物品、生物一致。细节靠像素画的明暗、倒角和形体，不靠更细的像素。
- **性能**：元素数有预算（第 4 节）；贴图页全不透明、2 的幂；不加方块实体渲染器，全部是烘焙模型。
- **不闪**：任何两个朝向相同、互相平行、投影有重叠的面，至少隔开 0.05 像素（`MIN_GAP`）；能删的被挡住的面直接删。生成时自动检查，有一处就报错。
- **旧草稿不用**：`worktrees/instrument-models`（`art/instrument-models`）那份未提交的重制稿不参考、不合并。

## 2. 材质与用法

调色板在 `instrument_kit.PALETTE`，每种材质五个色阶（暗 → 亮），画法在 `MATERIALS`。不要再用拉伸的原版贴图（金块、深色橡木板、混凝土……）。

| 材质 | 用在 |
|---|---|
| `marble` 白色大理石纹漆 | 星辰花钢琴、钢片琴的琴身外壳；琴凳以外的「白」都用它 |
| `walnut` / `walnut_light` 深色胡桃木 | 柜体、琴腿、谱架杆、管风琴木件；`walnut_light` 用在雕花凸起、扶手面这类要亮一档的地方 |
| `gilt` 淡金 | 收边线、铰链、脚套、雕饰、管风琴管口唇；**点缀**：一件乐器看得见的面积里大约一成以内 |
| `brass` 黄铜 | 小号、管钟管、踏板、定音鼓调音螺杆 |
| `silver` / `tin` / `steel` | 长笛与按键 / 管风琴金属管 / 琴弦 |
| `spruce` / `maple` | 音板、提琴面板 / 琴马、键盘框、谱架板 |
| `varnish`、`flamed_varnish` / `amber`、`flamed_amber` | 小提琴 / 中提琴、巴松（虎纹用在背板、侧板） |
| `ebony` / `lacquer_black` / `rosewood` | 黑键、指板、双簧管 / 黑漆件 / 弦轴、尾柱帽 |
| `ivory` | 白键、象牙镶条 |
| `velvet`（酒红）/ `velvet_navy`（魔女之森深蓝） | 琴凳、指挥台垫 / 旗、衬布 |
| `felt` / `felt_red` / `skin` / `parchment` / `copper` / `iron` / `shadow` | 槌头 / 键盘前红毡 / 鼓皮 / 谱页 / 定音鼓腔 / 支架 / 音孔、管口、腔体内部 |

需要新材质：在自己的组文件里往 `kit.MATERIALS`（必要时 `kit.PALETTE`）加一个**新名字**，不要改已有的。

母题：星辰花（五瓣小花，`STARBLOOM` 5×5、`STARBLOOM_SMALL` 3×3）每件乐器 1–3 处，在显眼但不抢戏的位置；
灵猫（竖琴柱头的坐猫、钢琴谱架两端的猫耳卷饰）保留并做得更精致。

## 3. 画法规则

1. **一面一块贴图**：用 `kit.cube()` 造元素，每个面按材质现画到这件乐器的贴图页上；木纹顺着长边（`grain` 可改），金属有高光带，边缘有一像素倒角。
2. **小于一像素的细节画在贴图上**（镶线 `frame_line`、印花 `stamp`、点色 `pixels`、渐暗 `gradient`、任意 `custom`），不要为了它多加元素。
3. **曲线不要台阶**：弯边用 `kit.wall()`（沿折线一段段转过去的薄板），圆柱用 `kit.polygon_prism()`（正多边形），斜杆用 `kit.segment()`。
   只有像素画本身该有的阶梯（比如 3 像素宽的小圆）才用台阶。
4. **剪影先行**：先在预览里只看轮廓（远看、物品栏图标）认不认得出是什么乐器，再加细节。
5. **明暗方向统一**：贴图上的高光在上缘、左缘，暗部在下缘、右缘；原版还会按面的朝向再乘一次明暗，不要在贴图里重复画朝向明暗。
6. **藏起来的面删掉**：贴在别的元素上、看不见的面用 `faces={"up": None}` 去掉，或者最后过一遍 `kit.prune_hidden()`。
7. **共面**：同一平面上要叠东西（镶片、标牌、花纹），改成画在贴图上；非要另加元素，就让它高出 ≥ 0.05，或者把底下那块切开不重叠。
   `polygon_prism()`、`wall()` 已经按这个规则错开（两端各缩进 MIN_GAP 的倍数），所以两段多边形柱首尾相接时会留一道很细的缝，接头处让它们交叠 ≥ 0.3 像素。
8. **金属与漆面不要噪点**：漆面、金属只有很轻的颗粒；木头的纹理也要克制，远看是一块干净的颜色。

## 4. 预算（元素个数，`instrument_kit.BUDGET`）

| 类别 | 上限 | 用于 |
|---|---|---|
| `large` | 220 | 钢琴、管风琴演奏台、竖琴、大键琴、定音鼓、管钟、指挥台 |
| `block` | 110 | 钢片琴、钟琴、风箱、乐谱架（含上面的乐器）、琴凳 |
| `pipe` | 28 | 管风琴音管（每种连接状态各算） |
| `held` | 70 | 手持乐器的物品模型（含 held / playing 变体） |
| `tool` | 12 | 琴弓、琴槌、指挥棒 |

贴图页最大 256×256；一件乐器（含变体）一张页，页名用乐器名。

**破坏粒子**：方块模型的 particle 不用整张贴图页（会碎成五颜六色），`Out.flush()` 按面积挑这件乐器最多的那种材质，画一张 16×16 的 `particle_<材质>.png`；自动挑得不对（白钢琴底面的胡桃木面积更大）就在 `block_model(..., particle=out.particle("marble"))` 里指定。多格乐器的 `_part` 跟着主模型。

## 5. 不能动的东西（契约）

- **注册 ID、模型文件名、方块状态、掉落、配方都不改**；旧脚本写出的每个模型文件，新模块都要写出同名的一份（多格乐器的 `_part` 只给粒子贴图）。
- **占地和朝向**：模型按 FACING=north 画（键盘 / 正面朝北，z 小的一侧），多格乐器的范围和现在一样（`tools/instrument_art.py` 顶部注释）。
- **演奏接触点**：Java 里的姿势按这些坐标把手放上去，新模型这些面的位置偏差不超过 ±0.3 像素：
  - 键盘顶面高：钢琴 13、大键琴 12.2、钢片琴 11.2、管风琴 14.8（`MusicianPoses.keyTop`），键盘前沿在琴凳一侧，左右各留 1.5–2.5 的琴身边（`keySpan`）。
  - 竖琴琴弦平面：朝北的模型里 z = 13（`strings.py` 的 `HARP_SHIFT` 把整架往琴凳一侧挪了 5 像素，碰撞箱 z 9–16），最低音弦 x = 5.9、每根往右 0.47，
    弦下端沿共鸣箱斜升（x 每 1 像素高 2.74，x = 5.9 时 4.3）。`MusicianPoses.HARP_STRINGS_Z`、`harpHand` 按这些数把手放在弦上，挪了琴弦就得一起改。
  - 钟琴音条顶面 y≈12.3，琴槌落点在朝北的模型里是 x 2.5–13、z≈6（`StationPoses` 写的是转过 180° 的演奏者坐标 z 6，`InstrumentPosts` 的脚位 (8, 0, −6) 同一套）；管钟管顶 y≈26.9、管间距 1.37；定音鼓鼓皮顶面 y≈13.3（`StationPoses`）。
  - 琴槌：握点 (8, 1.5, 8)，槌头中心 y：钟琴 10.7、管钟 9.8、定音鼓 10.8（`StationPoses.toolGrip/toolHead`）。
  - 手持乐器：`HeldRig` 里的支点和手位（小提琴支点 (8,1,9)、托琴颈 (8,13,11)、弓毛 x=8.35、弓根 (5.1,1.8)；长笛 (2.8,8,8)、手 (11.5,5.3,8)/(6.5,5.3,8)；
    双簧管 (8,15.6,8)、手 (8,5,10.8)/(8,11,10.8)；巴松 (12.33,12.1,12.5)、手 (9.4,0.5,10.6)/(6.6,7.5,10.6)）。改了支点就得改 Java，**不要改**。
  - 大提琴、低音提琴：`SEATED`（`tools/instrument_models/strings.py`）和 `HeldRig.CELLO/BASS` 的尾柱、倾角、弓触点、琴颈范围。
  - 琴凳面高 10（`StarbloomBenchBlock.TOP`）。
- **物品显示**：方块乐器用 `kit.display(elements)`（物品栏撑满一格、地上 / 手里和原版方块差不多大）；
  手持乐器保留现在的第一 / 第三人称变换（姿势调过），物品栏、地上、展示框按 `kit.fit()` 重算。

## 6. 流程

1. 读旧脚本里自己那几件的函数，弄清坐标和变体（held / playing / 谱架上 / `_part`）。
2. 在 `tools/instrument_models/<组>.py` 里写 `build(out)` 和 `PREVIEW` 列表，跑
   `uv run --no-project --with pillow --with numpy python tools/instrument_models/run.py <组> --preview <目录>`，
   看四个角度和物品栏图标，至少改两轮。检查（预算、边界、共面）不过时生成会直接报错。
3. 只改自己组的文件和自己乐器的贴图页；不碰 Java、不跑 Gradle、不提交。需要改 Java 的地方写进汇报。
4. 游戏内验收由维护会话跑 `instrument_gallery_ui`（全部乐器三排 + 物品栏图标 + 手持 + 掉落）。

## 8. 重做前的问题（2026-11-14 普查，已改）

- 钢片琴、钟琴、乐谱架、三种音管、风箱的物品没有显示变换：手里、地上、物品栏都按原尺寸画（拿着一整块）。
- 竖琴、管钟、低音提琴在展示框里是原版方块的两倍大。
- 几乎所有模型都有完全重叠的面（定音鼓 50 处，`disc()` 三块同高的长方体叠出圆），远处会闪。
- 全部用拉伸的原版贴图（金块、深色橡木板、方解石、混凝土），没有木纹方向、没有倒角。
- 物品模型链的显示变换现在由 `ItemModelDisplayTest.itemModelChainsEndInADisplay` 检查（沿 parent 链找 display）。
