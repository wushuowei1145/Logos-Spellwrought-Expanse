# 林冠层中的高大树木

0.8.1 不改变大陆地形和群系分布，在七种现有林地中稀疏混入两类大树。没有新增重复木材方块，全部使用各自对应的独立原木与季节树叶。

- 高冠阔叶树：古山毛榉林、翠玉密林、蕨林、苔谷中出现。沿用原版 fancy_trunk_placer/fancy_foliage_placer，分叉与宽冠，配置高度 16–25 格；树枝和树冠的实际最高点以原版算法为准。
- 高塔冷杉：冷杉腹地、北方松林、云根山林中出现。沿用原版 giant_trunk_placer/mega_pine_foliage_placer，2×2 树干、层叠针叶冠，配置高度 22–35 格、冠深 14–19 格。

每个适用区块以原版 rarity_filter 的 1/3 概率进行一次候选尝试，不保证成功。大树在普通树之前尝试生成，保留原有普通树、灌丛、林隙和地表植被，形成上层林冠。使用原版 OCEAN_FLOOR_WG 高度、水深/土壤检查与 biome 过滤；不增加 Java 运行时种树器、地形扫描或建筑填块。移除大针叶树原版 podzol 装饰，保持已有草皮风格。

只影响新生成区块，既有树林不会被扫描或替换。树更高会增加局部树叶数量，采用稀疏尝试与现有相邻叶面剔除；没有做硬件 FPS 或第三方光影验证。

验证：15 项单元与 36 项 GameTest 全部通过。调用原版 Feature 在隔离测试画廊实际生成两类树，固定样本树干最高点相对根部为 22/25 格、原木 78/101 个、树叶 848/411 个。另一真实自然生成的 96×96 格冷杉林样本找到 33 格连续高树干；样本数值不代表所有种子。

自然采样测试先显式加载固定范围，避免原版未加载区块的高度查询返回空结果；没有增加运行时世界扫描。并把旧蓝莓测试的固定光照等待改为等待真实亮度条件，不放宽任何生长断言。

普通实际客户端 tall_trees：2/2 场景、8/8 检查通过，包含原版 Feature 的隔离树形画廊与真实自然森林。截图见 screenshots/tall-trees/，两类画面分别注明，未把画廊当作自然生成证据。
