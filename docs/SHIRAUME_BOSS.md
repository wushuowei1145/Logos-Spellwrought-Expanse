# 九尾妖狐 白梅（しらうめ）：Boss 战

整理时间：2026-11-09。附属的第一个 Boss。场地是神狐聚落地下的封印之间（[FOX_SANCTUARY.md](FOX_SANCTUARY.md)「地下封印场地」）；模型在仓库外 `MinecraftLogosMod/fox_model/sealed_nine_tailed_fox`（人形）与 `sealed_nine_tailed_fox_beast`（狐形）。

本页先写设计，实现时逐节补上做法与测试。标了「补充」的是维护者没有提、我加的设定，不要的直接删。

## 1. 流程

```
封印杭 ×9 ──每断一根──► 色散
   │ 最后一根
   ▼
觉醒（约 21 秒）：红光蔓延 → 震 → 震 → 杀生石爆炸 + 黑白闪 → 过场：跪坐 → 起身 → 凝出流火 → 看向玩家 → 标题
   ▼
第一阶段：人形 + 流火，拼刀。每掉六分之一血一记投技（处决特写）
   │ 第一条血清空
   ▼
变身（约 7 秒）：单膝跪地 → 拍地 → 光柱 → 九尾狐叼着流火站起
   ▼
第二阶段：狐形，冲撞、大跳、尾扫，不能弹反；八分之一血以下加狐火飞弹、拉开距离
   │ 第二条血清空
   ▼
击败：无力趴下 → 化作花瓣消散 → 红光退去 → 奖励（流火；白梅的加入方式待定，见第 8 节）
```

## 2. 封印杭与觉醒

封印杭现有的行为不变（断一根清点剩几道、断裂声、狐火）。新加：

| 时刻 | 发生什么 | 后期与表现 |
|---|---|---|
| 每断一根 | 在场玩家（封印之间里或 64 格内）画面短暂色散 | 新全屏通道：从画面中心向外的红蓝分离，约 0.4 秒衰减；跟原版「屏幕效果」滑条缩放 |
| 最后一根，0 秒 | 现有的低吼与狐火 | 强一档的色散；**所有光源的光晕变成不祥的红色**，从杀生石向外一圈圈蔓延过去（补充：蔓延），直到战斗结束 |
| 3.5 秒（低吼放完） | 第一次震动，岩顶落灰，杀生石裂缝透出红光 | 镜头抖动（复用曦誓的抖动），低沉的隆隆声 |
| 6.5 秒 | 第二次震动，更重 | 同上，更强 |
| 8.5 秒 | 杀生石炸开：爆炸声、碎石、樱花瓣 | 黑白闪（默认四阶段，光源是杀生石）。闪光那一刻硬切进过场 |

**红色光晕**由两层组成，光影包下也成立：

1. 光源上的红色光晕：封印之间里所有发光方块（狐火灯笼、高石灯笼、倒挂町屋的灯、发光地衣）由 `GlowBloom` 加一团柔和的红色光晕，轻微闪烁。
2. 调色：封印之间里画面的高光（灯本身、被灯照亮的地面）色相往暗红转，幽蓝的狐火变成红色。只在镜头位于封印之间附近时生效。

**过场**（每个在场玩家各播一份，`CameraShots`，带遮幅与电影蒙版；过场期间玩家不受伤，白梅不动）：

| 时刻 | 镜头 | 白梅 |
|---|---|---|
| 8.5 秒 | 黑白闪下硬切：高处远景看杀生石，烟尘和花瓣落下 | 杀生石、石台、九个底座被拆掉（`SanctuaryVaultPiece.Removable` 三组），白梅出现在原处，日式跪坐、低着头 |
| 10.5 秒 | 平视的中景，慢慢推近 | 跪坐 |
| 13 秒 | 低机位仰拍 | 缓慢起身（3 秒），起身途中右手凝出流火（附属的凝聚效果，从柄往尖长出，樱花瓣） |
| 16 秒 | 面部特写 | 站定，转头看向这个玩家 |
| 17.5 秒 | 镜头从她面前拉回到玩家的位置，停在玩家肩后看着她 | 站姿，持刀 |
| 18 秒 | 画面正中出现大字标题「九尾妖狐　白梅」，下面一行小字 しらうめ | |
| 20.5 秒 | 标题淡出，镜头回到玩家眼睛，遮幅收起 | |
| 21.5 秒 | Boss 战开始：血条出现 | 开始行动 |

爆炸的同时，离杀生石太近的玩家（封印杭那一圈以内，半径 15）挪到底座以外的圆台上（半径 17–20，同一方位，脸朝圆心）；挪的那一刻画面正白，看不出来。圆台上玩家放的方块一起烧掉（第 4.7 节）。

## 3. 血条与阶段

- 原版 Boss 血条，名字「九尾妖狐 白梅」。第一阶段粉色、**六格刻度**（每格正好是一次投技的位置），第二阶段红色、无刻度。变身时血条从空慢慢涨满（补充）。
- 两条血都在服务端配置 `[shiraume]` 里；按觉醒时在场的玩家数加血（每多一人 +50%，最多 ×3）。
- 第一阶段不会死：血掉到 0 时停在 1 并开始变身。

## 4. 第一阶段：人形 + 流火

### 4.1 节奏

- **起手 → 挥出**：每一招都有明显的起手（举刀、拧身、沉腰），然后一下挥出。流火是没有重量的魔力刀，挥出本身极快，所以节奏全靠起手的长短和挥完的停顿。
- **红光**：即将挥出时（起手的最后一刻）双眼闪一次红光，带一声短促的「铮」（补充：声音）。连续招式只在第一刀的起手闪一次，后面几刀不闪。投技的瞄准结束时也闪。
- **快慢刀**：一字斩举到顶后随机停 0.5–1.5 秒再斩下。其他重招也可以带一点随机的停顿（补充：只给一字斩和逆袈裟加，其余固定）。

### 4.2 招式

数值都在招式文件 `combat/movesets/shiraume.json`（[npc-combat 的约定](COMBAT_SKELETON.md)：数值在招式文件、逻辑在共用代码），下表是第一版。距离按格，Boss 约是玩家的两倍高，刀也按两倍挂，所以够得远。

**独立招式**（被弹反时播自己的被弹反动作，失衡涨得多）：

| 招式 | 起手 | 挥出 | 伤害 | 说明 |
|---|---|---|---|---|
| 袈裟斩 | 刀举到右肩上 0.6 秒 | 右上斩到左下 | 8 | 最常用 |
| 逆袈裟 | 刀压到左下 0.5 秒（+0–0.4 随机） | 左下撩到右上 | 8 | |
| 横一文字 | 拧身、刀拉到右后 0.7 秒 | 从右往左大幅横扫，身前 180° | 9 | 范围最宽 |
| 突き | 收刀到腰侧 0.55 秒 | 往前冲 4 格直刺，30° | 10 | 打远的人 |
| 一字斩 | 双手举刀过头 0.6 秒 + 随机 0.5–1.5 秒 | 竖直斩下，前方一条 | 14 | 快慢刀 |

**连续招式**（被弹反不停，直接接下一刀；只有第一刀起手闪红光）：

| 招式 | 内容 |
|---|---|
| 燕返（维护者给的例子） | 离得远时先冲到锁定的玩家面前 → 右上举刀，劈向左下 → 停顿 → 左上举刀，劈向右下 → 停顿 → 双手举刀，一字斩（随机 0.5–1.5 秒） |
| 三连 | 袈裟 → 逆袈裟 → 横一文字，节奏快，最后接后跳 |
| 突き・斬り上げ | 直刺，紧接从下往上撩起 |

例子里「若没有被弹反，则短暂停顿后……」我这样理解：没被弹反（砍中、被盾挡下或挥空）时，刀挥到底停一下再起下一刀；被弹反时刀被弹回来，借这股劲直接起下一刀，没有那一下停顿。两种情况都会继续下去。

**移动**：中距离（4–8 格）持刀绕着目标侧移，像剑客对峙；远了（8 格以上）用冲刺（縮地，一瞬间贴到面前）接一套连招；被围时后跳拉开。

### 4.3 命中与防御

- 白梅的刀砍中时：先按原版近战的方式走一次格挡判定。盾牌、打刀、流火、黑钢长剑的格挡都能挡下；带弹刀的武器在窗口内是弹反（打刀 0.3 秒、流火 0.5 秒）。
- 没挡下：造成 Logos **奥秘**伤害（走 `Effects.damage`，Logos 的元素抗性照常算），但**不放 Logos 的命中特效**（流火玩家版已经有同样的开关）。她的刀和牙一直是奥秘；狐火飞弹和烧方块是她淡粉的狐火（见 `docs/FOXFIRE.md`）。
- 和玩家用的流火不同：玩家的流火「无形之刃」穿盾，白梅的刀不穿。

### 4.4 失衡

隐藏的数值，不显示。

| 来源 | 失衡 |
|---|---|
| 独立招式被弹反 | +30 |
| 连续招式其中一刀被弹反 | +18 |
| 受到伤害 | +伤害 × 0.35 |
| 2.5 秒没有新增 | 每秒 −8 |

到 100：白梅蹲下喘息 3.5 秒（这段时间受到的伤害 ×1.3，补充），站起来时快速挥出一刀（照样闪红光），然后后跳，失衡归零，继续循环。

### 4.5 投技（每掉六分之一血）

第一阶段血条每过一格刻度（5/6、4/6、3/6、2/6、1/6）放一次，一次大伤害跨过几格也只放一次：

1. 停下，沉腰把刀收到身侧，对准锁定的玩家蓄力 1.2 秒，流火的狐火烧旺。最后一刻双眼闪红光。
2. 沿直线冲过去（约 0.5 秒冲 16 格，方向在冲出时锁定），冲到头从下往上一记斩り上げ。
3. 被冲到的第一个玩家被挑飞，进入处决特写（`ExecutionShots`，12 刀）。别的玩家看到他被抛起、挨刀、拍到地上。
4. 重击那一刻结算：不看护甲（也不看保护附魔和抗性提升）。血量在一半以上 → 只剩 1 点血（吸收心一起算进去）；一半以下 → 直接击杀。不死图腾照常能挡（伤害不绕过无敌）。

投技不能格挡、不能弹反（补充：这是抓取技，靠看准冲刺方向往旁边闪）。

### 4.6 弹射物

- 每刻检查朝她飞来的弹射物（原版和其他模组继承原版 `Projectile` 的都算：箭、三叉戟、火球、药水、雪球，枪械模组的子弹、火箭弹）。她没在出刀、僵直、喘息时，一个小幅度的挥刀把它弹开：一半弹回给射它的人（`Projectile.deflect`，方向对准射手），另一半拨到旁边。
- 不是实体的伤害（瞬发的枪、其他模组的远程法术）看伤害来源：间接伤害或带 `is_projectile` 标签的，她空着且正面对着时挡掉，冒火花。
- 爆炸伤害减半（漏网的火箭弹）。
- 远处一直放冷箭的人：她会冲刺过去（第 4.2 节的縮地）。

### 4.7 防卡位

- **玩家放的方块**：封印之间里玩家放下的方块都记下来（存档）。白梅被挡住 2 秒、够不到目标 3 秒，或者身边 3 格内有玩家放的方块时，她一挥手，这些方块被她淡粉的狐火烧掉（附属的方块消散，不掉落）。觉醒和变身时圆台上玩家放的方块全部烧掉。圆台上玩家倒的水和岩浆也算。
- **实在卡住**：还是走不动时，化作花瓣消失，在目标附近的空地重新出现（补充）。
- **离场**：她不出封印之间。目标跑出去就回到圆台中间。
- **重置**：封印之间里 30 秒没有活着的玩家：人形跪坐在中央（狐形趴下），血慢慢回满，血条收起；有玩家进来就起身继续，阶段不变。红光一直在，直到她被击败。

## 5. 变身

第一条血清空：

| 时刻 | 发生什么 | 表现 |
|---|---|---|
| 0 | 单膝跪地，刀拄在地上 | 过场开始（遮幅、蒙版），中景 |
| 1.5 秒 | 一掌拍在地上 | 冲击波推开周围的玩家（不伤害），镜头抖动，色散 |
| 1.7 秒 | 地面迸出光柱把她整个罩住；原来九根封印杭的位置同时各冲起一道细光柱（补充：九尾九道） | 黑白闪（离上一次远远超过 0.7 秒） |
| 2–5 秒 | 光柱里人形换成狐形 | 泛光的光柱 |
| 5 秒 | 光柱散去，九尾狐叼着流火站起，九条尾巴张开，一声长啸 | 低机位仰拍 |
| 6 秒 | 镜头回到玩家 | 血条换成红色、从空涨满 |
| 7 秒 | 第二阶段开始 | |

## 6. 第二阶段：九尾狐

流火叼在嘴里。出招前双眼照样闪红光。这一阶段的攻击**都不能弹反**，盾牌能挡（带弹刀的武器在窗口内也只算挡下，她不会僵直）。

| 招式 | 起手 | 内容 | 伤害 |
|---|---|---|---|
| 猛冲 | 压低身子、后爪刨地 0.6 秒 | 直线冲 12 格，撞飞路上的玩家；撞上巨柱会晕一下（补充） | 12 |
| 大跳 | 伏低 0.7 秒 | 高高跃起，落到目标的位置（按落地时的预判），落点震地，4 格内伤害并掀起；落地前 0.6 秒地上先亮一圈红光标出落点（补充） | 14 |
| 尾扫 | 九尾收拢 0.6 秒 | 转身用九条尾巴横扫身后 270°，半径 6 | 10 |
| 咬击·甩刀 | 头往后仰 | 扑咬，接着甩头用叼着的流火横切 | 12 + 8 |
| 前爪 | 抬爪 | 左右两爪 | 8 ×2 |
| 咆哮 | — | 被围时把人震开，不伤害 | 0 |
| 后跃 | — | 拉开距离 | — |

- **八分之一血以下**：每招之后吐出 3–5 颗狐火飞弹，慢慢追向玩家，走位能躲开（每颗 5，她淡粉的狐火：打中炸开一团淡粉的火，之后狐火缠身，见 `docs/FOXFIRE.md`；盾能挡）；移动和起手都快三成，更喜欢后跃拉开再用大跳和狐火。
- 失衡：这一阶段只从受伤累积，满了踉跄翻倒 2 秒（补充）。没有投技。

## 7. 击败

第二条血清空：狐身无力地趴下（2 秒），然后从尾尖到头化作樱花瓣消散（附属的消散，花瓣，约 4 秒）。叼着的流火一起散去。血条消失，红光在 3 秒里退回原来的颜色。

奖励：每个参战的玩家（打过她，或她倒下时在封印之间里）各得一把流火，落在场地中央，只有本人能捡。一处封印之间只能打一次。

## 8. 白梅怎么加入（待定）

直接掉落一个召唤物确实说不过去。几个方案：

**A. 花瓣聚形，献刀赠形代（推荐）**：狐身散成花瓣后，花瓣没有飘走，而是在中央聚回来，凝成少女形态的白梅（凝聚效果），跪坐着、喘着气。短过场：她抬头看玩家，说几句话（字幕）——输了；按狐狸的规矩，输了要跟着赢的人；双手把流火递过来（流火就是她的刀，这样玩家拿到流火也顺理成章）；再从地上捡起一张断掉的封印御札，折成一个纸人形代，吹一口气写上名字递给玩家：「想见我的时候，就叫我的名字」。然后化作花瓣飞进形代里。

- 封印她的纸，成了带她走的形代，从「被封」到「立约」，和她的来历（被封在杀生石里）接得上。杀生石、玉藻前的传说里，九尾狐的灵也是被超度后立誓不再作恶。
- 多人时每个参战的人各拿一张形代，召唤出来的是各自的白梅（九尾，一尾一张，补充：最多九张）。
- 她在战斗中倒下就回到形代里，过一阵才能再叫；也可以接上神社石龛的 `active`（那里本来就留给神狐重生用）：形代放在激活的石龛里能更快恢复。

**B. 去神社请出来**：战后只得到流火和一张空白、印着梅花的形代。拿到地上神社的石龛前供奉，神狐们做一场仪式，白梅才现身加入。多一步任务，和聚落的神社接上，但第一次打完 Boss 拿不到同伴，可能有落差。

**C. 战后留在原地**：少女形态的白梅留在封印之间，玩家去找她说话（右键），她才交出流火和形代。可以再加一段对话。缺点是要做 NPC 对话。

少女形态的模型还没处理，同伴的召唤、跟随、战斗都另做。这一节定下来之前，第一版击败后只发流火。

光敏：黑白闪仍受原版「隐藏闪电的闪烁」和 0.7 秒间隔限制；色散和抖动跟「屏幕效果」滑条，滑条为 0 时不抖不散。

## 10. 多人

- 锁定目标：最近一段时间对她伤害最多的人，偏向当前目标；目标够不到、出了场或被处决后换人。
- 过场、色散、红光对封印之间里所有玩家生效；后来进场的人直接看到战斗，没有过场。
- 血量按觉醒时在场的人数加。

## 11. 实现

封印杭（`SealStakeBlock`）每断一根调 `ShiraumeFight.sealBroken`。`SanctuaryVaultPiece` 加了 `arenaBox()`。

### 11.2 模型与动作

- 人形的招式由 `tools/shiraume_moves.py` 编排，用 `combat_author` 烘焙到 Boss 自己的骨架（刀按 2.4 倍挂），写进模型目录的 `Animation/shiraume_moves.animation.json`；下摆八片跟着大腿算。预览：`python tools/shiraume_moves.py <Minecraft MOD 目录> --preview <输出目录> [动作名…]`。
- 狐形的动作在模型目录 `sealed_nine_tailed_fox_beast/tools/beast_moves.py`（不改工程，只读骨架），四条腿用平面两节反向运动学踩地。
- `tools/shiraume_assets.py` 把两种形态的模型、贴图和动作并进附属：人形取 `source/` 里编号最大的那一版（维护者最新保存的）。动作名：人形招式 `ryuka_*`，狐形招式 `fox_*`，模型自带待机里的尾巴拆成常驻叠加层 `pre_parallel0`。
- 招式的时刻改了两边要一起改：动作工具和 `combat/movesets/*.json`。

### 11.4 测试

```text
./gradlew runClient -PlogosJar=... -PldTest=shiraume_duel -PldTestHeadless -PldTestWindow=1280x720
./gradlew runClient -PlogosJar=... -PldTest=shiraume_awakening -PldTestHeadless -PldTestWindow=1280x720
./gradlew runClient -PlogosJar=... -PldTest=group:weapon_trails_ryuka -PldTestHeadless -PldTestWindow=1280x720
```

- `shiraume_duel`：白瓷台上召出人形，玩家站着挨打：出招、双眼红光、砍中；逼出投技，处决后只剩 1 点血，光环烧掉一枚；变身（光柱、狐形登场）；狐形出招；狂暴放狐火；击倒、化作花瓣、流火落下。
- `shiraume_trails`（与玩家流火的 `ryuka_trails` 同组 `weapon_trails_ryuka`）：停掉 AI 逐一放人形各招与狐形的 `bite_slash`，挥到底时截图，检查留下流火的刀光、起手时没有、挥完散尽。
- `shiraume_awakening`：真实的封印之间（同 `fox_vault_views` 强制每处聚落都有地下场地），拆掉九根封印杭：每根色散、红光、两次震动、爆炸、太近的玩家被挪到底座外、杀生石与底座拆干净、跪坐、起身凝刀、标题、开打。

都只在不开光影、不装 Sodium 的无窗口客户端里跑过。光影包下的红光、色散、红晕没有测，没有真人操作的弹反手感也要进游戏试。
